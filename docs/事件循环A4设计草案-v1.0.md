## §2 缺口分析：从「快照 poll」到「事件循环 epoll + 域名解析」差什么

1. **epoll fd 空间缺失**（#11）：epoll_create1 返回什么 fd、interest 注册在哪、close 谁收口——全无宿主。POSIX 消费面（事件循环框架/mio 族）要的是 fd 号 + ctl 注册 + wait 阻塞收割三件。
2. **epoll_wait 阻塞语义缺失**（#4/#7/#8）：快照源在册（sock_poll_one）但无 timeout 三档循环宿主；poll 自身的 timeout 忽略档同属此账——但 poll 是 std 启动判死先例面（sanitize_standard_fds），触碰它回归风险 > 收益（§3.2 裁定）。
3. **DNS 断链**（#5/#6/#10）：非字面量 node 恒 EAI_NONAME；协议/服务半边全在册——缺的只是 libc 侧接线（RPC + 错码映射 + EAI_AGAIN 立册）。
4. **epoll_event ABI 面未钉板**：aarch64 musl 自然对齐（events@0 u32 + data@8 u64 = 16B）vs x86 packed 异序——C-2a Stat 案同族「同尺寸不同字段序 = 最阴的静默错」，对源 libc crate 目标分支 offset_of 钉板（A3-1 addrinfo 立法同款）。
5. **std::net 对拍裁留件**（A3-3 kill criteria 执法记录）：撞 getsockopt/fcntl 启动路径假设族风险未 probe——本卡 probe 先行定范围盒，撞墙即裁留如实记录。

## §3 设计

### 3.1 fd 模型：EpollTable 独立段（23..=26）

- **新表 `EpollTable`（berry-fsclient，host 可测纯函数）**：4 槽（`EPOLL_FD_MAX=4`——v1 消费面单进程事件循环 1-2 实例，容量自定值）；fd = `EPOLL_FD_BASE(23) + 槽号`；表项 `{items: [Option<(fd: i32, events: u32, data: u64)>; EPOLL_ITEMS_MAX=8], live: usize}`（interest 数组值语义——fd 号 + 掩码 + data 透传三件）。
- **号段免疫**：段界 const 断言续钉 `SOCK_FD_BASE + SOCK_FD_MAX <= EPOLL_FD_BASE`（SocketTable 同法编译期执法——两表独立演化结构性免疫）。
- **归属链单点**：epoll fd 只进 close（释槽 + interest 全清）/fcntl（EINVAL——无旗面）/read/write（EINVAL——POSIX epoll fd 不可读写近似档）三链尾查询；socket 分派链零改动（表恒空时零漂移按构造）。

### 3.2 桩映射（POSIX → 实现）

| POSIX 调用 | 映射 | 备注 |
|----|------|------|
| `epoll_create1(flags)` | EpollTable alloc → fd | flags 只认 0（EPOLL_CLOEXEC v1 无 exec 面 → EINVAL 诚实拒）；槽满 → EMFILE |
| `epoll_create(size)` | 无桩缺席维持 | 现探现补纪律——消费者链接探针冒出再补（size≤0 → EINVAL、值忽略，musl 形态） |
| `epoll_ctl(epfd, ADD, fd, ev)` | interest 注册 | fd 域执法：socket 段（15..=22）白名单——console/fs fd → EINVAL 诚实拒 v1（不静默收下假就绪）；重复 ADD → EEXIST；interest 满（8）→ ENOSPC；掩码白名单 = EPOLLIN\|EPOLLOUT\|EPOLLERR\|EPOLLHUP，**其余位（EPOLLET 等）→ EINVAL**（ET v1 不做——诚实拒优于收位不执法） |
| `epoll_ctl(epfd, MOD/DEL, fd, ev)` | 换掩码 / 注销 | 不在册 → ENOENT；DEL 的 event 指针 POSIX 忽略（v1 同） |
| `epoll_wait(epfd, evs, maxevents, timeout)` | 快照 + 节拍循环 | maxevents≤0 → EINVAL；**timeout 三档**：0 = 纯快照立即返；-1 = 无帽节拍循环；>0 = ms→ns deadline 到帽返 0；LT 语义 = 每轮快照全量复报（berry-poll LT 同款免费）；快照源 = 逐 interest 项 `sock_poll_one`（EPOLL↔POLL 位数值同源 const 对拍——零换算）；命中项 events 掩码 + data 透传回拷，返回就绪计数；interest 中 fd 已 close（socket 表不在册）→ 该项报 EPOLLERR\|EPOLLHUP（POSIX 近似——fd 号复用风险 v1 文档化） |
| `close(epfd)` | 释槽 + interest 全清 | 归属链尾 epoll 段查询 |
| `poll` timeout 档 | **默认不动**（保持忽略档） | poll 是 std sanitize_standard_fds 判死先例面（A3-0 #3 立法点）——epoll_wait 阻塞档落地后该注释账即语义闭环（事件循环刀有了专用宿主）；poll 阻塞化收益低回归高，挂 v2（std 实传 timeout 值 probe 面留档） |

**阻塞档宿主** = `sleep_tick` 节拍循环（net.rs:197 同款）：快照 → 命中即返 → 未命中且未到帽 → sleep_tick(1s) → 重快照。唤醒粒度 1s（v1 无跨线程 ctl 唤醒面——单线程假设文档化；bsh 自验只打有限帽档，-1 档语义正确仅粒度粗）。

### 3.3 epoll_event ABI 钉板（C-2a Stat 法）

`#[repr(C)]` + `const _: () = assert!(offset_of!…)` 全字段编译期钉板：events@0 u32 / data@8 u64 / sizeof=16（**对源 = libc crate aarch64 目标分支实测**——x86 packed（12B）与 aarch64 自然对齐（16B）异序反例照 A3-1 addrinfo 注记，A4-1 首查项对源确认后再钉，不凭记忆）。`epoll_data_t` union v1 只用 u64 直传（ptr/fd/u32 形态消费方自行重释——单一 8B 透传槽）。

### 3.4 getaddrinfo DNS 档接线

- **快路不变**：parse_ipv4 命中 → sockaddr 直构（零 RPC——现状零漂移按构造）。
- **DNS 慢路**：miss 且 node 非空 → 名字合法性预检（字符集 [A-Za-z0-9.-] 且 len ≤ NAME_MAX=64——超长/非法 → EAI_NONAME 纯本地拒，不发包）→ `OP_DNS_QUERY` RPC（netd_rpc 底座 + CAP_FAST 10s 帽）→ 错码映射：ST_OK → addr 构 addrinfo（复用 A3-1 malloc 链——48B ai + 16B sa 同形）；ST_TIMEOUT → **EAI_AGAIN**（-3 立册 + gai_strerror 文案）；ST_BAD → EAI_NONAME；RPC 链断 / netd_h()==0 → EAI_NONAME（**拓扑降级同 evs/skt 静默门**——EFI/无盘路行为与现状零漂移按构造）。
- **首跑定谳项**：vnet DNS 应答域实测（ST_TIMEOUT 真可达性——SLIRP DNS 在线恒 OK，timeout 相可能仅链断/慢形态可达）；错码映射表按 netdproto 应答域**全表**写（可达性不赌——A3-3 B4「映射臂先宣后现」教训：域内码全部接线，不按「预期跑不到」裁剪）。

### 3.5 std::net 对拍（A3-3 裁留件回收，加分面非门）

- **probe 先行定范围盒**：audit 构建（strip=false）+ 反汇编 `std::net::TcpStream::connect` 消费面取数点（getsockopt/fcntl 启动路径假设族——C-2a「取证法 = 反汇编消费者取数点」同款）；`TcpStream::connect("localhost:18081")` 域名面恰吃新 DNS 档（SLIRP DNS → 127.0.0.1 离线确定）。
- **kill criteria 原文执法**：撞深水面（桩不可谎报/std 判死类）→ 裁留如实记录；自写 client + bsh 标记是底线验收（A3-3 同款不依赖 std 面）。

### 3.6 验收线（A4 整卡收口）

- **guest 自验**：bsh `epl_selftest`（⓪create1+槽满面 ①ctl ADD/MOD/DEL 拒面全表（EEXIST/ENOENT/EINVAL 域执法/ENOSPC 帽）②wait(timeout=0) 快照 LT 复报（两次连收同集）③wait 短帽（timeout>0）到点返 0 ④非 socket fd ADD 拒 ⑤getaddrinfo "localhost" → 127.0.0.1 对拍 ⑥非法名/超长名本地拒 ⑦close 释槽复用）→ `EPL ok` 标记（rootfs 相 40→41；**整段 netd 依赖**（epoll 快照对 socket 项发 OP_TCP_POLL + DNS 步）——照 EVS/SKT 全段同形：netd_h()==0 静默跳过（EFI 路 canon 不加 EPL = 拓扑真值）、排 fat 族前）。
- **host**：EpollTable 纯函数（alloc/释槽/ctl 三 op 拒面/段边界/容量帽）+ epoll_event 布局钉板 + EPOLL↔POLL 位 const 对拍 + DNS 错码映射表——fsclient/libc host 测扩容全绿。
- **零漂移硬线**：五相 smoke 既有全标记绿（rootfs 40 相含 POLL/EVS/SKT + RX/FAT/B4 66 相 + 金丝雀严格递增）+ smoke-image canon 24 零漂移。

## §5 风险与 kill criteria

- **kill（卡在册原文）**：std::net 对拍撞 std 深水面（getsockopt/fcntl 启动路径假设族——桩不可谎报/std 判死类）→ probe 定范围盒后按 kill criteria 重定范围留档，不硬扛；自写 client + bsh `EPL ok` 标记是底线验收（不依赖 std 面）。
- **poll timeout 回归面**：sanitize_standard_fds poll 判死先例——**默认不碰 poll**（§3.2 裁定：epoll_wait 专用宿主闭环该账，poll 阻塞化挂 v2）；若 A4-3 probe 顺带实测 std 实传 timeout 值则留档备查。
- **epoll_wait -1 无帽档**：v1 无跨线程 ctl 唤醒——1s 节拍轮询语义正确但唤醒粒度粗；空表 -1 = 结构性长睡（bsh 自验不触此档，文档化取舍——事件循环消费方 v1 按有限帽用）。
- **号段膨胀**：EPOLL_FD_BASE=23 段界 const 断言续钉（SOCK_FD_BASE+SOCK_FD_MAX ≤ EPOLL_FD_BASE 编译期执法）；fd 号三段（fs/console-alias/socket/epoll）全免疫。
- **epoll_event 布局**：aarch64 自然对齐 vs x86 packed 异序——对源 libc crate 目标分支 offset_of 钉板（A3-1 addrinfo 立法同族，A4-1 首查项）。
- **不做什么**：不做 ET（EPOLLET 白名单外 EINVAL）；不做 epoll_pwait/pwait2（信号面 v1 无）；不做 eventfd/inotify（非本卡，合册维持 ENOSYS）；不做 DNS 缓存/AAAA/IPv6（A 记录单条）；不做异步 DNS（阻塞 RPC 帽内）；不做 console/fs fd 入 epoll（socket 段白名单）；不碰 abi.toml（零新 syscall——全 libc 桩面）。
