## 3. OpenHarmony 默认壁纸（Apache-2.0）

- 入库：`user/bins/berry-launcher/ohwallpaper/img_wallpaper_default.jpg`
- 源仓 / commit：`openharmony/applications_launcher` @ `f75dfb6bf7276e942793b75e7a9081bbcd015843`
- 源路径：`product/phone/src/main/ets/common/pics/img_wallpaper_default.jpg`
- SHA-256：`20c7fa0a817edb0d630bf356714ee2cb22dcec0f57cb4a6879e2bc2c40b164b5`
- 修改：未修改源 JPEG。`tools/genohwallpaper.py` 按 `ImageSize.Cover`
  的 1080×1920 中央裁切预采样为 135×240 静态源图。

修改与生成：

- `tools/genohicons.py`：Settings/Files/Photos/Camera/Contacts/MMS 直接取
  上表官方 app 图标，Resize 到 108×108 并做 6-bit/channel 量化；Browser 仍用
  `icon_mask.png` + official glyph + 本仓色底。桌面按 162px 目标几何经
  `ImageSrc::ScaledArgb` 1.5×采样（源小图保 1MiB 进程堆帽）。
- 渐变色底与 app manifest/entry 为 BerryOS 自有内容；未复制 OpenHarmony 业务代码。
- 原始资产未修改；生成物在各 `user/bins/appstub/apps/<ID>/icons/icon.png`。
- `tools/genohstatus.py`：signal/wifi SVG 光栅化为 3x 状态图标；battery 按
  applications_systemui `batteryPic` 官方几何复刻；dock 按 applications_launcher
  `LayoutViewModel.calculateDock` + PhoneSmartDock 官方几何复刻。
- dock 源条 668×156（radius44、4 位、108px 图标），运行期 1.5× 采样到
  1002×234；背板把官方 `#85FAFAFA` 与默认壁纸逐像素宿主侧合成（v1 无
  alpha blend），分段像素做 5-bit/channel 量化压 RLE。
- 状态图标按 systemui `opacity=0.7` 与默认壁纸在固定布局位置预合成；
  生成分辨率与几何见 `tools/genohstatus.py`。
- 状态/dock 原始资产在 `user/bins/berry-launcher/ohstatus/`；生成物
  `user/bins/berry-launcher/src/status_icons.rs`。
