# iOS 视觉与流体交互复刻标准（v1.0）

Type: standard
Status: current
Updated: 2026-11-18
Version: 1.0.0

一句话说明：本标准以 Apple iOS 18 与 iPadOS 18 Human Interface Guidelines（HIG）为唯一视觉与交互北极星，锁死 BerryOS 全栈图形材质、曲率几何、色彩与排印字阶、组件形态、灵动岛与桌面壳层、流体物理公式及模拟器外框的一比一像素级复刻契约。

## 背景

前期界面在安卓三大金刚、Material `56dp` 顶栏与多平台共性控件之间摇摆拼凑，叠加正圆锯齿、纯色硬垫块与线性死板动画，导致成品观感粗糙割裂（诊断见 [GUI 与 SDK 及启动模拟器全栈深研](../.agents/research/2026-11-18-GUI与SDK及启动模拟器全栈深研.md)，裁决理由见 [全面复刻 iOS 18 视觉与流体交互范式裁决](../.agents/notes/proposed/2026-11-18-全面复刻iOS18视觉与流体交互范式裁决.md)）。本标准作为 [GUI 合成与 SDK 终态标准](GUI合成与SDK终态标准-v2.0.md) 的最高视觉与交互子宪法，彻底终结散装审美与跨生态缝合。

## 适用范围

- **适用对象**：`berry-gfx` v2 光栅与着色核、`berry-text` 排版引擎、`berry-ui` v2 组件库与主题系统、`berry-compositor` 合成器、`berry-shell` 系统桌面壳层、`imed` 输入法、`tools/berry` 宿主模拟器，以及全部官方与第三方 `.bap` 应用。
- **形态覆盖**：竖屏紧凑态（`< 600pt`，一比一复刻 iPhone iOS 18 界面）与宽屏扩展态（`>= 600pt`，自动切换复刻 iPadOS 18 浮动 Dock、`SplitView` 多栏与 `Stage Manager` 台前调度多窗）。逻辑点单位 `pt` 与系统虚拟像素 `vp` 严格 `1:1` 等价（`1pt = 1vp`）。

## 契约

### 一、几何曲率与同心圆角铁律（Continuous Squircle & Concentricity）

1. **全栈唯一圆角曲线（连续曲率超椭圆）**：
   - 全系统严禁使用曲率突变的传统正圆弧（$x^2 + y^2 \le r^2$）；一切圆角容器、图标、卡片、弹窗与窗口裁剪遮罩必须采用 $G^2$ 曲率连续超椭圆（Continuous Squircle，隐式场 $(|x|/a)^n + (|y|/b)^n \le 1$，桌面图标取 $n = 4.5$、UI 容器取 $n = 4.0$，配合三次贝塞尔平滑肩部切入段与 1px SDF 256 级覆盖率抗锯齿）。
2. **标准圆角半径阶梯（严禁组件私造非常规半径）**：
   - **屏幕物理内框遮罩**：iPhone 竖屏态 `55pt`；iPadOS 宽屏态 `18pt`。
   - **灵动岛实时胶囊（Dynamic Island）**：静默紧凑态 `126×37pt`（胶囊半径 `18.5pt`）；实时活动展开卡片态宽 `361pt`、高 `84..190pt`、超椭圆半径 `42pt`。
   - **底部模态抽屉（Sheet）与多任务卡片**：`38pt`（贴近底边时与 `55pt` 屏幕外框保持 `17pt` 视觉等距同心）。
   - **主屏悬浮毛玻璃 Dock**：外框半径 `34pt`（左右外边距 `12pt`、底边距 `12pt`、内边距 `12pt`）。
   - **应用图标（App Icon）**：iPhone 态 `60×60pt`、iPad 态 `68×68pt`，超椭圆圆角半径严格等于边长的 `22.37%`（即 `13.42pt` 与 `15.21pt`），禁止应用包自带圆角镂空透明边，统一提交满幅正方形原图由系统合成器与桌面按超椭圆母版实时裁切。
   - **控制中心与通知浮层**：控制中心 `2×2` 模块卡 `22pt`、`1×1` 圆形磁贴 `R = 32pt`（直径 `64pt`）、亮度/音量竖向滑柱 `R = 20pt`；通知卡片、Spotlight 搜索框与长按 `Context Menu` 统一 `20pt`；`Alert` 模态框 `14pt`（定宽 `270pt`）；`InsetGroupedList` 分组卡片与页面内搜索栏 `10pt`。
3. **同心圆角律（Concentricity Law）**：当外层圆角容器（半径 $R_{\text{outer}}$）内嵌内边距为 $p$ 的子圆角块时，子块圆角半径必须满足 $R_{\text{inner}} = \max(R_{\text{outer}} - p, 4\text{pt})$，严禁内外同半径导致四角视觉拥挤畸变。

### 二、四阶增艳毛玻璃与 iOS 18 语义色彩体系

1. **四阶增艳毛玻璃管线（Vibrancy Material Stack）**：严禁把单纯高斯模糊或半透明死灰色块当作毛玻璃；所有材质层必须按序执行四步光学合成：
   1. **降采样 Dual-Kawase 模糊**：对正下方已合成背景执行等效高斯标准差 $\sigma$ 的平滑模糊；
   2. **饱和度矩阵提拉（Saturation Boost）**：在保持感知亮度前提下对色度通道乘以增益系数 $S$（默认 `1.8x`），使壁纸与底层色彩透过磨砂层依然通透鲜活；
   3. **明暗语义纱幕（Tint Veil）**：按 Light / Dark 模式执行预乘 `SrcOver` 叠色；
   4. **微晶高光内描边与前景 Vibrancy 透色**：沿超椭圆内缘绘制 `0.5pt` 高光细边（Light `rgba(255,255,255,0.45)` / Dark `rgba(255,255,255,0.14)`）；浮层上的次级标签与分割线启用 `PlusDarker`（Light）/ `PlusLighter`（Dark）Vibrancy 混合，实时吸收背景冷暖色调。
2. **五档系统标准材质锁定值**：

| 材质档位 | 适用部件 | 模糊 $\sigma$ | 饱和度增益 $S$ | Light 纱幕 RGBA | Dark 纱幕 RGBA |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `UltraThinMaterial` | 侧边音量浮条、轻量浮签 | `14pt` | `1.8x` | `rgba(255,255,255,0.42)` | `rgba(28,28,30,0.48)` |
| `ThinMaterial` | 锁屏/横幅通知卡、桌面小组件 | `20pt` | `1.8x` | `rgba(255,255,255,0.60)` | `rgba(30,30,32,0.62)` |
| `RegularMaterial` | Dock、控制中心卡片、Alert、ContextMenu | `28pt` | `1.9x` | `rgba(248,248,250,0.74)` | `rgba(36,36,38,0.74)` |
| `ThickMaterial` | Spotlight 面板、系统软键盘底座 | `36pt` | `1.6x` | `rgba(242,242,247,0.86)` | `rgba(28,28,30,0.88)` |
| `ChromeMaterial` | 折叠态顶部 `NavigationBar`、底部 `TabBar` | `24pt` | `1.8x` | `rgba(249,249,249,0.78)` | `rgba(22,22,24,0.80)` |

3. **iOS 18 语义调色盘与深浅色海拔铁律**：
   - **分组背景色阶**：`systemBackground`（纯内容底 Light `#FFFFFF` / Dark `#000000`）；`systemGroupedBackground`（列表与设置画布大底 Light `#F2F2F7` / Dark `#000000`）；`secondarySystemGroupedBackground`（分组白色/深灰卡片面 Light `#FFFFFF` / Dark `#1C1C1E`）；`tertiarySystemGroupedBackground`（嵌套分组面 Light `#F2F2F7` / Dark `#2C2C2E`）。
   - **深浅色阴影与海拔纪律**：Light 模式下分组列表卡片零外阴影，仅浮动菜单/模态窗/拖拽态图标施加双层柔和阴影（Ambient `y=2pt, blur=8pt, alpha=0.06` + Key `y=10pt, blur=28pt, alpha=0.14`）；Dark 模式下**全局禁止黑色外投影**，Z 轴前后层级完全通过表面灰度逐级提亮（`#000000 → #1C1C1E → #2C2C2E → #3A3A3C`）表达。
   - **文本、分割线与强调色**：`label`（`#000000` / `#FFFFFF`）、`secondaryLabel`（`rgba(60,60,67,0.60)` / `rgba(235,235,245,0.60)`）、`tertiaryLabel`（`rgba(60,60,67,0.30)` / `rgba(235,235,245,0.30)`）；极细分割线 `separator` 线宽锁定 `0.33pt`（@3x 下恰为 `1px` 物理像素，色值 Light `rgba(60,60,67,0.29)` / Dark `rgba(84,84,88,0.60)`，列表行内左起点必须对齐正文左边缘而绝不横穿左侧图标列，每组末行隐藏分割线）；系统强调色锁定 System Blue（`#007AFF` / `#0A84FF`）、Green（`#34C759` / `#30D158`）、Red（`#FF3B30` / `#FF453A`）、Orange（`#FF9500` / `#FF9F0A`）、Indigo（`#5856D6` / `#5E5CE6`）。

### 三、SF 等价排印字阶与纯正 UIKit / SwiftUI 导航及控件契约

1. **11 档动态排印字阶与负字距（Tracking）**：
   - `LargeTitle`（`34pt Bold`, 行高 `41pt`, 字距 `+0.37pt`）、`Title1`（`28pt Bold`, `34pt`, `+0.36pt`）、`Title2`（`22pt Bold`, `28pt`, `+0.35pt`）、`Title3`（`20pt Semibold`, `25pt`, `+0.38pt`）；
   - `Headline`（`17pt Semibold`, `22pt`, `-0.41pt`）、`Body`（`17pt Regular`, `22pt`, `-0.41pt`）、`Callout`（`16pt Regular`, `21pt`, `-0.32pt`）、`Subheadline`（`15pt Regular`, `20pt`, `-0.24pt`）；
   - `Footnote`（`13pt Regular`, `18pt`, `-0.08pt`）、`Caption1`（`12pt Regular`, `16pt`, `0pt`）、`Caption2`（`11pt Regular`, `13pt`, `+0.07pt`）；
   - 状态栏时钟、灵动岛倒计时、计算器读数及列表右侧指标列强制启用 **等宽数字（Tabular Figures `tnum`）**。
2. **双态折叠大标题导航栏（废除安卓式 `56dp` 实心顶栏）**：
   - 根页面与列表页默认开启 `LargeTitle` 模式：初始态顶栏完全透明无底线，左上方返回钮采用系统蓝圆头左尖角符号配上一级标题（`< 设置`，`17pt Regular`，禁止使用带横杆左箭头 `←`），正文顶部内联 `34pt Bold` 大标题（左缩进 `16pt`，下拉越界时随橡皮筋阻尼在 `1.00..1.08x` 间平滑放大）；
   - 当列表向上滚动越过大标题基线时，大标题渐隐，顶栏 `44pt` 安全带在 `150ms` 内平滑淡入 `ChromeMaterial` 毛玻璃、`0.33pt` 底部分割线与 `17pt Semibold` 居中短标题。
3. **标志性控件几何与微动效一比一复刻**：
   - **`InsetGroupedList`**：左右屏幕边距 `16pt`、组圆角 `10pt`、单行最小高 `44pt`（双行 `60pt`）、行首彩色超椭圆图标底框 `29×29pt`（`R = 6.5pt`）、行尾细线 `Chevron`（`7×12pt`）；按压态行底高亮为 `#E5E5EA` / `#2C2C2E`，触发推页返回时执行 `300ms` 选中高亮平滑消退。
   - **`UISwitch`**：精确 `51×31pt` 胶囊槽（关 `#E9E9EB` / `#39393D`，开 `#34C759` / `#30D158`）配 `27×27pt` 纯白微阴影圆滑块；手指长按滑块时圆球横向弹性拉伸至 `33pt`，松手以弹簧滑动落位。
   - **`UITabBar`**：高 `49pt`（叠底部安全区共 `83pt`），`ChromeMaterial` 半透明底，最多 5 项垂直图标加 `10pt Medium` 标签，选中态渲染系统强调色。
   - **层叠模态抽屉（`Sheet`）**：支持 `medium` 与 `large` 停靠档，顶置 `36×5pt` 拖拽灰条；`large` 档升起时，后方主窗口自动以三维纵深缩小至 `0.92x`、顶部渐变为 `10pt` 超椭圆圆角并退居暗幕之后。
   - **长按预览菜单（`ContextMenu`）**：长按 `500ms` 触发背景全屏渐入模糊，被按卡片或图标以 `1.04x` 浮出保持锐利，紧邻弹出 `250pt` 宽毛玻璃菜单组。

### 四、iOS 18 系统壳层、灵动岛、导航双模与 iPadOS 连续体

1. **顶部状态栏与灵动岛实时胶囊（Dynamic Island）**：
   - 屏幕顶部安全区 `54pt`：左侧粗体时钟（如 `9:41`），右侧四格圆角信号条、Wi-Fi 扇形与圆角电池图标，前景随正下方窗口区域亮度 `200ms` 平滑反转纯白或纯黑；
   - 中央常驻灵动岛胶囊：无后台活动时呈静默纯黑胶囊；当系统存在计时器、音频播放、屏幕录制、文件投送或 AI 语义代操作（`ConsentGate` 授权动作）时，灵动岛以微欠阻尼弹簧自动向左右生长展示实时双侧微缩图标与动态波形/读数，单击膨胀为交互控制卡。
2. **主屏（Home Screen）、Spotlight 与模块化控制中心**：
   - 主屏采用 `4×6` 图标与桌面小组件混排网格，图标标签 `12pt Medium` 纯白带微弱可读底影；主屏任意位置向下轻扫立即丝滑拉出 **Spotlight 毛玻璃全局搜索框**与高频建议卡；长按空白处或图标进入全屏错相微幅摆动编辑态（`Jiggle Mode`，左上角浮现 `-` 移除圆钮）；底部悬浮 `34pt` 超椭圆四槽无字标签毛玻璃 Dock；
   - **左上/中部下拉**呼出锁屏同源壁纸通知中心（底部叠卡式 `Notification Stack`）；**右上角下拉**呼出 iOS 18 全圆角模块化控制中心（含四合一无线圆盘、媒体卡、支持越界弹性拉长的竖向全圆角亮度柱与音量柱，右侧支持多页分组上下滑切）。
3. **底部导航：默认 iOS Home 横条 + 设置页可选「经典三键」兼容开关**：
   - **系统默认态（`GestureBar`）**：底部居中悬浮 `134×5pt` 圆角横条（安全区 `34pt`），支持全套 iOS 流体手势——底部上滑飞回桌面原图标槽位、上滑悬停进入左侧弧形叠卡多任务切换器（`App Switcher`，上滑甩卡杀进程）、横条左右滑动在最近应用间无缝横切、屏幕左边缘全屏跟手侧滑返回（上层页左侧投柔和阴影，下层页从 `-30%` 视差平滑归零）。
   - **无障碍与习惯兼容态（`ClassicThreeButton`）**：保留「设置 → 显示与导航 → 导航方式」热切换开关；开启「经典三键导航」时，底部安全区切换为 `44pt` 全透明悬浮栏，使用 `berry-gfx` 抗锯齿矢量路径绘制 SF 细线条风格返回、主页、多任务三枚符号（彻底淘汰锯齿 AOSP 位图资产），点击呈现 `UltraThinMaterial` 圆盘微高光反馈，动作严格走同一套四级预测性返回与 `App Switcher` 协议。
4. **宽屏自动切换 iPadOS 18 形态（`>= 600pt`）**：
   - 当运行在平板 Profile、横屏大尺寸显示或桌面拉伸宽屏窗口时，壳层免重启自动切换为 **iPadOS 18 空间范式**：底部居中自适应扩充 Dock（左侧常驻应用 + 分割线 + 右侧最近 3 个应用）、应用内自动展开 `UISplitViewController` 毛玻璃侧边导航栏、窗口顶部居中三点菜单（`•••`）控制全屏 / 左右比例分屏（`Split View`）/ 侧拉浮窗（`Slide Over`），并在 `>= 960pt` 时支持开启 **台前调度（Stage Manager）**（左侧立体缩略工作区栈 + 中央最多 4 个超椭圆自由缩放重叠窗口，兼顾纯正苹果视觉与键鼠多窗生产力）。

### 五、流体交互物理公式（Fluid Interfaces Physics）

1. **对数橡皮筋阻尼（Rubber-Banding）**：所有滚动列表、Sheet 顶界与下拉面板越界位移 $d > 0$（视口跨度 $D$）时，视觉位移必须严格遵循 UIKit 公式 $d' = \left(1 - \frac{1}{0.55 \cdot d / D + 1}\right) \cdot D$，严禁死硬截停或线性跟走。
2. **指数衰减惯性与松手落点投射（Projection）**：滚动惯性每毫秒速度衰减系数定为常规 `0.998`、分页快滑 `0.990`；手势松手瞬间的翻页、回桌面、收放面板判定一律使用投射终点 $p_{\text{proj}} = p_0 + \frac{v_0}{1000} \cdot \frac{d}{1 - d}$ 计算，确保轻快短拨即时响应。
3. **$C^1$ 速度连续可打断二阶弹簧**：窗口开合与抽屉过渡采用临界阻尼弹簧（$\zeta = 1.0, T_r = 0.38\text{s}$），灵动岛与气泡弹出采用微弹性弹簧（$\zeta = 0.82, T_r = 0.32\text{s}$）；任何动画中途再次触屏必须 0 帧延迟接管当前位置与瞬时二维速度向量，重定标松手时原速平滑衔接到新轨道。

### 六、精品首发应用标准与 Xcode Simulator 级模拟器外观

1. **砍除伪装空壳，首发六款真功能 iOS 质感系统应用**：默认桌面严禁摆放无真实后端的半成品空壳应用；首发聚焦打磨六款 100% 像素对齐 iOS 18 的真交互应用——**设置**（头像概览卡 + 彩色小图标 `InsetGroupedList` + 导航双模/深浅色/壁纸/存储真控制）、**文件**（底部毛玻璃双标签 + 网格/列表 + QuickLook 预览）、**备忘录**（完整中文排版 + 带按键放大气泡的 iOS 拼音软键盘 `imed`）、**相册**（网格至全屏跟手缩放 Hero 过渡）、**时钟与计算器**（圆键计算器 + 实时驱动顶部灵动岛倒计时胶囊的计时器）、**终端与活动监视器**（高颜值暗色毛玻璃标签终端 + 微内核实时进程/能力/帧率监视器）。
2. **Xcode Simulator 同款超椭圆钛金属外框**：宿主模拟器 `tools/berry` 默认采用无标题栏透明异形窗口，绘制等宽钛金属微高光超椭圆设备外框（Bezel）与精确 `55pt` 屏幕内圆角硬件裁剪；控制按钮收纳为外框右上侧极简悬浮胶囊，完整支持 macOS 触控板双指顺滑惯性滚动与捏合手势。
