# BerryOS 战略路线总规划（2026-10）

> 版本：**1.0**（v1.0）｜2026-11-06

> **定位**：长线规划与裁决候选文档——管 v1 收官之后的远期路线（三地平线 H1/H2/H3）；现行近期排刀仍以 `路线图-v1.1.md`（Phase 框架）+ `VM里程碑设计草案-v1.0.md`（M-G1..G3）+ `SMP设计草案-v1.0.md`（S 线）为准，本稿**不推翻、做后继**（§6）。基线数字一律以 `tools/smoke.sh` + `tools/abi.toml` 为单一事实源（CLAUDE.md 基线漂移在册——复盘实测 rootfs 相 34 标记、host 363 测、ABI 31 号在册/30 实现）。
>
> **生成方式**：双 workflow 编排产出（2026-10-28）——第一轮「复盘」8 agents 七路盘点（规划线/实绩线/内核能力/生态应用/引导虚化多架构/测试质量/业界对照）提炼规划事实基线 20 条 + 矛盾警示 6 点；第二轮「规划」7 agents（产品端定位/生态兼容/内核完整度三立场规划师 → ADR 一致性/工程可达性/完备性批判三维对抗审查 → 整合）。三份提案与三份审查的高严重度 finding 已采纳进各里程碑卡；整合不掉的分歧列 §7 待裁决。本稿不改任何现行文件。

## §0 一页总览

```
H1  v1 收官（≈6-10 周，10-15 刀）
    代码主线（串行）：C-5 落库 → T-1（TLS 拷贝式 + 0x35 + pthread/futex）→ S-2 BKL
      → intent 收尾 + 遥测入场券 → PM governor → 工程卫生包 → 失败隔离首刀
    并行支线（零文件冲突）：V-5a 事实表(docs) · UTM 四条(手动) · SoC 选型 + µA 台架(research)
    出口：M-G1/G3 收官、31/31 syscall 全实现、v1 十项差件清零 → 宣告 v1
H2  v2（≈4-8 月，三线错峰）
    线A M-ECO 生态/内核能力：容量工程 → epoll 等价 → 信号/timer/mmap/FPU → sysroot
        工具链 → QuickJS → Node（验收题：Node 级软件本平台编译运行）
    线B M-HW 真机/省电兑付：bring-up → DEVMGR → µA 闭环 + 深度休眠 → 掉电安全 → .bap 真应用
    线C 慢线（≤1 刀/周期，#49）：S-3 per-CPU → M 系（M4 = intent 第一消费者）→
        安全面 → 验证深化/AI 数据集 → OTA 首刀范围
H3  v3+（年尺度，方向级）
    AI 调度可证伪实验 · T3 虚机(EL2) → T2 翻译人格 · 生态正面战/SDK ·
    工业定标 + 认证真相 · fastpath 横向基线 · 治理去单冠军
```

**主线选择理由**：H1 三案共识（C-5→T-1 串行是 T-1 草案 §0.2 时序硬约束），无冲突可整。H2 用「地平线错峰」缝合三案主张：内核完整度与生态兼容本是一体两面——Node 验收题（用户已裁决）恰是内核能力面的验收线，合流为线A；产品案的真机线提前在 H1 点火选型（无代码冲突）、H2 收割 µA 数据——死因判别（生态冷启动第一、金主耐心第二，`research/13`）与省电卖点 QEMU 结构性证不了（`research/12`）都指向尽早见真用户；SMP/调度按 #49 慢推不让道成线C。H3 收身份支柱长尾。

## §3 H3：远景线（方向级，不切刀）

- **AI 调度最小可证伪实验**：M4 数据集 → 外部 AI 策略服务经内核第一类接口干涉放置/频率/优先级（#38 边界：AI 是系统外考生）；判据先行，证伪即归档不硬推。
- **T3 虚机**（S4 EL2 + IOMMU 直通，WSL2 式）：真 Linux 内核进 VM，Node/nginx 全兼容兜底；**立项须 S4 范围盒正式 ADR**（含依赖链 S-2/S-3 + EL2/vGIC 面，40-80 刀量级）；手表端永不装（#39）。
- **T2 Linux 人格**（Starnix 式用户态翻译）：过 #14 证据门（持续记录「非 POSIX 不可移植且薄库无解」实例，重开仅限用户态兼容服务/VM 内嵌两形态）；`LNX ok` → 动态加载器 → 人格内 gcc 自举；覆盖率两里程碑停滞或维护 >30% 工时 → 冻结增量转 T3-only。
- **生态正面战**：SDK/应用分发对外、开发者文档、AI 工程面工位（#48）升格；治理去单冠军（第二贡献者路径、CI/发布权分散）+ 公开镜像合规前置（research 剥离自动化、GPL 隔离）。
- **工业定标 + 认证真相**：同硬件对齐 6.12 PREEMPT_RT（依赖 C1 + mainline Linux 板）；IEC 61508/62443 族认证可行性评估——不可行则话术降级「工业爱好者市场」（裁决见 §7）。
- **fastpath 横向基线**：自家同机方法论（C4）成熟后对标 seL4 986/Zircon 8157，为 PC 高性能话术供证据。
- **验证升级**：IPC 协议 + 能力规则轻量形式化（#26 TLA+/模型检查）。
- **BerryOS-M 静态 profile**：仅当真实 KB 级需求出现再评（#40 边界不动）。

## §5 明确不做什么

- 内核态 Linux 语义（Linuxulator）——#14 一票否决；T2/T3 全踩用户态/VM 侧，永不为兼容破内核洁净。
- fork（wait+spawn 面已覆盖，重启议程走 ADR）；MCU 档（#40）；三端同时开工（#39–41 sequencing）；x86 停最小集盒（#41），只做 HAL 验证不做兼容目标。
- GUI 桌面通用性（#49 拒）；手表应用限定无 GUI/单 framebuffer。（2026-10-28 修订：**移动 GUI 已开禁升第二里程碑 M-GUI**，排除盒收窄为「桌面通用性仍拒、移动 GUI 开禁」——见 §8 裁决 #6 与 `docs/GUI里程碑规划-2026-10-v1.0.md`；B5 手表真机应用范围盒不动）
- APK/ART/Binder 容器线（ARC++ 退场前车）；Wine 提前立项（前置 = T2 稳态 + display 服务，兼容子系统设计既定，v4 再评）；动态链接提前（仅 A10（原 A6）实证卡死才立项）。
- AI 进内核决策通路（#38 三不赌）；band 无遥测证据入场或抛弃公平基线（#42）。
- S-2 落地前动「syscall 主体不可抢占」免锁根基；SMP 跳步（≤1 刀/周期，#49）。
- ABI 破坏性变更（FROZEN v1 add-only；信号等新语义走新号）。
- 自研/改硬件（只买现成板与功耗计）；QEMU/TCG 功耗与性能数字进对外话术。
- 命令数量当生态 KPI（先修运行面再扩量——带毒家族教训）；兼容线无帽扩张（≤50% 工时帽 + 挤压 <20% 重议）。
- 大爆炸式里程碑卡/大爆炸重写（审查高严重度 + research 死因榜双执法：每面独立验收线）。
