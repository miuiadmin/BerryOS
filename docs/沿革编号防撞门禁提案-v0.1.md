## 三、门禁规格建议（G11「沿革并号注记门」，伪规格不改码）

```
gate_g11_annals_dup():
  扫 docs/阶段沿革.md 全部 ^## 标题，提取（编号 + 续尾?）
  R1 FAIL：同编号 ≥2 笔，且存在后笔（物理序第 2+ 笔）标题+正文
      均不含注记词表 → 红，报编号+行号
  R2 PASS：同编号各笔全为「N续」连载形（组内无线名缺失时的裸笔）→ 绿
  R3 WARN：同编号混有裸笔与续笔，或续笔无线名尾注 → 警，报清单人工消歧
  注记词表（首发）：原编 | 撞号 | 并号 | 考古 | 短命重开
```

预期首跑（按 §一 取证）：R1 红 4 组（一百一十二～一百一十五）；R3 警 5 组（三十一～三十五）；
A/B 类 40 组全过。首跑即活捉 = 门禁有效性的直接证据。
