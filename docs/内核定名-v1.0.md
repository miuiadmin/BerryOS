## 3. 软雷三条与对策

1. **「没核」同音梗**（语言面）→ 官方认领：tagline **「莓核——小到近乎没有的核」**
   （微内核极简人设自证）+ 钉死读法 **hé**（同「内核」之核，防儿化漂移）。
2. **商标软雷**（Class 25 字标 / 梅河地理标志 / RFID 商号）→ 对外始终绑「莓核」
   定字；正式对外传播前**人工**跑 USPTO/EUIPO/WIPO/中国商标网终验
   （网检不能，第 9/42 类中国商标网人工查为两案共同挂账）。
3. **GitHub 短名被占** → 用 `meihe-os` org（实证空置）；crates.io 无占位机制，
   首个版本发布才锁名——不急，开源发布时落。
