### 构建与运行命令（与 AGENTS.md 命令速览同源）

一次性前置：`rustup target add x86_64-unknown-none`（P7-x0 起 x86_64 最小集；stable 预编译 core，免 nightly）。

- `just build-x86`：x86_64 最小集构建——独立工作区 `arch/x86_64/`，**必须显式 `--target x86_64-unknown-none`**。原因（判例 §A84-85/§B21）：根 config 锁 aarch64（`build.target`）且跨 workspace 边界仍命中——不显式指定即落根 config 的 aarch64 目标。
- `just run-x86`：QEMU pc 机 + PVH ELF（-no-reboot）——七标记 PVH/TIMER/EXC/CTX/SYS/X86 ok（P7-x1..x4 四刀链）；退出 Ctrl-A X。
- `just smoke-x86`：x86 独立冒烟（7 标记恰一次；不并入主 smoke；已挂 CI——ci.yml 两条 x86 步）。

### x86 asm 与链接脚本细则（§A84-85/§B21/§B22 蒸馏）

- **asm 语法分家**：x86 asm 默认 Intel 语法（aarch64 侧 AT&T）——x86_64 的 `global_asm!`/`asm!` 须显式 `options(att_syntax)`。
- **PIC 与重定位**：`x86_64-unknown-none` 默认 PIC，`.long _start` 类 R_X86_64_32/32S 重定位对 local symbol 拒链——`arch/x86_64/.cargo/config.toml` 钉 `relocation-model=static`。
- **`.note*` 绝不能 DISCARD**：PVH 入口声明靠 ELF note（`Xen`/type 18）存活，丢了 note = 静默落 multiboot 路拒收 ELF64；note desc 用 `.long _start` 符号引用、非硬编码地址。
- **boot 页表体放 `.rodata` 文件面预零**：PT_LOAD 装载即零——硬件写权限看 PTE 位、不看 PT_LOAD 旗标。

### 中断路径细则（§A86-88/§B23/§B25/§B26 蒸馏）

- **ISR 桩对齐两层**：锚 rbp 后 `and $-16` 只归一被打断上下文的栈奇偶；call 边界 SysV 另要求 call 前 RSP ≡ 0 (mod 16)——`and` 后压奇数个 8B 寄存器再 call 即违约（9 GP=72B），须 `sub $8` 凑偶。纯整数叶子 handler 今日零可观测，调用树一出现 `movaps` 即 #GP → 三重故障静默退出；**新桩照 timer_isr 现形态抄**。
- **ISR 桩不存 XMM 的前提 = builtin target 禁 SSE**：builtin `x86_64-unknown-none` 全局 `-sse,-mmx,+soft-float`；换 custom target JSON 须自查两件——disable-redzone=true（builtin 已禁，不需要也不可加 flag）+ 保持 -sse/-mmx 软浮点（或 ISR 面补 XMM 保存），见 `arch/x86_64/.cargo/config.toml` 注。
- **8259 PIC init 的 IMR 敞开窗**：ICW 序列清 IMR = 全部 IRQ 短暂敞开——init 整个包在 IF=0 内，ICW4 后立即 OCW1 掩回（主片 0xFE 只放 IRQ0 / 从片 0xFF）；ICW 间 `io_wait()`（inb 0x80）。

### nomem 双架构同判（§A89/§B27）

A89 的 nomem 铁律不限于 x86：aarch64 `mmu.rs` 的 `tlbi` 同款不标 nomem——aarch64 面细则见 `01-内核编码.md`。

## 判例瘦行

- **x86 工具链/引导两则（P7-x0）**：①asm 默认 Intel 语法+PIC——x86_64 `global_asm!`/`asm!` 须显式 `options(att_syntax)`；R_X86_64_32/32S 对 local symbol 拒链（`arch/x86_64/.cargo/config.toml` 钉 `relocation-model=static`）；x86 构建显式 `--target x86_64-unknown-none`；②`.note*` 勿 DISCARD——PVH 入口靠 ELF note `Xen`/type 18 存活，DISCARD = QEMU 拒收 ELF64；note desc 用 `.long _start` 非硬编码。先问：目标三元组显式了吗？DISCARD 段里有 loader 要读的 note 吗？ → 雷册 §A84-85/§B21/§B22
- **x86 中断路径三则（P7-x1）**：①ISR 桩对齐两层、`and $-16` 只管第一层——call 前 RSP 须 ≡ 0 (mod 16)：`and` 后压奇数个 8B 寄存器即违约（9 GP=72B）→ `movaps` #GP 三重故障；修法 = `and` 后 `sub $8` 凑偶；②桩不存 XMM 前提 = builtin 禁 SSE（`-sse,-mmx,+soft-float`）——custom target 须 disable-redzone + 软浮点或补 XMM；③8259 PIC init 的 ICW 清 IMR = 敞开窗——init 全程 IF=0、ICW4 后立即 OCW1 掩回（主 0xFE 只放 IRQ0/从 0xFF）。先问：call 前 RSP ≡ 0 (mod 16)？SSE/red-zone 与 builtin 一致？控制器 init 关中断？ → 雷册 §A86-88/§B23/§B25/§B26
- **asm 勿给「架构上真读写内存」或「正确性依赖与相邻内存写保序」的指令标 nomem（P7-x4）**：nomem ⇒ 允许跨块重排内存访问；volatile 只管 volatile 操作彼此顺序、管不到普通 store 与 asm 相对位置——`invlpg` 与页表 RMW 零寄存器依赖即被上提（TCG 不建模该缓存 = QEMU 恒绿真机才爆）；`ltr` 架构上真读 GDTR+0x28 16B 描述符。任一 yes 即不标 nomem（nostack/preserves_flags 照留）；mmu.rs 的 `tlbi` 同不标。先问：该 asm 读/写可访问内存吗（LGDT/LTR/INVLPG 类）？其正确性依赖与相邻内存写的顺序吗？ → 雷册 §A89/§B27
