## 域铁律

一切声明皆派生物、一切门禁带防绕过、一切完成态机器可判——违反任一条即回改，不开例外口子。

### 1. 门禁分层与防绕过

| 层 | 机制 | 判什么 |
|---|---|---|
| pre-commit | 暂存命中 `docs/` 或 `.agents/` → `git checkout-index` 物化暂存区快照 → `check-docs.mjs --strict` 对快照跑 | 只判本次提交内容：兄弟会话的工作树半成品不拦、不被吞；工作树修好/索引留毒必须拒 |
| prepare-commit-msg | pid 印记闸 | 拒 `--no-verify` 绕过（pre-commit 写 `$GIT_DIR/berryos-gate.imprint`，印记 900 秒内新鲜、消费即删；merge/cherry-pick/revert/squash 流程免检） |
| reference-transaction | ref 层兜底 | 跨根合并闸（原职能保留，见 AGENTS.md 规则 10） |
| pre-push | main 线守门 + bot 身份闸 | 跨根提交推 main 拒；`berryos.bot-email` 登记的 bot 身份只准推 `wip/auto-*` 与 `hermes/*`，推 main 或集成分支拒；未配置则身份闸静默跳过 |
| CI（ci-light） | 服务端后手 | 本地钩子可被剥离，服务端 `--strict` 与 facts 对拍是最终判决 |

- 钩子门路径不认任何跳过变量：门路径强制 unset 环境继承的 SKIP 类旁路变量；唯二 owner 逃生阀 `BERRYOS_ALLOW_CROSSROOT=1`（跨根合并）与 `BERRYOS_ALLOW_NOVERIFY=1`（印记闸）。
- 快照收紧语义：现行文档的相对链接指向未跟踪文件时，快照门下视为断链——引用与目标必须同批进提交（兄弟会话的未跟踪半成品不得被现行文档当依据引用）。
- 新克隆第一步：`bash .githooks/install.sh`（设 `core.hooksPath` 并自验）。
- 明示残风险（不机判）：amend 吞并兄弟已暂存文件在 pre-commit 层不可靠机判——靠 staged 清单打印（可见性）+ pre-push + CI 三层兜底；共笔面文件（justfile/CI/AGENTS）整文件暂存前逐 hunk 查归属（雷册 §A125 判例延续）。

### 2. 判据单源与新鲜度

- smoke 判读词唯一家 = `tools/markers.sh`：MARKERS（裸相）/ROOTFS_MARKERS/ECO_MARKERS/RX_MARKERS 四族 + banner 正则 `BANNER_FORM_RE`；消费脚本 source 之，禁本地第二份拷贝；`bash tools/markers.sh` 直跑自检腿做哨兵↔消费者 1:1 映射机检（每消费脚本恰一次引用）。
- gui8 判读词唯一家 = `tools/gui8-smoke.py`（负向前瞻正则塞不进 shell 数组，单源在 py；计数经 facts 制品对拍）。
- 镜像新鲜度门：`tools/image-fresh.sh` 对拍 `out/manifest.txt` 的 sha256 与现场重算值；`gui8-smoke` 与 `smoke-image` 默认陈旧即重建——改二进制后跑旧镜像得出的结论违规作废。
- 工具版本地板：`bash tools/floor-check.sh --verify`（rustc 地板解析 `rust-toolchain.toml` 单源，不自持第二份；证不出的地板即失败）；CI 首步同脚本。

### 3. 数字自证（facts 制品）

- 计数事实唯一家 = `tools/facts.txt`：git 跟踪、`key=value` 排序行、零日期（数字变才有 diff）；`python3 tools/facts.py` 对拍（不符即红带 diff）、`--update` 刷新、`--selftest` 自检。
- 刷新义务：动计数输入面（测试/标记/文档/justfile 接线）的同一提交带 `--update`；刷新在暂存之后（facts 清单读 git index——先刷后暂存会把新文件漏计数，快照门当庭拦）；CI 对拍不符即红。
- 口径声明：`tests_rust` 是 `#[test]` 静态字面量口径，与 规则/07 的 cargo result 合并口径互不可比，勿混引。
- 检测器自检律：每个检测器（check-docs/facts/markers/floor-check/gate-selftest）配必触发的坏样例夹具——检测器变哑即红（a detector that goes quiet is an ERROR, not a pass）。

### 4. 规划双戳（design.md 节级完成态）

- 适用面：`.agents/plans/<模块>/design.md` 已含至少一条戳行者（戳在场即受检，免登记表）；新动工模块须采用（人律，可见性靠 facts 的 `stamped_designs` 计数）。存量未戳模块不强制回填。
- 戳语法（小节尾、引用块行，与中文数字小节共存）：
  - `> Verified: YYYY-MM-DD · <commit 哈希 7-40 位 hex> · N/N · tests <N|->`（本节是 .agents/README.md〔Curia 2.6 逐字副本〕双戳协议的 BerryOS 收窄表示；机读权威 = check-docs.mjs 的 VERIFIED_RE，两面同批改）
  - `> Quality reviewed: <评审人/范围/日期一行>`
- 反黑洞三红：盖戳节内出现裸 `- [ ]`（未验收项必须先撤戳重验）；`N/N` 不等于本节 checklist 实数；有 Verified 无 Quality reviewed。
- Deferred：`> Deferred: <项> → <相对链接>`，闭合时在原处留 RESOLVED 回执——欠账有去处、清账有回执。
- 棘轮：撤戳 = `stamped_designs` 数字降 = facts diff 可见，欠账只缩不涨。

### 5. 无人值守 runner（E 面）

- 宪法唯一家 = `.agents/skills/berryos-runner/SKILL.md`（人向接入手册同目录 RUNBOOK.md；punch-list = [E 面运营计划](../../.agents/plans/2026-11-22-e面运营.md)的「未完成事项」节）；Hermes cron prompt 只许一句指针「完整读取并严格执行」，禁承载规则本体。
- decide-then-report：无人会话遇决策自选「行业标准项或更可逆项」，记 `A: (run decision, DATE) <choice>. Reversal: <cost>`（落 PR 描述固定节；触及仓规的升格 notes/）；操作员事后否决权保留。
- 五类硬停（只此五类停机等人）：不可恢复数据丢失、凭据、花钱、共享基础设施、疑似算错的计算。
- park 语义：单项 park 不 park 全链；park 必落 punch-list（活跃计划的「未完成事项」节）+ PR 评论，禁 silently defer-and-forget。
- 一单元一推、推到绿：每单元本地全绿后单次推送，CI 绿才前进。
- git 面：独立克隆工作区（结构性隔离，不共享主仓工作树与索引）；身份 `berryos-hermes-bot`（经 `git config berryos.bot-email` 登记入身份闸）；只推 `wip/auto-*` 与 `hermes/*`，永不碰 main 与集成分支，绝不自 merge。
- 无人会话外壳（自动化开发二期 P0，2026-11-22）：`tools/run-e.sh` 单入口拉起（tmux 双会话 = run + 心跳，claude 独立 session-id，`BERRYOS_E_RUN=1` 环境判别，stop 对无人环境拒执——run 不能停自己）；心跳 300s 一拍以会话私有 transcript mtime 判活、指数退避 resume；`tools/e-supervisor.py` 只做 machinery 整批回退（3 小时零产品产出）与 repair 报修（6 小时零 ship），**永不许成为停 run 的原因**；Stop hook 四门 fixpoint（树净/punch-list 判空/门禁绿/无 repair——`tools/e-guard.py` 哨兵唯一写点）；FROZEN 集（宪法/闸/编排脚本）无人会话不可写；开工包 `tools/pack-work.py`、推绿 `tools/push-green.py`（三态判决，note=无答不归责）、内容寻址回执 `tools/e-receipts.py`。语义全文在 SKILL.md 与 RUNBOOK.md。
- 评审凭据（二期 P1）：评审口径唯一源 = `.agents/skills/berryos-runner/review-pin.toml`（`review-pin-check.py` 校验与镜头求解，`--live` 对账 Hermes 模型漂移）；结论 = 协议行回执（`LENS/HIGHEST`，`review-recv.py` 机器验收、三重指纹、不完整不落盘）；欠账五件套（`review-debt.py` 记账，**push-green 推前查账有欠禁推**——宕机是 delay 不是 approval）。
- 证物链（二期 P1）：`run-artifact.sh` 信封（running 先行/判决先写再收尾——任何被杀时序不出现假完成；40 份轮换；append-only 账本不可屏蔽）；`e-receipts.py wrap`（跑前跑后键一致才落回执——跑动中被编辑=回执作废）；`gate-wrap.sh` 一行式包裹（begin→wrap→verdict，rc 透传）。
- 控制面与债网（二期 P2）：`tools/control-plane.txt` 是治理工具清单——staged 命中即 pre-commit 逐件跑其 `--selftest`（此门在文档门早退之前无条件先跑；「未列名新治理件默认按控制面处理」是提交者义务——门本身纯清单驱动，漏登靠评审拦，见 tools/control-plane.txt 头注）；`.claude/MANIFEST.md` + `claude-audit.py` 五向对拍配置面（未登记新文件红）；三张 advisory 债网（`stale-parks.py` park 理由失效、`stranded-deferrals.py` 引用对象已合入、`answers-readback.py` 决账已落可重开——rc 恒 0，巡检面跑不进门）。
