# 12-引导与镜像

> 一句话定位：动 bootloader/EFI/装载器/盘镜像 前先读本文。判例全文 → docs/雷册-判例库.md（瘦行行尾锚点直达）；设计文档见文末「深读」。

## 域铁律

### EFI 十段与盘形制

- **EFI 引导链（`just run-efi`）**：AAVMF（`-pflash` 对）挂 `out/berryos.img` + ramfb 自举——BerryBoot 十段（`fw:`/`gop:`/`fs:`/`kfile:`/`init:`/`elf:`/`load:`/`mmap:` → `BERRYBOOT ok`）→ 内核接续（`HANDOFF ok` → `MMAP ok` → `ROOTFS ok src=handoff`）→ 裸相 32 + EFI 路生态 36（无 virtio 面；LSN/EVS/SKT/EPL/NETS 拓扑门静默不打 = 拓扑真值；GUI-1 起 +FBW/FBSERVE 双路上屏；GUI-8 段③ 起 +LAUNCH 双 EFI 专属；G4-2/4-3 起 +DPGP/DPGS/DPGN 三 dpg 标记 EFI 路同打）。十段全文 → 雷册 §C（本文不复制）。退出 QEMU 用 `Ctrl-A` 然后 `X`。
- **盘形制**：MBR + FAT16 96MiB + 0xDA 预留槽 16MiB。`just image` = V-3 单口整盘镜像 → `out/berryos.img`（MBR + FAT16 96MiB + 0xDA 预留槽 + 四件套，同输入同字节）+ 侧产物 `manifest.txt`（SHA-256 清单 v0 冻结）；`--key-hash` 只落 manifest。
- **BerryBoot 构建链（`just build-boot`）**：staticlib → rust-lld 静态全链接（链入 berry-loader）→ `elf2pe.py` 转 PE32+；V-3 起纯 EFI 产链，消费内核产物。

> 口径保活：§A6 瘦行的 fw_cfg 递送纪律为冻结口径，重排本文时一字不改——「blob 递送走 fw_cfg 具名文件 `-fw_cfg name=opt/berry/rootfs,file=…`（FILE_DIR 自描述；selector 收 BE u16 须整字 `write_u16`——MMIO 宽度敏感；data 口 u32 低字节 = 项首字节）」。QEMU `-kernel` 直加载侧（非 EFI 路）同受此辖：不走 Linux boot 协议，`-initrd` 不加载、fw_cfg INITRD_ADDR/SIZE 键空。

## 判例瘦行

- **QEMU 非 Linux ELF `-kernel` 不走 Linux boot 协议**：x0=0、RAM 无 DTB（0xD00D_FEED 零命中，LE 应读 0xD000_EDFE）、`-initrd` 不加载、fw_cfg INITRD_ADDR/SIZE 键空。blob 递送走 fw_cfg 具名文件 `-fw_cfg name=opt/berry/rootfs,file=…`（FILE_DIR 自描述；selector 收 BE u16 须整字 `write_u16`——MMIO 宽度敏感；data 口 u32 低字节 = 项首字节）。DTB x0 仅真机/Linux 协议生效（x19 预埋 `dtb::boot_probe`）；切 Linux Image 协议 = ADR 级重构留 v2。先问：blob 递送是否在赌 Linux boot 协议？ → 雷册 §A6
- **真实链接器的 PT_LOAD 不页对齐（G-eco-c/D5）**：`off ≡ vaddr (mod align)` 即合法（RO 段可与 text 共享页）——解析器（`berry-loader`）不收页对齐；消费端（svcmgr `spawn_elf`）用页铺平单 VMO 消化（逐段独立 vmar_map 会撞已映页）。cpio 容量 = `vmo_get_size` 页对齐含尾零页——walk 靠 `TRAILER!!!` 自终止，别假设缓冲尾巴是干净数据。先问：装载器把页对齐当默认合法条件了吗？ → 雷册 §A58
- **elf2pe 的 .reloc 槽位 = r_offset（最终镜像绝对 VMA），sym/addend 描述槽内容、不是槽位（V-0b）**：lld --emit-relocs 的静态 reloc 惯用「rsym=节符号（val=节基址 0x1000）+ addend=符号内偏移」形态——`collect_relocs` 把 rsym≠0 的符号值当槽位 ⇒ DIR64 全错打 RVA 0x1000，固件装载 +delta 重定位即砸穿代码。自检若用合成输入自造口径 = 钉板钉的是 buggy 输出——**合成基准必须复刻真实工具链产物的字段形态**（含 rsym≠0 节符号路径）。先问：自检基准复刻了真实工具链产物的字段形态吗？ → 雷册 §A90
