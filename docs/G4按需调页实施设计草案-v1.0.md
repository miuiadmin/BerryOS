### 1.2 ABI/IPC 面（pager 的全部原料已在册）

### 1.3 消费场景（G4 给谁用）

| 场景 | 现状（eager） | demand 化收益 |
|---|---|---|
| exec/`process_create` 装载 | 子代码+栈 VMO 须先 commit 再 map（user.rs spawn 链全 eager） | 按首触调页——启动内存足迹 ∝ 实触页 |
| rootfs 流式装载 | G-eco hexyl 整文件 eager 装载 | 大文件按窗填页 |
| pthread 栈段 / mmap 窗 | berry-libc STACK_VA_BASE 段 / berry-mmap 窗整段 commit | 匿名页按需（对齐通用 OS 直觉） |

### 1.4 并发面（G3 全抢占语境下的 fault 路径）

- **EL0 fault 杀链 = 锁入口第 13 类**（S-3c C4 成文：svc_enter 五锁全量
  + 按位收口放锁）——demand 分支若走阻塞路，**锁窗必须在 block 之前
  收口**（fault 线程睡持有 KL/pt_lock = 直接死锁面，G4 验收「无死锁」
  的第一对象）。
- per-AS PT 锁（`pt_lock(asid)`，S-4 4-2①）串行 map/unmap/protect——
  fault 填叶与并发 vmar_* 同锁窗；填叶后 `tlbi_aside1(asid)` + dsb +
  SMP broadcast（S-4 4-2⑤ 锁窗内只发不待——vmar_map 回滚臂同款）。
- 睡醒原语在册：`block_current`(sched.rs:1661) / `wake_matching`(:1807)
  ——G3-5c 刚全链实证（同 KL 窗查位+入队 = lost wakeup 结构性不可能）。
- lockdep 面（G3-5 转正常驻）：fault 路径新触锁序自动入环检测。

## §2 G4 机制面规格（设计定谳候选，实施刀入口再收窄）

### 2.1 缺页流（内存管理设计-v1.1.md §4 流程的实现落形）

```
EL0 访问未映射 VA
  → exception_sync_el0 EC=0x24（D-abort；0x20 I-abort 同形，§5-⑦）
  → FAR → 当前任务 root Vmar 区间查（asid 反查面）
  → 未命中 / 命中非 demand 区间 → 原杀链不变量保持（fail loud）
  → 命中 demand 区间（vmo, off）：
      ① 拷请求（task id + vmo handle + 页 off）到预分配请求面
      ② 收口全部锁（svc_enter 位账 + pt_lock）
      ③ block_current 挂 fault 等待面
      ④ pager（用户态服务）收请求 → 读盘/填数据
        → pager_supply_pages(0x21) → 内核 commit 该页 + 填叶
        （pt_lock 窗 + tlbi + broadcast，vmar_map 同款）
        → wake faulting task
      ⑤ 醒 → eret 重试指令（ELR 不动 = 免改 TrapFrame——AArch64
        缺页指令重执行天然免修）
```

- **内核不换页不读盘**（纯微内核，ADR #9）；策略全在 pager。
- pager 持 VMO 的特定权限（pager/SET_POLICY rights 位在册）——普通
  用户态服务，可换可崩（崩 = 该 VMO 页暂不可用，系统其余不受影响——
  内存管理设计-v1.1.md §4 定谳；fault 线程归宿语义 §5-⑤）。

### 2.2 递归防线（验收「pager 递归不爆」的设计答案）

1. **pager 自身 AS 全 eager**——服务自举面：code/栈/数据/请求环映射
   全 pre-commit，demand 化永不指向 pager 自己（能力面拦截 + 自测断言）。
2. **缺页处理路径零分配 + 零用户态内存访问**（ADR #9 原文执法）——
   请求面 boot 预分配；内核侧不 copy_from_user。
3. **fault-in-fault 深度帽**：per-task 递归计数 >N（N=2 起步）→ panic
   fail loud——防线 1/2 失效时的最后响雷，不静默。
4. pager 喂页用的源数据 VMO 同样 pre-commit（supply 链零缺页）。

### 2.3 死锁防线（验收「无死锁」的设计答案）

1. fault 线程 block 前**锁全收口**（§2.1②）——睡不持锁。
2. `pager_supply_pages` 走 SVC 同构锁序（svc_enter 锁序合同照旧）——
   与 fault 钩子锁序成环 = lockdep 面必抓（G3-5 转正检测器执法）。
3. 填叶在 pt_lock(asid) 窗内、broadcast 锁窗内只发不待（§1.4 同款）。
4. pager 单线程喂页首形（先通后优）——多线程 pager 留 G4-3 压测档。

## §5 开放问题（G4-1 入口侦察清单；①②④⑥⑦⑧ 已于 G4-1 入口裁决）

1. **DEMAND flag 落位**：`vmo_create` options（对象级 demand——VMO 整体
   按需，map 侧免查）vs `vmar_map` options（映射级——同 VMO 混合映射可）
   vs 双面。倾向 `vmo_create` 对象级（v1 options 语义注释已指 5 类后备
   方向，对象属性先行）；实施刀裁决。
   **〔G4-1 裁决〕vmo_create 对象级**：内核侧先形 = `Vmo::create_demand`
   （`demand: bool` 对象属性 + `is_demand()`；两值页态不动——demand 只移
   commit 时机，eager `map` 的全提交执法点照旧拒非 demand VMO）。ABI
   options 位激活 = G4-2（v2 位裁定 + berry-sys 镜像）。`map_demand` 对
   非 demand VMO 拒 `VmoNotCommitted`（复用错误码，语义 = 「此 VMO 不是
   按需后备」）。
   **〔G4-2 裁决〕options bit0 = `VMO_OPT_DEMAND`（1<<0）**：位激活走
   abi.toml [[option]] 注册表（CHAN_OPT_NO_INTENT 同款）+ `just abi-gen`
   四面再生；0x21 同刀 stage v2→v1（在册号激活，A7-4 add-only 先例——
   §0 非破冻判定）。语义 = 对象级 demand + **额外授 `RIGHT_SET_POLICY`**
   （在册未消费位首消费——0x21 门 = 持 Vmo + SET_POLICY 双验，普通 dup
   无此权不能冒充 pager）。`vmar_map` 对 demand VMO 分流 `map_demand`
   （对象属性分流，不开 0x16 options 新位——映射级混合语义留 v2+）。
2. **fault 等待面**：专用 fault 队列（新等待类，WakeReason 复用）vs
   Event 合成（G3-5c 内核私有 Event 表同款）。倾向专用队列（fault 语境
   无信号位语义，Event 位面是浪费）；block_current 签名兼容性实施刀核。
   **〔G4-1 裁决〕专用裸键**：零大小静态取地址作 `wait_obj`（fault/pager/
   done 三键）+ 专位 1<<51（`USER_SIGNAL_BITS` 位表登记）——不建 Event
   对象（位面浪费定谳成立），`block_current`/`wake_matching` 签名零动
   （G3-5c 已证任意 usize 键 + 位相交匹配全链可用）。G4-3 缺页风暴若见
   扫描热点再议 per-key 哈希——首形线性 SLEEPQ 扫描 = 既有 wake 面同款。
3. **请求递送**：channel_send（消息面现成、慢）vs 共享环 + Event
   （ADR #9 指名快路径、零分配）。首刀 channel 先跑通、G4-2 段内环化
   or 直上环——请求率低（首触一次性）时 channel 差距是否可测待 bench。
   **〔G4-1 形〕内核任务自喂闭环不走 IPC**：boot 预分配单槽
   （far/asid/armed 三原子）+ 裸键唤醒——ADR #9「零分配」先形。channel
   vs 环之争整体留 G4-2（EL0 pager 才有跨态递送面）。
   **〔G4-2 裁决〕两者皆不上——0x21 阻塞收货（syscall 即等待面）**：
   EL0 请求面 = 内核预分配**单槽照旧**（far/asid/armed 三原子）+ 专用
   裸键；`pager_supply_pages(vmo, src, src_off)` 无武装请求时 poll-first
   后 `block_current` 睡 pager 键——fault 探针武装槽 + 唤醒即递送。
   依据：①wait_one 先例已证 SVC 上下文 block_current 合法；②channel 面
   对单请求首形纯增重（拷贝 + 队列对象）；③环的收益（多 faulter 批量）
   在 G4-3 风暴才兑现——首形单槽 = 最小诚实面。ADR #9 零分配 ✓（0x21
   全程零分配）。EL1/EL0 分流：hal 第二探针槽（`*_el0`）+ 独立槽/键
   （dpg 内核 pager 对不劫 EL0 请求——arm 侧按臂唤不同键）。已知界：
   首形单 faulter 假设（多 faulter 错醒 = 重 fault 再进探针自愈，语义
   无害但风暴下热点——G4-3 per-request 键化）。
4. **asid→root Vmar 反查**：task 加 `root_vmar` 裸指针字段（spawn 时装，
   销毁窗同步——悬空面同 LATSGI_OBJ 前例）vs 全局 asid 索引表（ASID
   回卷 quiesce 窗〔S-4 4-3〕同窗维护）。倾向 task 字段（回卷窗已把
   asid 复用竞态关死，表维护面更宽）。
   **〔G4-1 裁决〕全局小表 + TTBR0 现读**：探针 `hal::current_asid()`
   从 TTBR0_EL1 现读 ASID（硬件单一事实源——task 字段方案的 asid 来源
   面被消掉），反查 = `vmar::register_demand_root/demand_root` 16 槽
   定长线性表（登记 = map_demand 调用方/对象属主，boot 屏蔽窗；**只登
   记不注销**——v1 boot-held 生存期，G4-2 process 退出语境再裁注销）。
   task 字段备选退役理由：对 handle 表 Vmar 还须解决装/卸窗，表方案对
   boot 直构/handle 表两语境同形。
5. **pager 崩溃语义**：fault 线程永久阻塞 vs 收 -EFAULT 杀 vs 该 VMO
   冻结标记。内存管理设计 §4 只定谳「系统其余不受影响」——线程归宿
   G4-2 裁决（牵涉 ABI 错误码合同）。
   **〔G4-2 裁决〕永久阻塞（MAX deadline）**：fault 线程睡裸键无超时——
   pager 死 = 供给永不至 = 线程常驻 SLEEPQ。可观测（PS 面可见）/可收拾
   （进程主可 kill 全家——process_terminatable 面）/**不传染**（其余
   系统零影响 = §4 定谳原文）。收 -EFAULT 杀 = 内核替 pager 判断死讯
   （误杀面：pager 慢 ≠ pager 死）；独立 kill-dpg-service 面（如
   `pager_detach` 收回供给权 + 唤 -EFAULT）留 G4-3 后按需裁——首形
   fail-loud-on-hang 比 fail-fast-on-guess 诚实。
6. **demand VMO × 3-2 悬空 PTE 防线交互**：demand 区间 unmap/decommit/
   close 的语义（无叶可悬空——防线是否天然满足 or 需新断言）；mapcnt
   对 demand 页的记账起点（supply 时 +1）。
   **〔G4-1 裁决〕记账起点 = 供给成功**：`supply_page` 填叶毕
   `track_map(+1)`；unmap 对 Demand 区间整体 untrack（未供给页
   `saturating_sub(0)` 零动作——防线自洽，无新断言）；`decommit`/close
   对已供给页走既有防线（mapcnt>0 拒/泄漏兜底）不变；protect 对
   Demand 区间 v1 拒 `NotMapped`（混合供给态语义留 G4-2 后）。
7. **I-abort（0x20）同期与否**：exec 装载核心用例是代码页 demand——
   但首刀只 D-abort（0x24）最小面更稳；0x20 同形分支 G4-2 起视 exec
   用例节奏。
   **〔G4-1 裁决〕只 D-abort**：0x24（EL0）+ 0x25（current-EL）两臂插
   探针；0x20/0x21 留杀链原路径。EL0 臂 G4-1 无 demand 区间 = 恒 false
   零行为漂移（G4-2 激活面即位）。
   **〔G4-2 裁决〕维持只 D-abort**：DPGP 首例 = 数据页读（0x24）；
