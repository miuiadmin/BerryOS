# 内核唤醒记账设计（PM-17 刀 1）

> 版本：**1.0**（v1.0）｜2026-11-07

> P10 唤醒源记账的**纯内核面**：谁唤醒了调度器（IRQ/IPC/引导），一次唤醒归
> 哪个源、何时到、何时被领走——省电支柱的地基观测。方案赛（A 极简面 vs B
> 归因完备面）终审裁决 → `research/pm-notes/刀1-前置两问-裁决.md`；本文
> = 裁决 §5 八件前置的实施定稿 + 形状冻结。不含 berry-power 服务 / sim
> 注入 / 真机（裁决 §5：八件无一依赖）。

## 1. 目标与范围

- **归因完备**：调度器每一次 `note_wake` 都能归到唯一唤醒源（u8 枚举），
  无主唤醒 = 写路径 bug，现场 panic（L0 执法，负延迟同族）。
- **零通道**：刀 1 不开导出 syscall——0x84 `telemetry_open` 改挂决策本文
  §9 冻结，实施随 berry-power 刀。
- **热路径纪律不破**：on_wake 只加原子计数 + 一次 cell 读（Relaxed），零
  分配零锁；IRQ 臂计数点同窗 O(1)。
- **不随 trace_off 关**：per-source 记账是**记账面**（计数器族先例，
  `telemetry.rs` intent 计数器），不是环**记录面**——双跑通道（t_off）只
  关后者。

三里程碑（各自 QEMU 独立可验、单独成提交）：

| 里程碑 | 内容 | 落点 |
|---|---|---|
| A | `[[wakesrc]]` 枚举单源 + 第五产物 `wake_gen` + 四元组执法 | `tools/abi.toml` / `gen_abi.py` / `arch/*/src/wake_gen.rs`（bc2582e） |
| B | 内核实现全链（cell/槽表/环扩/计数点/G1.5/ktest/标记） | `arch/aarch64/src/wake.rs` 等 13 文件 |
| C | 本文（形状冻结 + 偏差记录在案 + 演进节） | `docs/内核唤醒记账设计-v1.0.md` |

## 2. 唤醒源枚举（`[[wakesrc]]` 单源）

`tools/abi.toml` 增 `[[wakesrc]]` 段（add-only，与 GIC INTID 封闭集
`gic.rs` 一一对应）；`gen_abi.py` 第五产物 `wake_gen.rs` 三端同源（内核
HAL / 用户态 berry-sys 各一份生成物）：

| 值 | 常量 | 语义 | GIC INTID |
|---|---|---|---|
| 0x00 | `WAKE_SRC_NONE` | 哨兵：cell 未接线语境（副核首任务切入前）——**到达记账即 panic** | — |
| 0x01 | `WAKE_SRC_KERNEL_BOOT` | 引导窗（rust_main 直跑，首任务切入后冻结） | — |
| 0x02 | `WAKE_SRC_TIMER` | 定时器（CNTV PPI） | 27 |
| 0x03 | `WAKE_SRC_UART_RX` | 串口接收（PL011 RX SPI） | 33 |
| 0x04 | `WAKE_SRC_SGI_RESCHED` | 调度 IPI | SGI 1 |
| 0x05 | `WAKE_SRC_SGI_TLB` | TLB shootdown IPI | SGI 2 |
| 0x06 | `WAKE_SRC_IPC` | 任务语境（IPC 唤醒） | — |
| 0x07 | `WAKE_SRC_POWER_KEY` | PL061 电源键（sim-S2 A4②；到达-only，**永不进环**） | SPI 7 |
| 0x7F | `WAKE_SRC_UNKNOWN` | 未知 IRQ（只进到达计数，**永不进环**） | 其余 |

0x08–0x7E 预留段（`wake_src_valid` 恒 false；0x07 自 sim-S2 起为 POWER_KEY
到达-only 占用——同恒 false 不进环）；真机板级源随驱动刀
add-only 入册。四元组执法（`nr_total/nr_defined/nr_registered/
nr_ceiling=45`）随 A 里程碑同刀生效（裁决 §4）。

## 3. 归因机制（per-CPU 语境 cell）

HAL `wake.rs`：`CELL: [AtomicU8; 2]`，**下一次 `note_wake` 应归的源**。
写点三处，读点一处（`on_wake`）：

1. **`note_switch` 顶（任务语境基线 = IPC）**：切入任务/idle 即设。park 派发
   prev=null、不发射 note_switch，因此在 `dispatch_from_park_ctx` 的
   context_switch 前显式同写；覆盖 CPU1 首任务与每次 park 醒来派发。
2. **`exception_irq` 四臂前**：SPURIOUS 早退之后 `saved = load();
   store(src_of(id))` → 分派四臂 → **单出口恢复 `store(saved)`**。窗封闭
   论证：IRQ 不嵌套（handler 全程 PSTATE.I=1，`trap.rs`）⇒ save/restore
   同核串行闭合；恢复 `saved`（而非清哨兵）保证臂后任务语境唤醒仍归任务
   侧（偏差 §10-1）。
3. **初值**：CPU0 = `KERNEL_BOOT`（boot 直跑窗归因；首个切换后该源计数
   冻结——spawn 不经 `note_wake`，`KERNEL_BOOT.wakes` 经验恒 0，G1.5 只
   断言冻结不断言 ≥1，§10-6）；CPU1 = `NONE`（副核 bring-up 前无语境，
   到达记账 = 绊网 panic）。

排序 Relaxed 足够：cell 只被本核读写（on_wake 在唤醒发生核上跑），无跨
核序承重；跨核读者只看单调计数（快照语义）。

## 4. 记账面（`WAKE_SRC_TABLE`，128 槽值直索引）

```text
偏移  字段            类型        语义
0     wakes           AtomicU64   本源唤醒事件数（on_wake）
8     irq_count       AtomicU64   本源 IRQ 到达数（§6 分工）
16    no_waiter       AtomicU64   到达而无等待者（UART 良性竞态，§10-5）
24    first_ts        AtomicU64   首次唤醒 CNTVCT（哨兵 u64::MAX，fetch_min）
32    last_ts         AtomicU64   最近唤醒 CNTVCT（fetch_max）
40    last_ack_ts     AtomicU64   最近 IRQ 到达/派发戳（v1 = 到达戳，§10-4）
48    last_woken_id   AtomicU32   最近被唤醒任务 id（名字 FNV-1a-32，§10-3）
52    flags           AtomicU16   分类/sticky 位（下表）
54    ts_domain       u8          时戳域（v1 恒 0；G1.5 断言活动槽 == 0）
55    _pad            [u8; 5]
= 64B 整（repr(C)，telemetry_open 快照面的 ABI 形状 day-one 定型）
```

flags 位面（add-only）：bit0 `WSRC_F_TIMER_CLASS` / bit1
`WSRC_F_IRQ_LINE` / bit2 `WSRC_F_SGI_INTERNAL` / bit3
`WSRC_F_HAD_NO_WAITER`（sticky）/ bit4 `WSRC_F_SLEPT`（v2 预留恒不置）。

**槽表 128 值直索引**（`table[src]`，裁决原案 32 槽计数枚举——偏差
§10-2）：让 UNKNOWN 0x7F 有真槽可落**到达计数**，未定义段写点构造性不
达；.bss 8KB 同量级。守恒底账 `WAKE_ACCT_N`（独立 AtomicU64，**不随
trace_off 关**）：on_wake 槽写在前、N 末位 Release；并发瞬态只保证
`Σ 槽 wakes ≥ WAKE_ACCT_N`（一次广播可醒任意多任务）。G1.5 守恒采用
双读稳定窗（两对 N/Σ 均无变化且相等）——锚在独立总账而非环账
`wake_total()`（环账
随 t_off 冻结，裁决 §3-5 A 被反证点）。

## 5. 环记录面（`WakeRec` 扩 `source:u8`）

32B 保形：`source: u8` 吃 `_pad[0]`，`_pad` 缩 `[u8; 2]`（ABI day-one
定型的正统演进路）。`wake_check` 增第五查：`wake_src_valid(r.source)`
——环内恒 ∈ 6 真源（NONE/UNKNOWN 写点 panic 在前，事后审计兜底）。
`ts_domain` 不预烧进环（v2 SLEPT 域引入时再消耗 pad，裁决 §1-问④③）。

## 6. IRQ 到达计数分工（内核回调槽 vs HAL 侧计数）

| 源 | 计数点 | 时戳语义 |
|---|---|---|
| TIMER | 内核包装 `irq_tick_acct`（`set_irq_dispatch` 注册面前套） | post-EOIR 派发戳 |
| UART_RX | `rx_irq_notify` 顶（notify 槽无条件调用后） | pre-EOI 到达戳；`n==0` → `note_irq_no_waiter` |
| SGI_RESCHED / SGI_TLB / UNKNOWN | HAL 侧臂计数（`SGI_SEEN` 既有 / `TLB_SEEN` 新增 / `UNKNOWN_SEEN` 自函数内 static 升格），**G1.5 `wake_src_merge_hal()` 一次快照合并**（store 单调值幂等） | —（无唤醒路径，只计到达） |

分工依据：timer 槽只对 CNTV、rx 槽只对 PL011——SGI×2/未知臂**没有内核
回调槽可挂**（HAL→内核回调槽反转三先例不为此开新面），计数留 HAL、内核
合并读。

## 7. 无主唤醒三分类（PM-12 §3.3-4 定表）

| 类 | 语义 | v1 处置 |
|---|---|---|
| Ⅰ NONE（cell 未接线） | 写点漏路由（新切换位/新 IRQ 臂漏设 cell） | **on_wake 写点 panic**（强于事后计数） |
| Ⅱ UNKNOWN（未知 IRQ 有唤醒路径） | `src_of` 漏臂或 cell 直写 | 同上写点 panic；IRQ 级到达计数照记（真未知号可观测） |
| Ⅲ ORPHANED（持有者已死仍被唤醒） | 任务生死绑进程（v1 无孤儿任务） | **构造性空类**；动态段/驱动刀复活存活扫描时再议 |

## 8. 执法面（三段）

**写点（L0，盖全历史）**：`on_wake` 首段 `src != NONE && src != UNKNOWN`
两 panic（负延迟同族）；环写与直方图随 trace_off 让位，记账不随。

**G1.5（boot 尾，watchdog 内恰一次、`exit_current` 前——R-0 落点契约同
BENCHWAKE；**无条件**，不随 t_off 让位）**，五断言组：

1. 守恒：双读稳定窗内 `Σ 槽 wakes == WAKE_ACCT_N`（两路失联执法；不做固定差值帽，防一次多任务广播假红）；
2. 无主终检：NONE/UNKNOWN 槽 wakes == 0（写点在前的收口防线）；
3. 环境活水：TIMER ≥ 1（expire_timeouts ← on_irq_tick 全程在跑）且
   IPC ≥ 1（任务语境基线）——零值 = 记账链断，防「静默全绿」；
4. KERNEL_BOOT 冻结：round-over-round（watchdog 环尾稳态窗逐轮 + 尾部
   终检）——调度器启动后 boot 归因再涨 = cell 基线写点漏路由；
5. `ts_domain == 0`（活动槽——v1 单域）。

**WAKESRC 单行标记**（smoke 收割面，G1.5 ok 之后）：

```text
WAKESRC acct=<N> T=<w/i> U=<w/i/nw> R=<w/i> L=<w/i> I=<w> K=<w> X=<0/i>
```

（T=TIMER U=UART_RX R=SGI_RESCHED L=SGI_TLB I=IPC K=KERNEL_BOOT
X=UNKNOWN；w/i/nw = wakes/irq/no_waiter。行宽上界 ~340B 绝对最坏、实际
~80B。）

**ktest 纯面（`test_wake_src`，sched::init 前跑——槽表 pristine）**：
A 枚举值域（互异/≤0x7F/端点锚）；B `wake_src_valid` 白名单；C
`wake_src_class` 分类位映射；D 布局钉（32B/64B）+ 未触槽原语
（first_ts 哨兵/ts_domain=0）。

标记单源同步：`tools/markers.sh` 裸相 28→29（+`WAKESRC acct=`）+
`smoke-image.sh` KERNEL_MARKERS 硬拷贝 + 规则/07 计数表。

## 10. 与裁决的记录在案偏差（全部实施期发现，理由在案）

1. **臂尾恢复 `saved` vs 裁决原文「臂尾清 SRC_NONE」**（裁决 §5-2）：
   清哨兵会把臂后任务语境的唤醒错判成 Ⅰ 类 panic（IRQ 返回点不必然紧跟
   切换）；save/restore 才真正闭合。裁决此处措辞过糙，本文修正。
2. **128 值直槽 vs 裁决 32 槽**（裁决 §1-问③）：值直索引让 UNKNOWN 有
   真槽落到达计数、未定义段构造性不可写；8KB .bss 同量级。
3. **`last_woken_id` = 名字 FNV-1a-32 vs 裁决 `last_woken_pid`**：v1
   Process 无 pid 面；id 稳定性由名字承重（裁决 §1 补件①同款）——演进
   节挂 pid 轴切换。
4. **UART `last_ack_ts` = pre-EOI 到达戳 vs 裁决「ack=post-EOI 戳」**：
   rx_notify 槽在 EOI 前被调；v1 语义=到达戳（TIMER 槽=派发戳，两点位
   不同义，快照头注释区分）；post-EOI ack 接力（借 `Task.wake_vct`）=
   v2 精化项。
5. **UART `no_waiter==0` 断言降级为只打印**（裁决 §5-5 原设硬断言）**：**
   控制台醒-复睡窗内到达（位已置、poll-first 必命中、无丢唤醒）在
   rootfs 输入流下是**良性竞态**——硬断言会 flake；保留计数 + sticky 位
   + WAKESRC 行 nw 值，不设门禁。
6. **KERNEL_BOOT 只断言冻结、不断言 ≥1**：spawn 不经 note_wake（实证
   `sched.rs` 写点清单），`K.wakes` 经验恒 0；冻结断言（round-over-round
   等值）才是该源的正确执法形状。
7. **G1.5 活水断言收窄为 TIMER+IPC**（裁决 §5-5 列了 UART_RX）：裸相无
   输入流，UART_RX wakes 合法为 0——列入恒真集会假红；UART 活水归
   rootfs/注入相观察面。

## 11. 演进节（v2+ 挂账）

- **post-EOI ack 接力**：`Task.wake_vct`（在册）承载 ack 戳，
  `last_ack_ts` 语义精化为「被唤醒方领走时刻」。
- **SLEPT 域**：挂起刀引入双钟后 `ts_domain` 启用 + `WSRC_F_SLEPT` 置
  位；消费规则：域 ≠0 记录先加 `slept_ns` 偏移再与域 0 比较。
- **动态段复活**（驱动刀接管 IRQ 时）：`[[wakesrc]]` 仍走 add-only 编译
  期（板级源集随板卡编译期定）；若 0x88 登记面复活，幂等键 = name（§10-3
  同轴）。
- **pid 轴**：Process 出 pid 面后 `last_woken_id` 切换/并列，快照头
  version 升。
- **sim 注入相**（PM-12 §3.3-6）：全量执法（A4 无主=失败）等 sim 线；
  boot + 控制台相先行（本刀已覆盖）。
