## §0 定位与边界

**定位**：G2 已过（2026-11-04，S-5 收官）后，v2 主线下一关卡 = G3（多核 + 全抢占）。本文立四件规格——①全抢占机制面（§2）②lockdep 立项（§3）③延迟基准双跑口径（§4）④激进配置常驻 soak 模板（§5）——并提案刀序（§6）。

**非目标**：本稿不动任何代码；零 syscall/ABI 面（抢占是内核内部机制——冻结常量「并发/基线」行的分阶段兑现，非破冻）；不宣称 G3 过关。

**话术限定**（沿母案 §7）：全抢占宣称以 G3 过关为准——此前一律「抢占点可抢占（G1 形）+ 双核（G2 形）」；S-2 话术限定「内核串行 + 用户并行」已随 S-3/S-4 演进为 per-CPU + 细锁，但「syscall 主体不可抢占」至今保留（E0 纪元刻意不改——免锁根基）。

## §1 现况盘点（四面侦察基线）

### 1.1 机制面

- **切换点家族**（sched.rs 符号锚，行号随时漂、定位按符号）：`yield_now` :688 / `exit_current` :757 / `exit_current_with` :765 / `try_preempt` :1729（4-4 直切点）/ `on_irq_tick`（G1 tick 抢占）/ `on_sgi_resched` :2190 附近（S-3b 义务⑧ CPU0 SGI 快速重调度）/ `park_recheck`（副核 park 环承接）。
- **免锁根基**：v1 = SVC 入口硬件置 DAIF 屏蔽 + handler 全程不解蔽（隐式临界区）→ S-2 E0 显式化 BKL → S-3/S-4 E1 per-CPU + 细锁 + 锁序立法（KERN_LOCK 已于 S-3c 退役）。「syscall 主体不可抢占」语义至今未变。
- **preempt-on-wake 现况精确口径**：今天只有两个例外——
  1. `try_preempt`（IPC fastpath send 面，syscall.rs:1615）：唤醒后若出选者 `prio_effective` **严格高于**当前任务才直切（seL4 direct switch 的 v1 形态）；
  2. `on_sgi_resched`（跨核唤醒 CPU0 侧）：SGI 到 = 队列刚入新任务即旋转出选（**同 eff 也切**——轮转语义，非优先级判定）。

  **通用唤醒路径 `wake_matching`（:1600 附近）注释明言「不立即抢占：唤醒方自身不切换，等 tick/yield 再切」**；跨核唤醒落对核队列后同样只等对核 tick/SGI（TCG 有效 tick ≈ SLICE_HZ/2 → 最长整片延迟，:2178-2180 注释实证）。
- **切换原语已支持 syscall 主体中途切走**（`block_current` / `try_preempt` 契约先例：异常帧留内核栈、切回续行、eret 恢复 SPSR）——**G3 缺的是通用可抢占窗（DAIF 解蔽 + 抢占点），不是切换机制本身**。
- **锁纪元**：E0（BKL）/ E1（per-CPU + 细锁）已落；E2（per-ChannelEnd / per-Vmo 逐域下放）未启（母案 §2.1 表，S-4 起/v2 归属）。

### 1.2 lockdep

- `kernel/` 全树 grep 零命中——**零基础**。现况执法三件：注释纪律（S-2 §6 R8 契约注释立法）+ 锁序立法（S-3 §9.7：SQ > 队列 > REAPQ > 表 > 分配器 > ASID > 打印，七类全序）+ 持有集位图（S-3c c-1 义务⑥，debug 断言面）。全是**静态纪律，无运行时检测器**。

### 1.3 延迟基准

- `kernel/src/bench.rs` 629 行 19 fn：微基准 6（cntvct_pair / frame_alloc4k / frame_alloc64k / vmo_commit1p / vmo_rw4k / handle_evt）+ churn 3 族 + xh 6 族 + run/bench harness；标记面 = `BENCH ok n=6` + `BENCHCHURN ok` + `BENCHXH ok`（吞吐/容量面，`基准与压力测试设计.md` B-0/B-1/B-2/R-1 家族）。
- **无延迟分布基准**——无 wakeup→run 直方图、无 p50/p99 尾延迟口径；G3「低尾延迟」关卡无对账面。
- trace 现况：`telemetry.rs` 静态预储双环（切换环 3-4c + 唤醒环 4-0，零分配热路径）+ watchdog 机器断言已落；**tracepoint 宏 / chrome 导出 / trace 服务未落**（`可观测性设计.md` :56 落地注——挂 v2）。

### 1.4 soak 家族

- `just soak`（S-1 单核六断言）+ `just soak-smp`（S-5d 双核满载八断言）；**激进配置（全抢占 + 细锁全开）无常驻模板**——纪律②（测试策略 :37）自 G3 起生效，尚无落点。

## §2 全抢占机制面规格

**目标形态**：任意安全点可抢占——SVC 主体分段解蔽 + 通用唤醒抢占；分阶段语义等价小步（纪律①——FreeBSD 5.0 大爆炸是反面教材）：

- **阶段 P-A 抢占点加密**：per-CPU `preempt_disable` 计数 + 显式抢占检查点族（syscall 返回边界、长循环切片点、拷贝类大 buffer 分段处）。不变量：计数 > 0 窗内禁切换（等价今日 IRQ 屏蔽窗语义）；解蔽点 = 检查点（计数归零即探峰出选）。SVC 主体按域分批解蔽（首批候选：console 写、pipe 拷贝、FAT 读路径——每批先列「现依赖 IRQ 屏蔽的共享触达清单」再动）。
- **阶段 P-B preempt-on-wake 通用化**：`wake_matching` 族唤醒直切（同核：`try_preempt` 既有判定从 IPC fastpath 单点扩到通用唤醒面；跨核：SGI kick 已有，补齐对核侧优先级判定——对核在临界区内则置 need_resched 位，出窗即切）。唤醒延迟上界从「最长整片」缩到「临界区出窗」。
- **阶段 P-C 临界区收缩联动（E2）**：spin 临界区 preempt-safe 化——逐域下放（per-ChannelEnd / per-Vmo 锁）时同步裁决「preempt_disable vs local IRQ 屏蔽」二选一；不设固定刀号，随 P-A/P-B 推进暴露的共享触达逐块起刀。
- **每阶段验收**：ABI 零破冻声明 + 主 smoke 零漂移 + test-host 全绿 + **金丝雀重审记录**（唤醒直切会抬切换率——`switches=N` 严格递增语义保留但斜率变，稳态矩阵基线随阶段重标定；对照雷册 §A123 增量差设计判例）。

## §3 lockdep 立项（零基础）

**形态**（立项记录，实施刀细化）：debug 编译面 + 运行时检测器——

1. **cargo feature `lockdep`**（默认关——release/CI 主面零成本，激进镜像才开）；
2. **锁类注册表**（lock_class 静态登记，覆盖 SpinLock 家族 + 打印锁）；
3. **取放点 hook**（acquire/release 内嵌 debug 面，release 构建编译消除）；
4. **取放序环检测**（DFS 全序校验 → 环 = panic + 持有链打印，fail loud）；
5. **锁外打印禁令执法**（PRINT_LOCK 契约机器化——S-2 注释纪律升级为检测面）。

**与现况联动**：锁序立法（§1.2 七类全序）作为 lockdep **先验序**——检测器校验「实现不违立法」而非重新发明序；持有集位图（c-1 义务⑥）复用为持有链数据源。

**kill criteria**：debug 构建慢 > 3× 或误报率 > 10%（findings 大半是噪音）→ 降级为取放 trace 面（保留 1-3 项，弃环检测）。

## §4 延迟基准双跑口径

- **新增延迟分布基准**（B-0 家族扩，暂名 bench-lat）：wakeup→run 延迟直方图 + p50/p99——唤醒源三路（IPC send 唤醒 / timer 超时唤醒 / SGI 跨核唤醒），对拍今日基线（「最长整片」口径）证明 P-B 收益。
- **trace 开/关双跑**（`可观测性设计.md` :52 过关要件）：同二进制 telemetry 记录面开/关两配置各跑全基准 → 基线双份入库（bench_baseline 家族扩）→ 关-开差值 = trace 劣化度，帽 = 关基线的 x%（x 实施刀首标定，参照 R-1 δ 档先例）。
- **纪律**：跨机不可比承 bench-icount 先例（雷册 §A95/§A109 家族）；TCG 下 CNTV tick ≈ SLICE_HZ/2 口径注意（AGENTS 常见命令节）；尾延迟帽后续进激进 soak 断言面（§5）。

## §5 激进配置常驻 soak 模板（纪律② PREEMPT_RT 形）

- **配置面裁决**（倾向已记，实施刀定谳）：**编译期 cargo feature 集**（激进配置 = `preempt-full` + 细锁全开 + `lockdep` 的 feature 组合镜像）——独立二进制、语义纯净、回滚 = 换镜像；fw_cfg 运行时开关被否决理由 = 语义混装（同二进制两套抢占语义，回归面不可分）。
- **模板**：soak-smp.sh 骨架复用 + 激进镜像 + 新增断言面——尾延迟帽（§4 基线）+ lockdep 面（激进镜像默认带 lockdep feature）+ 既有八断言全保留；命令 `just soak-g3 [分钟]`（命名随实施刀定，落 `命令速览.md`，不进 CI——小时级与 soak 家族同口径）。
- **逐块转正流程**：激进 soak 暴露问题 → 修 → 稳定 N 跑（N 首跑标定，参照 S-5d 银行跑先例）→ 该块从激进 feature 转默认配置——转正记录逐条进沿革。这是 PREEMPT_RT 二十年上游化模板的 BerryOS 操作化。

## §6 刀序提案（每开发周期 ≤1 刀，守 SMP 线节奏）

| 刀 | 面 | 验收 |
|----|----|------|
| G3-1 抢占点加密（P-A 首批） | preempt_disable + 检查点族 + SVC 首域解蔽 | 主 smoke 零漂移 + test-host 全绿 + 金丝雀重审记录 |
| G3-2 preempt-on-wake（P-B） | 通用唤醒直切 + SGI 对核侧补齐 | 上两条 + smoke-smp 八相 + 唤醒延迟基准首跑对照 |
| G3-3 lockdep（§3） | feature + 环检测 + 立法校验 | debug 构建跑主 smoke + 误报率 < 10% |
| G3-4 延迟基准 + 双跑（§4） | bench-lat + trace on/off 基线双份 | 基线入库 + trace 劣化帽首标定 |
| G3-5 激进 soak 常驻（§5） | 模板 + 首银行跑 + 转正流程启动 | 银行跑 PASS（含尾延迟帽） |
| G3-6 关卡收官 | 全要件复验（延迟基准 + lockdep + trace 双过 + soak） | 测试策略 G3 行转「已过」+ 话术落档 |

- E2 临界区下放（P-C）穿插 G3-2..G3-5 按需起刀，不占固定刀号。
- G3-3（lockdep）与 G3-4（基准）无强依赖，可按周期容量对调；G3-1 → G3-2 顺序冻结（直切面依赖检查点基建）。

## §7 开放问题（实施刀入口侦察清单）

- preempt_disable 计数与既有 IRQ 屏蔽窗（`svc_window` / block_current 协议）的交织面——P-A 首刀侦察项。
- 副核 park 环在全抢占下的形态（park_recheck 保留 or 被 need_resched 合流）——P-B 侦察项。
- 稳态矩阵/金丝雀在全抢占下的基线重标定流程（谁先谁后、几次跑定谳）——每阶段验收内嵌。
- bench-lat 的唤醒源构造（内核任务对 or EL0 用户对）——G3-4 侦察项。
