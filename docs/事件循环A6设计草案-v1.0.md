## §2 尾部分析与 A 批收官裁定

§1.2 四件尾部逐一裁定，**无一件是「A 批内另立一刀」的料**：

1. **poll timeout（#1）**：A4 §3.2 已裁定不动——是裁定不是欠账；阻塞语义经 epoll_wait 已有宿主（A4-1 timeout 三档）。
2. **ppoll/select（#2）**：零消费者——现探现补纪律执法中（不立桩 = 纪律的正确执行，桩面惰性是设计）。
3. **sigaction 族（#3/#4）**：真身化 = 内核信号机制本体 = **下一卡范围**——不是 A 批尾部欠账，是下一卡的本体入口。
4. **eventfd/inotify（#5）**：挂账维持（v1 运行期不可达——消费者出现即裁留件复活，tail -f 面）。

**裁定：A 批（A1 容量前置 + A2-A5 事件循环/POSIX 原语前置线）就此收官**。交接物四件：①五标记验收基线（§1.1）②berry-poll 聚合器 / EpollTable / SocketTable 号段工程（fd 段编译期执法族）③net_gifts spawn 装配线（gift[6]→GIFT_H[4] 协议在册）④拓扑降级双门契约（netd_h()==0 + ENODEV(19)，EVS/SKT/EPL/NETS 四同款定型——A5-2 立法）。

**与 vision 对账**（A5 结算 stride_decision.next_probe）：prediction「Remaining tail is docs-only; no new dependency or ABI thaw」——盘点证实成立：尾部四件零代码刀需求、零新依赖、零 ABI 触碰；唯一 ABI 面（信号 add-only 新号）属下一卡本体立法（§5 风险注记）。
