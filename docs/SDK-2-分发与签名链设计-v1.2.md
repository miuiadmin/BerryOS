## 二、信任模型总纲（两层分离 + 机器裁决）

- **两层信任显式分离**：**源钥 = 通道**（镜像/仓库的身份），**包钥 + lineage = 身份**
  （开发者的身份）——签名索引只**见证**包钥，不**起源**信任（ostree summary
  默认不验缝隙的反面教材）。
- **换钥全机器裁决、零用户指纹比对**：三十年实证用户侧核验不可依赖（认证仪式
  自发率 14%，警告点击穿透 70.2%）——同 lineage 验链自动通过；跨 lineage =
  **新身份并行安装**（不覆盖、不询问）。永不引 X.509 链。
- **信任账本（语义 day-one，落盘随实施分期）**：
  `{lineage_id → anchors[(公钥, anchor_type ∈ tofu|system|ca|oem-system)], gen_max, ver_max}`
  ——`ca` 为占位：终态案 C（TOFU 起步→商店时代 A+CA 双验）的前向兼容口。
  `oem-system` = **OEM 系统锚**（ADR #82 V4 预埋，闸 B 件：OEM 厂签系统件的
  身份位，v1 值恒空）——条目四字段占位 `kind/issued_by/cert_status/
  last_revision`（v1 值恒空/active；`cert_status` 事实源单一化为签名索引，
  账本不存或只读回显）。**旧验证器对未知枚举保守拒绝 + 两步发布纪律**（新枚举
  进账本前，全网最低验证器版本先升——#82 附录二 Q6；anchor_type 全程 add-only）。
- **官方源钥出厂预装**：随镜像分发（首触信任**不走网络**——Linux Mint 2016
  官网掉包课）；预装清单随镜像工程落，pending 后继钥 day-one 登记（HPKP 课）。

## 三、签名（支柱 1 定案）

- **分离式 `app.bap.sig`**（不内嵌——.bap 载荷是冻结面 L1）。算法 **ed25519**
  （自建 berry-crypto，见下）；摘要 **SHA-512/256**（复用 ed25519 内部 SHA-512
  一份实现，guest 免带双哈希）。
- **key_lineage 语义修正（草案硬伤）**：ADR #59 预留壳 1..=16B **装不下** 32B
  公钥——lineage 定为**稳定身份别名**（Apple Team ID 同构：短、稳定、人读），
  轮换链/公钥/代际全进 .sig 信封。
- **.sig 信封（设计面，未冻结——§九关门触发器）**：
  `ver(u8) + alg_id + lineage_id 回声 + gen(u32 单调) + 当前公钥(32B) +
  线性单路径轮换链（每节点 = 旧钥对(新钥, gen, lineage_id) 的签名） +
  顶钥对(.bap 全字节摘要 + manifest 关键域摘要 + 信封头)的签名`。
- **换钥纪律**：重叠双签窗（Debian 2006 一刀切断粮课——过渡期新旧钥任一通过
  即验签过）+ 信封 pending 后继钥位 day-one。
- **护栏**：①防剥离——已签 id 再见无 .sig = 拒载；②单调水位 gen_max/ver_max
  防回放，账本未落盘期间**诚实声明「回放防护未生效」**（降级可见）；③验签与
  装载共用 ADR #59 TLV 单解释器——**禁双解析器**（Janus CVE-2017-13156 课）。
- **berry-crypto（自建）**：纯函数 crate，手写 ed25519 + SHA-512；合入门槛 =
  RFC 8032 测试向量 + Wycheproof ed25519 全向量（strict 语义）CI 门。延续仓
  零外部依赖纪律；数周级工程，不阻塞 host 面（host 工具先行）。

## 四、更新与增量（支柱 2 已裁推迟 v2）

- **v1 升级 = 卸载重装**（拍板 ②）；卸载 = 显式信任重置（账本该 lineage 条目
  删）+ 墓碑宽限记录。
- **freshness 水位（便宜件，设计面保留）**：per-app `ver_max` 单调水位——防
  回滚（旧版本号拒装）+ 防冻结（长期不更新可见）；仅系统路径可写。
- **回滚边界（v2 支柱 2 的前置纪律，先立）**：网络方向**只许升**；仅本地失败
  证据（墓碑/连续崩溃）才许回拨 + 失败版本拒载名单 + 回滚计数帽——自动回滚
  可被武器化（故意滚回带 CVE 旧版）。
- **增量更新 = v2 闸门三条件**（立法确认）：①BAP_MAX 抬帽联动（GUI 资产时代）
  ②单包压缩后 ≥50MB ③带宽成本可计——三条件同满足才立项；业界分界 ≈50MB，
  现 BAP_MAX=4MiB 差一个数量级。若立项：delta 仅传输层、重建整包后**同路验签**
  （禁独立路径）+ 索引 add-only。

## 五、分发形态（支柱 3）

- **v1 = 镜像内置官方源静态实例**：源元数据（源钥 + 签名索引）随镜像打包——
  netd 现仅 4 op（DNS/TCP 开/往返/关）无 HTTP/TLS、MSS=128，在线拉取 v2 再议。
- **签名索引必做**：源钥签索引；条目 = `{id, 三值版本, size, 哈希, key_lineage,
  公钥见证, last_revision, cert_status}`（六→八字段，ADR #82 V5 预埋：
  `last_revision` = 见证时的上游平台版本序，`cert_status` = 认证状态——
  事实源单一化为本索引，账本侧不存或只读回显）；索引级单调版本号防回滚/
  防冻结；**无墙钟过期**（QEMU 无可信钟）+ **版本当时钟**（一切时间义务——
  过期/停更/SLA——换算为上游版本序比较，不依赖墙钟，#82 附录二 Q12）；
  格式复用 ADR #59 TLV 单解释器。
- **sideload = 未知来源系统开关**（拍板 ④）：产品镜像默认关（Gatekeeper 式
  姿态）；**dev 镜像构建期预开**——smoke/selftest/host 注入链不卡门；开关状态
  与安装来源进 per-app 账本记录。
- **记录账本**：per-app `{锚定公钥, 来源, boot 计数, 版本水位}` + per-source
  `{指纹, 代际, pending 钥}`——与 §二信任账本同库不同键。零 TrustAll 永不立。
- **渠道门槛数据面**：`source_channel` 进 per-app 元数据保留（可见性策略预留）；
  遥测削至近零（零受众=空集）；target 门槛杠杆推迟至分发面存在（双轨设计 §五）。

## 六、实施分期（不外发裁定的排期面）

| 期 | 件 | 验收 |
|---|---|---|
| **P0 host 面** | mkapp 产 .sig + abi_revision 打戳；宿主验签工具；索引生成工具 | host 测：正样例 + 篡改/断链/换钥三负样例拒；索引版本号回降拒 |
| **P1 berry-crypto** | 自建 ed25519+SHA-512 crate | RFC 8032 + Wycheproof 全向量 CI 门 |
| **v2（推迟集）** | guest 验签 + 账本落盘（appd↔fsmgr 接线）+ 支柱 2 双槽/原子切换/自动回滚 + 在线源 + 增量闸门 | 随 v2 立项另定 |

## 七、manifest v2 衔接

distribution 域：`abi_revision`（双轨设计 §二）+ `source_channel`（来源记录）。
security 域：key_lineage 从预留壳转**身份别名**实用（签名块引用同一 lineage；
壳尺寸不变，语义收窄——ADR #59 勿需改）。

## 八、ADR 落册点

- **预 #77（随 SDK-2 开刀落册）**：分发与签名链立法（本档定案）；**#77 将并入
  OEM 身份**（ADR #82 信任簇 Q1/Q6/Q12 机制维 + V4/V5——lineage 星状分配、
  `anchor_type` 扩枚举与账本/索引字段执法随 #77 落地；SDK-2 开刀前最晚重议点
  = P0 合入前，见 #82 重议触发器）。
- **全签策略执法 = 关门触发器立法（进 #77）**：触发条件 = ①外发决定反转，或
  ②首个第三方 .bap 在野——先到即关门，此后无签包拒载（窗口论据：生态为零时
  立法成本趋零，错过不可补）。
- 本档不触碰架构决策.md（落册随 SDK-2 开刀，预号仅占位防撞）。

## 九、验收线（裁剪后）

1. host：mkapp 产 .sig → 验签过；篡改载荷/断轮换链/跨 lineage 三负样例全拒。
2. 索引：生成 + 验签 + 单调版本号（回降 = 拒）；条目八字段齐全（v1.2 起，
   含 `last_revision`/`cert_status`——V5）。
3. sideload 开关：关 = 拒装 + 显式错误；开 = 装 + 账本记录来源。
4. berry-crypto：RFC 8032 + Wycheproof 全向量过（CI 门，不过不合入）。
5. 诚实降级：无账本运行时「回放防护未生效」可见；防剥离样例拒载。

## 十、与草案 v1.0 的差异（审计面）

key_lineage 壳装轮换链 → 身份别名+信封（硬伤修正）；案 C 三案对比 → 定案+
五修正；两版并存原子切换 → 推迟 v2；源列表+TOFU 在线 → 镜像内置静态实例；
sideload 退化情形 → 系统开关；哈希/账本/护栏/分期/触发器全部新增。
