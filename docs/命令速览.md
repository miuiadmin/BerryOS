# 命令速览（仓库根）

> 定位：`AGENTS.md`「常用命令」的展开版，也是 just 配方的**单一事实源**。
> AGENTS 只留 8 条高频命令；新增/改名配方改本表，若属高频再同步 AGENTS 一行。
> 产物在 `~/.cargo-target`，路径解析单源 = `tools/paths.sh`。

## 前置（macOS 一次性）

stable 预编译 core 免 nightly；brew 的 qemu 含全 arch：

- `brew install qemu just`
- `rustup target add aarch64-unknown-none x86_64-unknown-none aarch64-unknown-linux-musl`

## 全表

```bash
just build          # 内核 ELF（自动先跑 build-user 补内嵌产物）
just build-user     # 用户程序 → 平像 + mkapp 打包 .bap + mkcpio 产 rootfs.cpio
just run            # QEMU virt 冷启动，行首 1 = 起始 EL1；halt 后 Ctrl-A X 退出
just default        # = run（无参数默认入口）
just run-el2        # virtualization=on，行首 21 = EL2→EL1 eret 降级
just run-rootfs     # fw_cfg 挂 rootfs + virtio 盘网 → svcmgr 消费链全谱（rootfs 相 51 标记）
just smoke          # 无人值守八跑冒烟（CI 同款）；标记清单 = tools/smoke.sh，语义注解 → 雷册 §C
just test-host      # host 单元测试（不依赖 QEMU）；host 面总口径以本命令输出为准
just abi-check      # ABI 单源守卫：abi.toml 三面产物逐字节比对（挂 build/smoke 前置）
just bcts           # BCTS 兼容性测试回放（ADR #84）：冻结件 tools/bcts/frozen/bcts@<rev>.toml 逐标记回放对账；--dry 清单回显
just abi-gen        # ABI 再生（改 ABI = 改源 → abi-gen → diff 随源入册）
just docs-guard     # 入口规则门禁：AGENTS 行数/字符/行长/探针/锚点/迁出目标 + CLAUDE 预算（build 入口/CI 前置）
node .agents/tools/check-docs.mjs   # Curia 文档自检：.agents/ + docs/ 头块/归属/断链（--strict 提交把关，报告模式只列不拦；非 just——直调 node，bench.py 同例）
just writable-globals # 可写全局清单门禁：新增 static mut 必须入册（check/CI 前置）
just size           # 内核体积基线报告（CI 同步打印）
just size-release   # release 内核体积基线（只报数不设门禁）
just build-x86      # x86_64 构建（必须显式 --target——根 config 锁 aarch64 跨 workspace 命中）
just run-x86        # QEMU pc + PVH ELF，七标记（PVH/TIMER/EXC/CTX/SYS/X86 ok）
just smoke-x86      # x86 独立冒烟（7 标记恰一次；已挂 CI，不并入主 smoke）
just run-smp        # 副核 bring-up + 参与态手跑（全仓唯一 -smp 入口）
just smoke-smp      # 副核八相冒烟（不进 CI）：相1/2 恰一次+金丝雀门；相3 LB；相4 ASIDR；相5 TLBS n=10；相6/7 ALLOC/HT n=320；相8 PP a=b=320
bash tools/smoke-lockdep.sh "$(bash tools/paths.sh kernel)"  # lockdep 双相执法（相 1 裸相 G3-3 F10 + 相 2 rootfs 满拓扑 DPGN 终态 + dpg 四行行序 + ovfl 零计；先 just build-user 再 cargo build --features lockdep，default 面直拒）
just smoke-image    # EFI 整盘镜像独立冒烟（已挂 CI）：十段 + 字节对拍 + RX 注入
just build-boot     # BerryBoot EFI 构建链（staticlib → rust-lld 全链接 → elf2pe PE32+）
just image          # 整盘镜像 → out/berryos.img + manifest.txt（同输入同字节）
just run-efi        # AAVMF 挂 berryos.img + ramfb——十段引导 + 内核接续
just berry-build    # 构建宿主设备壳（tools/berry host workspace，显式 host target）
just berry ...      # 宿主设备壳 CLI：doctor/run/shot/screenshot/shell/input（tools/berry，host target）
just berry screenshot --out out/shot.png  # attach 正在跑的设备，CLI 截图（不重启）
just berry device start --profile phone --json  # headless host（默认后台；--foreground 阻塞）
just berry shell --attach <id>                   # 给 headless host 开窗（关窗只 detach）
just berry power reboot / off                # 对运行中 session 重启/关机
just berry logs --tail 50                    # 串口尾
just berry display list / set phone16        # profile 列表/记录 next-profile（需重启）
just berry display set phone16 --restart
just berry display set 600x1000 --restart    # 自定义 WxH      # 立即停旧 host、起 480×854 新 host（新 run）
just berry shortcut screenshot
just berry shortcut resolution|reboot|power  # 窗口动作的 CLI 等价
just berry events --tail 20                  # 事件 JSONL
just berry stats                             # state/profile/memory/qemu_pid
just berry record --out out/rec --frames 10 --interval-ms 200  # PNG 帧序列
just berry record --apng out/rec.apng --frames 10 --interval-ms 200  # APNG
just berry play script.json                     # 步骤化回放/自动化（expect 断言）
just shell          # GUI 优先：有 out/berryos-portrait.img → just desktop；否则 console
just desktop        # GUI 桌面：out/berryos-portrait.img + FAT12 数据盘 + tablet + 1080×1920@60（9:16）
just berry-smoke    # P0 宿主面冒烟：doctor + kernel marker + EFI 截图（不建窗口）
just build-release  # release 链接守卫（挂 CI）：fat LTO ADRP 断链形态补面 + assert-flip
just run-release / just check / just clean
just bench          # B-0/B-1 基准：BENCH 六行 + 基线对拍；--el0 四项；--update 分段刷新
just bench-rt       # R-1 实时基准（fw_cfg 门控，缺席零扰动）
python3 tools/bench.py --lat   # G3-4 bench-lat：-smp 2（fw_cfg 门控 lat 对）wake→run lane 表（ipc/sgi 双路在册；未立 just 配方——直调 python3，smoke-lockdep 同例）
just bench-icount   # B-2 -icount 确定性通道（独立基线；L2 紧门禁 --prove 五跑烘焙；跨机不可比）
python3 tools/bench.py --trace-dual   # G3-4b trace 开/关双跑（icount 两臂 + 关-开帽 TRACE_CAP〔首标定=0.0 结构性零〕+ 双家族基线；--update 刷双份）
python3 tools/bench.py --dpg   # G4-3 D/E 刀：dpgb/dpge 门控变体卷双 boot（D 首触延迟 p50/p99 出表 + E demand/eager footprint 差分 d<e 断言；R-1 同族只出表无基线；E 臂 ~16min；未立 just 配方——直调 python3，--lat 同例）
just soak [分钟]    # soak 长跑心跳六断言（S-5d 心跳 v2.1 九字段；不进 CI；勿与 smoke/run-rootfs 并行——echod/evsclient/sktclient 18080-18083 端口面冲突）
just soak-smp [分钟] # S-5d 双核满载 soak（默认 30，≥2）：八断言含 sw1 双臂（递增 ∧ Δsw1 ≥320/拍载荷活性主判〔双写者在席 ≥57% 口径〕）+ park 越窗守卫 + churn 递增（S-5e M1 防假绿）+ 均拍下界 40s；30min 级后台跑须显式 timeout ≥7200000ms；同端口面禁并行
bash tools/soak-g3.sh "$(bash tools/paths.sh kernel)" [分钟]  # G3-5 激进 soak（lockdep feature 面 + 尾延迟帽，默认 60 拍）：soak-smp 八断言 + lockdep 三计数 + lat 双路 max 帽〔LAT_CAP_IPC/SGI 环境变量可覆盖〕；先 cargo build --features lockdep（default 面直拒）；SOAKG3_CALIBRATE=1 标定模式；不进 CI；端口面禁并行 + 长跑显式 timeout ≥7200000ms（无 just 配方——smoke-lockdep 同例直调）
bash tools/smoke-dpgsoak.sh "$(bash tools/paths.sh kernel)"  # G4-3 C-full N=15 满槽 dpg soak（门控变体卷 dpgf.on，正装面零漂移零新标记）：DPGF n=15 满配 + DPGF2 n=3 槽回收 + ovfl∈[1,DPGF_OVFL_CAP] + dpg 五行行序 + 降级/panic 零；先 just build；DPGF_CAP_S〔默认 600s〕/DPGF_OVFL_CAP〔默认 40〕可覆盖；lockdep 面 = 再 cargo build --features lockdep；不进 CI；端口面禁并行——soak 同例（无 just 配方直调）
```

## 口径

TCG 下 CNTV tick 实测 ≈ **SLICE_HZ/2**（非内核 bug；详 `docs/规则/08-QEMU与仿真.md` / 雷册 §A8）——读切换率别被 2× 误导。

## 维护
