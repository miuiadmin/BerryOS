## §0 问题定谳（吞吐墙解剖）

- 实测：hexyl demand 装载 ≈6 页/s（X-5 收官定谳；帽被迫抬高 HEXYL_EOF_CAP 10s→180s、
  DEADLINE_ROOTFS 420s→600s，641a879）。
- 两个结构性因子（G4 §8 原文口径）：
  1. **每圈 5 发 0x23 中 4 发是 miss**：单子 5 活槽（musl 子 4 file + 1 zero-tail；
     槽面 5 = 串口 win=05 真值，hybrid 窗 eager 预填不占槽——berry-exec :151；
     34 交叉核对校准：其 X-5 期规划器 9 窗口径系过计，期望页/s 标定以 5 为基），
     单线程子进程在飞臂 ≤1 → 每圈顺序各发一发恰 1 发命中 + 4 发 -EINVAL 空返；
     4×33ms = 132ms/圈 ≈ 圈时 80%（TCG 往返实测）。
  2. **发现延迟与供给节拍耦合**：arm 落在 pager 50ms 空闲睡 / 1ms 让步睡窗内，
     发现靠下一圈扫到——原文「供页与扫频解耦」即指此。
- 多子：32 槽 ÷ 6 musl 子 × 5 槽，聚合同被扫圈串行帽钉死（≈6 页/s 量级）。
- **诚实面前提**：33ms/RTT = TCG artifact（真机 SVC µs 级）→ 本刀真机理由 =
  多子 syscall 计数摊薄 + 装载形状，TCG 止痛是顺带。花号理由立在多子形状上，
  防「真机无感」翻案（§7-3）。

## §2 案① 0x24 表批供给（双视角收敛形——呈批稿）

### 2.1 接口形状

- `0x24 pager_supply_mapped_table(tbl: *const PagerWindow, n: u32) -> i64`
- `#[repr(C)] PagerWindow { dv: u32, sv: u32, delta: i64 }` = 16B/项；
  n ∈ [1,32]，表 ≤512B 拷入内核静态 staging（ADR #9 零分配）。
- rc 语义（count-wins，最小冻结面）：>0 = 供页数（中途失败不回滚，失败槽 faulter
  恒唤重臂走自愈——与 0x23 同义）；0 供才报 errno；-EINVAL = n 越界 / 聚合
  NoneForVd；-EBADF = 门败；**池空且已供>0 → 即返计数不阻塞**（调用方有进展）；
  池空且 0 供 → 泊键阻塞（同 0x23 阻塞收货语义，醒后重扫表——虚醒由重扫吸收）。
- N=32 冻结 = EREQ_SLOTS（dpg.rs:197）/ PAGER_SLOTS（svcmgr:117）三源镜像；
  抬帽走 len 兼容（调用方传 n），不破冻。

### 2.2 内核改动落点

- 新 handler 邻 `:808`；注册行入 SVC_CLASS_SQ_RQ_TABLE（:3447 先例）。
- 每项：双门 + 双 retain（2N ObjRefs，单一出口统一释放）→ `el0_take_for`
  内环 continue-take 逐 dv（**签名不动 = E3d/e/f 零耦合，deliberate de-risk**）→
  `pager_supply_one` 原样复用 → SUPPLY_BUF 逐页（KL 持有语义同 dpg.rs:422-432）。
- KL 窗策略：整批 ≤32 页一窗（v1 单核简形；vmo 256B 分块先例 syscall.rs:3423-3431
  供未来分窗参照）；SMP 前强制复审——喘息点（每 K 项 klock_exit/enter，take_for
  每 KL 窗 fresh 重验，正确性无损）设计在案不启用，挂 G4 §8 邻位账本。

### 2.3 用户态改动落点

- `pager_main`：快照活槽 → 栈数组（按最近供给序排序 = 免费微优化，命中项早扫）→
  单发 0x24；rc>0 求和进 PAGER_SUPPLIED 原子（与主任务同 .bss，零 IPC）。
- **boot 探测回退**：启动期 0x24(dv:0, n:1) 探测——新核 = -EBADF（号在册，门拒
  坏句柄）；旧核 = -ENOTSUP（号未注册）→ 静态路由缓存走旧 0x23 环（保留不删）。
- **stall_kick 钉死 0x23**（:4769 现形不动）：kick 单发语义 + 0x24 池空会泊键 →
  kick 任务挂死风险；kick 行 `tag: kick ok/dead rc= sw=a/b win=NN` 逐字节不变。
- HOLD 闸（X-3c 让位）与 1ms 活跃让步原语义保留——dpg 自供族键竞速公平护栏。

### 2.4 ABI 合规（四/五点同步）

tools/abi.toml → `just abi-gen` → kernel/abi_gen.rs + user/berry-sys/abi_gen.rs →
ABI doc §4/§8.2 → 手写包装（§8.3 双镜像；无 .h 镜像——已核）。nr_total 36→37。

### 2.5 测试形与期望

- ktest E3h（新；合并让号——原案 E3g 撞 AM-2a 停顿台账臂，刀①改 E3h）：多 dv
  表批（≥2 窗各 1 臂 → 一次调用供 2 页）/ 静默纪律
  （ktest.rs:504）；E3d/e/f 原绿零改动。
- 期望（模型）：单子 24-29 页/s（≈4-5×）；6 子聚合 ≈102-167 页/s
  （页/批 = min(32, 臂数)）——v1 rich 档多进程装载的真实需求面。
  未建模项 Δ（子进程页间执行串行）使加速比带宽 1.3×-4.9× → **验收第一刀先落
  页/s 直测仪**（§5），用实测定标而非拍阈值。

## §3 案② 争议与裁决（本稿裁决：机制成立，重定义可接受，刀位呈裁）

### 3.1 原文与重定义

G4 §8 原文 ② = 「arm 即唤醒 pager key」（**内核措辞**）。地图实锤：唤醒半边已在
（dpg.rs:288）+ 池空泊键已在（syscall.rs:885-896）→ 案②的真缺口 = **pager 从不在
键上泊车**（miss 环 + 1ms/50ms 睡驱动扫圈发现）。吞吐派重定义 = 零内核零 ABI 的
**用户态锚窗泊车**：锚 = 最近供给窗，每圈 0x23(锚) 先发。

### 3.2 机制（主会话亲验链）

- 命中（臂属锚）→ 1 RTT 供给；rc=-22 → 新近序走查其余槽（**全 miss 稳态不可达**：
  池内臂必属自家某窗——svcmgr 是唯一供给方；仅注销竞态可达，走查即自愈）；
  **池空时 0x23(锚) 本身泊键阻塞** → arm 落地 → :288 唤醒 → 醒后重试
  el0_take_for(锚) → 属锚即供、属他窗 -EINVAL 返出走查。
- 安全性：双 retain 跨阻塞持有（SVC 入口 :827-848）；陈旧锚（窗注销/进程死）醒后
  take NoneForVd / -EBADF → 走查活槽快照自愈 + E3e 孤儿 GC 兜底。
- **与被否决变体的本质区别**：泊车条件 = 池全空 = 无任何等供者 → 睡眠无饿他风险。
  风险派否决的 NoneForVd-睡变体是「池有臂但无属我臂时睡」——那会饿他 dv 臂，
  死锁面成立；锚窗泊车不取该形态。

### 3.3 分歧实录与裁决

- 风险派否决三变体：不重构扫圈（≈+1%）/ NoneForVd-睡（死锁）/ 池变即唤（复杂度）
  ——**均未接战锚窗泊车本体**。其前提「miss 往返不可免——哪个 dv 有臂的知识只在
  内核，逐 dv 问询逼用户态盲扫」被「池空泊键+醒后重试」打断：泊在键上时发现零
  延迟，miss 只发生在「臂属他窗」局，锚窗局部性吃掉大头。
- 诚实带宽：p（下页同窗率）≈0.9（段内顺序装载）→ 24-29 页/s（3.8-4.7×）；
  p≈0.5（码/数据窗交替）→ ≈1.4-2×；**构造上不劣于基线**（最坏 = 今日扫圈形）。
- **本稿裁决**：机制成立（亲验链如上）、风险派否决不覆盖此形态 → 值得立刀位；
  但**顺序是裁点非机制点**（§4 呈裁）。风险派的「唤醒链 = 已建成尾延迟/自愈基建」
  定位正确——锚窗泊车正是让这套基建开始干活的最小用户态改动。

## §4 混合与刀序（呈裁）

- **混合刀：双视角同判不立。** ① 语义包含 ②（表入参把路由搬进内核，泊车/唤醒
  原语相同；① 落地后 ② 的锚窗/走查代码即死码）；残余增量 ≤3%（主要是 1ms 让步
  护栏——本就该保留）。反向叠加（①之上再留②独立形态）= 双供给路径并存 + 仪器
  双语义 + 死码，纯负资产。
- **刀序二选一呈裁**：
  - **序 A（吞吐派，本稿推荐）**：② 先（~30 行 svcmgr 扫圈重构，TCG 止痛立即
    兑现 + 直测 Δ 为 ① 验收数学定标）→ ① 后（结构终形：多子摊薄 + 段界走查消除
    + 最坏稳定）。② 代码被 ① 吸收，丢弃成本可忽略。
  - **序 B（风险派）**：① 单刀（X-5 刚收官，刚稳定的供给链少一次行为变更）；
    ② 作零代码确认件并进 ① 验收节叙述（:288 唤醒链 + poll-first 定态文档）。
  - 本稿倾向 A 的增量论据：全 lane 每日 smoke/bench 都付 hexyl 装载税，4× 止痛对
    迭代速度有复利；且风险派自己把吞吐阈值标为 openQuestion「首净窗基线×0.7」
    ——序 A 把这个基线测量前置成了产品件。倾向 B 的论据：行为变更面最小化。
    **裁权在仓主。**
  - **交叉核对回执（2026-11-08，34 lane）**：四点全过（锚点逐处亲验 + miss 数学
    与 win=05 实测自洽），刀序亦支持 A——付税人视角（全 lane 每次 smoke/bench 付
    装载税，帽 600s 已兑现；② 纯用户态 30 行落在 svcmgr 扫圈，blast radius =
    walk 环，EagerGuard/x5_foot 非回归网已在 bench 候着）。**两 lane 同推 A，
    裁权仍在仓主。**

## §6 风险 / 回滚 / kill criteria

- **R1 ABI 花号**（36→37/45，四十年合同）：理由立在多子形状（§0）非 TCG 止痛；
  revert 后 0x24 冻为在册未实现号（0x85 先例）。
- **R2 KL 窗拉长**：32 页批单窗 ≈65-130ms TCG；v1 单核无争用 OK；SMP 前强制复审
  （喘息点已设计未启用）。
- **R3 回滚三层**：boot 探测自动回退旧环（-EBADF vs -ENOTSUP）→ 内核 revert →
  号位冻结在册。
- **kill criteria**：净窗加速 <2× = TCG 噪声护栏即撤；任一零漂移面破 = 撤。
- ①②共通不动面：stall_kick / EagerGuard / demand 门 (a')-(e') / berry-exec
  逐窗供给表注册路径零改动。

## §7 开放问题（呈裁清单，两派合并去重）
