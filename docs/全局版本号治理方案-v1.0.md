# BerryOS 全局版本号治理方案

> 版本：1.0（v1.0）｜2026-11-12
> 【定位】基于 79 轮 workflow 三路研究（现状调查/业界对标/方案设计）的全局版本号统一方案。
> 【事实源】现状数据从仓内代码/tools 全量实勘；业界对标从 Linux/Android/Zircon/HarmonyOS/Windows 五系统提炼。

## 一、现状混乱点（按严重度）

| # | 混乱点 | 严重度 | 示例 |
|---|---|---|---|
| 1 | 内核 workspace 0.2.0 vs 用户态全部 0.1.0 | 高 | boot banner 0.2.0 / berry-sys 0.1.0 |
| 2 | SDK 版本 0.1.0 与系统版本 0.2.0 脱钩 | 高 | 三轨互不相干（0.1.0 vs 0.2.0 vs level 1） |
| 3 | user/ workspace 无 [workspace.package] 段 | 中 | 30 个 bin 各自独立 0.1.0 |
| 4 | GUI 域版本 v0 恒 1 无运行期拒绝 | 中 | VER_* 全 = 1 无协商执法 |
| 5 | [app] version 记录不消费 | 低 | mkapp 校验长度不校验兼容 |
| 6 | 六份 SDK 设计文档版本各异 | 低 | v1.0/v1.0/v1.1/v1.2/v1.0/v1.0 |

## 二、业界最佳实践对标

| 系统 | 层次 | 核心做法 | 最大坑 |
|---|---|---|---|
| Linux | kernel + userspace + ABI（3 层） | syscall 号永不改——ABI 是铁承诺 | distro 版本与内核版本脱钩致碎片 |
| Android | platform + API level + SDK + HAL + vendor（5 层） | API level 单一数字贯穿——一个数字管理所有兼容性 | vendor 分支碎片化 |
| Zircon | kernel + ABI revision + SDK（3 层） | ABI revision 是稳定 ABI 的唯一真值 | 工具链版本与 ABI revision 耦合 |
| HarmonyOS | OH version + API version + SDK + HAP + HDI（5 层） | API version 是原子单位 | HDI 版本与 API version 映射不透明 |
| Windows | NT + build + SDK + TargetFramework（4 层） | SDK version 独立于 OS version | WinRT/Win32 双 API 面版本分裂 |

**BerryOS 应学**：Android 的「API level 单一数字贯穿」+ Zircon 的「ABI revision 唯一真值」。

## 三、统一方案：三轨版本体系

### 层次表

| 轨 | 名称 | 格式 | 当前值 | 谁管 | 谁消费 |
|---|---|---|---|---|---|
| L-ABI | Platform Level | u32 单调递增 | 1 | abi.toml | 内核/appd/mkimage/BCTS |
| L-SYS | System Version | semver | 0.2.0 | Cargo workspace | boot banner/sysver/uname |
| L-APP | App Version | semver（自由） | 各自 | .bap manifest | 记录/分发渠道 |

### 兼容性保证

| 承诺方 | 受诺方 | 保证 | 检查时机 |
|---|---|---|---|
| L-ABI level N | 所有 app | level N 上的 syscall 不移不删 | appd 装载 `min_level ≤ level` |
| L-SYS semver X | 所有服务 | major=0 期间不承诺稳定 | sysver VMO 对拍 |
| L-APP version Y | 分发渠道 | 自由串不消费 | OTA 可用 build number |

### 版本协商

```
app 侧：.bap manifest [compat] min_level → appd 装载检查
system 侧：sysver VMO → svcmgr 三方对拍（PR ≡ level ≡ .berryver）
CI 侧：ver-check + abi-check 双门
```

## 四、迁移路径（最小步骤）

| 步 | 动作 | 影响 |
