## §2 缺口分析（三面排序依据：门 / 独立性 / 验收 / 使命对齐）

1. **信号面**：消费面最广（uu 家族/std/pause 谎报桶全景）但真身化 = 内核加号 = **保留门 C**（abi.toml v1 冻结）——首刀形态只能是呈报（owner 裁定 add-only 是否属破冻），不能直干。
2. **mmap 匿名档**：**零 ABI**（桥层全走 vmar_map/vmo 既有号）+ 独立性最好（libc 侧 region 表 + 自验件）+ 使命对齐直通（「带 mmap 的第三方 C 样例零改动跑通」总规划验收线原文）。唯一前置 = VA 段规划避让（§1.5 #16）+ 零消费者按能力卡先例立项（§1.3 #12）。
3. **timer 面**：clock 族真身分布已半满（nanosleep/getres/settime 在位）；REALTIME 分档零 ABI 但撞 U4 date 钉板（§5 #3）；timer_create 族 = 深水后置。
4. **FPU 面**：出局（§1.4 归属裁定）。

## §3 设计与首刀定序

### 3.1 裁定：A7-1 = mmap 匿名档 libc 桥（零 ABI 直干）

- **形态**：berry-libc 新增 mmap region 表模块（AliasTable 先例：纯函数核心 + host 测试）——`mmap(NULL, len, prot, MAP_ANONYMOUS|MAP_PRIVATE, -1, 0)` → vmo_create+commit（逐页，C-2c 纪律）+ vmar_map(self_vmar_h(), …) → 返回 addr 入表；`munmap` → vmar_unmap + vmo close + 出表；`mprotect` → v1 诚实档 EINVAL→改 EACCES 拒或 unmap+remap 双裁（实施刀首查项）。
- **VA 段**：栈 bump 段 0x6000_0000±256MiB 避让 + MMIO 0x7000_0000 避让 + 映像/堆现状避让——专属 mmap 段定值（候选 0x5000_0000 起下行 or 栈段上方 0x7000_0000-256MiB 下方空窗，实施刀按 size.py 布局定谳）。
- **范围盒执法**：仅 MAP_ANONYMOUS（fd≠-1 或非 ANON → EINVAL/EACCES 诚实拒）；文件映射（MAP_PRIVATE over fs fd）= staging 伪映射（整读入 VMO 再映）**挂 A7-3 另裁**；demand paging = v2 深水（总规划 #9/#20 递归复杂度在册）。
- **验收**：host region 表纯函数测（对齐取整/查表/出表/双重映射拒）+ guest 自验步（C 样例形态：mmap→写读对拍→munmap→再 mmap 复用面）→ `MMP ok` 标记（rootfs 相 43；EFI 路零 fs 依赖按构造可打，链序 A 系契约排 fat 族前）。
- **消费者声明**：自验件即消费者（A2-A5 能力卡先例——五卡六标记同款立项依据）。

## §5 风险与 kill criteria

1. **保留门 C 执法**：信号面加号呈报前零实施——A7-1 mmap 零 ABI 按构造不触门（既有号桥接）；若实施中发现需内核新号（如 mprotect 需 vmar protect op）即停刀呈报。
2. **VA 段撞车**：mmap 段与栈 bump（0x6000_0000±256MiB）/MMIO/映像撞 = spawn 期 D-abort 静默面——实施刀先跑 size.py + pthread.rs 段表对拍；region 表带段界 const assert 钉板。
3. **U4 date 钉板冲突**（A7-2）：clock_gettime REALTIME 分档后 date 输出随 boot 时长漂移 = U4 步③ 字面钉板「Thu Jan  1 00:00:00 UTC 1970」破坏——处置二选一（分档即移钉 / 维持单钟诚实文档化）随 A7-2 呈报，勿静默改。
4. **出参宽度坑**（C-2a 钉板法预埋，A6 §3 承诺执法）：mmap 返回 void*（8B 全宽出参——非 handle 4B 桶）；munmap int；region 表入参边界对齐取整按 POSIX 口径（偏移非页倍 EINVAL）。
5. **kill criteria**：mmap 匿名档若撞 std/musl 内部消费者判死面（malloc 大页回落档 sbrk/brk 类——**sbrk/brk 零符号现状同探**）→ probe 定谳后裁留；不追 POSIX 全谱（mremap/remap_file_pages 等零符号维持现探现补）。
6. **本稿自身零风险**（纯 docs 新增）。
