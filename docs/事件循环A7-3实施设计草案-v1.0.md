## §2 裁定（预授权线 1：刀程拆解自主定夺——不撞门 C，不建 user_gate）

**采纳 A 案：MAP_PRIVATE staging 伪映射真身**。理由：
1. **使命对齐直通**：「带 mmap 的第三方 C 样例零改动跑通」总规划验收线的下半句——真实 C 样例里文件 mmap 场景远多于匿名（config/数据文件/资源映射）；A7-1 只落了上半句（匿名档）。
2. **工程量小且全积木**：classify 扩臂 + fd 运行时校验 + STAT 定长 + chunk 循环 + vmo_write 桥 ≈ 80 行，零新内核面/零新协议 op/零新 crate。
3. **零在册消费者不阻塞能力卡**：A2-A5/A7-1 同款立项依据（自验件即消费者）；B 案（挂 v2）= 验收线缺口永挂 + staging 形态无 v2 更优解（v2 增量 = demand paging/懒拷贝，与 staging 正交——staging 现在落不挡 v2 升级）。

**B 案（挂 v2，fd≠-1 维持 EINVAL + 文档化）不采**，留作 kill criteria 回退档（§4 #5）。

## §3 设计

### 3.1 分诊分工（classify 纯函数面 vs mmap.rs 运行时面）

**classify（berry-mmap，host 全矩阵 +N 测）**——静态参数面，fd 臂从 `Reject::Invalid` 改判：
- `fd≠-1` 且 `MAP_ANONYMOUS` 位在 → EINVAL（POSIX 矛盾面）
- `fd≠-1` 且 flags 含未知位 / `MAP_FIXED` / `MAP_SHARED` / 缺 `MAP_PRIVATE` → EINVAL
- `fd≠-1` 且 `offset % PAGE != 0` → EINVAL（POSIX 钦定：offset 须页对齐——与匿名档 offset≠0 拒位同族）
- `fd≠-1` 且 length==0 / 页取整溢出 / prot 缺 READ → EINVAL
- 通过 → `Ok` 新增第二形态（`MapKind::File` 返回值或等价——匿名档现 `Ok(round_len)` 单值，改为携带档位枚举）
- 取整长 > VMO_MAX → ENOMEM（`Reject::TooLarge` 复用）

**mmap.rs 运行时面**（libc 状态，不进纯函数）：
- fd 表查询：fd<0 或 fd∈console 段（0/1/2）或表查无 → **EBADF**（POSIX：bad fildes）；无 fs gift 时 fd 表恒空 → 同归 EBADF（与 fs.rs ENOENT 降级哲学分立——mmap 的错误主语是 fd 不是路径）
- fd 非 O_RDONLY 打开 → **EACCES**（POSIX：fd not open for reading；v1 收窄拒 O_RDWR——own-write 视景缺口见 §3.3）
- STAT 定长：`offset + len > file_size` → EINVAL（§3.3 偏差档）；STAT 失败 → EIO 档 errno 映射（fsclient FsErr → errno 现有映射复用）

### 3.2 staging 主管（mmap_locked fd 臂，全程持 MMAP_LOCK）

first_fit 取洞（匿名档同窗）→ `vmo_create(round_len)` → **chunk 循环**：`get_chunk(path, offset+i)` → `berry_vmo_write(vmo, buf, i, n)`（隐式逐页 commit，§1 #3；**不经 fs.rs RA 缓冲**——直 RPC 零 RA 状态扰动，§4 #3）→ `berry_vmar_map(hv, 0, vmo, 0, &mut va, len, RW)`（恰-RW 硬约束 §1 #2——**PROT 只读请求亦恒 RW 映射**，v1 无 RO 执法面 = 与「用户页本可执行」同档诚实，头注文档化）→ 入 REGIONS。
**MAP_PRIVATE 语义精确成立**：staging 私有 VMO + RW 映射 = 急切全量私有拷贝——写入只及私有拷贝、永不动源文件（POSIX lazy-COW 的 eager 版，语义等价、内存代价 2x 帽内可控）。
失败回滚 = 匿名档零泄漏纪律同款（未映 close 直放；已映 unmap+close）。

### 3.3 POSIX 偏差清单（文档化诚实档，头注 + 本稿双载）

- `MAP_SHARED` → EINVAL（无回写/msync 面，挂 v2）；`msync` 维持 stubs ok! 桶——**恰好正确**（POSIX 对 MAP_PRIVATE 的 msync = 无操作档，非谎报）
- 超 EOF 映射 → EINVAL（POSIX = 零填 + SIGBUS 面；v1 无信号不可表达，诚实拒）
- 恒 RW 硬映射（RO 请求不降权——内核恰-RW + v1 零 RO 执法）
- 只收 O_RDONLY fd（O_RDWR → EACCES；own-write（同 fd 未 commit 写入的 mmap 视景）缺口文档化——单 client 串行 RPC 下零在册场景）
- staging = 整档急切读（≤32MiB VMO_MAX 镜像帽）；demand paging/懒拷贝 = v2 正交增量
- offset+len ≤ file_size 强制（POSIX 允许越界映射）——同「超 EOF」档

### 3.4 自验件（bsh mmp_selftest 扩步 n=5→n=9——**rootfs 相数不变**，同一标记加步）

新四步（fd 档链 + mprotect 挂账件）：
- ⑥ 文件档真身：`put_file("fmap.txt", 数据)` → libc `open(O_RDONLY)` → `mmap(len, PROT_READ|PROT_WRITE, MAP_PRIVATE, fd, 0)` → 映射内改写一字节 → 读回改动可见 → **私有语义核心断言**：`get_file` 重读源文件逐字节不变 + `stat` size 不变 → `munmap` → 复映射读回 = 改写前原内容（staging 与源解耦二次证）
- ⑦ 拒位三连：MAP_SHARED（EINVAL）/ offset 非页对齐（EINVAL）/ 超 EOF（EINVAL）
- ⑧ fd 面拒位：fd=1（console 段 EBADF）/ fd=99（表查无 EBADF）/ O_WRONLY fd（EACCES）
- ⑨ mprotect 保内容环（§3.6）：映射内写哨兵 → `mprotect(PROT_NONE)`==0（dormant 化）→ `mprotect(PROT_READ|PROT_WRITE)`==0（复映）→ 读回哨兵逐字节不变（VMO 保内容实证）→ 追写再读（RW 复活面）
链序维持 fat 族前（EFI 路可达——RAM 树 fs RPC + put_file 先例，FS ok 同款面）；errno 断言走 `berry_libc::get_errno()`（mmp 步② 同款）。
**smoke 两脚本同步**：`MMP ok n=5` → `MMP ok n=9`（smoke.sh rootfs 相 + smoke-image.sh ECO canon——注记块同改）。

### 3.5 mprotect 保内容升级（A7-1 落地追记 ④ 挂账件收编——本稿补遗 2026-10-30）

A7-1 追记 ④（`docs/事件循环A7设计草案-v1.0.md` 沿革）定谳 mprotect 现行为「命中 EACCES / 未命中 EINVAL」并把 **unmap+remap 保内容档挂 A7-3**——本刀收编（两档映射统一受益，零 ABI：仅 `berry_vmar_unmap`/`berry_vmar_map` 既有号）：
- **dormant 态**：Region 增 `dormant: bool`——地址段 `vmar_unmap` 摘除但 **VMO handle 保留在表项**（内容活在 VMO 页集）；VA 段占用语义不变（POSIX：PROT_NONE 映射仍占地址空间直至 munmap）→ first_fit 判占用按 (va,len) 不看 dormant，零改动。
- 分诊（mprotect 三臂升五臂）：
  - 未命中/交叠非整段 → EINVAL（A7-1 语义不变）
  - 命中 active 段 + `prot == PROT_NONE` → `vmar_unmap` + dormant=true，返 0（**保内容摘除**）
  - 命中 dormant 段 + `prot` 含 READ|WRITE → `vmar_map(vmo, RW)` 复映 + dormant=false，返 0（**保内容复活**——vmar_map 失败则段维持 dormant、VMO 未失，零泄漏返错）
  - 命中 active 段 + `prot` 恰 RW → no-op 返 0（POSIX 不变权限 = 成功）
  - 命中 + 其它 prot 组合（PROT_READ 单独等）→ EACCES（内核恰-RW 硬约束 §1 #2，无 RO 档可表达）
- `munmap` dormant 段 → close VMO + 摘表项（回收与 active 段同构——挂账件不新增泄漏面）。
- 消费前景：guard page 模式（线程栈 PROT_NONE 护栏 = pthread/std 线程面 T-1 线下游同族）+ malloc MADV 类近似——零在册消费者同 §2 理由 3 不阻塞。

## §4 风险与 kill criteria

1. **staging 双倍内存**（源文件 + VMO 拷贝）：32MiB 帽 + v1 场景（配置/小数据档）可控；kill = 任何 boot 期内存压力标记漂移（BENCHXH/churn 面）即回退 B 档。
2. **RA 缓冲互扰**：fs.rs 单 RA 静态缓冲被 staging 读扰动 → fd 0/1/2 面三失效点漂移。设计钉死：staging 走独立 get_chunk 直 RPC **不经 RA**（§3.2）；实施刀自评审复核这一点。
3. **fd 表与 mmap 锁嵌套**：mmap_locked 持 MMAP_LOCK 期间走 fs RPC（get_chunk 经 fsclient 会话锁？）——若 fsclient 会话有自有锁则构成锁序面。fs.rs 现路径（read/write）在 libc 调用层无锁（单线程根基 static mut 直写合法——fs.rs 头注）；mmap 桥同根基零嵌套。实施刀首查项：确认 get_chunk 路径零锁（与 MMAP_LOCK 无嵌套面）。
4. **扩步后 `MMP ok n=8` 相位时长**：fd 档 chunk RPC 在 TCG 下慢（RPC 成本模型 Gotcha）——fmap.txt 取小档（≤2 chunk）控步时长；collect 帽参照 M3DEMO cp 步 30s 先例按需参数化。
5. **kill criteria**：host 矩阵或五相 smoke 任何漂移 → 回退 B 档（fd≠-1 恢复 EINVAL + 本稿 §3.3 偏差清单一并入册作 v2 挂账依据）。
6. **mprotect dormant 泄漏面**（§3.5 补遗）：dormant 段 VMO 滞表 = 有界（≤16 槽容量帽）生命周期泄漏档——同「常驻子不 reap」取舍先例，头注文档化；munmap 路径回收与 active 同构是唯一出口，实施刀自评审复核「dormant 段 munmap 必 close VMO」。
