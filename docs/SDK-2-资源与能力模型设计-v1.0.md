# SDK-2 资源与能力模型设计 v1.0

> **性质**：资源访问 API 的粒度契约与 manifest 能力声明面设计（立法档）。
> **溯源**：SDK-03 原则 1（对抗复核修正表述已吸收）；史实（Android 十五年四轮返工 / iOS 14 同病 / Chrome File System Access 正例）见 SDK-03 §二。
> **状态**：设计定稿 · **P0 已开工 2026-11-11**（P0-1 信封 TLV/信任账本 + P0-2 自研 ed25519 原语两刀入 base，沿革二百三十一/二百二十三）· 预 ADR（§七）；实施随 SDK-2 主刀。
> **基座**：ADR #45 零分区四棵树沙箱=能力 · 能力即权限内核态 handle · ADR #59 manifest v2 三域 · SDK-1a 词表闭集执法先例。

## 一、模型总则

1. **对象/树 handle 是资源访问的唯一单位**。授权与撤销都发生在 handle 粒度；
   系统不存在「按类别批量发放」的原语——内核侧天然如此（handle 表），
   本设计把同一纪律延伸到 SDK 声明面与 berry-sys 封装层。
2. **禁止任何「全类别资源」原语**：manifest 声明面、berry-sys API、未来
   高层库均不得出现 all-files / all-media / all-devices 式入口；CI 设
   grep 守卫（词表闭集外的新词必须过评审）。
3. **「收紧不构成行为变更」**：收紧只缩小授权域，不改 API 契约与编程模型
   ——应用零代码迁移，但**必须**优雅处理句柄缺失/撤销（§五错误契约）。

## 二、manifest 能力声明面（词表域扩展）

归属裁决：能力声明进 **[manifest] 词表域**（ADR #59 三域之一）扩展，
**不与 security 域（签名/key_lineage）混置**。

```toml
# manifest v2 词表域扩展示意（字段名随 SDK-2 定稿）
[caps]
fs  = [{ select = "rootfs:/photos", mode = "rw" }]   # 树级选择器，闭集文法
net = [{ select = "client:http", mode = "out" }]
```

- `select` 文法**封闭**（TLV 校验器单解释器执法，ADR #59）：
  `服务:路径前缀` 两段式；路径段编译期可判子集关系。
- v1 词表闭集机制（fs∈{rootfs}/net∈{client}）不变——本设计把闭集从
  「服务级」深化到「树级」；词表仍是服务的镜子：每个 select 目标必须有
  appd 翻译面真装配，声明了拿不到 handle 即空头支票（现役纪律延续）。
- **无聚合语法**：不提供 `fs = "all"`、`mode = "*"` 等通配；需要多树就
  多行枚举。

## 三、合法广域通道（文件管理器/备份类用例）

粗权限缺通道必以特殊门还魂（Android 11 教训）。设计正门：

1. **显式用途类目**：词表域预留 `purpose` 标注（`filemgr`/`backup` 类目
   闭集），声明即触发安装期与运行期的增强提示，不扩授权域本身。
2. **用户显式逐树授予**：appd 翻译面在首访问时发起逐树授权（授权记录
   进 per-app 能力表；授予=向应用 handle 表注入树 handle，拒绝=显式失败）。
   授权可撤销；撤销语义=§五错误契约，不静默。
3. **通道不绕过粒度**：广域通道发放的仍是**一组树 handle**，不是类别令牌
   ——撤销、审计、收紧都在同一粒度模型内闭环。

## 四、生命周期与撤销

| 事件 | 语义 |
|---|---|
| 安装期 | mkapp 编译期闭集校验（select 文法 + 词表内）；purpose 类目触发安装提示 |
| 运行期首访问 | appd 按声明装配 handle；广域用例走 §三.2 授予流程 |
| 撤销 | handle 表回收；在途调用得到显式错误（§五），不静默成功/不静默重定向 |
| 收紧（平台侧） | 只缩小授权域（词表收窄/树前缀细化），零代码迁移即为合规 |

## 五、错误契约（句柄缺失/撤销）

- 缺失与撤销返回**稳定枚举 + 附因**（对接 SDK-2-错误域设计）：
  `E_CAP_UNGRANTED`（声明了未授予）/ `E_CAP_REVOKED`（已撤销）/
  `E_CAP_OUT_OF_SCOPE`（越选择器）——三分不开「拒绝原因」就永远说不清。
- 附因结构必含：所需 select 串、缺的那一环（未声明/未授予/已撤销）。
- **禁止**：返回 EACCES 一把抓（不可编程消费）；静默降级成功。

## 六、验收线（SDK-2 开刀时）

1. mkapp：闭集校验覆盖 select 文法；负样例含 all-files 式聚合语法必须拒。
2. host 测：词表「服务镜子」断言——每个可声明目标在 appd 翻译面有装配路径。
3. grep 守卫：公开 API 面无「全类别」原语（章程 §六.2）。
4. 用例演练：文件管理器最小走查（声明 purpose → 逐树授予 → 撤销 →
   显式错误）作为 SDK-2 验收场景之一。

## 七、ADR 落册点

- #78（候）：资源模型细粒度立法（对象/树唯一单位 + 禁全类别原语 + 广域
  通道 + 收紧≠行为变更）。与 ADR #45 关系：#45 定沙箱结构，本 ADR 定
  SDK 声明面与粒度契约，互为表里。
