## §0 主会话缝合裁决（三路冲突处）

### 裁决一：内核簿记取 kern 案——live_threads 计数 + thread_key，弃 tasks[8] 数组案

- **采纳**：`Process.live_threads: usize`（三增点一减点）+ `Task.thread_key`（0=无）+
  `set_task_thread` + `kill_all_tasks_by_pinned` 重扫循环（每轮从 SLEEPQ 头/RQ 头全新扫描，
  跳过 CURRENT）。
- **弃**：libc 路的 `Process.tasks: [usize;8] + n_tasks` + `thread_only` 旗方案。理由：
  ①无 8 线程人为帽（线程栈/TCB 随 REAPQ 回收，无 Process 式不回收泄漏——PROCESS_MAX 帽
  立法理由对线程不成立）；②零注册义务（try_assemble 单点初始化 thread_key=0 覆盖全部
  构造器，数组案要 process_start/thread_start 双点注册）；③terminate/exit 扫描免数组
  （重扫循环 n≤3 O(n²) 无碍，且免「数组与真实任务集漂移」面）；④kern 案逐行号镜像
  process_start（校验序/H2 try 化先行/retain 对账），代码依据更深。
- libc 案 OPEN 3（8 槽满返码）随之消解。

### 裁决二：join 取 kern 案——内核 Thread TERMINATED 信号面，弃用户态 Event join

- **采纳**：`Thread.exited: bool` + `signal_state` 加 Thread 臂（exited → SIGNAL_TERMINATED）
  + `wait_get` 第四臂 Thread。pthread_join = `object_wait_one(th_h, TERMINATED, u64::MAX)`
  → 读 retval → 清栈清块关三 handle。
- **弃**：libc 案的 join_ev 用户态 Event。理由 = **竞速实锤**：trampoline 在
  `object_signal(join_ev)` 之后仍要在自己栈上跑完 `free(Parcel)` + `berry_thread_exit()`
  陷阱；时间片恰在该窗耗尽被抢占 → joiner 醒来 `vmar_unmap(stack)` 拔了垂死线程脚下的栈
  → 恢复执行即 fault 杀 → 非确定性 EXCEPTION dump（「标记不得建立在竞速上」的反面设计，
  单核抢占下窗口真实存在）。内核 TERMINATED 在 exit hook「任务永不再跑点」置位——joiner
  醒时线程真死透（Ziron/Zircon 同语义，Zircon 正是为此把 join 做内核侧）。
- 连带修改：pthread struct **删 join_ev 字段**；trampoline 尾免 object_signal（retval 写
  完 → dtors → state=Exited → free(Parcel) → thread_exit）。
- PI 中性论证在案：pi.rs donor_edge 派生位掩码只含 READABLE|WRITABLE，TERMINATED 不入
  → 等 Thread TERMINATED 的睡眠者结构性退出 donor 面（Process TERMINATED 同款先例）。
  TERMINATED 是内核派生低位，**无需登记 USER_SIGNAL_BITS 表**（该表只收高 32 位用户位）。

### 裁决三：TLS 导出接口取 tls 案四全局——libc 案三全局是其子集

- **采纳**：crt0 导出 `BERRY_TLS_VADDR / BERRY_TLS_FILESZ / BERRY_TLS_MEMSZ /
  BERRY_TLS_ALIGN`（usize×4，`#[no_mangle] pub static mut`，写点唯一 = berry_tls_setup
  先于 main；ALIGN=0 ⟺ 无 PT_TLS）+ 安全访问器 `tls_template()`。子线程块 =
  `malloc(memsz + 0x10 + 16)` → **tls_place 同一算术复用** → 清零 + 从
  `[BERRY_TLS_VADDR, +filesz)` 拷模板 → TP = data − 0x10 → struct pthread 嵌 TLS 窗尾
  （data + align8(memsz)），洞 `[TP, TP+0x10)` 写 struct pthread 自指针。
- **统一算术口径**：libc 案「TP=块首」描述系 align≤16 且块 16 对齐时的特例；通用式以
  tls_place 为准（data = (base+0x10+align−1) & !(align−1)，TP = data−0x10，洞 =
  [TP, TP+0x10) 恒 16B）。家族实测 p_align 全员 8，两式数值同。
- libc 案「MEMSZ==0 → pthread_create 返 EAGAIN」守门保留（无 PT_TLS 程序如 bin/hello：
  子线程块 = 纯 struct pthread 无 TLS 胞元，自洽）。
- 主线程无堆块：pthread_self 读洞指针，null → 返回静态 MAIN_PTHREAD（主线程不可 join，
  join(self) 返 EINVAL）；主线程 arena 洞保持清零（.bss + 显式清零双保险）。
- 第一层 unreferenced 四全局在 fat LTO 下可能被 DCE（layer-1 无消费者）——无害，第二层
  stubs.rs/pthread.rs 引用后自动保留；不加 #[used]。

### sys_thread_start handler

插 sys_thread_create 后；注册在 NR_THREAD_CREATE 与 NR_THREAD_EXIT 之间。校验序（镜像
sys_process_start）：①entry==0 || sp==0 || sp%16≠0 → -EINVAL（无出参无预清）；②
caller_table → get_raw(th, Thread, RIGHT_MANAGE)：坏/类型 -EBADF、缺 MANAGE -EACCES；
③thrd.owner() → as_process_mut；④`thrd.started || thrd.exited` → -EBADSTATE；⑤
`proc.state != Alive || !proc.started` → -EBADSTATE（首线程必须经 process_start）；⑥
`try_spawn_user(entry, arg, sp, b"user_thread", proc.ttbr0_pa, proc.asid, proc.ht 指针)`
（与首线程同一入口；None → -ENOMEM，try 化在一切不可逆变更前——无 bootstrap 迁移零回滚
面）。成功尾四连写：thrd.started=true；proc.live_threads+=1；Process retain +
set_task_pinned；Thread retain（vt）+ set_task_thread。**无 per-process 线程帽**（对抗
审查复核点：若认为 EL0 自扰面值得帽，加 THREADS_PER_PROC_MAX=64 拒 -ENOMEM 独立小改）。
sp 不做映射校验（process_start 同政策：错 sp = 首切 fault 杀兜底）。

### live_threads / thread_key / EXIT_HOOK / kill_all

- `Process.live_threads: usize`（plain usize——单核 IRQ 屏蔽路径专用无原子）：增点三
  （Process::new 初始 0 / process_start 成功尾置 1 / thread_start 成功尾 +=1）；减点唯一
  = task_exit_hook（所有退出路径汇经钩子）。
- `Task.thread_key: usize`（0=无）try_assemble 单点初始化；`set_task_thread`（set_task_
  pinned 镜像，写点契约 = 任务未跑 IRQ 屏蔽窗）。
- EXIT_HOOK 签名 `fn(usize, i32)` → `fn(pinned: usize, thread_key: usize, code: i32)`
  （内核内部 C-ABI 槽非用户 ABI；sched 三调用点 + install 注册同步，漏改编译错 loud）。
- `kill_task_by_pinned` **原地重写**为 `kill_all_tasks_by_pinned(pinned, code)
  -> Option<(&'static [u8], usize)>`：外层重扫循环（钩子内 wake_matching 搬动 SLEEPQ，
  不得持游标跨轮；单 kill 摘队先于钩子序照旧）；**RUNQUEUE 扫描跳过 CURRENT**（process_
  exit 杀兄弟会命中自己）；返回 (首杀名, 总数)。打印上移调用方：terminate 打
  `TERM: killed '<name>'`（count>1 追加 ` x<n>`）；process_exit 静默。

### task_exit_hook 分序（四步序的线程版）

pinned==0 → 直通（内核任务/boot 裸表，thread_key 结构上必 0）。pinned≠0：
①线程簿记（thread_key≠0）：t.exited=true → wake_matching(thread_key, TERMINATED)（join
唤醒）→ ObjRef::release(thread_key)（可能 drop Thread → 释放其 Process retain——进程尚有
本任务运行钉住 ≥1 安全）；
②进程账：live_threads−=1；**减到 0 → 末线程收口 = 原四步原样**（mark_exited 首因保码 →
exit_code=code → wake_matching(pinned, TERMINATED) → proc.ht.drain()）；
③release(pinned) 最后。**非末线程绝不 mark_exited、绝不 drain proc.ht**（K1 教训线程版）；
drain 幂等为 terminate 群杀后防御面兜底。

### Thread join 面

`Thread.exited: bool`（与 started 并存两 bool 不上 enum——最小扰动）；signal_state 加
`KernelObj::Thread(t) => Some(if t.exited { TERMINATED } else { 0 })`；wait_get 类型链
Event→Channel→Process 后加第四臂 Thread。

### 0x33/0x36 语义重梳

- **0x36 thread_exit = 仅退当前线程**：exit_current_with(0)——非末线程 → 钩子只做 Thread
  簿记 + 计数减；末线程 → 进程收口码 0。
- **0x33 process_exit = 全进程退出**（Ziron 真语义）：`current_pinned()≠0 →
  kill_all_tasks_by_pinned(p, 0)` 先静默杀兄弟（各自走钩子；调用者仍活无人触发收口）→
  `exit_current_with(code)`（钩子：末线程 → mark_exited + 调用者 code + TERMINATED +
  drain + release）。kill 在 exit 之前（`-> !` 尾补清理不可达 Gotcha 不适用——死码只在
  exit 之后）。EL1 裸调用者（pinned=0）跳过 kill 面行为与今逐字同。单线程既有消费者
  （EXIT ok/appd/bsh &&/C-4b Ctrl-C 面）kill_all 恒空转 **零漂移**。兄弟 code 传 0（首因
  码 = 调用者 code）。两号保持 `-> !`。
- kill_all 在 SVC 屏蔽窗内零阻塞零让出（指针手术 + 钩子 + REAPQ 压队）——「handler 不得
  忙等跨任务」铁则不破；REAPQ cap 32 溢出 = 泄漏 + 首 4 loud（既有政策）。

### 0x3B process_terminate 交互（按 C-4b 落库后形态）

唯一改动：started 分支 `kill_task_by_pinned` 换 `kill_all_tasks_by_pinned`——群杀逐任务
走钩子，末任务钩子完成 Process 收口；terminate **不再做 started 路径的 Process 侧收口**
（防 drain 双跑/refs 打穿）；前置门不变（自杀/已 Exited → -EBADSTATE；未 start → 无
release 收口）；时序自洽：Alive+started ⟹ live_threads≥1 ⟹ 目标全在 SLEEPQ/RQ（单核、
CURRENT=调用者且自杀门已拒）。

### SYS_futex(98) 候选 A 形态

- futex_wait(addr, expected, deadline)：①load≠expected → ret 0；②池取槽（16 槽静态
