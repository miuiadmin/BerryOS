## §2 缺口分析：从「协议在册」到「guest 对拍可跑」差什么

1. **bsh 无 netd 端下放路径**（#7）：协议位在册（#2/#3）、产侧先例在册（#6）、容量恰满（#4）——缺的只是 bsh 侧新装配点（netd SEND|RECV dup 第三元）+ 按需包装。
2. **无 std 消费 guest 件**（#10/#11）：netprobe 已删；重建 = std bin + CRT0_SEED 尾锚 + musl 链 + rootfs 发行挂线（build-user 产链 + mkcpio 入 rootfs）。
3. **std::net 运行期深水面未定谳**：A4-3 证的是静态零缺口；运行期 fcntl O_NONBLOCK 档/getsockname/setsockopt 具体档位族是否踩桩判死面 = 首跑定谳项（A3-3/A4-3 同款 probe 纪律——kill criteria 在册执法）。
4. **能力放大面**：netd 端下放任意子进程 = 网络能力扩散；v1 单用户演示面可接受但须文档化 + 按需装配（不全量——df/du/grep 等 fs 消费面零漂移按构造）。

## §3 设计

### 3.1 bsh 装配面：按需第三元（least privilege）

- **新包装 `net_gifts()`**（fs_gifts 同形）：fs_gifts() 二元 + netd 端 `berry_handle_duplicate(netd_h(), RIGHT_SEND|RIGHT_RECV, …)` 第三元；`netd_h()==0`（EFI/裸拓扑）→ 返 None → 调用方静默跳过（拓扑降级同 EVS/SKT 契约）——**fs_gifts() 本体与三既有消费点零改动**（既有 spawn 面行为零漂移按构造）。
- **消费点裁一人**：只有网络消费 spawn 走新包装——本卡唯一消费者 = netprobe 自验步（§3.3）；`run_output`/`run_capture_fs`/`pipe_capture`/裸 `run_capture` 全维持现状。
- **gifts 数组形态**：`&[rootfs_dup, fs_dup, netd_dup]` 三元 extras——berry-exec ≤3 断言恰满（#4）；stdin 占位语义同 fs 面（空 feeder EOF 留队无害）。
- **权利位对源首查项（A5-1）**：svcmgr 侧 `net_b` dup 的 rights 形态（#6 :544 上下文）——SEND|RECV 预判（fs 端同形），对源后再钉。

### 3.2 netprobe 件（std 消费 guest 件重建）

- **形态**：std bin（musl 链 + berry-libc shim）+ CRT0_SEED 尾锚（#10 纪律）；args 面收 `host port [payload]`；流程 = `TcpStream::connect` → write payload → read 回显 → 逐字节对拍 → exit 0/1（对拍失败 loud）。
- **域名面顺带**：connect 目标给 `"localhost:18083"` 字符串形态（std 内部走 getaddrinfo → A4-2 DNS 档 → 127.0.0.1）——域名解析 + 连接 + 回显三面一刀全验；IP 字面量快路对照步（同 EPL 步⑤ 双查形）。
- **产链挂线**：`user/bins/netprobe/` 新 bin + build-user 产链 + mkcpio 入 rootfs（bin/netprobe）——rootfs 条目 x41→42。

### 3.3 bsh 自验步 + 挂线（A5-2）

- **`nets_selftest`**（名取 std::net spawn 面；链位 = epl_selftest 后 fat 族前——A 系契约）：
  - ⓪ `net_gifts()` None（netd_h()==0）→ 静默 return（EFI canon 零变化按构造）
  - ① spawn netprobe "localhost" 18083（走 net_gifts 三元 + run_capture_gifts_cap 形态）→ 收割输出逐字节对拍 → n_ok
  - ② IP 字面量对照步（"127.0.0.1" 18083 快路零 DNS RPC）
  - ③ 失败面：netprobe 缺席（rootfs 无件）→ 诊断行 loud（`bsh: nets: netprobe absent`——区别于拓扑静默门）
  - → `NETS ok n=2`（rootfs 相 41→42）
- **smoke.sh 挂线**：ROOTFS_MARKERS + 计数面（rootfs 相 + RX/FAT 合相 +1）+ 子串互非复核（`NET ok` vs `NETS ok`——NETS 不含 "NET ok" 子串安全，TAB/TAGTAB 前例复核法照走）+ evsclient 18083 hostfwd 面已由 smoke 编排在册（SKT 同款复用零新端口）。
- **EFI 路**：无 netdev → ⓪ 静默门挡断 → canon 生态 24 零漂移（结构性不打）。

### 3.4 std 深水面 probe（首跑定谳，kill criteria 执法）

- **probe 先行**：A5-1 落装配面后先净室手跑 netprobe 单件（worktree + smoke 环境形态）——运行期撞桩判死面（`abort` 静默死 = G-eco-d d-1c 排障方法论：先 grep berry-libc 自家打印认领）即按 kill criteria 裁留如实入册。
- **预判风险面**：fcntl F_GETFL/F_SETFL（O_NONBLOCK——std 非阻塞 connect 可能用；A3-1 fcntl 真身面 F_DUPFD 在册、F_GETFL 档未证）、getsockname/getpeername（connect 后取本地地址族）、setsockopt 具体档（SO_RCVTIMEO 类）。撞墙 = 补桩面（机械改动类预授权）或裁留（深水面）二裁——桩可谎报则谎报（G-eco-d「先查 std 对失败是否 abort」纪律）。

## §5 风险与 kill criteria

- **kill（A4-3 裁留原文执法）**：std::net 运行期撞深水面（桩不可谎报/std 判死类）→ probe 定谳后按 kill criteria 重定范围留档；bsh 装配面 + `NETS ok` 自验步（不依赖 std 面——netprobe 若裁留可降级自写 client 形态，A3-3 同款底线）。
- **能力放大面**：netd 端下放 = 网络能力扩散——v1 按需装配单消费者（netprobe 步）+ 文档化；v2 再裁 gift 策略面（细粒度 rights/白名单）。
- **端口互斥**：18083 复用 SKT hostfwd 面（smoke 编排在册）——勿与 evsclient 并行冲突；echod 18080 照旧。
- **rootfs 容量**：netprobe std bin 体积（hexyl 同量级预判 ~1MiB）——rootfs ≈27.3MiB + netprobe 远低于 32MiB 帽（VMO_MAX_SIZE 同口径）零风险；`just image` 盘 96MiB 余量足。
- **不做什么**：不动 env 块协议/berry-exec 断言（恰满零扩容）；不做 gift 策略引擎（v2）；不做全量 spawn 面 netd 下放（least privilege）；不碰 abi.toml（零新 syscall）；不动 fs_gifts 三既有消费点（零漂移硬线）；EFI canon 24 零漂移（拓扑门挡断按构造）。
