## 一、双源与盲区（G10 管什么、不管什么）

G10（`tools/docs_guard.py`，c03b758 落地）三不变量：① 区标注（N）== 区内表格行实数；
② 头部「主索引：N 份」== Σ区标注；③ 登记集 == docs 根实存 .md 集。**计数面已机器根治**。

G10 **不查**的人工面（本清单的主对象）：

| # | 漂移形态 | 危害 | 检法 |
|---|---------|------|------|
| 1 | 升版改名后**标签列版本漏改**（文件名 v1.1、标签列仍 `· 1.0`） | 读者按标签列引旧版口径 | §三 命令 ② |
| 2 | 新登行**标签列漏版本号**（版本化文档标签列无任何 x.y） | 违反「标签列同步标」约定，长存即成两义温床 | §三 命令 ② |
| 3 | 一句话定位**状态后缀过时**（写「待开工」实则已收官） | 时效漂移，低危（索引头部已注明落地后缀随手更新） | 人工抽查 |
| 4 | 标签列**预 ADR 候号漂移**（台账改号、索引行未随迁） | 指向已占用/空置号的错误事实（round 8 实猎 5 处） | 对拍 `架构决策.md` 头部台账，**按 §三④ 归属对拍（预留 vs 占用须甄别，v0.1 检法 6 误报实证）** |

## 三、复核命令（可复制，三条覆盖四形态）

```bash
# ① 计数面（G10 全量，含三不变量）
just docs-guard

# ② 标签列 ↔ 文件名版本对拍（形态 1/2；输出零行 = 干净）
python3 - <<'EOF'
import re
for l in open('docs/索引.md', encoding='utf-8'):
    m = re.match(r'^\|\s*\[([^\]]*)\]\(([^)]+)\)\s*\|\s*([^|]*)\|', l)
    if not m: continue
    target, label = m.group(2), m.group(3)
    fm = re.search(r'-v(\d+\.\d+)\.md$', target)
    if fm and fm.group(1) not in re.findall(r'\d+\.\d+', label):
        print(f'漂移: {target} 标签列[{label.strip()}] 缺/异于 v{fm.group(1)}')
EOF

# ③ 行数快对（不动 guard 时的人工秒查：表行总数应 == 头部主索引数）
grep -c '^| \[' docs/索引.md

# ④ 预 ADR 候号归属对拍（形态 4，v0.2 修正检法；输出零行 = 干净）
#    v0.1 误报教训：只查「号在台账出现」会把台账自身的「预留」行（号已留给本件）
#    误报为占用。正确判据 = 台账中该号条目的**归属**（预留括号里的件名/主题）
#    与索引行标签列「预 ADR #N」所属文档一致——一致即正常预留，不一致才是漂移。
#    区间形（#75–#80 预留）须展开成单号集，否则只捕尾号、余号全部误报（实测坐实）。
python3 - <<'EOF'
import re
idx = open('docs/索引.md', encoding='utf-8').read()
head = open('docs/架构决策.md', encoding='utf-8').read().split('\n## ')[0]
reserved = {}
# 单号形：#65 预留（主题）；区间形：#75–#80 预留（主题）
for m in re.finditer(r'#(\d+)(?:\s*[–-]\s*#?(\d+))?\s*预留（([^）]*)）', head):
    lo, hi = int(m.group(1)), int(m.group(2) or m.group(1))
    for n in range(lo, hi + 1):
        reserved[str(n)] = m.group(3)
for l in idx.splitlines():
    m = re.match(r'^\|\s*\[([^\]]*)\]\(([^)]+)\)\s*\|\s*([^|]*)\|', l)
    if not m: continue
    target, label = m.group(2), m.group(3)
    for cn in re.finditer(r'预 ADR #(\d+)', label):
        n = cn.group(1)
        if n not in reserved:
            print(f'形态4: {target} 标签列预 ADR #{n} —— 台账无预留条目（查改号/占位）')
EOF
```

### §三④ 判据说明（v0.2 增补）

台账头部两种条目形，判读相反：

| 台账形 | 语义 | 索引行「预 ADR #N」 |
|---|---|---|
| `#N 预留（主题/件名）` | 号已**留给**该主题，未落册 | 归属一致 → **正常**；归属不符 → 漂移（round 8 实猎形） |
| `#N 增补（件名）` | 号已被**正式落册**占用 | 标签列仍称「预」→ **漂移**（候号已兑现，标签列应去掉「预」或随迁新号） |
| `#M–#N 预留（区间形）` | 区间内号全数预留 | 须展开单号集再对拍（漏展开则只捕尾号，余号全误报——v0.2 实测） |

v0.2 首跑（2026-11-09，base 92fa84f）：6 行进检（#65/#75/#77/#78/#79/#81），逐行归属对拍全一致（API治理章程→#65 预留、SDK 五件套→#75–#80 预留、应用规范→#81 预留）——**零真漂移**；v0.1 检法（号 ∈ 台账即报）6 行全误报，坐实「预留 vs 占用」甄别必要性。
