## §1 目标形态与验收

用户验收原话：**像 OpenHarmony 一样完整的 GUI 界面、图标、左右滑动桌面；电脑上用模拟器就能打开我们的 GUI 界面。**

| 验收件 | 形态 |
| --- | --- |
| 桌面 | 多页图标网格 + 左右滑动翻页（拖动跟随 / 松手吸附 / 页指示器）+ 壁纸 |
| 图标 | 应用图标 + 名字，点击启动 .bap 应用 |
| 状态栏 | 顶部固定条（时钟 + 电量/静音占位图标），桌面内容避让 |
| 输入 | 点击 / 拖动两手势起步（模拟器鼠标 = 触摸代理；采集源裁决见 §3-A） |
| 载体 | `berry shell`（宿主自持窗口 + AAVMF/ramfb 引擎；见 `berry设备壳设计草案-v1.0.md`）打开 GUI；`run-efi` 仍是无头串口验收 |
| 持久化 | 桌面布局落 FAT（JSON / 定长记录），跨 boot 保布局 |

完整功能闭包 = 附录 B「一、最小移动 GUI 系统闭包」15 件；v1 明确砍掉的面（通知/卡片/文件夹/Dock 高级面/角标/最近任务/暗色主题等）以附录 B「二」末段清单为准——**范围盒写死，防 GUI 诱惑膨胀**。

> **目验载体注记（2026-11-03）**：本表原写「`just run-efi` 打开 GUI」——实为 `-nographic`，屏幕只走串口。窗口载体由 `berry设备壳设计草案-v1.0.md`（ADR #62）承接：`berry shell` = QEMU 引擎 + 宿主自持窗口；`run-efi` 保留无头串口验收。手机档渲染 480×1000（ramfb commit）见该草案 §7。

## §3 架构裁决候选（2026-10-28 用户裁决：A–F 按默认执行、随刀落 ADR——下表默认即现行口径）

**服务摆位总图**（微内核纪律：内核零 GUI 知识，全部用户态服务）：

```
            ┌─ guifbd（显示服务：GOP fb 持有者，整屏 flush）
EL0 服务 ───┼─ gui-inputd（输入服务：采集源 → PointerEvent 流）
            ├─ gui-wmd（窗口服务：两层窗 + Z 序表 + 命中分发 + 避让）
            └─ appd（既有，扩 icon/label/事件面）
EL0 应用 ──── berry-launcher（单 GUI 进程：berry-ui 库内嵌视图树 + SwipeView×Grid + 状态栏）
                 └─ 点击 spawn .bap 应用（全屏独占窗起步，回桌面 = 应用退出/失焦）
内核 ──────── 零新增面（fb MMIO 窗 = vmar_map 物理窗授能，既有 VMO/Vmar 能力模型）
```

## §7 特效能力终态评估（2026-10-29 问答沉淀）

**一句话口径：现在画不出（v1 操作集最小面 + TCG 无 GPU），架构缝全部留对（协议/API 按终态 day-one 定形）——「又好、又低功耗、响应又快」三角在协议层不矛盾，三者的解法住在同一张协议面上（damage / 停帧 / latch+credits / 离线着色器）。**

### 7.1 为什么现在不能（期望管理进册）

- v1 操作集 = fill_rect / line / blit / glyph-run / present + 纯色 paint——AA/宽色域/compute/3D 明确列「可后补」（`user/berry-gfx/src/lib.rs` v1 边界注释）；特效三要素（任意变换 / 混合 / 着色器）均未入场。
- 验收环境 TCG 无 GPU：800×600 RGB32 全屏 ≈1.9MB/帧，§5 kill line 已备（滑动 <10fps → 降 RGB565/480p 或「步进翻页无动画」）。
- **v1 观感目标 =「能用」（桌面/翻页/点击启动），不是「华丽」**——范围盒纪律的期望面。

### 7.2 为什么路线能：特效地基对账（全部已在库）

| 特效需求 | 缝（语义位） | 已落位 |
| --- | --- | --- |

### 7.4 清醒剂（纪律入册）

- **先进分两半**：设计先进（上限高 + 不欠协议债——已到手）≠ 兑现先进（把缝一个个用起来——GUI-2..9 刀序的事）。
- **缝 = 债**：day-one 留的协议位必须有消费者计划 + 验收锚（裁决 G 六件全挂断言的通则化）——留位没人消费 = 死复杂度；**先进性靠断言执法，不靠信念**。
- BeOS 之鉴：技术先进是必要非充分条件；真机 GPU「最后一段」不因架构先进而变短（Asahi 四年 + 个位数专家价码——「留缝不实现」层边界不变）。

### 一、最小移动 GUI 系统闭包（15 件，按依赖序）

构成「图标 + 左右滑动桌面 + 状态栏 + 触摸操作」的最少功能件（括号内为 OpenHarmony 对应证据）：

1. **显示服务（guifbd）**：消费 GOP framebuffer（V-6a 已携面、实测 800x600），BufferInfo（stride/像素格式/分辨率）+ 整屏 flush 语义，fbcon 渲染核复用（UIL: frameworks/window/window_impl.cpp 的 UpdateHalDisplayBuffer/Flush；frameworks/dock/screen_device.h）
2. **2D 软光栅 crate**：rect/fill/line/blit/字形 blit/图像 blit 六原语，trait 化可插拔——fbcon 字形 + 蜂格渲染核为种子（UIL: interfaces/innerkits/engines/gfx/gfx_engine_manager.h + frameworks/engines/gfx/soft_engine.cpp）
3. **图像解码**：图标格式（PNG 子集或自定义紧凑格式）→ ARGB + LRU 缓存（UIL: frameworks/imgdecode/）
4. **字体档**：多字号字形 bin + 索引 + 缓存，自 8x16 单字号面扩（UIL: frameworks/font/glyphs_file.h、ui_font_cache.cpp）
5. **保留模式视图树 + 脏区管理**：View/ViewGroup/Invalidate + 矩形合并裁剪重绘（UIL: interfaces/kits/components/ui_view.h + frameworks/components/root_view.cpp）
6. **帧循环**：软 vsync（16ms 定时器）驱动 Measure→Render 脏区刷屏；FPS 统计内建（UIL: frameworks/core/task_manager.cpp、render_manager.cpp）
7. **输入服务（gui-inputd）**：QEMU USB 平板/virtio-input 采集 → PointerEvent 结构（单点起步、结构留多点位）（MMI: interfaces/native/innerkits/event/include/pointer_event.h）
8. **窗口服务最小面（gui-wmd）**：两层窗（状态栏系统窗 + 全屏桌面窗）+ 坐标命中分发 + 窗口信息表推送输入服务（WWM: wmserver/include/window_zorder_policy.h；MMI: window_info.h 契约）
9. **手势识别 + 仲裁**：tap/pan 两识别器 + referee 竞争裁决（ACE: frameworks/core/components_ng/gestures/gesture_referee.cpp）
10. **动画器**：全局 tick + 2-3 条缓动曲线（可定点）+ 惯性/边界回弹（UIL: frameworks/animator/easing_equation.cpp；ACE: frameworks/core/animation/）
11. **网格布局**：行列 GridLayout 图标定位与行列配置（UIL: frameworks/layout/grid_layout.cpp）
12. **分页滑动容器**：SwipeView——拖动跟随/松手吸附/翻页动画/边界回弹/页指示器（UIL: frameworks/components/ui_swipe_view.cpp；ACE: pattern/swiper/）
13. **状态栏应用**：顶部固定条（时间 + 电量/静音占位图标）+ 桌面内容避让（SUI: features/statusbarcomponent/ + clockcomponent/；WWM: avoid_area_controller.h 思路）
14. **应用枚举 + 图标模型**：appd 扫描 .bap → 图标+名字清单（manifest 扩 icon/label 字段），增删事件通知（LNCH: LauncherAbilityManager.getAllLauncherAbilityInfo + bundleMonitorOn；ResourceManager.ts）
15. **启动器（berry-launcher）**：壁纸 + 页×网格组装 + 指示器 + 点击 spawn + 回桌面（LNCH: product/phone/.../EntryView.ets + GridSwiper.ets；布局持久化照 PageDesktopLayoutConfig.ts 模型）

伴生加分件（不占闭包名额）：DFX 三件——FPS 统计 / 视图树 JSON dump / 事件注入器 + PC 端注入 server（UIL: frameworks/dfx/、tools/server/、tools/qt/simulator/），直接服务「AI 测试友好化」支柱，GUI smoke 可靠断言的地基。

### 二、BerryOS 起步档建议档位：lite 档形态 × 完整档切面

**结论：实现形态取 lite 档（arkui_ui_lite），服务边界取完整档（Rosen/SCB）的切法——「lite 实现 + 完整架构缝」。**

> **2026-10-29 注记**：本节档位判断经八维调研（`research/GUI-09` §2.c）确认与终态收敛形态（B 形态 buffer 过界）天然兼容、作为**实现路线**继续有效；但「技术定调上限」由 ADR #50–#54 接管（协议面按最先进终态一次定形 + berryui 声明式 API 面 + pass 形态渲染 API）——本节不再是对标上限。

| 维度 | lite 档（UIL 实证） | 完整档（G2D+ACE 实证） | BerryOS v1 取舍 |
| --- | --- | --- | --- |
| 进程形态 | 单进程内嵌引擎（合成另属 window_manager_lite） | 独立渲染服务 + 客户端库 + parcel 级 IPC | 三薄服务（显示/输入/应用管理）+ 单 GUI 进程 |
| 渲染 | 软光栅 + 脏区（ROM 900KB/RAM 90KB） | GLES/Vulkan/RASTER + 合成器 + HWC | 软光栅 + 脏区（与 G2D RASTER 回退同路） |
| UI 编程面 | C++ 命令式保留模式 38 组件 | ArkTS 声明式 + 差量更新 + 状态装饰器 | Rust 命令式保留模式（组件按需手写） |
| 动画 | int16 定点缓动零浮点 | 服务端插值 + 弹簧/摩擦物理 | 定点缓动起步，物理曲线后补 |
| 输入 | 拉取 + 命中冒泡（进程内） | 独立服务 + 责任链 + UDS 派发 | 独立服务 + normalize→dispatch 两级链 |
| 字体 | 点阵 bin + radix 索引 | FreeType 矢量 + emoji + 文本整形 | 点阵起步（fbcon 顺延），矢量后补 |
| 窗口 | 单窗直写屏 | 60 类型 + Z 序表 + 焦点链 + 避让 | 两层窗 + Z 序小表 + 单焦点 + 状态栏避让 |

三条判断依据：

1. **可达性**：QEMU AAVMF + ramfb 无 GPU、无真 vsync、TCG 吞吐有限——完整档的 GLES/Vulkan 双 API、HWC、变帧率面全部不可验；G2D 自己的 RASTER 纯软回退（bootanimation 即软渲染起步）与 UIL 整栈软渲染是唯一可跑路径，fbcon 已在同一路线上。
2. **资产复用**：BerryOS 已有件（GOP 携面、fbcon 字形+渲染核、virtio 驱动框架、.bap spawn + appd、FAT、channel/event/wait_many、pthread-futex）全部落在 lite 档闭包内；完整档独有件（双侧 RS 树、命令序列化远程渲染、差量更新、JS 前端）没有一件是「图标 + 滑动 + 状态栏」必需——UIL 用 SwipeView × GridLayout × 固定条三个原语即表达该形态（LNCH 是其上组装层证明）。
3. **微内核纪律的落点**：GUI 不进内核，但也不必照搬 Rosen 的 parcel 级重 IPC——取其「独立服务 + 薄契约」切法砍到三契约：显示（framebuffer/flip 面）、输入（PointerEvent 流）、应用管理（枚举/启动/事件）；UI 框架与 launcher 同进程起步，输入命中经窗口信息小表（WWM↔MMI WindowInfo 契约同构，高频 vsync 类信号留专用通道缝）。

v1 明确砍掉：JS/ArkTS 前端与状态装饰器、差量更新、GPU 双 API、HWC、多窗合成、通知系统、服务卡片、文件夹、拖拽、Dock 高级面（拖入/最近/编辑）、角标、无障碍、暗色主题、变帧率、最近任务、手势导航（以「点桌面空白/失焦回桌面」简化面替代）。

保留升级缝（设计留位、实现后补）：2D trait 换 GPU 后端（virtio-gpu）；视图树拆「录制/回放」远程渲染（RSCommand/DrawCmdList 形态）；动画移合成服务端执行；PointerEvent 多点位与 MOVE 重采样；窗口类型表按 SUI 九窗注册表扩展；状态栏图标组件化注册表（插件数据源形态）。
