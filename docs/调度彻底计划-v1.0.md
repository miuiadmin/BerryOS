## 1. 目标与原则

**目标一：调度是三大身份支柱的机制核心，支柱差异不落机制分叉。** 省电 · AI 原生调度 · PC 高性能共用一条机制链（class 链 rt > deadline > fair > idle ＋ 三槽 RCU 策略表 ＋ EM 能量表 ＋ intent 查表键）；支柱差异全部落在「表的参数」（IntentProfile 按设备档位选表）与「表的来源」（advisor / AI 实验轨道 / manifest 角色表 / 启动配置），不落在机制分叉上（02 号 §2 总判词，capacity 抽象「一条路径三端通用」的必然推论，[调度器设计](调度器设计-v1.1.md):63-69）。任何「为某支柱加一条机制分叉」的提案先过排除 8 问第 1 问（[架构综合纲领](架构综合纲领.md):133）。

**目标二：终态 = 四层框架，不是四套调度器。** 冻结机制内核（EL1）/ 窄腰注入面 / 可插拔策略全谱（EL0）/ 观测外迁面（横切）——前三层在册（白皮书四层图），第四层是 W3 外迁族的终态方向且与业界同向（Zircon libsched environment-agnostic 收敛，02 号 §1.3）。详细契约见 §2。

**目标三：不打补丁，从底层系统框架设计。** 本计划对调度域的既有病灶（调度-PM 契约空转、IntentProfile 查表闲置、证据面单核化）给出结构解，不做叠床架屋式最小修；与显示加速体系同构（三路研究＋定稿＋刀序可回滚＋kill criteria 全程，先例 [显示与加速体系设计](显示与加速体系设计-v1.0.md) §4-§5）。

**目标四：一开始做最好最优秀 = 立缝在册、渐进有判据。** 七件「现在立缝」全部已在册（trait 冻结 / intent 编码冻结 / EM 表形状 / 观测面外迁 / 绝对截止时间重编程 / 单比较器 / 三槽 RCU＋shadow 双轨，02 号 §4.1）；三件渐进各有 kill criteria 在册（EAS 选核 / band 执法 / AI 学习策略），与业界节奏一致而非落后。

**原则（裁决冲突时的上位依据）**：①在途线收编不推翻——W3 外迁族 / SMPD v1.4 / PM 三期 / perf 四线零碰，刀序原号引用不重开；②公平是机制默认，intent 是策略输入，叠加永不替代（ADR #42，[架构决策](架构决策.md):51）；③机制在内核、策略可插拔，`SchedClass` trait 签名冻结一字不改（[调度器设计](调度器设计-v1.1.md):53-61）；④小步纪律——每刀独立 QEMU 可验、独立提交、独立可回滚；⑤kill criteria 随刀挂、不做事后补（ADR #21/#42 既有纪律前移到每张刀单）；⑥测量先于治理（噪声底先于形态裁决，入场券基建先于 band 并线）；⑦QEMU/TCG 只报功能、顺序与相对趋势，绝对分位与功耗属真机阶段（调点调度 1.1 §8.2 口径继承）。

**排除项**：不重开 SMPD/PM/W3 既有刀序（原号引用）；不推翻 ADR #69/#70（否决 BKL / async 内核，重议仅经各自触发器）；不做 per-handle 硬预算与指令级调度（调点 1.1 排除面）；不提前缴 4 核＋复杂度税（2 核档远程读可受，SMP 部署设计 :102-108）；MCU 档整体排除（ADR #40）。

## 2. 终态架构（四层，01/02 号合流）

```text
┌──────────────────────────────────────────────────────────────────┐
│ ③ 策略面（用户态 EL0，可插拔全谱——崩则降级保活，调度正确性不依赖）  │
│   advisor（确定性生成，同输入同输出可 diff 审计）                    │
│   AI 实验轨道（(B) 分类器 →(A) 学习策略，kill criteria 全程挂）      │
│   PM governor（DVFS/热/休眠——频率唯一裁决者）/ manifest 角色表      │
│   IntentProfile 按设备档位选表（手表表无 placement 列）              │
│       ▲ 遥测读（合并视图）              │ 候选 PolicyEntry 表        │
├───────┼──────────────────────────────────┼────────────────────────┤
│ ② 注入面（窄腰 ABI，能力门控）            ▼                         │
│   policy_bind 0x83 六 op（COMMIT/STATUS/PROMOTE/DEMOTE/UNBIND/     │
│     SHADOW_COMMIT；±64 三点夹紧；gen 陈旧拒收）                     │
│   intent 声明（u8 六档冻结，pledge 只降不升）/ RIGHT_MANAGE 门控     │
│   · Job 级 SET_POLICY（v2）/ freeze token / timer slack / bootparams │
├──────────────────────────────────────────────────────────────────┤
│ ① 机制内核（EL1，冻结面——SchedClass trait 签名一字不改）           │
│   class 链：rt > deadline(EDF＋ΣU≤0.95) > fair(EEVDF×N 带) > idle  │
│   三槽 RCU 快照＋shadow 双轨＋divergence / hazard-lite / 写者锁     │
│   band CBS 8 槽（默认全关，与接口缺席逐位等价）/ freeze / PI 捐赠   │
│   intent 随消息传播（三道帽 8 跳/50ms/400ms）/ tickless 绝对截止期   │
│   capacity 拓扑 / EM 表 / util EWMA / per-CPU runqueue＋偷取＋SGI   │
├──────────────────────────────────────────────────────────────────┤
│ ⓪ 观测面（横切全层，host 钉板终态——W3 *face 族外迁）                │
│   telemetry 切换/唤醒双环 · HDR 897 桶 per-CPU 双路 · stats 查询面  │
│   五仪表盘 · *face 纯函数 host 单测（判定律单源，先 host 后内核）    │
│   口径纪律：QEMU 趋势 → 真机分位（p50/p99/p99.9 门禁随真机相）       │
└──────────────────────────────────────────────────────────────────┘
```

**机制内核（冻结面）**：trait 签名＋class 链＋原语集，业界五家对照（Linux/Android/Zircon/QNX/Zephyr，02 号 §1）后无一件需要返工。**注入面（窄腰）**：全部策略经数据表 / 声明进内核，无第二语义域（ADR #58 单一词汇表立法精神）。**策略面（全谱可插拔且可崩）**：与 PM 同级同模式，崩则内核回退启发式继续调度（ADR #21/#28 降级保活）。**观测面（终态增量）**：W3 外迁族把「内核调度逻辑只能在整机里测」的业界常态翻转为「判序单源＋host 单测＋内核消费壳」，与 Zircon libsched 同向且已跑在前（HEAD 已并 face 族 22 crate，hermes lane 深化在途——01 号 §2.1 两级口径）。

**跨层不变量五条**：①公平是机制默认，intent/band/AI 全部叠加永不替代；②调度路径零频率写点，频率裁决单点归 PM 服务（[调度器设计](调度器设计-v1.1.md):355 红线）；③RT/deadline 一律屏蔽 AI 干涉，band 环扫跳过 deadline 任务（HELD_THROTTLE 一消费者一位）；④空表等价——绑空表与未绑逐位全等（POLICY ok 机器断言）；⑤冻结面演进 = 原地升版不翻契约（`SchedClass` trait 冻结硬约束，[sched/src/lib.rs](../sched/src/lib.rs) 头注）。

## 3. 裁决集（十裁，每裁给依据与反论）

**裁一（机制链不分叉）**：三大支柱不是三套机制，是同一机制链的三组参数来源。依据：02 号 §2（业界五家对照后总判词）＋ capacity 抽象三端通用（[调度器设计](调度器设计-v1.1.md):63-69）＋ intent=查表键零新层级（ADR #42 第一段）。反论：「为 AI 单开一条调度路径」——违 #38 三不赌与 #21 带内纪律，ghOSt 迁往 in-kernel BPF 的自我否定是业界反面（SCHED-01:9）；「为省电单开低功耗调度器」——tickless＋EM 表＋PM governor 三件已构成省电机制链，无需第二调度器。

**裁二（机制内核冻结面）**：`SchedClass` trait 签名与 class 链终态冻结，后续一切演进（band 化 ×N 实例 / EAS 选核 / v2 RT）都在 trait 之内实例化或叠加，不改签名。依据：trait 冻结与 `sched/src/class.rs` 一字一致（01 号 §三.1 实测核对）；五家插拔轴各异（Linux=BPF、Zephyr=队列、QNX=调度器整体、Zircon=无），BerryOS 轴选在「策略数据」——最粗粒度、最稳、no_std 可行（02 号 §4.1-1）。反论：「预留 trait 演进缝更灵活」——sched_ext 的 ABI 明示无稳定性保证（02 号 §1.1 一手）是灵活的代价面；band 化经 `priority() -> i32` 映射严格序已证明不需要改签名（[调度器设计](调度器设计-v1.1.md) M4 节）。

**裁三（策略面可插拔可崩，三槽 RCU＋shadow 双轨是终态形态）**：运行时换表、可回退、可 A/B 判定的三槽 RCU＋shadow 双轨＋divergence 对账是策略插拔的终态答案，业界五家参照中为空白（[白皮书](调度器架构白皮书-v1.0.md):93-103 对标表）。依据：2026 年新证据维持判词——LAVD 演化（gaming → servers → eventual enforcement → 回馈上游 EEVDF 计划）反向趋同「可 A/B、可回退」形态（LWN 1097209，02 号 §1.1）。反论：「sched_ext 式整核热切换表达力更强」——BPF 能写任意数据结构，但 BerryOS 动作空间四类封顶（ADR #21 修订）本来就以 expressiveness 换保守性，内核 716 行策略面＋宿主侧确定性 advisor 的可测试 / 可回退 / 可审计占优（02 号 §2.2 差异判词）。

**裁四（观测面外迁宪法定型）**：face crate 族 = 调度纯逻辑层（host 测试义务层），sched = 并发机械＋HAL 桥（QEMU/ktest 义务层）——两层单源纪律（改 face crate 的语义 = 改 sched 行为）由本计划显性化为结构宪法；新增机制从 day-one 就问「判定律进哪个 face」，判定律先 host 钉板后进内核，违反即刀单不合格。依据：W3 族 Q1..Q66 既有实践的制度化（01 号 §2.1；03 号 §3.3-1 成法列举）；Zircon libsched environment-agnostic 同向印证（02 号 §1.3）。反论：「外迁终点不可达，徒增 crate」——终点判定有可验收判据（判定律 100% 单源在 face crate 且 host 钉板，sched/src 保留面 = 真指针 / IRQ 屏蔽窗 / 上下文切换，成册随 CP-01，开放问题 7）。

**裁五（AI 支柱终态 = 机制在位＋轨道在跑＋判据在册）**：AI 本身可被 kill 而支柱不塌——接口保留、遥测优先、A/B 判定可撤，kill criteria（M4 前在可复现 A/B 中无可测尾延迟 / 能耗收益 → 永久 hint-only）是 day-one 设计的一部分。依据：ADR #21 修订（2026-10-16 D5，[架构决策](架构决策.md):30）＋ 端侧学习型调度零确证生产先例；LAVD 的 criticality 推断量产化验证了 (B) 分类器路线（02 号 §2.2 新证据），但不改「收益必须可证」的立法。反论：「任务书与 AGENTS 身份节把 AI 列为身份支柱，本裁与身份冲突」——措辞张力如实记录（02 号 §0.4），归 owner 拍板（开放问题 9）；本计划按 ADR 现行法行文，支柱的兑现形态恰是「后悔药也是设计的一部分」。

**裁六（band 第二段凭入场券，查表键即终态不是债务）**：扁平 EEVDF＋latency-nice 是 band 必须打败的零假设；入场券（过载尾延迟差＋饥饿计数＋wasted-cores 金丝雀）证据不足则单实例＋查表键形态即终态，不并线、不算欠账。依据：ADR #42 第二段（[架构决策](架构决策.md):51）＋ [白皮书](调度器架构白皮书-v1.0.md):109 ＋ SMP 部署设计 :160-163；Linux 主线就是扁平 EEVDF，band 只在预约语义与整带功耗杠杆两件 weight 做不到的事上有净收益（[调度器设计](调度器设计-v1.1.md) M4 入场券节）。反论：「band 机制已建（CBS 8 槽＋全局原子账）不用白不用」——默认全关与接口缺席逐位等价是诚实态；执法并线的唯一门是实证收益，不是沉没成本。

**裁七（v2 工业 RT = band 的对象化升格，不是 APS 移植）**：QNX 血统取词汇（预算包络 / 只在竞争时执行 / 空闲 loan / 整数微记账）与记账模式（client-pays 消息记账），结构上把 APS 的死因（策略焊进热路径）从设计里剔除；v2 若需硬分区隔离，只做「band → 分区对象」升格案（动态成员 / 继承树），键位（intent_effective＋`Process.band_id` 双键）已预留，不新开第二套分区机制。依据：[AI 调度设计](AI调度设计-v1.0.md):76,86（APS 反面判例）＋ SCHED-01:10 ＋ 02 号 §2.4（差异清单收口：APS 有而 band 无的只有「分区是一等 OS 对象」一件）。反论：「直接移植 APS 更快到达工业 RT」——APS 死因判例（每次决策扫全部分区、分区硬上限 8）正是要避开的形态；admission ΣU≤0.95 显式含 band 项（CP-14 补写）后 deadline 保证已独立于分区形态成立。

**裁八（SMPD 刀序原样收编，铁门不绕）**：波一以 SMPD-0..5 原号刀序为基座（CP-02..CP-07 映射），SMPD-0 不绿后续 SMP 刀不开（在册铁门，SMP 部署设计 :66）；SMPD-0 被外部裁决（X-6 fix-or-withdraw）阻塞期间，CP-03/CP-04 的设计预研与 host 面可并行，QEMU 相执法一律等绿门。依据：SMP 部署设计 v1.0 刀序权威＋ 01 号 §1.6 实测对账（SMPD-3/4 已落码：1869412f band 全局原子账、078073be divergence per-CPU 分账、54fc9b64 双核终验 60 ok；SMPD-0/1/2/5 未动——代码 grep `POLICY-S|SMPBENCH|BAND-S` 零命中，git 与 01 号两源）。反论：「为进度绕开 SMPD-0 先做 SMPD-1」——铁门立门理由是基线钉板（多核证据面没有可信基线则后续验收全部失真）；「SMPD-3/4 已落说明刀序可跳」——3/4 是无 SMPD-0 前置的数据面刀（原子账 / 分账），0/1/2/5 是验证与激活刀，不可互替。

**裁九（调度-PM 契约：频率裁决单点归 PM，berry-power 必须立项）**：调度器只产信号（util EWMA / placement hint / EM 数据面），绝不写频率；PM governor 是省电支柱终态图景的承重墙，当前 berry-power 服务实体未建 = 三大接缝中最大的空转机制（01 号 §四.2）。依据：[调度器设计](调度器设计-v1.1.md):355 红线 ＋ PM 三期立法三件已落（ADR #66-#68）而消费侧缺位（util/EM 三产无消，01 号 §2.4）；PM-15 六面零新 syscall 裁决在册。反论：「调度器直接改频更快兑现省电」——违机制 / 策略分离与 #21 带内纪律，且 Linux schedutil 与 EAS 的独占搭配是「调度器出信号、governor 裁决」的同向先例（02 号 §1.1）；「等真机再做 berry-power」——QEMU 期即可兑现的功能面（订阅通道 / 容错三断言 / watch/perf/balanced 三档形态）不必等功耗计。

**裁十（三条新缝现在留，三笔旧债现在清）**：缝一，EEVDF 睡眠任务 lag 衰减语义——Linux 用 deferred dequeue＋VRT 衰减防「短睡重置负 lag」作弊，BerryOS 在册文档无对应条款，设计位立法占位（三选：入队即衰减 / 保留 / 完全重置，各自作弊面写清），随 CP-09/CP-12 前裁（02 号 §4.2-8 建议）；缝二，util 信号跨核迁移组合语义——PELT 数学可组合而 BerryOS per-CPU EWMA 不可组合，均衡器 band 维度化前补「迁移任务的 util 结转」决策位（不结转 / 新窗起学 / 按 EM 容量比折算，02 号 §4.2-9）；缝三，管家核（reserved core）Topo 缝——PC 完整 advisor 跑管家核已在册而 Topo/capacity 表无保留核字段，v1.4 SMP 相立 reserved 标志位（LB/偷取/放置全绕行，02 号 §4.2-10）。债一，timer slack＋policy 三元组 day-one 承诺未落码（`grep slack kernel/src/ sched/src/` 零命中，01 号 §1.2）——CP-11 补刀或改口，不允许承诺悬空；债二，注入传输形态终裁写死：v1/v3 终态 = 0x83 16B×≤128 直传，不建共享环（注入频率 10-100ms 慢循环级、批量上限 2KB、零新内核机制；[AI 调度设计](AI调度设计-v1.0.md):42 的共享环表述随 CP-13 升版改口）；债三，调点 1.1 收官尾巴两笔（CMP-1..4 host property / `Task.obligations` 位图）正式清偿或降级为「以现形态为终态」的 ADR 追记（01 号 §四.8）。反论：「缝与债都可以等实现时再说」——lag 与 util 两缝在 band 维度化与均衡器刀前不裁，实现时随手选档就是「打补丁」；timer slack 是唤醒合并（省电第二杠杆）的内核机制载体，悬空即省电支柱缺件。

## 6. 重议触发器与开放问题

### 6.1 重议触发器（任一触发，对应裁决带新证据重开）

1. X-6 终裁出果（fix-or-withdraw）→ CP-02 解锁，波一重排；若撤刀形，SMPD-0 基线语义重述（裁八部分重议）。
2. band 入场券判定出果 → CP-12 开账或关账；关账则 M4 第二段立案为「查表键即终态」，IntentProfile 升为唯一 intent 消费面（裁六执法）。
3. AI kill criteria 复核出果（CP-15）→ 升格走 shadow PROMOTE 路径，或永久 hint-only 关账（裁五执法）。
4. 4 核＋真机或模拟档落地 → per-CPU 读者快照与写者锁形态复议（SMP 部署设计 :102-108；反噬则 K4）。
5. 上游演化改写证据面：LAVD/sched_ext 生态若把「影子双轨＋A/B 判定」变成上游标配，裁三的业界空白判词重述；EEVDF lag 衰减或 PELT 组合语义若上游大改，裁十缝一/缝二重议（02 号 §1.1 追踪面）。
6. 真机 SoC 选型落定（Phase 8）→ CP-18/MS-3 议程化；若首板即非对称大小核，CP-09 与 CP-19 合并窗口重排。
7. lockdep 违规率持续高企（激进镜像 soak 连续两个开发周期不收敛且锁序立法＋持有集位图双管齐下无效）→ #69 触发器激活，局部粗锁复评（K9）。
8. QNX APS 8.0 存废证实或工业 RT 需求提前 → 裁七升格案窗口提前（v2 RT 谱 CP-17 议程重排）。
9. 三大身份支柱措辞 owner 拍板（开放问题 9）→ 裁五按新措辞重述，机制面不动。
