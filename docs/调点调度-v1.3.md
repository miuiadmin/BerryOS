## 4. SMP 策略（上）：全局策略表、placement overlay 与写者锁

- **已落·写者锁 ✅（四刀，沿革一百三十二）**：`POLICY_LOCK`（AtomicBool
  CAS 自旋锁，Acquire/Relaxed）+ 五写者函数入口全串行（bind/bind_gen/
  bind_gen_shadow/promote/demote——错误路径同解锁防泄漏）；锁序钉
  「表/KL」档禁嵌 RQ/SLEEPQ；单核 CAS 首试即成零行为变化。候选形态
  之争（粗粒度 vs seqlock）就此收敛为粗粒度 CAS——复用三槽 RCU 为
  底层，未长第二套发布协议。
- 全局表 vs per-CPU（预研建议①）：**未裁未动**——现状三槽 RCU 即全局
  单表形态，gen 全局单调天然成立；per-CPU 读者快照指针未做（2 核档
  远程读尚可接受，4 核+ 复议）。
- placement overlay（预研建议④）：**半落**——字段 S6 已在；apply()
  顺带消费 + `placement_hint()` 读出口已落（首刀，沿革一百二十九，详
  §6）；「选核处消费接口」仍预留（唤醒/迁移/spawn 三路未接，等真
  SMP 相）。
- **未落**：跨核换表等价断言（LB 金丝雀「换表窗零丢片/零双跑」）、
  各核见表 gen 漂移合法窗观测——随 smoke-smp 扩展相承接。
- 依赖：KL-first 锁序不可破（§A112）；换表窗不得与 SVC 分类表窗嵌套
  出跨核 ABBA；写者锁与 shadow 三件共用一把（§5——已兑现同锁）。

## 8. 真机框架（上）：双轨发布与环境控制

- 双轨发布（预研建议①）：同一内核镜像 QEMU/真机双轨可发布——构建面

- RPi4 特有面（预研）：GIC-400 vs GICv2 差异、PL011 串口时钟、DVFS

## 10. 多核回滚安全与护栏

- 回退链多核化（1.2 §9 三层链版本化）：服务崩溃→启发式、表龄超阈→
  watchdog 自动回退、权限吊销→通道关闭——每层加「跨核生效时延」列：
  换表原子性决定回退不是瞬时的，时延上界即验收线。
- 核心问题：回退瞬间跨核语义——各核见表 gen 漂移（§4 合法窗）内，
  placement 消费与 band 记账的一致性底线是什么？「回退 = 回到 1.2
  行为」的逐位等价断言（POLICY ok 先例）多核怎么扩？
- 不变量清单增量（1.2 §10 全表版本化 + 多核列）：band 预算 AI 不可触
  （全局原子账单点执法）、placement 不得违反 RT/deadline 屏蔽、单调
  收窄跨核成立（gen 全局单调）、调度路径零频率写点（§7 红线入表）。
- 核心问题：护栏执法点多核竞态——防饥饿 boost 跨核谁执行（每核自查
  vs 交叉核复核）？空闲核金丝雀（band 入场券件，1.2 §7）SMP 怎么定义
  ——「恒空闲核不存在」时入场券作废还是改口径？
- 依赖：§4 写者锁（回退 = 一次写者换表走同一路径）；advisor 表龄
  watchdog（1.2 §4 未竟件）随真机线或 SMP 线先落。

## 14. 风险与 kill criteria

- 风险表起点：全局表写者锁成跨核瓶颈（2 核尚可、4 核+ 反噬）；placement
  消费打不过零假设（EAS 版「band 打不过扁平」，1.2 §7 同型）；真机
  环境噪声淹没 A/B 信号；HDR 桶溢出/失真（长尾进溢出桶 = p99 假稳）；
  shadow harness 观察者效应多核放大（核间干扰新面）。
- kill criteria 候选（ADR #21 框架对齐）：placement/EAS 线真机拿不到
  可复现收益 → placement 降回「落字段不消费」（1.2 形态即退路）；
  全局表在目标核数不可扩展 → SMP 线冻结于 2 核档并文档化（v2 复议
  per-CPU）；真机噪声底高于预期收益量级 → 门禁只保功能不保性能。
- 核心问题：每条 kill 的判据数字、判官（谁跑真机 A/B、谁签收益单）、
  时限与复核节奏；降级后接口保留形态（hint-only 长什么样——1.2 §14
  同问的真机版）。
- 依赖：§8 环境不确定度预算（噪声底是判据数字的输入）；§9 三路基准
  的 QEMU 侧方差数据先行。
