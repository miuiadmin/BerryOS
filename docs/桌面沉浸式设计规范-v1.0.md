# BerryOS 桌面沉浸式设计规范 v1.0

Type: standard
Status: superseded
Superseded-by: [iOS视觉与流体交互复刻标准-v1.0.md](iOS视觉与流体交互复刻标准-v1.0.md)
Updated: 2026-11-18
Version: 1.0.0

一句话说明：owner 2026-11-16 至 11-17 连续裁定的桌面视觉形态——壁纸从屏幕顶到底一条直通，所有 UI 元素（状态栏/dock/桌面图标/导航键）以白色符号或彩色图标直接浮在壁纸上，无任何不透明底色块。本文是唯一视觉真相源，改动前必须对照。

## 1. 总体形态

```
┌─────────────────────────┐
│ ← 壁纸直通到屏幕顶 →     │ y=0
│ 状态栏内容（白字浮壁纸）  │ y≈0-117
│                         │
│ ← 壁纸 →                │
│ 桌面图标（浮壁纸）        │ y≈200-1400
│                         │
│ Dock 栏（SmartDock 面板）│ y≈1550-1725
│                         │
│ 导航键（白符号浮壁纸）    │ y≈1785-1920
│ ← 壁纸直通到屏幕底 →     │ y=1920
└─────────────────────────┘
```

**铁律：壁纸之上不允许出现任何不透明纯色 Rect 底块。**

## 2. 状态栏（顶部 117px）

| 项 | 规格 |
|---|---|
| 高度 | 117px = 39vp × 3（OH_STATUS_H） |
| 背景 | **无**（壁纸直通，scrim 已撤） |
| 内容 | 信号/wifi 图标 + 时钟——白色符号直接浮在壁纸上 |
| 禁止 | scrim 衬底 / 预混深色带 / 任何 Rect 底块 |

## 3. 桌面图标格

| 项 | 规格 |
|---|---|
| 背景 | **无**（CELL_FACE_BG Rect 已撤） |
| 图标 | .bap 包 BYI1 图标，自带渐变色底（genohicons OH 风格） |
| 禁止 | 格子底块 / 按压面 Rect |

## 4. Dock 栏

| 项 | 规格 |
|---|---|
| 形态 | SmartDock 面板（OH 官方 BYI1 分段面） |
| 背景 | 面板自带半透明蓝底（genohicons 生成，非 Rect 覆写） |
| 图标 | 四位（联系人/相册/设置/短信），Material Icons 同义形 |
| 禁止 | BottomTabs 白底 Rect / 额外底色块 |

## 5. 导航条（底部 135px）

| 项 | 规格 |
|---|---|
| 键数 | **3 键**（返回/主页/多任务——安卓 12 式） |
| 符号 | 返回=‹ chevron / 主页=● 实心圆 / 多任务=□ 空心方 |
| 键尺寸 | big=96px / compact=44px |
| 间隔 | big=176px（25/50/75 宽度均布）/ compact=76px |
| 条高 | big=135px / compact=44px |
| 底色 | **透明**（NAV_BASE_BG=0x00000000，A=0 跳过=透壁纸） |
| 旋转/关机 | **撤出屏条**（Web 桌面下旋转无消费者、关机走 berry API） |
| 禁止 | NAV_BASE_BG 设为任何 0xFF...... 不透明值 / Rect 按压底块 / 五键布局 / BottomTabs 常驻桌面页 |

## 6. 禁止清单（改动前自查）

| 禁止项 | 原因 | 替代 |
|---|---|---|
| 状态栏 scrim Rect | 盖壁纸 | 壁纸直通 |
| 桌面格 CELL_FACE_BG Rect | 盖壁纸 | 图标自带底 |
| 导航键 NAV_BASE_BG 不透明 | 黑色方块 | 0x00000000 全透明 |
| 导航键 Rect 按压底块 | 黑色方块 | glyph 亮度变化 |
| BottomTabs 白底 Rect | 白条 | 撤 |
| BottomTabs 桌面页常驻 | 与三键重复 | sys 页切入时按需建 |
| 五键导航（含旋转/关机） | owner 已裁三键 | 别名保 NavNodes 结构 |

## 7. 应用打开后的系统栏行为（目标态）

| 项 | 目标 |
|---|---|
| 状态栏/导航键 | 常驻应用之上（波3 带合成 v1） |
| 带背景 | 透明——应用色透出=「跟随」 |
| 应用内容 | edge-to-edge 满幅绘制 |
| 应用避让 | WM_GETINFO 扩 inset 四域（add-only） |
| 禁止 | set-bar-color 类协议（Android 15 已废） |
