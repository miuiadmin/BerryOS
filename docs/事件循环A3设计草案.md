## §2 缺口分析：从「sid 会话」到「POSIX socket fd」差什么

1. **fd↔sid 映射层缺失**（#7-9）：socket fd 不存在；connect/accept 产出的会话只能拿裸 sid 走 RPC（bsh evs 形态）。POSIX 消费面（std::net/自写 C 样例）要的是 fd 号进 read/write/close/poll 统一分派。
2. **非阻塞地基缺失**（#4/#6）：F_GETFL/F_SETFL 无宿主、sockopt 族 ENOSYS——std::net 与事件循环消费方（berry-poll 接 fd 面）都先碰这堵墙。
3. **名字解析全断**（#5）：getaddrinfo 恒 EAI_NONAME——std::net 连 10.0.2.2:18081 直连都被拒（musl 语义 IP 字面量不走 DNS，桩把它一并拒了）。
4. **RT 语义 vs send/recv 分离**：netdproto OP_TCP_ROUNDTRIP = 收发一体（写+读回）；POSIX send = 只发、recv = 只收。echo 链上 RT 恰好同构，但通用 socket 面（先写后异步读/半关闭）需要 SEND/RECV 分离 op 或 DRAIN 组合——**A3-1 首查项**（两案：①新增 OP_TCP_SEND/OP_TCP_RECV 协议面；②send 走 RT 空载读丢弃/recv 走 POLL+DRAIN 组合——协议不动纯客户端拼装）。裁定轴：vnet 单会话「收发一体」模型是否把「已发未收」字节卡死在 RT 应答里（echo 外形态）。
   **裁定（A3-1，2026-10-29）= 案②**：vnet 代码实读推翻「收发一体」前提——serve 命名 RT 臂（`drivers/bins/vnet/src/main.rs:961-977`，sid≠0）是**纯发送臂**：`table.send_data` → `drive_until(arm_idle==Some(true), 30s)` → ST_OK/ST_TIMEOUT，应答 dl 恒 0（1B `[st]` 不携回显）——「写+读回」只属 legacy RT（sid=0 走 echod 对端）。「已发未收字节卡死」形态不存在：send 后字节即在对端，recv = POLL 就绪位 + DRAIN 收割组合（bsh evs data-wait/DRAIN 链已是同语义实证，A2-3）。**协议零改动**（netdproto/vnet 双端零 new op）；残留 = send 阻塞语义是「等 ACK」（arm_idle 30s 帽）非 POSIX「仅入队」——v1 文档化可接受，真异步写留 v2。

## §3 设计

### 3.1 fd 模型：SocketTable 独立段（15..=22）

- **新表 `SocketTable`（berry-fsclient，host 可测纯函数）**：8 槽（容量与 `TCP_SESSIONS_MAX=8` 同源单一定值）；表项 `{kind: Unconnected/Client/Listen/Server, port: u16, sid: u32}`；fd = `SOCK_FD_BASE(15) + 槽号`。
- **号段免疫**：别名/ fs 扫描上界 15 排他（#7），socket 段 15+ 结构性无碰撞；fcntl F_DUPFD ceiling=15 边界零改动（dup socket fd → ENOSYS 同 fs fd 口径，零漂移）。
- **POSIX「最低可用号统一空间」v1 明弃**：分段的诚实简化（fd 号具体值无在册消费方依赖——std/自写程序只要求唯一与有效）；文档化取舍，统一空间留 v2。
- **libc 分派接线单点**：read/write/writev/close/poll 的 fd 归属链尾插 socket 表查询（fs miss → socket miss → EBADF）；console/fs 零改动零漂移。

### 3.2 协议映射（POSIX 桩 → netdproto op）

| POSIX 调用 | 映射 | 备注 |
|---|---|---|
| `socket(AF_INET, SOCK_STREAM, 0)` | SocketTable alloc Unconnected 表项 | 不发包；AF/PF 非 INET 或 type 非 STREAM → EAFNOSUPPORT/ESOCKTNOSUPPORT（域执法） |
| `connect(fd, sockaddr_in)` | `OP_TCP_OPEN`（尾随 sid=0 legacy 形）→ Client 表项 | ST_NODEV/ST_TIMEOUT → ENODEV/ETIMEDOUT 错码映射表 |
| `bind(fd, addr)` | 表项本地记 port | 纯本地（netdproto LISTEN 自带 port——bind/listen 拆 POSIX 面、合 RPC 面） |
| `listen(fd, backlog)` | `OP_TCP_LISTEN(port)` → lsid → Listen 表项 | ST_FULL → EADDRINUSE 近似档；ST_NODEV → ENODEV |
| `accept4(fd, …)` / `accept` | `OP_TCP_ACCEPT(lsid)` → dsid → 新 Server 表项 + 新 fd | ST_EAGAIN → EAGAIN（非阻塞语义原生）；accept 桩 = accept4(flags=0) 委托 |
| `send(fd, …)` / `write(fd)` | **案②已裁定（§2-4）**：命名 RT（sid≠0 纯发送臂，send_data → arm_idle ACK 30s 帽） | 阻塞/非阻塞按 F_SETFL 旗分岔；协议零改动 |
| `recv(fd, …)` / `read(fd)` | `OP_TCP_DRAIN`（带据 ST_OK+data / 无据 ST_EAGAIN） | 阻塞 recv = POLL 节拍 + DRAIN 循环（bsh evs data-wait 同款，1s 节拍）；非阻塞 = EAGAIN 直返 |
| `poll(fds)` socket 项 | `OP_TCP_POLL` flags/rbytes → POLLIN/POLLOUT revents | 映射纯函数 host 钉板 |
| `close(fd)` | `OP_TCP_CLOSE(sid)` + 释槽 | Listen fd 关 = 撤 listen 会话 |
| `fcntl(F_GETFL/F_SETFL)` | 表项 O_NONBLOCK 旗（socket fd 专属） | fs fd 保持 EINVAL/ENOSYS 原值零漂移 |
| `setsockopt`/`getsockopt` | 谎报白名单：setsockopt v1 无语义者（SO_REUSEADDR/TCP_NODELAY…）返 0；getsockopt SO_TYPE→SOCK_STREAM 等定值 | 「errno 档位跟上游消费面白名单走」Gotcha 纪律；白名单初值 A3-2 按 std::net 消费面实测定 |
| `htons/ntohs/htonl/ntohl` | 字节序桩（rotate 一行族） | sockaddr_in 构造消费面；A3-1 首查在册情况后补 |

### 3.3 getaddrinfo 真实现（IP 字面量档）

musl 语义：IP 字面量在 getaddrinfo 内自消化（不走 DNS）。真实现 = 自写点分四段解析器（`parse_ipv4` 纯函数 host 钉板）→ sockaddr_in 直构（`sin_family/sin_port(BE)/sin_addr` musl 布局，C-2a Stat 钉板法：`const _: () = assert!(offset_of!…)`)；service 端口解析（十进制或 NULL）；非 IP 字面量 node → 保持 EAI_NONAME（DNS 域 = netdproto `OP_DNS_QUERY` 在册，接通留 A4/后续刀——vnet SLIRP DNS 离线确定性面已备）。**解锁面**：std::net `TcpStream::connect("10.0.2.2:18081")` 类 IP 直连全链。

### 3.4 sockaddr ABI 面

`sockaddr_in`/`sockaddr`/`sockaddr_storage` `#[repr(C)]` + offset_of 全字段编译期钉板（musl aarch64 asm-generic 口径——sin_family@0 u16/sin_port@2 u16(BE)/sin_addr@4 u32/sin_zero@8 u8[8]，sizeof=16；sockaddr = family u16 + data[14]）。C-2a Stat 布局案同族执法：「同尺寸不同字段序 = 最阴的静默错」。**addrinfo 布局对源 = libc crate linux_like 非 android 分支**（ai_addr@24 紧随 ai_addrlen 的 glibc 序；hermit/android 分支 ai_addr 在 canonname 后——异序反例证明必须对目标源确认，A3-1 实录）。**sockaddr_storage 裁出至 A3-2**（A3-1 零消费方——accept 出参面真消费时钉板，不长第二套纪律）。

### 3.5 验收线（A3 整卡收口）

- **guest 自验**：bsh `skt_selftest`（evs 七步链的 fd 皮：socket→bind→listen→accept 链/非阻塞 EAGAIN 节拍/data-wait/recv(DRAIN)/send/close——期望值字面常量）→ `SKT ok` 类标记（smoke 挂线，rootfs 相 +1；名对表在册标记防子串撞）。
- **std::net 对拍（若 getaddrinfo+谎报面够）**：guest 内 `TcpStream::connect("10.0.2.2:18081")` 环回写读对拍（hostfwd 环回自连同 A2-2 段③；宿主 evsclient 对拍源复用）——**加分项非门**：撞 std 深水面（async 线程池/sockopt 判死类）即裁留 A4 sysroot 对表，kill criteria 原文执法。
- **host**：SocketTable/parse_ipv4/revents 映射/错码映射表纯函数新增全绿（fsclient host 测扩容）。
- **零漂移硬线**：五相 smoke 既有标记全绿（console/fs/别名面零改动按构造）。

## §5 风险与 kill criteria

- **kill（卡在册原文）**：A3 socket ABI 撞 musl/std 假设结构性墙（桩不可谎报、std 启动路径判死类）→ 重定 A3/A4 范围盒留档，不硬扛。判定锚点 = A3-3 std::net 对拍面；自写 client + bsh 标记是底线验收（不依赖 std 面）。
- **RT 收发一体语义墙**（§2-4）：若「已发未收」字节被 RT 模型卡死且组合案拼不出通用 send——协议面加 OP_TCP_SEND/RECV 是 vnet+netdproto 双端改动（容量帽/黄金字节/域执法三纪律照旧）；首跑对拍 filter-dump 取证（A-7 先例）。
- **poll socket 项与 std 启动面**：poll 真实现是 std 判死先例（#3）——socket 项 revents 扩展不得动 console/fs 档既有行为（零漂移按构造 + smoke 执法）。
- **号段膨胀**：SOCK_FD_BASE=15 魔数与 ceiling=15 的关系写 const 断言（fsclient 侧 `FD_BASE+FD_MAX+ALIAS_MAX <= SOCK_FD_BASE` 编译期钉板）——两表独立演化时结构性免疫。
- **不做什么**：不做 DNS 解析面（getaddrinfo 只吃 IP 字面量，DNS 留 A4+）；不做统一 fd 号空间（v2）；不做 dup socket fd（ENOSYS 同 fs 口径）；不做 epoll（A4 以 berry-poll 语义为蓝本）；不做 UDP/raw socket（AF_INET+SOCK_STREAM 域执法拒其余）；不碰 abi.toml（零新 syscall——全 libc 桩面）。
