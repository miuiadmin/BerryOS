## 1. SLIRP 确定性（标记的地基）

- QEMU `-netdev user`（SLIRP）内建**虚拟 DNS = 10.0.2.3**：guest 发往 10.0.2.3:53 的 UDP 查询由宿主网栈代答。
- 查询 "localhost" → 宿主 `/etc/hosts` → **127.0.0.1**：macOS/CI Linux 恒有该条目，**离线确定**（无外部网络依赖——SLIRP 不真出网）。
- 因此 `DNS ok addr=127.0.0.1` 是**状态谓词非竞速**（4-5a「标记不得建立在竞速上」纪律）：应答内容唯一确定，只有全链（DNS 编码 → UDP 校验和 → IPv4 → virtio TX → SLIRP 代答 → RX → 解析）逐环正确才能打出。
- SLIRP 应答形态的已知偏差（A-7 实证族）：padding 补到最小线宽（解析按报文域长度权威消化）、CNAME 别在意外（解析已跳 CNAME 取首个 A）。

## 2. A-8a API 摘要（已落地，`user/berry-netproto/src/lib.rs`）

- **UDP**（RFC 768）：`encode_udp(out, src, dst, sport, dport, payload)` / `parse_udp(buf, src, dst) -> Udp`——8B 头、12B IPv4 伪头参与校验和；**len 字段权威**（<8 拒 / >buf 截断拒 / ≤buf 尾随容忍——ARP/IPv4 padding 纪律同源）；**csum=0 = IPv4 合法「未算」放行不校**；编码侧算得 0 发 0xFFFF（0 线上保留）。
- **DNS**（RFC 1035 子集）：`encode_dns_query_a(out, id, name) -> usize`（flags 恒 RD、QDCOUNT 恒 1；label 1..=63、wire 名 ≤255、点/NUL 拒面全执法）/ `parse_dns_a_reply(buf, want_id) -> [u8;4]`（id/QR/opcode/**TC 拒**/rcode/QDCOUNT=1 + question QTYPE/QCLASS 校验 + 遍历**跳 CNAME 取首个 A**）。
- **压缩指针环防护**：指针目标必须**严格小于**当前读位（前向指针一律拒——自指/互指环与越界同死状）；指针位点的结束偏移 = 指针处+2。
- 校验和拆 `rfc1071_sum`（不折叠 u32 部分和，**可精确结合**）+ `fold_invert`——UDP 三段分开累加（伪头/头镜像/payload）== 拼接整算，零拼缓冲。
- 测试 11→17：UDP 三测（wire 钉板 + naive 伪头交叉复核 + 0→0xFFFF 补档角搜索证明 / 坏字节 + 伪头错配 + csum=0 放行 / len 两向拒 + 容量面）+ DNS 三测（query 黄金向量 + 拒面全扫 + ok63=81 恰含 / reply 黄金 43B + 逐 flag 坏 / CNAME 跳过 + 平铺名 + 前向指针拒）。

## 3. A-8b 服务化设计要点（下一步）

- **vnet 常驻**（vblk A-4 同款纪律）：ARP 解网关 MAC 后**不再退出**；`serve()` 循环 = recv RPC（空队 wait READABLE **10s 帽超时重臂**——常驻服务空闲合法，P6 A-3 echo 教训）+ 处理 DNS_QUERY + 应答；**退出不复位问题随常驻消失**（A-7 瞬态探针的 STATUS=0 复位是退出路径的义务，常驻服务无此路径）。
- **berry-netdproto**：单对双向 channel 严格串行 RPC（fsproto/blkproto 同款）；请求 `[op u8][nlen u8][name]`、应答 `[st u8][addr 4B]`（ST_OK/ST_BAD/ST_TIMEOUT）；编码器 None 拒绝契约 day-one。name 长度帽 ≤ 64（DNS query 面 wire ≤255 已足）。
- **拓扑**：svcmgr 预拉 vnet（vblk 先拉的先例——fsmgr 依赖序同款）：channel_pair 得 (net_a, net_b)——net_b 随 env 块 gift 迁 vnet，net_a 留 svcmgr 为 client；vnet 需要的 vblk 端（fsmgr 用的 blk_a）不相关，网络无盘依赖。
- **DMA/队列几何**：复用 A-7 双队列（rx q0 / tx q1）+ rx 单描述符整收；DNS 查询 ~27B + 应答 ≤512B 远小于 160B 缓冲帽 → 应答帧可能 >160B（512+ 头）——**rx 缓冲需扩或 DNS 应答截断拒**（SLIRP localhost 应答实测 ~70B，安全；通用面文档化「> 缓冲则 ST_BAD」）。

## 4. 风险与对策

| 风险 | 对策 |
|------|------|
| SLIRP 应答延迟（TCG 下慢） | 应答帽 30s（vblk BLKD 同款——服务慢 ≠ 服务死）；smoke rootfs 相 DEADLINE 已 240s 有余量 |
| 应答帧 > rx 缓冲 160B | localhost 实测 ~70B；通用面截断 → ST_BAD 诚实拒（文档化） |
| 第二实例持窗杀服务（A-4 单主人教训） | svcmgr 单遍拉起唯一路径；bsh `run vnet` 恒 `mmio_vmo: None`（无窗死在 find_device 只死自己） |
| DNS 名面注入（v1 无交互输入） | 自验名硬编码 "localhost"（rootfs 相 stdin=/dev/null 下确定性成立） |
| 标记子串混叠 | `DNS ok addr=` 带参形态；与既有标记两两互非子串（A-1 FS ok 教训，A-8c 时全表复核一遍） |
