## §0 定位与边界

**定位**：G2 已过（2026-11-04，S-5 收官）后，v2 主线下一关卡 = G3（多核 + 全抢占）。本文立四件规格——①全抢占机制面（§2）②lockdep 立项（§3）③延迟基准双跑口径（§4）④激进配置常驻 soak 模板（§5）——并提案刀序（§6）。

**非目标**：本稿不动任何代码；零 syscall/ABI 面（抢占是内核内部机制——冻结常量「并发/基线」行的分阶段兑现，非破冻）；不宣称 G3 过关。

**话术限定**（沿母案 §7）：全抢占宣称以 G3 过关为准——此前一律「抢占点可抢占（G1 形）+ 双核（G2 形）」；S-2 话术限定「内核串行 + 用户并行」已随 S-3/S-4 演进为 per-CPU + 细锁，但「syscall 主体不可抢占」至今保留（E0 纪元刻意不改——免锁根基）。

## §1 现况盘点（四面侦察基线）

### 1.1 机制面

- **切换点家族**（sched.rs 符号锚，行号随时漂、定位按符号）：`yield_now` :688 / `exit_current` :757 / `exit_current_with` :765 / `try_preempt` :1729（4-4 直切点）/ `on_irq_tick`（G1 tick 抢占）/ `on_sgi_resched` :2190 附近（S-3b 义务⑧ CPU0 SGI 快速重调度）/ `park_recheck`（副核 park 环承接）。
- **免锁根基**：v1 = SVC 入口硬件置 DAIF 屏蔽 + handler 全程不解蔽（隐式临界区）→ S-2 E0 显式化 BKL → S-3/S-4 E1 per-CPU + 细锁 + 锁序立法（KERN_LOCK **已收缩为表类锁非退役**——k2r 勘误：仅 TABLE 位类号入口 + 直调窗 klock_enter 全谱取，kern_lock.rs 现役；E2 逐域下放待启）。「syscall 主体不可抢占」语义至今未变。
- **preempt-on-wake 现况精确口径**：今天只有两个例外——
  1. `try_preempt`（IPC fastpath send 面，syscall.rs:1615）：唤醒后若出选者 `prio_effective` **严格高于**当前任务才直切（seL4 direct switch 的 v1 形态）；
  2. `on_sgi_resched`（跨核唤醒 CPU0 侧）：SGI 到 = 队列刚入新任务即旋转出选（**同 eff 也切**——轮转语义，非优先级判定）。

  **通用唤醒路径 `wake_matching`（:1600 附近）注释明言「不立即抢占：唤醒方自身不切换，等 tick/yield 再切」**；跨核唤醒落对核队列后同样只等对核 tick/SGI（TCG 有效 tick ≈ SLICE_HZ/2 → 最长整片延迟，:2178-2180 注释实证）。
- **切换原语已支持 syscall 主体中途切走**（`block_current` / `try_preempt` 契约先例：异常帧留内核栈、切回续行、eret 恢复 SPSR）——**G3 缺的是通用可抢占窗（DAIF 解蔽 + 抢占点），不是切换机制本身**。
- **锁纪元**：E0（BKL）/ E1（per-CPU + 细锁）已落；E2（per-ChannelEnd / per-Vmo 逐域下放）未启（母案 §2.1 表，S-4 起/v2 归属）。

## §2 全抢占机制面规格

**目标形态**：任意安全点可抢占——SVC 主体分段解蔽 + 通用唤醒抢占；分阶段语义等价小步（纪律①——FreeBSD 5.0 大爆炸是反面教材）：

- **阶段 P-A 抢占点加密**：per-CPU `preempt_disable` 计数 + 显式抢占检查点族（syscall 返回边界、长循环切片点、拷贝类大 buffer 分段处）。不变量：计数 > 0 窗内禁切换（等价今日 IRQ 屏蔽窗语义）；解蔽点 = 检查点（计数归零即探峰出选）。SVC 主体按域分批解蔽（首批候选：console 写、pipe 拷贝、文件读中介拷贝段——k2r 勘误：原记「FAT 读路径」，kernel 无 FAT 面，域定谳 → §8.B；每批先列「现依赖 IRQ 屏蔽的共享触达清单」再动）。
- **阶段 P-B preempt-on-wake 通用化**：`wake_matching` 族唤醒直切（同核：`try_preempt` 既有判定从 IPC fastpath 单点扩到通用唤醒面；跨核：SGI kick 已有，补齐对核侧优先级判定——对核在临界区内则置 need_resched 位，出窗即切）。唤醒延迟上界从「最长整片」缩到「临界区出窗」。
- **阶段 P-C 临界区收缩联动（E2）**：spin 临界区 preempt-safe 化——逐域下放（per-ChannelEnd / per-Vmo 锁）时同步裁决「preempt_disable vs local IRQ 屏蔽」二选一；不设固定刀号，随 P-A/P-B 推进暴露的共享触达逐块起刀。
- **每阶段验收**：ABI 零破冻声明 + 主 smoke 零漂移 + test-host 全绿 + **金丝雀重审记录**（唤醒直切会抬切换率——`switches=N` 严格递增语义保留但斜率变，稳态矩阵基线随阶段重标定；对照雷册 §A123 增量差设计判例）。

## §3 lockdep 立项（零基础）

**形态**（立项记录，实施刀细化）：debug 编译面 + 运行时检测器——

1. **cargo feature `lockdep`**（默认关——release/CI 主面零成本，激进镜像才开）；
2. **锁类注册表**（lock_class 静态登记，覆盖 SpinLock 家族 + 打印锁）；
3. **取放点 hook**（acquire/release 内嵌 debug 面，release 构建编译消除）；
4. **取放序环检测**（DFS 全序校验 → 环 = panic + 持有链打印，fail loud）；
5. **锁外打印禁令执法**（PRINT_LOCK 契约机器化——S-2 注释纪律升级为检测面）。

**与现况联动**：锁序立法（§1.2 七类全序）作为 lockdep **先验序**——检测器校验「实现不违立法」而非重新发明序；持有集位图（c-1 义务⑥）复用为持有链数据源。

**kill criteria**：debug 构建慢 > 3× 或误报率 > 10%（findings 大半是噪音）→ 降级为取放 trace 面（保留 1-3 项，弃环检测）。

## §4 延迟基准双跑口径

- **延迟分布基准 = R 线家族扩**（k2r 勘误：原「新增（B-0 家族扩）」失真；k2r-rv 再勘：原「单路→三路扩容」框架不准——R-0 现为全因混桶 + sig/tmo 分计非单路，timer 路 wake→run 已有 R-1 承接）：暂名 bench-lat = **wake→run 段补盲**（IPC send / SGI 两路——run 侧戳一行 + 直方图复用 R-0 形态）+ 唤醒源分桶口径 + G3 阶段对照，对拍今日基线（「最长整片」口径）证明 P-B 收益。
- **trace 开/关双跑**（`可观测性设计-v1.0.md` :52 过关要件）：同二进制 telemetry 记录面开/关两配置各跑全基准 → 基线双份入库（bench_baseline 家族扩）→ 关-开差值 = trace 劣化度，帽 = 关基线的 x%（x 实施刀首标定，参照 R-1 δ 档先例）。
- **纪律**：跨机不可比承 B-2 -icount 确定性通道立项理由（`基准与压力测试设计-v1.0.md` §13；k2r 勘误：§A95/§A109 实为 icount 漂移归因配方非本源先例，配套引用）；TCG 下 CNTV tick ≈ SLICE_HZ/2 口径注意（AGENTS 常见命令节）；尾延迟帽后续进激进 soak 断言面（§5）。

## §8 执行结果区（实施刀逐刀回写）

### G3-1 段① 入口侦察（2026-11-04；行号 = 当日基线，漂移按符号定位）

**A. 交织面测绘（§7 项① 结论）**——v1 冻结形态下不变量栈四层：

1. **SVC 硬件窗**：EL0 `svc` → 异常入口硬件置 DAIF（PSTATE.I=1）→ `exc_sync_el0` → EC=0x15 → `arch::syscall::dispatch`（按类位集 `svc_enter_class`：结构锁经 SVC_WINDOW 槽 = `sched::svc_window`（`held_locks`/`svc_mask` 记账 + 出口断言 held==class）+ TABLE 类 KL 类内末取）→ handler → `svc_exit_class` → `sched_exit_check`/`roll_quiesce_check`（零锁）→ eret 恢复 SPSR（用户 DAIF）。**「handler 全程不解蔽」属实**（§1.1 代码级验证）。
2. **内核任务直调窗**：`klock_enter` = `disable_irq` 先于一切取锁（雷 2）+ `svc_enter_class(ALL)`；窗外（`klock_exit` 后）IRQ 解蔽直到下一窗（task_waker 自旋段即此形态）。block_current 协议 = 显式 disable → block（舞蹈按位放锁）→ 续行重取（`klock_acquire_switch`：结构升序 + KL 最内）→ klock_exit 解蔽。
