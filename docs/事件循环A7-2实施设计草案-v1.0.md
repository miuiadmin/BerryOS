## §2 U4 date 钉板处置终呈（A7-0 §5 #3 钦定「随 A7-2 呈报，勿静默改」）

**A7-0 风险前提实测不成立**：#3 原文假设「REALTIME 分档后 date 输出随 boot 时长漂移 = U4 步③ 字面钉板破坏」。实测 U4 步③ = `run_capture("date", None, &["-u", "-d", "@0"])` 断言 `b"Thu Jan  1 00:00:00 UTC 1970\n"`——`-d @0` 让 chrono 走**解析渲染面**（epoch 0 字面 → 格式化），全程不调 clock_gettime/gettimeofday。钉板对 clock 语义**结构性免疫**。

「随 boot 漂移」的是**裸 `date`（无 -d）**——而它今日就已漂：单钟档下 REALTIME 请求实收 monotonic（= epoch 0 + uptime）。分档后 REALTIME = epoch 基（默认 0）+ monotonic，**逐 ns 同值**——裸 date 输出与今日逐字节同形。

**裁定（A 案，呈 owner）**：
- **维持钉板原样**（`-d @0` 渲染面无需任何改动）+ 分档默认基 0 = 现行为零漂移。A7-0 #3 前提不成立 → 风险消解入册（本稿即册）。
- **增补（建议随刀）**：U4 步③ 后追加**漂移容忍活钟步**——裸 `date -u` 子进程，字节判据 = 前缀 `"Thu Jan  1 00:"` + 中段 `MM:SS`（5 字节，冒号在第 3 位）+ 尾 `" UTC 1970"`。把「漂移」从时序噪声反转为 **REALTIME 活性断言**（boot→u4 ≈2-4min TCG，小时域 `00` 结构性稳定——smoke rootfs 相全链帽远离 59min 边界；破界形态的放宽预案见 §5 #2）。
- B 案（不采）：非零默认基 / 真壁钟源（QEMU virt PL031 RTC / fw_cfg）= 设备刀或服务刀量级，v1 零 RTC 消费面，出 A7-2 零 ABI 盒（挂账 v2 时钟服务，与 `docs/架构决策.md` FS/网络服务化同族裁决留位）。

## §3 设计（libc 侧分诊 + 合成，全在 sys.rs 单文件）

### 3.1 clk 分诊表（Linux 编号入参，纯 match 自明级）

| clk（Linux 值） | 返回 | 依据 |
|---|---|---|
| REALTIME(0) / REALTIME_COARSE(5) | `EPOCH_BASE_NS + mono_ns`（合成壁钟） | base 默认 0 = 今日值逐 ns 同形（零漂移） |
| MONOTONIC(1) / MONOTONIC_RAW(4) / MONOTONIC_COARSE(6) / BOOTTIME(7) | `mono_ns` 直读（今日行为） | v1 无 NTP 面（raw≡mono 诚实）/ 无挂起面（boottime≡mono 诚实）/ coarse = 粒度承诺差异非值差异 |
| 其它（PROCESS_CPUTIME(2)/THREAD_CPUTIME(3)/TAI(11)/未知/负值） | `-1` + `set_errno(EINVAL)` | 诚实拒；零在册消费者（§1 #9）——现探现补执法 |

现失败路径返 `-1` 不设 errno（`sys.rs:28-30`，结构性不可达——内核对 clk=0 恒成功）；分诊拒位是**首个真实 errno 路径**，必须 `set_errno`。

### 3.2 EPOCH_BASE_NS：静态零写者纯合成档

`static EPOCH_BASE_NS: AtomicU64 = AtomicU64::new(0)`（per-process 静态；v1 **无写者** → per-process 差异零可观测，无需全局钟服务）。v1 语义文档化 = **「壁钟 = epoch 0 + 单调运行时」**——一致性满足（单调非减、跨调用一致），绝对值非真历法（诚实注记头注释 + 本稿）。

### 3.3 clock_settime 立场：恒 EPERM 维持（拒 per-process 假成功面）

clk 分诊只改**读面**。写面若做成「REALTIME set → 写 EPOCH_BASE 成功」：调用者（uu_date `-s` 子进程）设的是**自己进程的基**，退出即蒸发——「设置成功」文案 + 零全局效果 = 假成功面（比 EPERM 恶劣）。EPERM = POSIX「无特权不可设」标准档（v1 无全局钟服务 = 无特权层，语义恰合）。MONOTONIC set 亦维持 EPERM（musl/Linux 真值 EINVAL，但差异零消费面——不顺手改，漂移最小化；两档统一注记）。

### 3.4 clock_getres：维持全成功谎报档（不动）

`_clk` 继续忽略恒 {0,1ns} 成功。收紧到分档拒 = 给持冷门 id 的未知消费者（getres 查询面广于 gettime）引入 panic 面，零收益——「必须成功」纪律（§1 #2）优先。

### 3.5 clock_nanosleep 分诊补笔：维持 `_clk` 忽略（文档化）

REALTIME+TIMER_ABSTIME（壁钟绝对睡）今日语义 = 「把壁钟值当单调钟绝对时刻」；分档后 base=0 下 REALTIME 值 ≡ mono 值，行为不变。非零基（v2）才需换算 `deadline = d − base`——零在册消费者用 REALTIME 绝对睡，补换算 = 无验收面代码。**注记入 sys.rs 头注释**，v2 随写者面一起裁。

### 3.6 补桩五真身（同 face 2-行体；自验件即消费者——A2-A5 能力卡先例）

| 符号 | 形态 |
|---|---|
| `time(t: *mut time_t) -> time_t` | REALTIME 档秒（§3.1 同式）；出参非空写同值；time_t = c_long 8B 全宽出参（A7-0 #4 出参宽度纪律） |
| `gettimeofday(tv: *mut Timeval, tz: *mut c_void) -> c_int` | tv = REALTIME 档 μs（`Timeval{tv_sec: time_t, tv_usec: suseconds_t}` 16B，`#[repr(C)]`）；tz 非空写全零返 0（POSIX obsolete 容忍档——musl 同形，防栈残留读回） |
| `settimeofday(tv, tz) -> c_int` | EPERM（§3.3 立场对称；tv 忽略） |
| `nanosleep(req, rem) -> c_int` | `clock_nanosleep(MONOTONIC, 0, req, rem)` 包装；rem 非空清零（v1 无信号中断面——睡不可中断恒返 0） |
| `usleep(usec: c_uint) -> c_int` | nanosleep μs 档（usec→Timespec）；返 0/`-1+EINTR`?——POSIX 无 errno 面，恒 0（同上不可中断） |
| `timer_create/settime/gettime/delete` | **维持零符号**（深水后置——内核对象或 futex 线程模拟，A7-0 #10 口径不变；零消费者 grep 实测维持） |

## §4 验收设计

- **guest**：bsh `clk_selftest` 六步 → `CLK ok n=6`（rootfs 相 **43→44**、RX 合相 **69→70**、smoke-image ECO canon **25→26** / 全标记 **64→65**——A7-1 落库后的树静窗口同步 smoke.sh/smoke-image.sh；链序 **A 系契约位：mmp_selftest 后、fat 族前** = EFI 路零盘面同打）。**步数勘误（2026-10-30 实施时定案）**：本稿原文「五步 → CLK ok n=5」——§2 后补 ⑤ 增补步后计数未同步，实现按实有六步定案 **n=6**：
  - ⓪ mono 双读单调非减 + nsec 域合法（`0 ≤ nsec < 1e9`）
  - ① REALTIME 合成一致：同窗双钟 `rt ≥ mono && rt − mono ≤ 1s`（base 0 下逐 ns 同值，容忍两 syscall 取样间隙）
  - ② `time()` / `gettimeofday()` 互恰（同窗 ≤1s）+ tv_usec μs 域合法 + time() 返回值 == 出参回填
  - ③ `nanosleep(50ms)` 活性：前后 mono 差 ∈ [50ms, 5s]（TCG 宽带）
  - ④ settime 双档拒：REALTIME/MONOTONIC 各 `-1` + errno==EPERM（`berry_libc::get_errno()`——mmp 步② 同款断言式）
  - ⑤ 裸 `date -u` 子进程漂移容忍钉板（§2 增补步：前缀+中段数字域+尾判据，REALTIME 端到端活钟面）
- **host**：零新 host 面（分诊 = 4 臂 match + `saturating_add`，自明级；berry-libc `#![no_std]` 无 host harness——`sysconf`/`getpid` 常量同档先例 `sys.rs:110+`）。审查若要求纯函数面，回收路径 = berry-clock 小 crate（berry-mmap 先例）——挂账非本刀。**test-host 609 恒定**。
- **smoke**：五相全绿 + 金丝雀严格递维持 + `just smoke-image` canon 更新后复跑（EFI 路 `CLK ok` 同面）。

## §5 风险与 kill criteria

1. **EINVAL 收紧面**：六 id 外从「静默 mono」变 EINVAL——现册消费面 grep 实证仅 REALTIME/MONO（§1 #9），但未来第三方 C 样例可能持 CPUTIME 类冷门 id（`clock_gettime(CLOCK_PROCESS_CPUTIME_ID)` 计时测量是常见写法）→ kill criterion：五相 smoke 全 rootfs 程序集回归零扰动即证现册安全；冷门 id 真消费者出现时按现探现补扩臂（CPUTIME = mono 顶替是可接受近似 or 真身 = 遥测环面，随需求裁）。
2. **date 小时域边界**：boot→u4 > 59min 则 `00` 破（smoke 帽结构性远离；soak 形态不打 u4 链）——破界形态预案：中段判据放宽至任意 `\d{2}:\d{2}`（活性断言降档，日/年域仍钉 1970）。判据实现处注记。
3. **出参宽度**：timespec/timeval 8B×2、time_t/suseconds_t 8B 全宽——非 handle 4B 桶（A7-0 #4 预埋执法）；tz 写零防栈残留（§3.6）。
4. **gettimeofday 首个 timeval 出参面**：`Timeval` 结构本刀新增定义（libc crate 侧已有声明）——布局对 musl aarch64（两 8B）编译期 `const _: () = assert!` 钉板可选（C-2a Stat 立法档；两字段同宽无互挤面，钉板从简）。
5. **kill criteria**：若分档改造引入任何 smoke 标记漂移（U4/U3 date 面、std SystemTime 消费者）即回滚分诊、维持单钟 + 诚实文档化（A7-0 #3 原 B 档）——本稿 §2 破案后该档降为纯防御位。
