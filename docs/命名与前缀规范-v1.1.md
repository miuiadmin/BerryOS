# 命名与前缀规范——berry 单一家族

Type: standard
Status: current
Updated: 2026-11-08
Version: 1.1.0

一句话说明：BerryOS 全系统标识符前缀用 **berry 单一家族**（四形分上下文），不引入第二前缀；内核 Rust 内部不加前缀。

## 背景

仓主提议品牌前缀计划（对照 HarmonyOS 的 `Hi` 族，候选 `Be`）。裁决：**否决 `Be`、立法 berry 单一家族**——理由与备选否决记录 → `.agents/notes/implemented/2026-11-08-brand-prefix-berry.md`（决策因果，一事实一归属）。本标准只载规则。

## 契约（四形分上下文）

| 上下文 | 形态 | 例 | 现状 |
|---|---|---|---|
| crate / 包 / 工具 | `berry-` | `berry-sys`、`berry-manifest`、`berry-launcher` | 全仓 38 个 crate 已合规 |
| C-ABI 函数与类型 | `berry_` | `berry_handle_t`、`berry_attest` | ABI 冻结面已合规 |
| 宏 / 常量 / 环境变量 | `BERRY_` | `BERRY_ROOTFS_MAX`、`BERRY_ABI_VERSION` | 新面即刻遵守 |
| 产品 / 组件专名 | `Berry` | BerryBoot、BerryUI、BerryOS | 既定 |
| 应用包格式 | `.bap` | Berry App Package | 既定 |

## 例外白名单（无前缀合法）

- `bsh`——berry shell 的既定短名（用户天天敲，短即正义）
- `memset` / `memcpy` / `memmove` / `memcmp` 等 freestanding 基础件——C 标准形态，加前缀破坏可移植认知
- 上游协议 crate 内部符号（如 fatfs）——第三方面不改造
- 既有 bench / soak 变量与常量（环境变量 `LAT_CAP_IPC`/`LAT_CAP_SGI`/`SOAKG3_*`/`*_KEEP_LOG` 等；`TRACE_CAP`/`ROOTFS_MAX` 实为模块/内核常量非环境变量——名实修正 v1.1）——存量零迁移；**新增** bench 变量用 `BERRY_` 形
- `uu/` 下的 POSIX 命令名（cat/cp/ls…）——与 `bsh` 同理：用户天天敲的标准名，短即正义（v1.1 成文，2026-11-08 首扫基线）
- 仓内测试 / 演示 / 守护 bin 的短名（appdemo/bench1/dpgp/svcmgr/fsmgr/gui-wmd/vblk/vnet/vprobe 等）——bins 生态名以语义为先，berry- 前缀不强制（v1.1 成文；守护进程 berry- 化方向如需再议）
- 内核映像内跨 crate 的 `extern "C"` 符号（sys_* 派发/task_* 入口/svc_window/on_irq_tick 等）——映像内链接面非对外 ABI，同「内核 Rust 内部」白名单逻辑（v1.1 成文）
- SDK Rust 面常量（RIGHT_*/SIGNAL_*/SCHED_FLAG_* 等 35 项生成器双轨）——**挂 SDK 五件套刀归档**（生成文件勿手改，走 tools/abi.toml + abi-gen）；C 面已 BERRY_ 合规
- 内核 **Rust** 内部符号——模块系统天然命名空间（学 Linux），前缀只出现在跨边界导出面（C-ABI / 宏 / 环境变量）

> 互证注记：`BERRY_ERR_AGAIN` / `BERRY_ERR_BUSY` 已在 drivers 各 bin 自发使用——规范与代码事实一致，立法只是成文化。

## 应用条款

- **新面即刻遵守**：新增 crate/ABI 符号/宏/环境变量一律按四形表；评审含命名项。
- **存量零迁移**：全仓 38 个 `berry-` 前缀 crate 与冻结 ABI 已合规；`bsh` 等白名单项永不清算。
- **SDK 面**：`berry-sys` 公开 API 按 `berry_` 延续（SDK 五件套 ADR #75–#80 落册时引用本标准）。
- 违规处置：新面违规在评审拦；本标准不溯及既有面。

## 版本与兼容

升版走 `Version:` 递增（MINOR=兼容新增例外/形、MAJOR=不兼容改形），被取代翻 `superseded` + `Superseded-by:` 链到现行版（Curia 取代链执法）。

## 适用边界

管标识符前缀，不管一般命名风格（kebab/蛇形等循各域规则）；商标检索与品牌视觉（logo/配色）不在此面。
