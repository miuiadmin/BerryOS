## §2 裁定：方案 B「协同式用户态投递」（预授权线 1 自决）

**采纳 B 案：内核最小两号（send/take）+ 掩码/sigaction 表/投递执行全在 libc 用户态。** A 案（内核全托管：内核存 sigaction 表 + SVC 返回帧改写投递 + sigreturn 蹦床恢复）出局。四维对拍：

| 维 | A 内核托管（Linux 形态） | **B 协同式（采纳）** |
|----|------|------|
| 免锁根基（kill criteria 本体） | SVC 返回帧改写 + tick 抢占点注入——投递路径贴着调度核心，任何「投递中需解蔽/需等待」即撞铁律 | 投递 100% 用户态（libc 调用栈内）——内核两号零阻塞/零解蔽/零分配，**按构造不撞** |
| 微内核哲学 | 内核管用户回调地址表 = 「把东西塞进内核」反模式 | 信号语义（表/掩码/默认动作）= 用户态策略；内核只管「跨进程位置位」这一不可委托面 ✓ |
| sigreturn 蹦床 | 需 0x86+0x87+0x88 三号 + 帧保存/恢复 asm 面 | 就地 C 调用 handler（POSIX 允许 raise/handler 同栈）——**免蹦床免第三号** |
| POSIX 语义完备度 | 全（异步抢占任意点） | 协同式：投递点 = libc 阻塞调用返回后 + raise/abort 即时——compute 紧循环收不到（POSIX 允许任意延迟档，文档化 §3.6） |

B 案 POSIX 缺口（compute 中延迟、不中断已阻塞调用）在 v1 最小集诚实可接受——与「自验件即消费者」能力卡口径一致：本刀消费面 = uu crash 装配（装表真跑）+ raise 自杀 + bsh 自验，无一要求异步抢占。

## §3 设计

### 3.1 内核两号（add-only：0x86/0x87）

- **0x86 `berry_signal_send(h_process, sig)`**：h=0 → 当前进程（raise 面，零 handle 需求）；h≠0 → Process 门控 **MANAGE**（同 terminate 权利面）。sig ∈ 1..=64 界检（else -EINVAL）；位置位 `pending |= 1 << (sig-1)`（**幂等 = POSIX 标准信号合并语义**）。目标非 Alive → -EBADSTATE。**不唤醒目标**：投递点在用户态，内核不预知哪个 syscall 是投递点（延迟档，§3.6）；不解蔽 IRQ、零分配、不忙等。
- **0x87 `berry_signal_take(*pending_out)`**：原子交换取走当前进程 pending（`swap(0)` 语义）——libc 拿到集合后逐位投递；投递中新到位置回内核 pending（下轮 take）。出参 u64 = 非 handle 出参 8 字节（`copy_out_u64` 口径）。零 handle 面零权利位（「对象几何非内容」惯例）。
- **Process 字段**：`pub pending_signals: u64`（process.rs——clean 文件）。u64 位图 = 信号 1..=64 一位（sig-1 为位号；realtime 段 34..=64 随 sigrtmin/max 定值同覆盖）。

### 3.2 libc signal.rs（谎报桶回收主体）

新模块 `user/berry-libc/src/signal.rs`（mmap.rs 先例——状态 + 纯函数 + host 可测面）：
- **sigaction 表**：`[u64; 65]` handler 值数组（0=SIG_DFL / 1=SIG_IGN / 其它 = fn 地址——musl 口径）。真身 3 参（musl aarch64 原型）：读 act 的 handler/flags 字段（**musl `struct sigaction` 布局对着 musl aarch64 源抄 + `offset_of!` 全字段编译期钉板**——C-2a Stat 案立法档；SA_SIGINFO 三参 handler v1 不分派文档化）、oldact 写当前表值（回读一致性）；sig ∉ 1..=64 或 SIGKILL(9)/SIGSTOP(19) → EINVAL（POSIX 钦定不可捕获）。
- **掩码**：libc 侧 `mask: u128`（语义位 1..=64）+ **held 集**（blocked 窗内 take 到的位暂存，unblock 时再投）。sigprocmask 真身：how ∈ {BLOCK=0, UNBLOCK=1, SETMASK=2} 界检 + oldset 全宽 128B 写真值（musl sigset_t 口径，出参宽度纪律）。
- **sigemptyset/sigfillset/sigaddset/sigdelset/sigismember 真身**：128B 位图纯内存操作（ok! 零参桶退役）。
- **投递核心 `dispatch_pending()`（修复轮二式 = 两遍走）**：take_total（内核 take | held_swap(0) 归并）→ **第一遍（可见性）**：Hold 位**即刻持久化进 held**（升序逐位 classify）——嵌套投递（handler 内 UNBLOCK 补投）take_total 归并 held 才能取到「已 take 未处置」的阻塞位；其余进工作集（本遍分诊结果不携带）；**第二遍（delivery-time）**：工作集升序逐位 classify **按步重查**（每步重读掩码与表）；掩码变更**只对嵌套投递即时生效**——handler 返回后包络全量恢复投递前掩码（sigreturn 口径，后续位按恢复后掩码分诊，Linux 同形），**表/disposition 变更对后续步即时生效并持久**；修复轮二式弃两旧形态——①「轮首 `plan_dispatch` 冻结执行」把 handler 中途的表变更挡在轮外 + 外层 Hold 步把嵌套已投位重落 held=残留双投（对抗审查 MAJOR），②修复轮一式「Hold 惰性落位」把已 take 未处置位悬在轮局部变量里两头不见——位号序敏感（仅「Hold 位号 > Call 位号」触发）嵌套不可见=永久滞留（mini-review S1 回归，**六步 ⑤ 主钉板**）：掩码内 → held 暂存跳过；SIG_IGN → 丢弃；handler → **errno save/restore + 就地调用 handler(sig)**，且**全量快照恢复包络**（进 handler 前 `saved_mask = SIG_MASK`、`SIG_MASK |= 本号位`——SA_NODEFER-off 最小档防 handler 内 console 写触发 may_dispatch 对同号递归重入；调用毕 `SIG_MASK = saved_mask` **全量恢复**——真 sigreturn 口径，handler 内 sigprocmask 改动不外逸，§3.4 偏差注）；SIG_DFL → 默认动作表：忽略类（SIGCHLD/SIGURG/SIGWINCH/SIGCONT/SIGIO 等 POSIX 忽略档）丢弃；其余终止类 → exit(128+sig)。
- **raise(sig)**：send(0, sig) + dispatch_pending() 即时投递（POSIX 对自身即时档）。
- **kill(pid, sig)**：pid == 42（getpid 定值锚）→ raise；else ESRCH（诚实：v1 无 pid 面确无此进程）。
- **signal(sig, handler)**：musl 语义 = sigaction 持久 handler 桩（无 SysV RESETHAND）。
- **abort 改装**：先解除 SIGABRT 阻塞（POSIX/C11 钦定——block 态下 handler 也要真跑，修复轮补）再 raise(SIGABRT)——SIGABRT handler 在场则真跑（uu crash 装配语义化；handler 返回/无 handler/默认动作均汇入现终止路径 console 诊断 + EOF + exit(134)（134=128+6 码位恰合,零漂移）。
- **sigaltstack 维持 ok! 桶**（v1 无 altstack 面；头注更新诚实档）；sigrtmin/max 定值 34/64 维持。

### 3.3 投递点接线（协同式最小集）

`may_dispatch()`（take 空则零 syscall 快速返——热路径成本一次 take）挂：io.rs console read/write/writev 返回后（writev = std `write_vectored`/LineWriter 消费面，修复轮补齐）、fs.rs read 返回后、sys.rs nanosleep/pause 返回后、futex.rs/pthread.rs wait 族返回后。**EINTR 偏差**：不中断已阻塞调用（先完成 IO 再投递/继续睡完）——pause 真身化补显式等信号面（§3.5），nanosleep 类不产生 EINTR（§3.6 偏差清单）。

### 3.4 POSIX 偏差清单（文档化诚实档，头注 + 本稿双载）

- 协同式延迟投递：compute 紧循环收不到信号（POSIX 允许任意延迟档）
- 不中断已阻塞调用（无 EINTR 面）；pause = 显式等信号真语义（§3.5）；sigsuspend 零符号维持现探现补
- SA_SIGINFO 三参 handler / siginfo_t 面不实现（act.flags 接受并忽略，文档化）
- 掩码语义位 1..=64（内核 u64 对齐）；musl sigset_t 1024 位全宽兼容读写、64 外恒零
- kill 仅自杀档（pid==getpid）；跨进程 = bsh kill 面走 handle（send h≠0）——pid→handle 映射 v1 无
- 默认动作 = 忽略类丢弃 / 终止类 exit(128+sig)（无 core dump / 无停止类——SIGSTOP 不可捕获已拒、SIGTSTP 按终止类处理文档化）
- **KILL/STOP 不可阻塞的单一执法点 = 投递期豁免**（berry-signal `classify` 对其无视掩码直落表查——`plan_dispatch` 批量面同源；Linux `sig_kernel_only` 同形；对抗审查 F2 裁定）：掩码**存储位**允许含 KILL/STOP（sigprocmask 回读与 Linux 一致——非偏差档）
- **sigaction/signal 对 KILL/STOP：纯查询与装 SIG_DFL 合法**（POSIX EINVAL 只罩 catch/ignore——musl/Linux 对拍；berry-signal `installable` 分诊，对抗审查 F3）：启动期「存全量快照」循环（`sigaction(sig, NULL, &saved[sig])`）不误伤
- **oldact 简化回读**：槽值 + 空掩码 + 零 flags/restorer（表只存 u64 槽，per-sig mask/flags 快照面留按需扩——对抗审查 F5 补记）：save/restore 回灌惯用法下 flags/mask 静默清零
- **handler 包络 = 全量快照 ∪ 本号位、返回全量恢复**（SA_NODEFER-off 最小档防同号递归重入——对抗审查 F4；**libc 投递修复轮翻正**：原「仅本号位临时 block + was_blocked 条件恢复」改真 sigreturn 口径——`saved_mask` 全量快照、handler 返回全量恢复，handler 内 sigprocmask 改动不外逸）；sa_mask 参数整条忽略（维持偏差）
- **同号跨嵌套窗两代实例各投一次**（修复轮 mini-review S4 裁定 = 冻结 plan 时代既有已知偏差，挂账不修）：handler 执行期对同号的新 raise → 嵌套轮投新实例 + 外层轮投持留旧实例 = 该号 handler 跑 2 次（POSIX 2.4.1/Linux = 同号同时至多一个在飞、合并为 1 次）；修法需 per-invocation 在飞声明集随包络嵌套保存/恢复，超最小集范围——偏差清单挂账

### 3.5 pause 真身化

`loop { dispatch_pending(); 睡 100ms 窗 }`——take 到非空（含 held）→ errno=EINTR 返 -1（POSIX 真语义,假 EINTR 桩退役）；10s 假睡死等面消失。

### 3.6 自验件（bsh `sig_selftest` 六步 → `SIG ok n=6`，rootfs 相 44→45）

- ⓪ 投递活证：sigaction 装 SIGUSR1(10) handler → raise → 哨兵写入 + handler 返回续行（后续步继续跑 = 返回续行证）
- ① 回读一致：sigactiion oldact == 所装值；sigemptyset/sigfillset/sigaddset 位图断言 + sigprocmask oldset 回读
- ② 掩码档：block SIGUSR2(12) → raise → 哨兵**未**写（延迟）→ unblock → 哨兵写（held 再投证）
- ③ kill 面：kill(getpid(), SIGUSR1) == raise 等价；kill(999, SIGUSR1) == -1 ESRCH
- ④ 默认动作终止档：spawn `bin/sigchild`（新 musl 小 bin,ps 先例独立工作区形态——raise(argv 选定信号)）raise(SIGTERM) → collect_fg 收 143（128+15）退出码

## §5 风险与 kill criteria

1. **kill criteria（门 C 裁定原文延伸）**：投递点撞「syscall 主体不可抢占免锁根基」即停刀呈报——B 案按构造不撞（全用户态）；**若实施中发现 pause/sigsuspend 语义被迫内核化（需要唤醒阻塞目标）即停刀呈报**（那才是撞门的形态）。
2. **musl SigAction/sigset 布局坑**（C-2a Stat 案同族）：offset_of! 全字段钉板；sigaction 3 参签名对 libc crate aarch64-musl 真原型抄（勿照 glibc 4 参）。
3. **errno 纪律**：handler 调用点 save/restore（POSIX：handler 不许破坏 errno）。
