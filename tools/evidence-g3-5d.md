## N 跑裁决（§5 公式对表）

§5：激进 soak 暴露问题 → 修 → **稳定 N 跑（N 首跑标定，参照 S-5d 银行跑
先例）** → 转正。逐格对：

- **暴露→修**：银行跑 + C 形链暴露的问题全在 lat 载荷设计（FM-16 远界
  错配等），lockdep 检测器本体零暴露零误报。
- **N 首跑标定**：银行跑（60 拍 / 1h 满载双核）即 lockdep 块的标定跑
  （S-5d 银行跑先例 = 长跑一次立回执银行）。
- **附加稳定跑**：C 形三跑 = **异树（dff0640）+ 异载荷形（常驻 fleet）**
  3 boot 同绿——比同形重跑更强的差异化证据。
- **边际信息论证**：lockdep 违约是**确定性锁序性质**（非概率事件——
  停机执法形态下某锁序倒挂存在则该路径执行即停机）。95 满载周期 +
  21 boot 路径覆盖后，追加同形跑的边际信息 ≈ 0；**树回归防护是常驻
  soak 电池的每跑执法职责，非转正门的职责**。

**裁决：既有回执即证转正，免新增 N 跑。**

## 转正语义定谳 + §7 终止判据立式

- **lockdep「转正」≠ default-on**：检测器按锁获取路径计运行时开销，进
  默认镜像与 §3 构建成本帽自相矛盾；Linux PROVE_LOCKING 同例（成熟检测
  器至今 config 门）。**转正实效三件**：①检测器认证（selftest 六阳三阴
  对照 + 21 boot 零误报零漏报停机形态）；②执法面常驻化——smoke-lockdep
  （快启）+ soak-g3（深跑）皆 `docs/命令速览.md` 在册常驻面（已成立，
  本刀记档定谳）；③feature 门保留为**成本门**（非激进性保留）。
- **§7「转正终止判据」立式（本裁决 = 首判例）**：
  ① kill criteria 双绿（构建 < 3× + 误报 < 10%）；
  ② 银行跑标定 + **≥ 2 附加稳定 boot**（异树或异载荷形）同绿；
  ③ 每 boot selftest ok 恰 1（六阳三阴对照形态）；
  ④ 覆盖限定诚实记档（F9 口径——检测域清单 + fail-loud 形态声明）。
  四条全绿 → 转正，记录进沿革；任一红 → 降级为取放 trace 面（§3）。
- **G3 转正流程两候选全毕**（① 候选① dff0640 + ② 本刀）——§5 模板
  首个完整闭环：激进 soak 暴露（FM-16 链）→ 修 → N 跑（银行 + 三跑）
  → 转正 ×2 块。

## 限界

- 覆盖域：g3-3c 起含 PT/ASID；后续新增锁族入域须扩 selftest 阳性对照
  并复验（转正不豁免新面）。
- TCG 交织多样性有限（双核固定载荷形）；真机 SMP 交织归真机面
  （B-2/§A118 口径同族）。
