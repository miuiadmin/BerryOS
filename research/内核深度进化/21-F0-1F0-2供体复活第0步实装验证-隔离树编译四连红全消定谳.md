## 主发现三：ASID 归还闭环两接线——17 号第 7 点外的配套义务

- overhaul 侧 ASID 归还走 `Vmar` 结构面（`asid: AtomicU16` + Drop 尾 `asid.swap(0)` + aspace destroy 路径 free_asid）；base 侧 Vmar 是 plain `u16` 字段 + G4-2 Drop（KL 窗注销 demand root）——**直接贴 syscall 取号窗而不接归还 = 每个销毁进程泄漏一号**（8 位宽 255 号、16 位 65535 号，长跑必耗尽）。
- 本件接线（base 形适配）：`Vmar::drop` 尾（kern_release 之后）`free_asid(asid)` + `self.asid = 0` 幂等守卫；`sys_process_create` 建表失败臂 `free_asid` 归还。boot/ktest 直构对象（MiniAspace 等）v1 不销毁，Drop 归还面自然覆盖 handle 表三释放点（close/replace/drain → drop(Box::from_raw)）。
- 语义注记：ktest 侧 `asid_ghost`（永不登记孤儿装配）与 dpg 侧探针号经 Drop 归还后**位图语义不变**——free(0)/重复 free 空操作守卫在 asidface 单测钉板。
