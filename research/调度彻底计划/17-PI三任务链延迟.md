# 17 号：PI 三任务链延迟——CP-14 修订项 G 卡收编

> 实测日期：2026-11-17（凌晨-上午窗）。环境：Apple M3 Pro / QEMU 11.0.3 Homebrew TCG / 单核 `virt`（与 13/14 号同机同版本）；内核 = HEAD `5b1f2c635` + 本刀探针增量（隔离 `CARGO_TARGET_DIR=target-cp14`）。任务书：CP-14 修订项——06 号综合定谳两处点名之一（[06 号](../调度深度调研/06-综合定谳-v1.0.md):27「PI 三任务链 G 卡延迟用例收编——结构验收全、延迟实测零」；[02 号 §③](../调度深度调研/02-实时性.md):81「三任务链 client 唤醒延迟上界的 G 卡用例留正式关卡未跑」——[docs/IPC设计-v1.0.md](../../docs/IPC设计-v1.0.md) 拆步表 4-3 行验收列原文）。本件落四件事：①双面载体落码（ktest `PILAT-K` 确定性界断言 + boot `opt/berry/pilat` 探针真 SVC 四任务组）；②实跑数据（lat p50/p99 与链解析 res p50/p99，两 rep）；③理论界对拍（02 号在册链式界 vs 实测）；④探针形态迭代的三轮定谳（检查点式抢占体系下「最高 eff 无检查点自旋 = 垄断」——r1-r3 实跑证据链）。推断一律显式标注；ktest 零回归（boot 冒烟 32/32）。

## §0 结论速览（五条）

1. **G 卡闭合——双面载体在位、数据在册**：ktest `test_pilat`（[kernel/src/ktest.rs](../../kernel/src/ktest.rs):7084，标记 `PILAT-K ok` + `PILAT-K chain_cyc=`）钉**确定性半边**——链建立字段断言（两跳继承 low 须经 mid 的实时 `pi_inherited` 到 32）、解链三跳出选身份断言（每跳解锁后下一次出选必是被提升的持有者、干扰者链悬挂期零出选）、无 PI 负控（用户位等待零边 → 干扰者先出选 = 确定性反转证明）；boot 探针 `task_pilat_hi/low/mid/inf` 四任务组（[kernel/src/main.rs](../../kernel/src/main.rs):5100 起，fw_cfg `opt/berry/pilat` 门控）出**真 SVC 延迟半边**——`PILAT lat min/p50/p99/max n=` + `PILAT res p50/p99` 串口行 + 界断言。06 号「延迟实测零」的扣分锚自此有数。
2. **实测延迟贴界走**（两 rep，µs）：lat p50 = 30092/30091（period=30ms——链按节拍器精确交付）、p99=max = 37808/38532（= period + 7.8/8.5ms，**< 1 slice**（10ms，忙核唤醒量化窗））、min = 26158/26884；**链解析 res（低优 send → 高优 grant，两跳 + 三次调度动作）p50 = 91/98、p99 = 190/222**。对 02 号在册界（链式 ≤8 跳 ≈800ms + ΣCS，[02 号](../调度深度调研/02-实时性.md):61）：实测最坏 38.5ms 的构成 = ΣCS（30ms 周期锚）+ 量化窗（≤1 slice）+ 链解析（µs 级）——**账面每一项都可分解对上，无未解释残差**（推断：残差 ≤1.5ms 归 tick 相位与唤醒路径开销，量级由 res p99 上界钉住）。
3. **PI 机制本体开销 µs 级、量化窗主导尾延迟**：链解析 res p50 ≈ 91-98µs（含两次 mid-SVC 接力直切——见 §3 动态定谳），「三任务链延迟」在 v1 形态下的真实瓶颈是**忙核唤醒粒度 1 slice**（02 号 §⑤ 缺口三的既知项），不是 PI 图重推本身。ktest 手驱面三跳 `chain_cyc` = 10375/9813 cyc（157-166µs @62.5MHz，TCG 宿主速率敏感口径——只报数不设墙，LOADGEN A3 判例）。
4. **形 B 罩 SVC-park 态（本刀最大机理发现，r1-r3 尸检定谳）**：每轮低优 work-send 的唤醒路径里，重推清零趟会把**在环 CURRENT**（发送者自身）的 boost 一并清掉（[kernel/src/pi.rs](../../kernel/src/pi.rs):113-114 环走查无状态过滤、pick 后任务留环 Ready）→ 唤醒的接收者严格更高 → `try_preempt` 把发送者**中途切走停进 send SVC 内**（[sched/src/sched.rs](../../sched/src/sched.rs):3125 严格更高才切）；发送者的解围同样靠 PI——**中优回到等待位入睡时，捐赠边把 parked 低优重新抬回 32**（形 B 扫本核在环者，含 mid-SVC parked 态）→ 下次出选即续行。链每轮在 parked 持有者周身**拆除又重建**——这正是 G 卡要测的机制本体在跑的活证；第 40 轮（再无入睡者重捐）三任务尾段冻结、探针 r1 挂死即此形的边界（§4）。
5. **探针形态定谳（可复用判例）**：测量任务（最高 eff）**不可**自旋等待被测对象收工——检查点式抢占体系（G3：SVC 出口/有限域检查点，[02 号 §1.3](../调度深度调研/02-实时性.md):35）下无检查点自旋 = tick 重选恒最高 = 垄断；且干扰者（prio 8）停转前恒压回落到 0 的链尾。正序 = 统计 → 断言 → 串口 → 置 END → 退场，被测三方自然收尾（中优 16 续行、干扰者见旗退出、链尾 0 终选）。

## §1 方法

### 1.1 拓扑（服务链形——02 号 §③「高优 client → 慢 server ← 低优干扰者」的两跳链化）

通道两对、三私有表（表分隔即链精确性——共表会被共享表粗粒度喷洒成单跳）：

| 任务 | prio | 表内端点 | 角色 |
|---|---|---|---|
| pl_hi | 32 | endA_c:RECV | 链头 donor——`wait_one(endA_c:READABLE)` 等回复（被测延迟的请求方） |
| pl_mid | 16 | endA_s:SEND + endB_c:RECV | 链中继——等原料时是 donor（受捐 = 持 endB_s 的 low）、持回复端时是受捐者（hi 的边） |
| pl_low | 0 | endB_s:SEND | 链尾「锁」持有者——`thread_sleep` 到绝对周期锚模拟 CS（每轮生产一条原料） |
| pl_inf | 8 | （无表） | 干扰者——起转延迟 100ms（pl_low 首跑窗）后长自旋至收工旗 |

捐赠边（配对律 READABLE 向：等 READABLE → 解锁 = send peer → 受捐 = 持 peer 且带 SEND）：hi 的边 → mid；mid 的边 → low——**两跳链，low 须经 mid 的实时 `pi_inherited` 到 32**（J2 链式面的延迟对照形）。测量口径：**lat = pl_hi 每轮 t_req（入 wait 前 clock_read）→ t_grant（收到回复后 clock_read）**；**res = pl_low send 前时刻 → t_grant**（链解析两跳）。协议参数：rounds=40、period=30ms（> slice 保量化窗不吃周期信号）、grace=1s（PI/INTENT/FAST/AIDEMO boot 对收尾）、每轮 wait 帽 10s（链断 = 超时断言红）、`set_slice_hz(100)` 测量档（LG 探针同值同因——缺省 10Hz 的 100ms 量化窗会吃掉 30ms 级信号）。

### 1.2 双面载体（与 PI ok / PI-K 的既分工一致）

- **ktest `test_pilat`**（结构 + 确定性界，sched::init 前手驱）：PL-1 链建立（sleepq_insert 手搭 + `pi::recompute()` 直调——J 段同款，钩子此时未注册）；PL-2 解链三跳（醒 → **真 PER_CPU_RQ 入环**〔`rq_insert_kt`，J8 同款——形 B 的重推全域〕→ 重推断言环上保 32 → 摘真 RQ 冻结随行 → 本地 `Runqueue` 出选断言身份〔LOADGEN 同款机械〕）；PL-3 无 PI 负控（同拓扑但 donor 只等用户位 → `donor_edge` 五拒零边 → low 醒后入环 eff 0 → 出选 = inf(8)——boot 形态下同一拓扑会挂死，ktest 折成可断言的「干扰者先出选」）。
- **boot 探针**（真 SVC 全链，`opt/berry/pilat` 在位才 spawn——rt/loadgen 同款「机制不是自律」，[tools/fwcfg-keys.toml](../../tools/fwcfg-keys.toml) 已登记）：早读块置武装位 + `set_slice_hz(100)`（timer::init 前，G5 setter 契约）；spawn 块（sched::init 后 boot 屏蔽窗内）建两对通道 + 三私有表 + 四任务；串口四行（lat/res/bound/ok）。

### 1.3 复现配方

```bash
CARGO_TARGET_DIR=$PWD/target-cp14 cargo build
qemu-system-aarch64 -machine virt -cpu cortex-a72 -m 128M -nographic \
  -kernel target-cp14/aarch64-unknown-none/debug/berry-kernel \
  -fw_cfg name=opt/berry/demo-face,string=off \
  -fw_cfg name=opt/berry/pilat,string=1        # 收锚 = `PILAT lat min=` 行
```

（探针相 = 裸 `-kernel`——smoke.sh boot 相同形，服务相 park 不影响早窗收割；demo-face off 去 task_a/b 忙环与 EL0 舰队噪声，13 号同款。ktest 段全量照跑——`PILAT-K ok` 同 boot 在席。）

## §2 数据

### 2.1 boot 探针两 rep（µs；period=30000、slice=10000、max_cap=90000）

| rep | lat min | lat p50 | lat p99=max | res p50 | res p99 | 断言 |
|---|---|---|---|---|---|---|
| r4 | 26158 | 30092 | 37808 | 91 | 190 | 全绿 |
| r5 | 26884 | 30091 | 38532 | 98 | 222 | 全绿 |

原始行：`PILAT lat min=26158 p50=30092 p99=37808 max=37808 n=40 us` + `PILAT res p50=91 p99=190 us (low_send-hi_grant)`（r5：`min=26884 p50=30091 p99=38532 max=38532`、`res p50=98 p99=222`）。rep 间差：p50 差 1µs、p99 差 724µs（< 量化窗的十分之一）——TCG 口径下信号量级远超 rep 离散。

### 2.2 界分解（对拍 02 号在册界）

| 分量 | 理论 | 实测（r4/r5） | 依据 |
|---|---|---|---|
| ΣCS（周期锚） | period = 30000µs | p50 = 30092/30091 | 低优绝对锚睡眠（「慢 server」的受控形态） |
| 唤醒量化窗 | ≤ 1 slice = 10000µs（忙核粒度恒 1 slice，v1 既知） | p99 − period = 7817/8511 | [02 号 §⑤](../调度深度调研/02-实时性.md) 缺口三 |
| 链解析（两跳 + 三调度动作） | 无闭式在册 | res p99 = 190/222 | 本件新立（含 §3 的 mid-SVC 接力直切） |
| **合计上界** | **period + 1 slice + ε** | **max = 37808/38532** | 断言门 = period + 6×slice = 90000（6× 余量，TCG 噪声容差） |

02 号在册链式界「≤8 跳 ≈800ms + ΣCS」（[02 号](../调度深度调研/02-实时性.md):61，推导链未入册的量级判）在两跳场景的对应展开 = ΣCS + 量化窗 + 解析——实测每一分量都对上（800ms 是 8 跳轮帽满载的保守包络，本场景两跳 + 受控 CS，不可比绝对值、可比结构）。

### 2.3 ktest 手驱面（确定性，同 boot）

`PILAT-K chain_cyc=10375`（smoke 本刀 run）/ `10375`（pilat-r1 boot）/ `9813`（r2 boot）cyc——三跳解链（低优醒 → 真环重推 → 出选；中优同；hi 终选）的手驱实测，157-166µs @62.5MHz。TCG 宿主速率敏感（LOADGEN A3 判例）——只设 100ms 失控护栏，数值归报告面。

### 2.4 ktest 零回归

`SMOKE_PHASES=boot SMOKE_KEEP_LOG=1 timeout 400 just smoke`：boot 标记 32/32 到齐、rc=0；ktest 段 `PILAT-K ok` 在席、既有 `PI-K ok`/`PI ok`/`LOADGEN ok` 全绿（全日志 smoke 相 + 探针相三份在席互证）。fwcfg 键表对拍过（26 键，[tools/fwcfg-check.sh](../../tools/fwcfg-check.sh)）。

## §3 链动态定谳（r1-r3 尸检 + dump 证据）

r1 挂死形态：40 轮全完成（lo39/mid39 时间戳在席、res=31µs）但收工旗 500ms 零观测。r3 任务现场转储（超时点）：

```text
PILAT task RQ pl_inf base=8  eff=8  pi=0 wobj=0                wdl=320948375    slice=0
PILAT task RQ pl_low base=0  eff=0  pi=0 wobj=0                wdl=452196250    slice=625000
PILAT task RQ pl_mid base=16 eff=16 pi=0 wobj=18446743525034475264 wdl=1075390000 slice=625000
PILAT task RQ pl_hi  base=32 eff=32 pi=0 wobj=18446743525034459392 wdl=1075388562 slice=0
```

定谳链（每条有据）：

1. **低/中都停在第 40 轮 send SVC 内**（wdl = 各自 wait 帽的绝对周期换算、slice 满额未耗 = 被授片后未得跑尾段；`wdl` 低 = 452196250 cyc ≈ D_39 换算——已醒已发；done 旗零 = 尾段〔store + exit〕未执行）。
2. **每轮 send 都发生 mid-SVC 接力直切**：唤醒路径的重推清零趟罩在环 CURRENT（[pi.rs](../../kernel/src/pi.rs):113-114 环走查无状态过滤；pick 后任务留环——tick 抢占支 `(*cur).state = Ready` 同证），发送者 boost 被清（低优 32→0）→ 唤醒者严格更高 → `try_preempt` 直切（[sched.rs](../../sched/src/sched.rs):3125）——**接力棒径直交给链下一环，是 res p50 ≈ 91µs 的构成部分**。
3. **parked 发送者的解围靠链重建**：中优回等待位入睡时，捐赠边把在环 parked 低优抬回 32（形 B 罩 SVC-park 态）→ 下次出选续行 → `thread_sleep` 入睡 → 链周身重建完成。**每轮「拆-建」一次，40 轮全跑通即此循环的活证**。
4. **第 40 轮边界**：再无「中优入睡重捐」（中优尾段是收工不是入睡）→ 低优停在 0、中优停在 16、hi 自旋垄断（tick 重选恒 32 最高）——三尾冻结。探针修正 = hi 不等收工旗（环因果完备已被 lo39/mid39 可读实证：store → send → wake → hi 续行的同核序），统计后直接置 END 退场，三方自然解（[main.rs:5224](../../kernel/src/main.rs) 收序注）。
5. **二级反转边界（探针设计判例）**：干扰者停转（读 END 旗）前恒压 prio 0 的链尾——无 PI 时链尾的 DONE 尾段同样不可达（测量面正确性的另一面：PI 在则链尾每轮以 32 出选，不存在此压）。

## §4 缺口与后后手

1. **形 C 面不变**：本刀 G 卡只收形 A/B 链（channel 派生位等待）；Event/WAIT_ANY 无界仍归 P3-4/v2（[02 号 §③](../调度深度调研/02-实时性.md):81）。
2. **SMP 面**：链解析的全图重推 RQ 扫描只罩本核（[pi.rs](../../kernel/src/pi.rs):41-42 SMP 残留注）——跨核链的 res 面归 SMP 专项；本件单核数据是下界基线。
3. **真机复测留位**：TCG 口径只报功能、顺序与相对趋势（13 号同律）；res p50 91µs 的绝对值真机复核后随 G 卡升级为门禁候选——当前门禁 = period + 6×slice（结构界 + 量化窗，不依赖宿主速率）。
4. **PILAT 标记未入 smoke 集合**：`PILAT-K ok` 随 ktest 全量形态在席（smoke 覆盖）；boot 探针行（`PILAT ok`）为 fw_cfg 门控面，按 rt/loadgen/soak 先例不入 KERNEL_MARKERS（tools/smoke-image.sh 归 owner 域）。同归 owner 随迁：[docs/IPC设计-v1.0.md](../../docs/IPC设计-v1.0.md) 4-3b 尾注「G 卡用例的 client 唤醒延迟上界验收留正式关卡」字样——本件即该验收的完成记录。
5. **探针与 18 号四带复测同窗互不干扰**：pilat/loadgen 两键独立、本刀全部探针相 boot 均未同窗混发。
