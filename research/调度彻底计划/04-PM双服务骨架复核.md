## 2. 契约对照 ADR #66/#68 逐条（复核面一）

契约原文锚：`docs/架构决策.md` 决策总表 #66 行 = :74（①trips 自报+step_wise 迟滞+三类输出 / ②帽不新开通道 / ③失败隔离 / ④thermal_level 四档 / ⑤JEITA 五档+P11 出票 / ⑥sim 同接口 + smoke 断言四件套）；#68 行 = :76（③SDK 六面走 berry-pwproto 零新 syscall / ⑥初值+策略表项可调+遥测导出 / P11 `CHG_OP_VOTE_LIMIT{limit_pct, reason:u8}` 最少者赢、断线自动撤票、chargerd 持有）。任务书指定六查项逐条如下。

### 2.1 帽聚合唯一性（#66 ②）——过

立法原文：「频率帽汇入 berry-power 同一内核聚合点取 min（唯一合法帽书写面）……对调度器 = 系统态叠加票（#42 只叠加）」。
落点：`user/bins/berry-power/src/cap.rs`——三源定席 thermal/schedhint/lowbatt（:20-29），`caps` 私有数组 + `set()` 唯一写面（:63-73，坏源/零帽拒面且拒不改旧值），`aggregate()` 在席取 min、平票源号小者胜（:86-96，确定性归因）；全组合 125 形穷举钉板（:112-142）。berry-thermal 侧只产请求值不持通道：`Verdict::freq_cap_pct` 注明「写面 = berry-power 聚合点取 min（#66 ②，本引擎不出通道）」（`user/bins/berry-thermal/src/lib.rs:179-181`）。组装层钉板：调度 hint 帽 400kHz 压过 schedutil 请求的 eff=min 联测（`user/bins/berry-power/src/lib.rs:368-387`）。
缺口（如实留窗）：「内核聚合点」本体与写通道 op 未立法未建——`FreqCapAgg` 是其纯函数形态，真实写面挂 CP-08/CP-10 刀（`user/bins/berry-power/src/main.rs:25-28` 窗 4）。判定：骨架相契约语义完备，唯一性在纯面上成立（单一聚合函数、单一写入口），内核侧执法位留窗属实。

### 2.2 票仲裁（#68 P11 + #66 ⑤）——过，但带 F1 单位桥

立法原文（#68）：「P11 充电限值票（`CHG_OP_VOTE_LIMIT{limit_pct, reason:u8}`，最少者赢、断线自动撤票、chargerd 持有）同窗冻结」；（#66 ⑤）「charge_current_limit 票（P11 电流版）由 berry-thermal 出票、chargerd 仲裁（#68）」。
落点：`user/bins/berry-power/src/charge.rs`——三席 JEITA/低电/用户（:22-30），`vote()` 席/票面/reason 三拒面（:78-91，`CHG_REASON_NONE` 出票面不可投），`withdraw()` 断线撤票库面（:95-102，「通道层断链/出票方亡事件映射到此；未投席撤 = 幂等」），`arbitrate()` 最少者赢、平票席号小者（:117-128）；64 形穷举 + 撤票顶位链 + 禁充档 0 + 拒面零副作用测试（:144-270）。出票边界：berry-power 不养第二套热表——sim 热快照只进遥测不旁路出票，`thermal_modem_telemetry_only` 测试钉板（lib.rs:433-447）；JEITA 席留给 berry-thermal（charge.rs:22-23）。
**F1（单位桥，接线刀必办）**：berry-thermal 出票面 = `charge_limit_ma`（mA，`user/bins/berry-thermal/src/lib.rs:182-184`，忠于 #66 ⑤「电流版」原文）；berry-power 仲裁面 = `limit_pct`（%，忠于 #68 冻结形态）。两文各执一面、两 crate 各忠一文，mA↔pct 换算与终裁无人认领——charge.rs:14-15 只有「百分比先行——推断标注」，是注记不是裁决。挂 chargerd/CP-08 刀裁。
另：「chargerd 持有」的通道执行面（票持有者/动态票主注册）= chargerd 服务本体，立法件无代码——本面只供它将消费的仲裁数学单源，留窗如实注（charge.rs:11-15）。判定：过（仲裁数学与立法逐字对齐；单位桥为立法自带缝，非实现走样）。

### 2.3 迟滞（#66 ① step_wise 查表 + 迟滞）——过

### 2.4 JEITA（#66 ⑤ 五档第一张系统热表）——过
