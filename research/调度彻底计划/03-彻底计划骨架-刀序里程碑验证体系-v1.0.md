## 0. 一页结论

1. **调度域现状一句话：机制面超前、部署面欠收口、证据面单核化。** 调点调度 1.1–1.3 全落（S0–S5 六里程碑 + S6 策略服务 + SMP 三件套 + EAS 四件 + HDR 测量 + 热路径 O(4n)→O(n)，`docs/调度器设计-v1.1.md:242-254`），但全部以**单核等价验证**收官；多核部署未钉板（smoke-smp 八相是 2026-11-07 时点快照，X-6 刀① SMP soak 楔死在飞，`docs/调度器SMP部署设计-v1.0.md:45-49`）；AI 有接口、有护栏、有最小演示（AIDEMO ok），但**收益证据为零**（ADR #21 kill criteria 悬而未决）；EAS「形状在、算法留」（compute_energy 不在仓库，`docs/调度器设计-v1.1.md:346`）。
2. **骨架判断：三波推进，每波一个可验收出口。** 波一（近期）= 收编 W3 余项 + SMPD 收口——把在途线的既有承诺兑现成多核绿灯，出口 MS-1 挂 G2 复验；波二（中期）= em 能效 + intent M4——把 EAS/PM/band 三件「形状在、算法留」补成真机制，出口 MS-2 挂 G5 的 QEMU 代理面；波三（远期）= AI 原生全谱 + v2 RT + 真机拓扑——把证据面从 QEMU 代理指标升级到真机分位与功耗，出口 MS-3 挂 G5 真机面与 Phase 8。
3. **排刀总原则五条：** ①在途线零碰只收编（sched 域是 W3/hermes lane 活跃主战场，本计划不代打任何一刀）；②SMPD-0 不绿后续 SMP 刀不开（在册铁门，`docs/调度器SMP部署设计-v1.0.md:66`）；③测量先于治理（SMPD-1 噪声底先于 SMPD-4 A/B 形态裁决，入场券基建先于 band 并线）；④每刀独立 QEMU 可验、独立提交、独立可回滚（小步纪律，PM-17 §3.3-6 同款）；⑤kill criteria 随刀挂、不做事后补（ADR #21/#42 既有纪律前移到每张刀单）。
4. **验证体系的骨架是「四层 × 九类」：** host 单测面（W3 外迁族钉板惯例的制度化）/ QEMU 面（ktest+smoke 相构成）/ 性能面（bench 四口 + icount 确定性通道 + sched_baseline.json 基线对拍）/ AI 测试友好断言（空表等价、有/无 AI p99 相等、RT 屏蔽、越界拒收、崩溃降级——设计总原则 3 的调度域执法面，出处 `docs/规则/07-测试与冒烟.md:7` + `docs/AI工程面设计-v1.0.md:32`）。

### 1.4 缺口清单（从现状到终态缺什么）

1. **多核部署未钉板**：smoke-smp 八相无在册最新绿灯；跨核策略一致性（POLICY-S）/ band 跨核账（BAND-S）/ 跨核唤醒基准（SMPBENCH）三面空白（`docs/调度器SMP部署设计-v1.0.md:50-58`）。
2. **EAS 有信号无算法**：EM 表形状在、compute_energy/FEuC 零算法（`docs/调度器设计-v1.1.md:346`）；util EWMA 无消费者（PM 共享环 ABI 未接，:355）。
3. **intent 第二段未启动**：band 执法默认全关（:372）；IntentProfile 映射表、(B) 分类器、timer slack 执行载体均属 M4 窗口（ADR #42 :51；`docs/AI调度设计-v1.0.md:104-108`）。
4. **AI 收益证据为零**：AIDEMO 证明开销不变量，不证明收益；kill criteria 复核点（M4 前）无载体——需要首份 SMP A/B 对照报告（SMPD-4 出口）。
5. **证据面单核 + 无绝对分位**：HDR 真机相未跑；唤醒基准是方案 A 忙等单核口径（`docs/调度器设计-v1.1.md:388-393`）；绝对数 vs 相对门未裁（:393）。
6. **v2 RT 谱未落**：RT 静态池（`docs/调度器设计-v1.1.md:90-94`）、PI 形 C 设防（`docs/系统优化路线图-v1.0.md:222-229`）、M5 admission 补写（`docs/调度器设计-v1.1.md:203`）全部在设计位。

### 2.5 与在途线关系总裁定（顺延还是并行）

- **W3 外迁族：并行，永不代打。** 其产出（判定律 host 钉板化）是本计划验证体系的地基；唯一的计划内动作是 CP-01 文档重锚（docs 面），且执行归框架定稿会话。W3 若触 sched pub fn 面，API 参考随迁义务照旧（沿革二百一十九起既定合同）。
- **SMPD 线：收编为波一主轴（CP-02..CP-07 原号引用），不重开刀序。** SMPD-0 被外部裁决（fix-or-withdraw）阻塞期间，CP-03/CP-04 的**设计预研与 host 面**（如跨核基准的 HDR 数学已在 hdrface）可并行准备，但 QEMU 相执法一律等 SMPD-0 绿门——「本刀不绿后续刀不开」是 SMPD 自己的铁门，本计划不绕。
- **PM 三期：并行，两个挂接点。** CP-08（util 消费者）与 CP-11（timer slack = PM 刀3 + intent 执行载体合流）；调度侧纪律只有一条——频率裁决单点归 PM，调度路径零频率写点（`docs/调度器设计-v1.1.md:355`）。
- **perf-gui 线：无竞态，单向消费。** DPG panic 立账（显示定稿刀 2②）的结论若落在调度邻域（rq 锁序/exit-reap），由 CP-02 的楔死收口统一承接，不在显示线重复修。

### 3.2 G5 拆半提案（推断，需 owner 拍板——开放问题 4）

G5 的在册通过标准（`docs/测试策略-v1.0.md:28`）把「频率/放置策略对」（QEMU 可出代理面与相对趋势）与「省电可量化（真机功耗计）」写在同一关。 BerryOS 的现实是 QEMU 结构性证不了省电卖点（`docs/战略路线总规划-2026-10-v1.0.md:28` 主线选择理由节同源判断）。 提案：**G5 拆 G5-Q（QEMU 代理面：idle residency + 每秒唤醒数 + 交互唤醒 p99 三代理指标 day-one 口径，`docs/测试策略-v1.0.md:84-87`；频率/放置策略对的功能与相对趋势）与 G5-H（真机面：功耗计 + 绝对分位）**，MS-2 挂 G5-Q、MS-3 挂 G5-H。 不拆的代价：MS-2 的全部出口长期无关卡可挂，进度不可见。 此为推断，**需 owner 拍板**。

### 3.3 host 钉板面覆盖率目标（AI 测试友好的调度域执法）

### 4.2 性能面基线账（现行在册 + 升级纪律）

### 4.3 AI 测试友好断言清单（每条可执行，非口号）

1. **空表等价**：绑空表与未绑逐位全等（POLICY ok，smoke 第 11 标记在册沿革）——「AI 缺席零影响」的机器断言。
2. **开销与策略复杂度无关**：有/无表 pick 开销差 <50%（PP-4 门，实测绝对注入开销 2cy）；AIDEMO rt2≤2×rt1（TCG 容差 2x 噪声界）+ -icount 精确版/真机 p99 留 G 卡复测。
3. **RT 屏蔽专项**：AI 尽力干涉 rt/deadline 任务，断言这些任务调度零变化（`docs/测试策略-v1.0.md:106`）。
4. **越界拒收**：参数超界 → 内核拒收、记日志、保留上次有效值（H8-H11 负例批 + policydemo 门控自验已落，沿革八十七轮）；weight +200 → clamp +64 双点执法。
5. **崩溃降级**：杀策略服务 → 内核回退启发式继续调度无死锁；监督重启后恢复（`docs/测试策略-v1.0.md:104`）。
6. **遥测 schema 两级分层**：第一级（util/唤醒/切换/运行时长）QEMU 可靠，v3 分类器只准用第一级；第二级（cache miss/能耗/温度）真机门控只记录（`docs/AI调度设计-v1.0.md:54` + `docs/测试策略-v1.0.md:108`，两源）。
7. **band/intent 附加断言**（随 M4 启用，断言基建先于 band 合入）：带严格序尾延迟 + 兜底预算可观测 + wasted-cores 金丝雀（`docs/测试策略-v1.0.md:90-94`）。
8. **策略注入 fuzzer（v3+）**：随机策略表项找护栏漏洞与饥饿路径（测试策略 :107）——挂 CP-13 刀单。
