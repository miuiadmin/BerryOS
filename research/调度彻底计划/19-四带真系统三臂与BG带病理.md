# 19 号：四带真系统三臂复测——boot 探针 b=0/1/2 与 BG 带执法病理

> 实测日期：2026-11-17（上午窗 03:00-03:45）。环境：Apple M3 Pro / QEMU 11.0 Homebrew TCG / 单核 `virt`（与 13/14/18 号同机同版本）；内核 = HEAD `5b1f2c635`（含 CP-09 EAS M2 四带全开 `dcf359c5c`）+ 本刀增量（隔离 `CARGO_TARGET_DIR=target-cp14`）。任务书：CP-14 两处点名之二——「LC/BG 带激活后（×2→×4），loadgen A/B 重跑：四带 vs 两带 vs 零带的调度质量对比（interactive p50/p99 变化 / burst 吞吐变化）」。**与 18 号分工（一事实一归属）**：ktest 机械面六组（A5/A6 四带组、`LgBandMode` 三档、`thrBK` 字段）的落码叙事与数据归属 [18 号](18-四带AB复测.md)；本件 = **真系统 boot 探针三臂**（b=0/1/2——b=2 为本刀新增臂：过载源 `lg_bu` 改落 INTENT_BACKGROUND 带，走生产 tick/consume/throttle 执法路径）+ **b=2 尾延迟病理的首证与证据链**（ia/ut p99 2-81s + 带 runtime 记账单跳 82s，候选机理两条标注推断，归后续专项刀）。口径纪律同 13 号：QEMU/TCG 只报功能、顺序与相对趋势，绝对分位不进门禁；推断一律显式标注。

## §0 结论速览（五条）

1. **真系统面 b=2（四带）主判据同向成立**：burst 吞吐 **133-136/s → 27-29/s（-78%）**（BG 带驯化过载源——18 号 ktest 面 -72% 的生产路径对拍）；interactive p50 **14.2ms → 5.0/8.9ms**（两带 → 四带，过载源让路后交互唤醒提速 1.6-2.8×）。18 号「真系统面对本载荷族四带 vs 两带结构上不可见」的推断（burst 源 plain spawn 不入带）在 b=2 臂下不再成立——**b=2 正是把 burst 源放进 BG 带的最小改动**（[kernel/src/main.rs](../../kernel/src/main.rs):2173）。
2. **b=2 出尾延迟病理（新发现，本件最大产出）**：ia/ut p99 = 2.0s（r1）/ 81.6-104s（r2）——与 b=0/b1（p99 ≤ 116ms）差一至三个数量级，且跨 rep 量级漂移（竞速/相位型）。SCHED 证据（§2.3）：band3（UTILITY）runtime 记账在相邻两行 SCHED 间**单跳 +82.1s 而 picks 仅 +6**（482ms → 82.1s；band3 picks 此后冻结 5843→5878，band2 亦近冻）。
3. **候选机理两条（推断，未判别）**：A = 带 `consume` 记账读到 stale `last_vct` 基准 → 单跳巨额 delta 越线 → `throttle_all` 冻结带成员；B = 巨额越线后翻期 CAS 下一期边界远在未来（或解限后 low_weight VD 重臂越出地平）→ 解限不达/不出选。**分叉面**：ktest 手驱面（18 号，显式 configure + 逐 sub-unit consume）无此病理；b=1 两带真系统面亦无 → 嫌疑集中在「BG 带懒武装 + UT/IA 带共存」的生产组合。
4. **b=0/b1 基线与 13/14 号历史带吻合**：b=0 ia p50 14.5ms（13 号 g1 17.2ms 同量级）、ut p50 17.9ms（18.5ms）、吞吐 133/s（121/s）；b=1 ut p99 116ms 与 14 号「band 轴尾事件」+75ms 判据同向。四带激活对两带臂的真系统面无可见漂移（ktest 面的 A2 漂移叙事归 18 号 §0-3）。
5. **宿主高载窗 flake 实录**：load avg 26-39 窗内两次 ktest 相红（A5 `ia p50 ≤5ms` 一次、BANDM4 G1 长片时序一次）——A3/LOADGEN 族既知 TCG 宿主速率敏感面（非语义回归）；b=2 第三 rep 因此未取得，低载窗补跑归后续。

## §1 方法：boot 探针 b=2 臂

13 号配方单源：`-fw_cfg name=opt/berry/demo-face,string=off` + `-fw_cfg 'name=opt/berry/loadgen,string=s=0;b=<0|1|2>'`（**分号必须整参引号**——裸 `;` 被 shell 切断致 fw_cfg 值残缺，本刀实踩一次三臂全无效重跑）；收锚 = `LG bu units=` 行；ktest 段全量照跑（三臂 boot 的 ktest 六组另与 18 号互证）。落码两处：`lg_parse_cfg` b 值域 0|1 → 0|1|2（[main.rs](../../kernel/src/main.rs):4889）；b=2 时 `lg_bu0/1` 改 `spawn_intent(INTENT_BACKGROUND)`（:2173；b<2 两臂同形 plain spawn——13/14 号口径保真），sleeper 侧 b≥1 与原 b=1 同形。生产路径的带行为 = 懒武装（tick/consume 消费点按 [INTENT_BAND_TABLE](../../iprofile/src/lib.rs):394-478 表行；BG 行 40ms quantum/250ms latency_target → 期占率帽 16%）。

## §3 候选机理与后手（推断）

1. **候选 A（带记账 stale-baseline）**：[class.rs](../../sched/src/class.rs) `FairBand::tick`/consume 链的 delta 基准（per-CPU `last_vct`）在某消费点读到远旧值 → 单跳巨额 delta 记入 UT 带账 → 配额（20ms/50ms 量级）4000× 越线 → `throttle_all` 冻结。反证缺口：per-CPU 基准每 tick 刷新，82s 陈旧需要「tick 长期不更新而带消费点仍跑」的窗口——哪个消费点能绕过未定位。
2. **候选 B（翻期/解限饥饿）**：巨额越线后 `DEADLINES` 翻期 CAS 的下一期边界仍在未来 → `period_check` 长期假；或解限发生但 VD 以 low_weight（UT=64）重臂后越出选择地平。band3 picks 冻结到底更支持「解限后仍不出选」或「解限未达」，SCHED 行上不可分。
3. **判别实验（后续刀，本件不动 sched 生产码——生产行为变更须独立刀 + 全量门禁）**：关 BG 懒武装单变量复跑 / SCHED 行加 per-band DEADLINES 投影 / 带 consume 点加 delta 帽断言（delta > 2×period 即 panic 留现场）。
4. **复现配方** = §1 b=2 臂；病理触发竞速型（r1 2s / r2 81-104s），低载窗多 rep 取分布归后续。

## §4 缺口与后手

1. **b=2 病理归专项刀**（§3）；本件立证据与嫌疑面。
2. **LC 带真系统载荷缺位**（两面均无 LC intent 载荷——18 号 §0-4 同判）。
3. **绝对分位真机复核**：TCG 只报趋势（13 号同律）。
4. **b=0/b1 单 rep**：与 13/14 号历史带吻合已足；b=2 双 rep 为主判据。
5. **fwcfg loadgen 键 b=<0|1|2> 口径已随迁**（[tools/fwcfg-keys.toml](../../tools/fwcfg-keys.toml) loadgen 行）。
