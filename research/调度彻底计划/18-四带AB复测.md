## §0 结论速览（六条）

1. **三组主判据成立：四带把两带的限流代价从 utility 挪给过载源**。utility p50：零带 757µs / 两带 **39666-39670µs** / 四带 **8-9µs**（boot1/boot2 双跑；四带 vs 两带 ≈ **4400×**，vs 零带 ≈ 94×）；utility p99 三组 1260 / 39668-39682 / 37799-38784µs——四带把限流 dwell 从中位赶回尾部（utility 自身 20ms/60ms 配额不变，尾仍在）。机理：BG 带（40ms/250ms，期占率帽 16%）冻结 burst 过载源 → utility 醒后近即时出选（环近乎空）。interactive p50 三组平坦（827-1074 / 346-384 / 349-350µs，零带高是 utility 不限流的竞争面）——**交互零牺牲律穿过四带保真**。
2. **burst 吞吐：两带 1738-1739 → 四带 480 units（−72%）**；ranBK 434ms→120ms，120/720 = 16.7% ≈ 40ms/250ms 帽（配额执法兑现，逐位对表）。另一个方向性事实：两带 burst（1739）**高于**零带（960）——两带 UT 限流让出的窗被 burst 回填（ranBK 240→434ms）；四带把这笔回填收进 BG 帽。wall：483 / 680 / 720ms——四带 wall 最长但 ran 合计仅 362ms（空转窗 = 双限流叠加期无可出选者，防御支路首度激活，ktest.rs:9845-9851 注）——wall 差额是**供给余量**不是供给不足。
3. **HEAD 基线漂移（重大旁证，非本刀）**：两带 A2/A4 utility p50 从 R5 的 768/10810µs 漂为 HEAD 的 39666/39670µs（样本聚成 ~39.7ms 单簇，p50≈p99）。pristine HEAD 对照 boot（无本刀改动的隔离 worktree 构建）同值 39666/39667——**漂移实证非本刀引入**；根因【推】= R5→HEAD 间 SMP-01 F1 批次把 `lazy_enforce` 接进 `Fair::scan_filtered`（[sched/src/class.rs](../../sched/src/class.rs):478-482，5131ebcd5）：睡眠者醒后入环首扫即被镜像补置限流位——R5 期「睡过限流窗者醒后即刻出选」的逃逸面被关闭，限流从尾事件（p99 37ms/p50 0.77ms 双峰）变中位事件（相位锁定的 40/60ms 占空，§3.1）。
4. **LC 带 = 载体性 null（如实记）**：loadgen 载荷无 LC 任务（ktest 面 spawn 恰 interactive/utility/background 三型，ktest.rs:9636-9640）——LC 5ms quantum/512..1024 权重无消费载体；四带组的 LC 槽武装受理面成立（configure 受理 + `band_on` 断言，[band] 证据行 `m4spLC intent=1 q_ns=5000000 w=512..1024`）。任务书假说「LC 带=interactive 应更短 quantum→更快响应」在**本载荷族**无载体：interactive 带 quantum 两带/四带同值（10ms，[iprofile 表行 2](../../iprofile/src/lib.rs):414-422），且 ktest 驱动授片走手驱 unit 面不经 `grant_cycles`（quantum 轴的消费点归生产授片八点+BANDM4G，§3.3）。
5. **BG 长片假说的判读修正**：「BG 带=burst 应更长 quantum→更高吞吐」——实测差异显著但方向相反（−72%），且机理是**配额帽**（40ms/250ms CBS 执法）不是长片增益：BG quantum 40ms 不进 ktest 驱动授片面（手驱 250µs sub-unit）。长片增益（少抢占→高吞吐）的载体在生产 `grant_cycles` 路径，而真系统探针的 burst 源是 plain spawn（UNSPECIFIED，[kernel/src/main.rs](../../kernel/src/main.rs):2160-2161）不入带——**真系统面对本载荷族四带 vs 两带结构上不可见**【推：结构论证，未实跑探针】。
6. **四带是否改善调度质量（任务书问题③）：ktest 机械面上是**——utility 中位延迟 39.67ms→8µs、interactive 不动、burst −72%+wall 空转窗（=过载源让路后的供给余量）。这是「带参数差异化在当前负载下」**显著**（p50/p99 均有差异）的一面；不显著的两面同样如实：interactive 族平坦（本来就非瓶颈）、LC 无载荷。判据边界：本结论限 ktest 手驱配额执法面；quantum/权重两轴的生产行为差异归 BANDM4/BANDM4G（本 boot 全绿同 R5 值：`BANDM4G diff exh=10/0 flips=29/4 cross=0/5`，`BANDM4 ok n=4`——四带参数阶梯结构面在席）。

## §1 方法与复现配方

- **本刀落码（ktest LOADGEN 扩展，纯增量）**：①`LgGroup.band: bool` → `LgBandMode` 三档枚举（ktest.rs:9516-9523）——Off/Two 语义与 R4/R5 逐位同（武装序 [IA, UT]、参数 20ms/60ms、翻期扫/consume/收口路径不变）；②Four 档武装集 = [LC, IA, UT, BG]（ktest.rs:9749-9760），LC/BG 参数与表行懒武装形同源（quota = 本带 quantum_ns、period = 本带 latency_target_ns：LC 5ms/1ms、BG 40ms/250ms，ktest.rs:9602-9605）——IA/UT 保持 ktest 经典 20ms/60ms（Four-vs-Two 差分只隔离 LC/BG 增量）；③consume 映射扩 kind==2 → BG（ktest.rs:9888-9903，Off/Two 下 burst 仍不进带——R4/R5 语义）；④差分断言：Four 组 `thr_bk >= 1`（background 配额须越线，ktest.rs:10049-10051）+ 收口/样本数/slack 上界断言全组共用；⑤输出面：band 标签 off/on/on4（A1-A4 字面前缀零漂移），行尾追加 `thrBK=`（A1-A4 恒 0），cmp 行扩六列（ktest.rs:10115-10118/:10145-10147）。
- **构建与 boot**：`CARGO_TARGET_DIR=$PWD/target-b4x cargo build`（内核工作区；EPERM 坑隔离，[berryos-dev 规约](../../.agents/skills/berryos-dev/SKILL.md) §一）→ 裸 QEMU boot（`-machine virt -cpu cortex-a72 -m 128M -nographic -kernel < berry-kernel>`，`timeout 480`）——ktest 在 rootfs/timer/sched init 之前跑（[kernel/src/main.rs](../../kernel/src/main.rs):991-992），无 rootfs 拓扑即收 ktest 面（boot 尾 park/timeout 收，信号 15 终止为预期形态）。**3 次主 boot**（boot1/boot2 = 本刀构建双跑；boot3-final = 终态注释勘正后复跑）+ **1 次 pristine 对照 boot**（`git worktree add --detach /tmp/b4x-head HEAD` 干净构建，仅补 userbins 产物件——编辑隔离对照）。
- **判据口径**：每 boot 单跑得六组（ktest 面准确定性——R4 两跑/R5 单跑先例，忙等 CNTVCT 锚定，宿主负载只扰动 boot 早期与 ia p50 噪声带）；µs = 周期 × 16/1000（@62.5MHz，13 号同源）；样本量 ia/ut 各 16（4 任务 × 5 唤醒——p99 = 最近秩，小样本上界口径同 13 号 §5-2）；p99 个值不作判据（boot 间 2× 带宽，13 号 §2.1 同口径），判据立 p50 与形状。
- **基线**：R4 = [AB-01](../调度深度调研/AB-01-CP06首份AB数据-ktest负载生成器-v1.0.md) 两跑（两带时代）；R5 = [14 号](14-FairBand差异化后数据.md) §2.2 单跑（两带行为差异化后）；HEAD 基线漂移后 R5 的 A2/A4 值不再是「现 HEAD 的两带对照」——本件两带对照 = 同 boot 的 A2/A4（HEAD 同内核同构建，唯一差 = 本刀 Four 组增量）。

## §3 分析

### 3.1 HEAD 基线漂移根因【推】：lazy_enforce 关闭「睡眠逃逸」，限流变中位事件

机理链（候选，置信中高——pristine 实证漂移非本刀，具体归因 commit 推断）：SMP-01 F1 批次（5131ebcd5）把 `band::lazy_enforce` 接进 `Fair::scan_filtered` 逐节点对账（[sched/src/class.rs](../../sched/src/class.rs):478-482；[sched/src/band.rs](../../sched/src/band.rs):390-414）——带限流镜像真 → pick 扫描**幂等补置** HELD_THROTTLE。R4/R5 期限流位只由驱动显式 `throttle_all` 环扫置位：**睡眠中（SLEEPQ，不在环）的 utility 任务躲过环扫**，醒来入环即出选（p50 768µs 的快分量）；HEAD 期醒来首扫即被镜像补位 → 等翻期。后果：utility 4 任务 × 10ms burst vs 20ms/60ms 配额 → 每期前 20ms 烧尽配额、后 40ms 全员冻结、翻期又同步烧尽——相位锁定的 40/60ms 占空，每次唤醒落在冻结窗内 → lat ≈ 40ms−ε 单簇（39666/39668 的 p50≈p99 形状与 ranUT=240ms/wall=680ms=0.35 占有率对 0.33 配额的边缘超线自洽）。这是**执法完备化的语义正确代价**（跨核限流残留结构性饿死的修复面，band.rs SMP-01 段注），不是回归——ktest 全断言绿（LOADGEN ok/ktest done 三 boot 在席）。真机相可用 per-band 限流计数遥测分解验证（14 号 §5-5 同挂账）。

### 3.2 四带主差分：BG 帽把过载源让路给 utility（数据全通）

A5 vs A2 逐项：ranBK 434→120ms（−72%，= BG 40ms/250ms 帽的 16.7% 期占率兑现，逐位对表）；utility p50 39666→8µs——BG 冻结期 utility 醒来即出选（环内竞争者只剩 IA 短 burst 与偶发 BG 回场窗）；utility p99 37799-38784µs——utility 自身 20ms/60ms 配额的冻结尾仍在（Four 组 UT 配额与 Two 同值，ktest.rs:9763-9764），恰证「中位改善来自 BG 让路、尾部残留来自 UT 自身配额」的分解。wall 680→720ms 与 ran 合计 362ms 的差额 358ms = 双限流叠加空转窗（UT 40/60 占空 × BG 210/250 占空的交叠——防御支路推进，ktest.rs:9845-9851）——**这是设计语义**（供给余量），单核满载形态下表现为 wall 变长，多核/真负载形态下是可给其他类的余量。A6（slack+四带）ut p50 39014-39030 ≈ A4（39666-39670）：10ms 顺延被 ~30ms 限流 dwell 部分吞并（p99 60268-119090 宽尾，slack+限流复合相位，boot 间 2×——p99 个值不作判据）。

### 3.3 任务书两假说对账（判读修正，非失效）

- **「LC 带=interactive 应更短 quantum→更快响应」**：本载荷族**无载体**——loadgen 无 LC 任务（spawn 三型 ktest.rs:9636-9640）；interactive 带 quantum 在两带/四带同值 10ms（[iprofile 表行 2](../../iprofile/src/lib.rs):414-422）；ktest 驱动授片 = 手驱 250µs sub-unit（ktest.rs:9872-9879），`grant_cycles` 的 quantum 消费点（[sched/src/class.rs](../../sched/src/class.rs):844-849）不经驱动面。实测 ia p50 两带/四带 346-384/349-350 平坦 = 预期 null。LC 更快响应的可测载体 = 后续给 loadgen 加 LC 型 sleeper（探针 spawn 面扩展），归后续刀。
- **「BG 带=burst 应更长 quantum→更高吞吐」**：实测 burst 480 vs 1739（−72%）**差异显著但方向相反**——差异全部来自 BG **配额执法**（40ms/250ms），quantum 40ms 在本面无消费点（长片增益需生产授片路径：40ms 片 vs 全局 10ms 片的少抢占差，[sched/src/class.rs](../../sched/src/class.rs):844-849 + 生产授片八点）。且真系统探针的 burst 源是 plain spawn（UNSPECIFIED，[kernel/src/main.rs](../../kernel/src/main.rs):2160-2161 注「过载源两臂同形」）——真系统面四带 vs 两带对本载荷族结构上不可见【推：结构论证；探针 12 boot 复跑未做——其 g2/g1 对照在 ×4 前后预期逐位同形，载体性 null 不花 boot 预算】。

### 3.4 与 BANDM4/BANDM4G 的证据面合拢

本 boot 全绿的结构面：`BANDM4 ok n=4`（四带现役集/工厂门/参数阶梯严格递增/表源执法/共存/spawn 面——dcf359c5c 扩展）+ `BANDM4G diff exh=10/0 flips=29/4 cross=0/5`（IA/UT 代表对的 quantum/latency/quota 三轴行为差异化，与 R5 值逐位同）+ 本刀 A5/A6（BG 配额轴的行为差异化数据 + LC 武装受理面）——四带的「参数差异化有消费」证据闭环：LC（结构受理）、IA/UT（BANDM4G 三轴）、BG（本件 thrBK=3 + ranBK 帽）。四带中唯一零行为证据的仍 LC（无载荷），与 §3.3 载体性 null 一致。
