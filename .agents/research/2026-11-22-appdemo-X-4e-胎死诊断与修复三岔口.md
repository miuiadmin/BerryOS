# gui8 点击段 appdemo X-4e 胎死诊断与修复三岔口

Type: survey
Status: current
Updated: 2026-11-22

一句话说明：gui8-smoke 点击段失败（`app APPDEMO up` 永缺）根因定谳——appdemo 自带 [link-user.ld](../../user/bins/appdemo/link-user.ld)（58770642，11-07 真实系统化 Phase 0）以 `. = 0x1000` 开局把 ELF 头排出所有 LOAD 段，`__ehdr_start` 链接期解析为 0（[tlsscan.py](../../tools/tlsscan.py) 151 行在册的 X-4e 机制原文），crt0 `_start` 首调 `berry_tls_setup` → `find_ptls(0)` 读 e_phoff（+0x20）即 D-abort 胎死——先于 main 第一行；同链 stdhello（无脚本、默认基址 0x200000、头在 LOAD 内）烘焙值 0x200000 活体对照实锤。该雷 11-07 落地后一直被上游更早的失败（输入楔死、批3 位置崩、wants_fs 合流）遮蔽，2026-11-22 点击链首次走通（inputd h=9、CLICK ok n=1）方才见天日。本文只诊断不动刀，修复三岔口待 owner 裁决。

## 证据链（全部可复现）

- 崩溃形态（/tmp/gui8-smoke.xkvmiz4e/boot-a.log 492-531 行）：D-abort(lower) ISS=0x7，PC=0x133a4，FAR=0x20，x30=0x100c，G1.5 击杀 `user_child`——点击拉起的 appdemo 本体，先于 `app APPDEMO up`（main.rs:299 首行）。
- 反汇编对号：0x1000 `_start`（mov x19,x0 / mov x20,sp / bl berry_tls_setup——[crt0.rs](../../user/berry-libc/src/crt0.rs) global_asm 逐指令对上）；0x133a4 = `adrp x9,0x6d000; ldr x9,[x9,#0x670]; ldr x10,[x9,#0x20]`——GOT 槽 0x6d670 载 `__ehdr_start` 后读 e_phoff（ELF64 头 +0x20 偏移）。
- ELF 解析实锤：appdemo（cargo-target 与 app-stage 双件）first LOAD va=0x1000、无任何 LOAD 覆盖 vaddr 0、PT_TLS 在席（memsz 0x18）、GOT 槽烘焙值 **0x0**；stdhello first LOAD 0x200000、GOT 槽烘焙值 **0x200000**、PT_TLS 同在——同链同旗（justfile 205-215 行 musl 同链自述）唯一差异 = appdemo build.rs 注入 `-Tlink-user.ld`。
- 旁证：tlsscan.py 24/151/160 行对该机制有完整预判（「PHDRS 时 lld 把头排出所有段 → __ehdr_start 解析为 0 → crt0 find_ptls 胎死（X-4e）」）但 0x1000 平像族豁免（「装载不读」假设）放行了 std+crt0 族——豁免面与 crt0 运行期真读 ehdr 的事实矛盾，门失效。

## 修复三岔口（待裁决）

- 案 A（改链接脚本，头入段）：link-user.ld 加 FILEHDR（PHDRS 式）或前置头段——但头占 0x1000 起约 0x1d8B，`_start` 后移 ≠ 0x1000，而内核 `spawn_user` 的 entry 硬约定 0x1000（脚本头注自述）→ 须连改内核取 ELF entry；另 access_ok 0x1000 下界禁 VA 0，头只能进 0x1000 段内。动面=脚本+内核装载器双面。
- 案 B（改 crt0，模板烘焙，推荐初步倾向）：本族不读 ehdr——tlsscan 已在构建期算得 PT_TLS 四元组（VADDR/FILESZ/MEMSZ/ALIGN，python/rust 双份算术在册），mkapp 打 .bap 时烘焙成静态四全局（或 manifest 域），crt0 按族选择读烘焙值；0x1000 平像契约与内核装载器零改动，tlsscan F1 门同步收紧「std+crt0 族必须有烘焙面」。
- 案 C（改装载器，整文件映入）：UserProcess::build 连头整体映入并把 entry 指向真入口——与 access_ok 下界、既有镜像几何（首页装像次页栈）冲突面大，动面最广。
