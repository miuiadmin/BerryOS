## 结论

### 一、声明式与状态管理：保留树 arena + 命令面，粒度三层递进

- 引擎内核 = 保留树 arena + 布局 + 脏区合并 + 遮挡剔除渲染 + 输入手势 referee + 动画表 + 三态停帧 + 双轨遥测（`user/berry-ui/src/lib.rs:1-4`）；单线程立法 `&mut self`、无 Cell 无 Sync（`lib.rs:42`）；零 alloc 零 panic 铁律（`lib.rs:36-37`）。
- 信号树本体：`Ui` 门面持定容 arena `nodes/gens/free_stack`（显式 free 链）+ damage + 输入缓冲 + 动画表 + 遥测环 + 依赖边 + a11y 侧表 + press_map + focus + 输入内容侧表（`lib.rs:454-494`）；`Node` 冻结 19 字段 = 144B、编译期断言执法（`lib.rs:380-381, 426-446`）；NodeId = gen 槽位代数打包防悬空（`lib.rs:503-505`）。
- 信号核粒度三层：per-node `layout_dirty/paint_dirty` 双位（`lib.rs:442-443`）；`props_geom_equal` 纯着色变零重排（值变不动布局，`lib.rs:532-570`）；S7 实验轨 per-prop `ChangeMask` 八位（W/H/GAP/BG/FG/TEXT/SCALE/CROSS，GEOM 与 PAINT 两组不叠、三漏斗统一 `apply_change` 单源分派，`user/berry-ui/src/mask.rs:1-16`，`cfg(feature = "s7")` 默认构建不编入）。属性级依赖缝 `dep.rs` 已接线记录（`DEP_EDGES_MAX=64` 幂等边表）但 v1 记录不消费、失效仍视图级 invalidate（`user/berry-ui/src/dep.rs:4-7`）。
- desc DSL 形态：AST 二进制 TLV 双入口（API 面数据驱动 + 描述结构可序列化，ADR #52；`user/berry-ui/src/desc.rs:1-3`）；前序 TLV 流逐字节定义（kind u8 + flags + key + 定长 props + SIZE/A11Y/ALIGN 扩展块 + child_count，`desc.rs:7-27`）；byte-exact roundtrip 由 golden 字面量守卫（`user/berry-ui/tests/tlv7.rs:1-10` 及 tlv2 至 tlv6 六轨）。无响应式宏与绑定语法——状态更新走命令面 `set_props/set_text/set_offset`，事件经 `WidgetEvent` 值面携出（Msg-only 零闭包，`lib.rs:236-249`）。

### 二、组件：41 kind 全通电，pattern 19 配方族落齐，v1 降解面明确

- 41 kind 全列于 `ViewKind` 枚举（`desc.rs:170-212`：Root 至 DragReorder），渲染全部通电（`user/berry-ui/tests/gallery2.rs:1-3`「41 ViewKind 全通电」；`user/berry-ui/src/paint.rs:30` 注释收尾「41 kind」）；TLV 分五批 add-only 落齐（Phase 1 七件、P1 九件、P0 尾四件、P1 尾五件、P2 七件 tag 34..=40，`desc.rs:20-27` 及 :105-115 批注）。测试面：集成 258 + 内联 61，超六波方案「每件至少 2 测、总数不低于 250」之门（方案步骤 3）。
- pattern 完成度：`user/berry-ui/src/pattern.rs`（3022 行）= 19 移植配方族全落齐（AppBar/TopBar/Scaffold/NavHost/TabBar/BottomTabs/Seg/Step/Card/ListItem/Collapse/SwipeItem/DragReorder/Chip/Badge/Fab/IconButton/Gauge/Qr/Sheet/Drawer/Refresh 中的 19 族，52 单测；[PORT-XB.md](../../PORT-XB.md) 二节逐件表）+ 主树既有值面 4 件（几何常量族、`ItemState` 五态色表 `pattern.rs:86-105`、`NavStack` 纯数据页栈 `pattern.rs:117-178`）。「23 配方」是移植源 ui-wave2 刀 3 资产口径（`pattern.rs:21-23`）；差额件中七件以 kind 直载退役组合配方、Tabs 联动控制器/Sbar/Check/Radio/DatePick/TimePick 不移植（PORT-XB.md 二节「不移植」行）。
- v1 降解面：paint「组件 v1 固定色板」为过渡豁免（ACCENT=0x1976D2 Material 蓝非 OH brand，主题收编挂后续刀；`paint.rs:70` 起色板块、`user/berry-ui/src/theme.rs:19-21`）；Qr 为确定性占位图案非真编码（`paint.rs:1395, 1604, 1624`）；Canvas 为占位棋盘格（`paint.rs:134, 1255`）；per-node 圆角挂样式系统（`paint.rs:203`）；Input/Edit 文本走引擎侧表 `INPUT_TEXT_MAX=8`（`lib.rs:177-179`）；Focus 态五态表值面占位同 Normal（焦点环原语缺，`pattern.rs:84-85`）。画廊 43 格附诚实标注清单（`gallery2.rs:8-21`、[WAVE2-GALLERY](../../WAVE2-GALLERY/README.md)）。

### 三、动画：五属性定点缓动，无弹簧、无速度续接中断恢复

- `AnimProp` 恒五属性：OffsetX/OffsetY（Transform 型落 paint 偏移不重排）+ Width/Height/Gap（Layout 型改 props 重排），`kind_of` exhaustive match 单源分型、漏臂即编译错（`user/berry-ui/src/anim.rs:28-57`）。
- `Easing` 四档 Linear/StepEnd/QuadOut/CubicOut，Q16.16 定点全整数中间量（i128 防溢、无浮点；`anim.rs:59-69, 233-260`）；定容槽 `ANIM_MAX=16`（`lib.rs:82`），完成语义应用精确 `to` 终点后移除（`anim.rs:438-445`）；死节点/代数失配仍完成移除，防 anim_active 卡死停帧（`anim.rs:15-17`）。
- 弹簧无（Anim 无物理参数）、关键帧多轨无、转场体系无；中断恢复半档：SwipePager 吸附途中 DragStart 可抓回中断动画跟手（`user/berry-ui/src/swipe.rs:220-221`），但重新起拍 QuadOut 240ms 吸附、不携带松手初速度（`swipe.rs:262, 281-299`）——对标可中断弹簧（iOS interpolatingSpring 初速度续接）缺速度续接面。动效 token 闭集（16 档 duration + 9 条 bezier）数值已采齐但仅文档态（[应用规范](../../docs/应用规范-v1.0.md) §3.5，:175）。

### 四、手势与输入：referee 七 Msg + 重采样终跳，长按双击捏合无

- 手势 referee = per-pointer 状态机（`user/berry-ui/src/hit.rs:132-144`），Msg 恒七变体 Press/Release/Click/DragStart（axis 锁轴）/DragMove（resampled 标注）/DragEnd（vx, vy 速度携出）/Cancel（`desc.rs:853-863`）。拖拽有：`DRAG_SLOP_PX=8`（`lib.rs:90`）、速度环 96ms 窗首末差分、i128 中间量钳 ±32768（`hit.rs:178-229`）；DragStart 在 resample 替换前入环防速度低估（`hit.rs:178-181`、`lib.rs:2171-2178`）。
- 长按无、双击无、捏合/旋转无（Msg 无变体，LongPress/DoubleTap 全库零命中）；多指槽位 PTR_MAX、满丢计数 loud（`hit.rs:139-143`）。
- 重采样终跳：`resample_to_target` 纯函数，括点线性插值 + 前向外推视界帽 min(跨度/2, 8ms)、后向外推不提供，常量 5/2/20/8ms 全引 berry-guiproto 单源（`user/berry-ui/src/resample.rs:54-115`）；语义对齐 Android `target = expected_present - latency`（`resample.rs:15-17, 34-38`）。
- `pump_input` 现状：逐事件维护 MOVE 滑窗（INPUT_BUF_MAX=8）、resample 替换坐标并标注 `resampled` 位、press_react/widget_react 同帧即时消费（`lib.rs:2147-2224`）；SwipePager 跟手橡皮筋 ×0.5、翻页三判据速度 500px/s 优先再位移 40% 再回弹（`swipe.rs:11-13, 236-263`）。

### 五、输入法：引擎面焦点环在位，softimed 停规划稿，真 IME 全缺

- 引擎侧：Input/Edit kind 落地（`desc.rs:197-198`）、`set_focus` 焦点环与 caret 单源（`lib.rs:1662-1698`）、`input_text/set_input_text` 内容侧表（`lib.rs:1702-1713`）、焦点光标有视觉（paint INPUT_FOCUS_RING，`paint.rs` Input 色板段）。
- 协议侧：波 2 add-only 已定义 OP_WM_FOCUS=0x66、OP_WM_BACK=0x67、OP_INPUT_INJECT=0x22 与 IME 文本提交面（payload = ASCII 字节串）（`user/berry-guiproto/src/lib.rs:106-122, 1894-1936`）。
- softimed 现状 = 规划稿未落地：波 3 设计稿（`Status: draft`）§5 定为 SERVICE 底窗 QWERTY-lite ASCII 软键盘、显隐 = 焦点窗 ime_wanted、按键经 OP_INPUT_INJECT 与真实输入同一事件面（波 3 设计 :67-86）；bin 未建（`user/bins/` 无 softimed 目录），未完成事项在册（波 3 设计 :117）。
- 真 IME 缺口：CJK 输入无（字形不在档，见十）、候选窗无、组合文本（preedit）协议无、软键盘 shift/长按挂账波 5（波 3 设计 §9，:135）、引擎侧 KeyEvent/TextEvent 消费接线未做（波 3 移交清单，[波3 三栏侦察](2026-11-15-波3三栏侦察.md) :85）。

### 六、多窗：件二带裁兼容档在役，真合成与焦点层位是波 3 目标态

- 架构 = 呈现与窗口策略分离（ADR #61）：guifbd 只管呈现，gui-wmd 本地权威处理 wm 六 op、present/hdi 经其中继（`user/bins/gui-wmd/src/main.rs:1-6`）；权威窗口表 = 静态定容、两层窗 APP/SYSTEM + Z 序 + parent/group 缝 + 单焦点域、单车位 TABLE_WAIT 现答现快照、AVOID_SYS 不变量式避让（单矩形保形裁剪、四条剩余带取面积最大者）（`user/bins/gui-wmd/src/table.rs:1-24`）。
- 合成现状 = 件二带裁兼容档：guifbd present 六 op v1 = blit-at-SUBMIT，SUBMIT 时同步 damage 裁剪 CPU blit 直写 fb、无 pending 帧状态机（`user/bins/guifbd/src/guest.rs:38, 632-657`）；后果 = 应用全屏 SUBMIT 即被盖、wmd SYSTEM 层从未用（六波方案 :16 现状底册原文）；真合成 = 波 3 带合成 v1（缓存 SYSTEM/SERVICE 带、按 SERVICE>SYSTEM>APP 重放，六波方案步骤 4）。guifbd v2 帧批面（per-rect flush + 异步发车 + fence）是 virtio-gpu 后端提交序优化、非多窗合成（`user/bins/guifbd/src/lib.rs:26, 238`）。
- 焦点层位现状：WM_LAYER 三常量已定义 APP=0/SYSTEM=1/SERVICE=2（`berry-guiproto/src/lib.rs:114-130`），但建窗值域执法只到 SYSTEM（`wm_layer_known: l <= WM_LAYER_SYSTEM`，`lib.rs:437-440`）、SERVICE 建窗拒面；窗口创建旗仅 AVOID_SYS 一面（`lib.rs:442-444`）；OP_WM_FOCUS/BACK 编解码在协议面（`lib.rs:1894-1936`）但 wmd 无分发臂（波 3 未完成事项 :107-108）；状态栏/壁纸 = launcher 窗口内容层非系统窗（`user/bins/berry-launcher/src/desktop.rs:17` 裁决四-e）。

### 七、无障碍：a11y 侧表与 TLV 携出在位，无屏幕阅读器消费端

- `A11yEntry` 侧表存在：容量 32（`lib.rs:210-211`）、条目 = NodeId + role + 内联标签、gen 位与 arena 三重对拍防悬空（`lib.rs:221-229`）；role 常量域五角色（NONE/BUTTON/TEXT/IMAGE/TOGGLE/LIST_ITEM，`lib.rs:213-219`）。
- 写入与序列化：`set_a11y/a11y_iter` 公共面（`lib.rs:1442-1466`）；TLV a11y 扩展块（flags.bit2，role u8 + label 至多 64B，`desc.rs:24-26`）；encode 面 `a11y_out`（`desc.rs:2723-2845`）随描述流携出。
- 消费端现状 = 仅应用侧自写与测试：settings 逐控件挂 role（`user/bins/settings/src/main.rs:292-462`）、launcher 时钟 in-place 覆写与翻页 rehang（`user/bins/berry-launcher/src/frameloop.rs:316-317, 411-416`）、桌面 32/32 满（`desktop.rs:19` 裁决八）；gui-wmd/guifbd 无 a11y 消费（grep 零命中），无屏幕阅读器、TTS、系统 a11y 服务。钉板测试在 `user/berry-ui/tests/a11y.rs:1-8`（remove 连带清/重建清表/NodeFull loud/take 幂等）。

### 八、主题：OH 常量单源 light/dark 双档在册，无切换入口、无动态取色

- `theme.rs` = OH 官方表常量单源：light 档 12 token（brand/background/font/icon/warning 系，`theme.rs:17-43`）+ dark 档同语义名镜像 11 token（`theme.rs:45-64`）；消费面 `Tokens::pick(Theme)` 单点取整套（`theme.rs:96-122`）；圆角 token OH_RADIUS 8vp = 24px 与 pattern DENSITY 对拍钉板（`theme.rs:66-74, 159-165`）。
- 暗色现状 = token 双档在册、无系统级暗色模式：bins 侧无 `Tokens::pick` 消费（launcher/settings grep 零命中）；paint「组件 v1 固定色板」不查主题档（`paint.rs:70` 起豁免块）；dark 档 brand_pressed 与 brand 同值未区分（`theme.rs:112, 141-146`）。动态取色（壁纸取色）无；`dim_accent` 派生常量在 pattern 面待收编（`pattern.rs:28-30`）。

### 九、自适应：几何单源 1080x1920@3x，无断点、无折叠、无旋转

- 几何单源 = `DENSITY=3`（1080×1920 = 360×640vp @3x，`pattern.rs:60-61`），vp 转 px 常量族全由此派生（TOPBAR_H=168px、BOTTOMTABS_H=144px、LISTITEM_H=144px，`pattern.rs:63-70`）；六波硬约束「几何单源 OH phone 档 1080×1920@3x 经 WM_GETINFO 协商」（六波方案 :17）。
- 运行面几何动态化：launcher 桌面几何全经 wm GETINFO 动态、ui.viewport() 注入（`desktop.rs:29` 裁决 D）；应用几何经 WM_GETINFO 应答回显（guifbd 真值源）。
- 断点无、折叠无、旋转无：无媒体查询/断点系统；旋转自由化显式挂账波 5（六波方案步骤 6）；SwipePager 页宽冻结在建树时、viewport 变更需重 attach（`swipe.rs:61-63` v1 挂账）。

### 十、国际化与字体：1-bit 点阵四档 95 枚 ASCII，CJK 与 i18n 框架均无

- 字体四档 `FontSize`：S8x16（fbcon 单一事实源同款）/S16x32/S24x48（1x 整数最近邻放大档）/S32x48（HD 档 Noto Sans 原生光栅化非放大）（`user/berry-gfx/src/font.rs:150-159`）。
- 点阵数据：HD 档 32×48 字模 95 枚恰 ASCII 32..126，字源 Noto Sans CJK SC Regular 的 ASCII 子集光栅化（SIL OFL 1.1），产物格式 v2 附 ADVANCE 比例推进表、生成器 `tools/genhdfont.py`（`user/berry-gfx/src/font_data_hd.rs:1-15`）；低档位图 font_data_s2/s3 同族。测量双供件：Monospace（逐位复刻现状）与 Proportional（HD 档真比例宽，`user/berry-ui/src/metrics.rs:1-10`）。
- CJK 无：本轮 UI 文案限 ASCII 为硬约束（`pattern.rs:42-43`；六波方案 :19「本轮 UI 文案限 ASCII 无 CJK 字形」）；i18n 框架无——无 locale、无资源束、无字符串表，文本内联 `TextBuf` 至多 64B（`lib.rs:80`）。

### 十一、性能：damage 合并与三态停帧成体系，HDR 直方图在内核不在 UI

- damage：`DamageSet` K≤8 定容、Σ×1.25 浪费帽合并（L 形角交拒并的判定式单源）、满 8 找最小包络、零面积丢弃（`user/berry-ui/src/damage.rs:12-16`）；`RectSet` 遮挡剔除保守少记覆盖（`damage.rs:17-18`）；overdraw 预算 2.5×（`lib.rs:91`）。
- vsync 与背压：`set_vsync` 协商倒数注入（`lib.rs:2260-2264`）、`next_vsync_tick` 含沿不欠拍（`user/berry-ui/src/frame.rs:76-94`）、credits 背压帽 CREDITS_MAX 帽满不提交（`frame.rs:130-158`）。
- 停帧优先：三态 RUN/SETTLE/IDLE 纯函数状态机（`frame.rs:29-74`）、IDLE 即 `next_wakeup=None` 撤软 vsync 定时器睡事件（`frame.rs:96-109`；`lib.rs:43-45`）、静默 2000ms（OH 常量）强降 Idle 兜底（`lib.rs:92`；`frame.rs:67-69`）、idle 票 sticky 停帧粘滞显示服务不再唤醒引擎（`frame.rs:202-210`）、「无 damage 不提交」跳过帧诚实零票（`frame.rs:160-179`）。
- 运行时卡顿采集：telemetry 64 帧环 `FrameRec` 十二字段 expected/actual 双轨，jank 判定 actual > expected + period/2 在 `note_presented` 单源、计数器族含 deadline_miss/spinup_late_frames（`user/berry-ui/src/telemetry.rs:1-40`）；消费现状 = host 断言（tests）+ launcher 帧计数（`frameloop.rs:494-497`），guest 侧收口归 GUI-9 未做。
- HDR 唤醒直方图：`hdrface` 是内核调点调度延迟直方图 crate（对数线性桶 + 分位数学，W3-Q16；`hdrface/src/lib.rs:1-7`），UI 栈（berry-ui/guifbd/launcher）零消费、无唤醒延迟直方图面。
