一句话说明：对 VNC 三波（对外暴露与认证 / 成熟化 / 分发与打包，均未 commit 的工作树态）的四路只读 sweep（代码 / 文档 / 测试 / 仓库卫生）发现做去重、并路、与已知边界清单对拍后的分级遗漏清单与裁决，供 fix 阶段取用。

## 问题

VNC 三波已全部落地（三份计划均 done，见 [../plans/2026-11-13-vnc-desktop-suite.md](../plans/2026-11-13-vnc-desktop-suite.md)、[../plans/2026-11-13-vnc-maturity-wave2.md](../plans/2026-11-13-vnc-maturity-wave2.md)、[../plans/2026-11-13-vnc-packaging-wave3.md](../plans/2026-11-13-vnc-packaging-wave3.md)），本 survey 回答两个问题：其一，四路 sweep 的发现里哪些是真遗漏（剔除已知边界与重复）、各属于什么等级；其二，哪些归本刀在 fix 阶段修、哪些只记录（跨会话属地或需用户裁决）。本文只裁决，不改任何代码。

## 方法与来源

四路 sweep 均为只读（不改文件、不跑改状态命令；并行会话在跑的 run 与 QEMU 全程零触碰），产出以 JSON 回报，本 survey 是其汇总载体。四路范围与命令族：

- 文档路：[tools/berry/README.md](../../tools/berry/README.md) 与 [CLI-first 设计 v1.3](../../docs/Berry设备平台-CLI-first设计-v1.9.md) 的每个 VNC 旗标 / 动词 / 默认值 / 输出样例对 berry CLI 实取 help 与代码逐项对拍；三计划三笔记链接与产物存在性；`web/NOTICE.md` 与 vendored 树对拍（find / du / shasum / curl 校验命令）；`docs_guard` G10；`check-appdir.sh` 对存量 AppDir 实跑；[阶段沿革](../../docs/阶段沿革.md)三节与三波验收记录抽核。

triage 阶段（本文档落笔前）对承重发现做了只读复核：F01-F07、F12、F15-F20 的代码行号与语义逐一重读核实，F13/F14 的两处 `~/.berry` 残留物 `ls` 确认仍在，`node .agents/tools/check-docs.mjs` 复跑为 `检查 203 篇 / 告警 0 条`（sweep 时点的 p33 笔记断链告警已被并行会话自修，不再进清单）。
