## 问题

VNC 六波已全部落地（单测 96 绿、五门全绿、check-docs 零告警，见 [../plans/2026-11-13-vnc-complete-wave5.md](../plans/2026-11-13-vnc-complete-wave5.md) 与 [../plans/2026-11-14-vnc-compliance-wave6.md](../plans/2026-11-14-vnc-compliance-wave6.md)），本 survey 回答三个问题：其一，四路 sweep 的发现里哪些是真遗漏（剔除六波各计划边界 / 偏差 / 未完成节已登记者与重复）、各属于什么等级；其二，哪些归后续 fix 线修、哪些只记录（跨会话属地或需用户裁决）；其三，第一轮 survey 遗留台账 F16-F24 逐条的当前处置判词（已解决 / 仍开放 / 归属并行）。

## 方法与来源

四路 sweep 均为只读（不改文件、不起会改状态的命令；并行会话在跑的 run 与 QEMU 全程零触碰），产出以 JSON 回报，本 survey 是其汇总载体。四路范围：

- 代码路：`tools/berry/src` 五六波新面全文审读（`ws.rs` / `tls.rs` / `display/vnc.rs` / `web.rs` / `vnc_cfg.rs` / `commands.rs` / `control.rs` / `main.rs` / `qmp.rs`）+ packaging 四脚本与 `THIRD-PARTY-NOTICES.txt` + `check-appdir.sh`；SHA-1 手写实现按 FIPS 180-1 独立走查（初值 / 填充 / 轮常数 / 链接链），`cargo check --release` 零警告，非测试 unwrap 全数清点（Mutex::lock 惯例 + tls.rs 单处文档化 expect）。
- 文档路：[tools/berry/README.md](../../tools/berry/README.md)、[packaging/README.md](../../tools/berry/packaging/README.md) 与 [CLI-first 设计 v1.5](../../docs/Berry设备平台-CLI-first设计-v1.9.md) 的每个 VNC 旗标 / 动词 / 默认值 / 输出样例对 berry CLI 实取 help 与源码格式串逐项对拍（负例用隔离 BERRY_HOME 实跑，正路输出按纪律以源码格式串 + 验收记录对拍）；TPN 与 `Cargo.lock` 的 cargo tree 实树对拍；五六波计划 / 笔记 / 索引行 / 沿革事实抽核（字节数 / sha256 / 单测数 / 门输出逐项复现）。
- 测试路：`cargo test --release` 基线复跑（96 passed / 0 failed）+ 五波 U25-U33（19 新增）与六波 U34-U40（13 新增）测试矩阵逐项对落到源码行；justfile 两 VNC 冒烟配方检索；超时余量与端口稳定性盘点。
- 仓库卫生路：`git status` 全量归属甄别（五六波件 / 并行件 / 生成物三类）、口令样串与私钥全仓 `rg`、`~/.berry` 与 `/tmp` 残留盘点、`out/` 150 项 mtime / 哈希 / TPN 同一性链、`.gitignore` 七项生效核验、沿革双占全景 census、索引三不变量实测。

triage 阶段（本文落笔前）对承重发现做了只读复核：F25-F34 的行号与语义逐一重读核实，Desktop.app / berryos.img 哈希与 AppImage mtime 实测，沿革二百系列 `rg` 全景重数，台账 F16 / F18 / F20 / F22 / F23 / F24 的证据行重读或实跑，wave6 计划契约 1 的 TPN 枚举核对。

分级口径沿用第一轮：P0 必修 = 功能或安全缺陷（live 可复现）；P1 应修 = 文档漂移 / 明显缺口；P2 建议改进；P3 仅记录 = 跨会话属地、知悉报备或需用户裁决。共 17 条（F25-F41）：P0 × 0、P1 × 5、P2 × 4、P3 × 8。零 P0 的依据：代码路全文审读无 live 可复现的功能 / 安全缺陷，SHA-1 独立走查与 FIPS 180-1 一致且 FIPS + RFC6455 向量已钉，TPN 与 Cargo.lock 实树无漏登，cargo check 零警告，敏感物（口令样串 / 私钥 / 证书）全仓零泄漏。
