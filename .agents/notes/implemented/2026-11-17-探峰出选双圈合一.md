# Agent Note: 探峰出选双圈合一（W3-Q93 · 04 号审计机会一②）

Status: implemented

## Problem

04 号调度热路径审计机会一（SVC 尾检查点探峰瘦身）三件套中，①len 门与③计数移窗已随 owner 快赢（0ea3d11ad）落地，②双圈合一遗留：`try_preempt` RQ 锁窗内先 `Runqueue::has_eff_above_filtered` 只读探峰一圈（早退扫描），命中后 `Fair::pick_next_filtered` 第二圈扫描出选——命中形态同一环扫两遍。g3-1b 域（SVC 全程 IRQ 屏蔽）常态下探峰恒空付整段锁对+全环扫描的账已由 len 门清偿，但 len>1 的多任务形态（探峰真承重）双倍扫描仍在。

## Decision

单圈合成：扫描累加器本就追踪最高 eligible 带——把「探峰谓词」折进出选扫描内，`best_eff > v` 一个比较即门。

- ringface `ScanAcc::best_eff()` 访问器导出（纯增量，零语义面）；host 三钉板：哨兵/全过滤不动律（i32::MIN 初值 = 旧空环 false 同义）、带门与旧探峰两圈参考实现 3000 例全域对拍（含 v 恰界两侧）、pure 形哨兵退化律（PURE_EEVDF 开形带比较恒假——双圈合一对 pure 形不适用的编译期根因记录）。
- sched `Fair::pick_next_if_above(rq, topo, my_cur, v)`：解冻 → 单圈 `scan_with_eff` → `best_eff <= v` 早退（幻影出选防线逐位保持——门假不消耗 head 槽位）→ 出选三件套（advance_past/policy::apply/note_pick 与 pick_next_filtered 同款）。`scan_with_eff` 返回 (best, best_eff) 元组，旧 `scan_filtered` 薄壳维持（trait pick_next / pick_next_filtered 两消费面签名不动）。
- `try_preempt` 双圈换单圈；`has_eff_above_filtered` 退役删除（唯一生产消费点已换，谓词语义由 ringface 参考实现钉板延续）。
- ktest DL-B4 四钉：门假不耗 head 槽位（后继 pick_next_filtered 首见者 = head 序首）、带门恰界出选对拍、空环/全过滤哨兵、解冻时序前移面。

**语义差异面（审计明示接受）**：解冻时序前移——旧形探峰 false 早退不经 pick_next_filtered 头部不解冻；合一后解冻在扫描前（S5-c 头部同源），门假也解冻。方向 = 解冻面扩大（限流 deadline 任务自愈更早、DL_ON_RING 死账面更小），正确性加强非削弱；dl_on_ring 门 0 时零成本，v1 常态零行为差。

## Alternatives considered

- 探峰圈保留早退优化（命中即返省半圈）→ 否：命中形态恰是最需要省的（出选二圈全扫免掉），早退只省探峰假的后半圈而 pick 反正要全扫；合一后恒一圈全扫，两形态总成本均不增。
- has_eff_above_filtered 保留注释化退役 → 否：pub(crate) 零调用 = dead_code 编译红；谓词语义已由 ringface host 钉板参考实现承载，双留即双实现违背单源纪律。

## Impact

test-host 257 组 2553 全绿（ringface 8→11）；四门禁绿；台账随源重产 1132（class.rs +3、runqueue.rs −1、ktest +1）；sched+kernel no_std check 零新警。沿革三百八十八。
