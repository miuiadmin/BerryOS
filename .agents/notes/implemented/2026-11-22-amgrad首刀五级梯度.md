# am §一首刀：五级处置梯度决策核 berry-amgrad

Status: implemented

一句话说明：E lane R9（DAG `am §1` 有界片段）——契约一「终态五级弹性处置梯度」的策略面钉板：新 crate `user/berry-amgrad`，五级表单源化为 `choose(facts) -> Option<Tier>`（RAM 谱系 L0<L2<L1<L3 升格序 + L4 磁盘正交梯度仅在 RAM 面静默时）；实证租约豁免压制 L2 冰封与 L1 深化（契约二.1「唤醒即解冻」联动——冻结进程获租约即解冻在途，不再加深处置）；防抖窗双钉值 3s/0s（契约原文）；`bg_ms == 0` 语义 = 前台永不因窗触发；无触发返 `None`（决策面禁造默认动作）；host 8 测。执行机构（VMO 弃页/pager 换出/SuspendToken/job_kill/pkgmgr）涉内核与 appd 服务面，挂建造清单入 owner 边界队列。

## 裁决与判例

- **决策核先于执行机构（单源防漂移）**：五级表的「哪一级」判定若由 appd 与内核各拼一套必漂移——先把判定单源化，机构接线刀消费同一 [`choose`]；表语义由逐行测试钉板（每梯度一腿 + 升格序 + 豁免压制）。`A: (run decision, 2026-11-22) 决策核先行（纯策略面可钉板；机构接线等边界）. Reversal: 删 crate 撤两行接线即净退。`
- **租约豁免延伸到 L1 深化压制**：表文只说租约豁免 L2 冰封——本刀把「冻结进程获实证租约」同判为豁免 L1（换出深化）：租约意味着解冻在途，加深处置与「唤醒即解冻」互斥；此延伸已在 doc 注记，owner 可否决回卷。
- **紧缺档 0s 窗不冻结前台**：`bg_ms > 0` 才是已退后台事实——0s 窗 + 前台（bg_ms=0）不触发（实测伤钉板：高压档前台应用被误判 L2）。
- **「刚切后台」窗宽占位**：表未钉此值——`JUST_BG_WINDOW_MS` 占位常量注记归 appd 配置刀，真值到位只改常量。
