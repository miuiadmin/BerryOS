# 遥测进程账读口 op=4 刀与 ps 雏形（TCB 运行账第一真源＋bsh ps 第 25 内建）

Status: implemented

一句话说明：owner 令「都做」第二刀——规格轮 wf_c8fc3993-2b2＋实施轮 wf_0ee25fbe-356＋主线修复三段式；内核 TCB 立运行账第一真源（Task 扩 cpu_ticks/switches/wakes/run_since 四 Relaxed 原子字段＋note_switch/note_wake 充账前移——调度器切点即唯一账本本体）＋0x84 op=4 全体在役任务快照（SLEEPQ+RQ0+RQ1 三并集遍历·SQ_RQ_TABLE 四锁同窗一致·40B 轻头＋40B 行×128 帽 5160B）＋berryctl ps --json 雏形（--json day-one 第三件）＋bsh ps 第 25 内建（CLI ok n=14→15 步⑮）；审查 critical 修（ktest 前缀恒等偏移错——ProcStatHdrV1 多一 u32 使 now_vct 在 @32 非 wsrc 判例照抄的 @24——排除窗重算）＋major 记档（park 派发路径 cpu_ticks 诚实少计——dispatch_from_park_ctx 无 note_switch 盖戳，副核高 park 频态下 cpu≈0，已知边界非虚计）。

## 裁决与判例

- **TCB 第一真源**（可观测性 §3「禁重复记账源」合规论证）：调度器切点是运行事实的唯一发生位——cpu_ticks/switches/wakes 在此自然记入 Task（TCB）即唯一账本本体，非第二记账源（memstat「聚合账 vs 明细账」同型）。
- **锁类整号升格 TABLE→SQ_RQ_TABLE**：0x84 五档共享整号——SQ/RQ 遍历需结构锁，handler 内窗自取违七层冻结序（SQ>队列>REAPQ>表），整号改类=入口终态正序合法构式（thread_sleep 0x37 先例）；op=0..3 连坐=入口多三对无争用 TTAS。
- **park 派发路径 cpu_ticks 诚实少计**（major 记档）：dispatch_from_park_ctx 无 note_switch 盖戳（谱 R5「sched 侧零 diff」守约），run_since 结算后清 0 使未盖戳段零结算——单调性/e2e 门不受影响（只少计不虚计）；副核高 park 频态（TCG 演示拓扑）下 CPU1 任务 cpu_ticks≈0 属该已知边界。补救通道=第三盖戳位（R5 例外裁决），挂主线裁量。
