# 机会五①②：偷取空环早退免锁门与 REAPQ 免锁空门

Status: implemented

## Problem

[04 号调度热路径审计](../../../research/内核深度进化/04-调度热路径-Top5优化机会-v1.0.md) 机会五①②：`try_steal_one` 每次探测三段锁+两圈走查——空手是常态形（idle 偷取），空环时密度快照段白付整对本核 RQ 锁对（含持位记账；审计「整圈走查白付」经勘察订正：head None 走查本就零迭代，白付的是锁对）；`reap_drain` 每次调用无条件取放 REAPQ 锁（TTAS CAS 对）——即使队空；调用面 = CPU0 每次 yield_now 切回尾 + idle_loop 两臂环顶（服务循环主力原语，console/svcmgr 每轮至少一次）。三路勘察（wf_de6f4724-f1b）钉死三陷阱：`is_empty()` 是 head Cell 裸读（跨核无锁窗=形式数据竞争，必须用 `len()` AtomicUsize Relaxed）；空判-only（tick 拉取门独占者形 mine==1 的密度承重，扩成恒跳破带偏好语义）；REAP_POST_HOOK 恒调（吞钩子=静默期无界滞留，违背 process.rs「滞后上界=一个收割周期」不变量）。

## Decision

- **①空环早退**（try_steal_one 密度快照段）：`if rq_of(me).len() == 0 { (0, 0) } else { 原快照段逐字保留 }`——门读 len()（runqueue Q3 跨核免锁读先例；tick 拉取门同款在职先例），空形 (0,0) 是快照定义值（与锁窗空形产出逐位相等，steal_band_rank 0>0 假=兼容档）；两向无害：读旧非零（对核 steal/kill 出环 store 未达）→门不开、锁窗快照照旧逐位同形；读旧零（对核唤醒入环 store 未达）→按 (0,0) 用，仅 utility 候选档 COMPAT/DEPRIOR 翻一档软偏好——与既有「快照-扫描间隙对核唤醒入环竞态最多翻边界档一档，容忍」同族同向；全冻结环 len>0 门不开（冻结计数语义=潜在 interactive 负载的刻意设计逐位保留）。
- **②REAPQ 免锁空门**：`REAPQ_LEN` 升 `static AtomicUsize`（A12 原子化免入册——writable_globals.txt 删行，--check 87 entries 过）；`reapq_push` 先槽后计数（锁窗内 fetch_add(1, Relaxed)——家法 WAIT_HASH/LB_TICKS 全 Relaxed 不加 Release）；`reap_drain` 入口（held_test 退化判后、reapq_acquire 前）Relaxed 读零即跳锁窗段——**门只罩锁窗段，REAP_POST_HOOK 恒调于分支汇合后**（HT_DRAINQ 32/拍分块尾账与 REAPQ 失耦）；锁窗内 Acquire 权威重读保留。正确性（收窄版，勿照抄审计对 WAIT_HASH 的过度引用）：门读在锁窗外——清零写点唯一=CPU0 自身 drain ⇒ 零假阳性；唯一漏读形=跨核 push 恰落，一拍有界（yield 尾/idle 环顶每拍必到兜底）；深 park 滞留面沿用 cap 256 既有契约不扩。
- ktest 零改动核证：偷取族钉纯函数面（steal_band_rank 合成输入），ktest 期 par_enabled=false 使 try_steal_one 头部早退（门不可达）；REAPQ_LEN 读者面恰=push/drain 两函数。

## Alternatives considered

- **③密度账本化（per-RQ int/util 计数器挂 link_back/unlink 原语层）**：可行（勘察定谳——账点完备性同 DL_ON_RING 论证）但独立刀：唯一强制义务=recv settle 在环改档的重登（锁包 write_back+计数修正）+integrity_check 密度对账扩展+ktest resync_density 配套；落地时①被超集吞没（可接受一次性买办）。挂后续刀。
- **恒跳快照形**（非空判-only）：破 tick 拉取门独占者形带偏好语义——弃。
- **伴生刀 HT_DRAINQ_LEN 免锁门**（process.rs 同配方）：砍 idle 每拍 KERN_LOCK 线乒乓的真收益点——勘察建议项，另刀待议。
- **push 侧 Release 加严**：非零路径锁 Acquire 配对足够、漏读面单边有兜底——家法全 Relaxed，不加。

## Consequences

- 验证实跑（隔离 target-s5c）：cargo build 绿、writable_globals --check 87 entries ok、boot smoke 32/32（含 SMP 握手标记与全套 ktest）。
- 对抗审查（wf_148a5ad9-481，9 agent 三维+逐 finding）：6 发现全 CONFIRMED 且**零代码缺陷**——笔记/沿革缺口（本笔=清偿）+五条有利裁定（SMP-S3 草案 :364 历史快照豁免滚新；API 参考 reap_drain 行无需滚句 183 口径不动；writable_globals 删行口径与 CI 面一致；ktest 偷取/排水零牵连复核过；三段新增注释逐句核验零失实）。
