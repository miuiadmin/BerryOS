# 驱动两波架构债清理（scrim 族退役 + armed 引线钉板 + driver/hal 正交定谳）

Status: implemented

一句话说明：清理驱动波 1/波 2 落地后的四项架构债——scene::status_scrim 族标退役、icons.rs NAV_ARMED_BG 钉「活代码」引线防误清、berry-driver/berry-hal 正交关系文档化、五 crate Cargo.toml 研究报告互链核实（创建刀已还）；顺带定谳 launcher/src/icons.rs 孤儿文件挂账。

## Problem

任务书四债，核查中两项事实修正：

1. scrim 族生产消费面为零：2026-11-16 桌面沉浸化刀撤 launcher 状态栏深色衬底后，`scene::status_scrim()` 全仓零生产调用（仅 host 测试保活）；随退伴件 `STATUS_SCRIM`/`SCRIM_SAMPLE_ROWS` 两常量与 `icons::wallpaper_top_rows` 的生产链同断。任务书把函数定位在 icons.rs——实体在 scene.rs（icons.rs 只持供件口 wallpaper_top_rows）。
2. 任务书断言「NAV_ARMED_BG armed 路径不可达（on_key 裁决）」与代码事实不符：armed 面消费链完整且活——`status_faces()` 表项 → `NAV_POWER_ARMED`(id 10) → launcher frameloop `set_power_face` 二击关机窗换面；导航键是覆盖态逃生面，消息分流「恒最先」。on_key/keynav 裁决的真实边界是**键盘路径**不触发 armed（键盘词汇仅箭头翻页；裸 Esc 需超时裁决而 on_key 无 timer 钩子，弃）。
3. berry-driver 与 berry-hal 关系无文档（HEAD 上互不依赖、各只 path 依赖 berry-virtio）——是否让 driver 依赖 hal（probe 的 MMIO 面）待定谳。核查期间观察到并行 lane 在途演进：virtio_example 接线 berry-hal（Cargo.toml 加 path 依赖、rd32/wr32 本地 volatile 对退役，未提交）——定谳措辞需两态（HEAD 与在途）皆真。
4. 五 crate（berry-partition/berry-driver/berry-hal/berry-rtc/berry-watchdog）Cargo.toml 研究报告互链待核。

## Decision

- **scrim 族退役不删**：`scene::status_scrim()` 加 `#[deprecated]`（note 指向本篇）+ 退役文档；保活测试加 `#[allow(deprecated)]`——像素数学留独立对拍护栏，复活即有真值面。`STATUS_SCRIM`/`SCRIM_SAMPLE_ROWS`/`wallpaper_top_rows` 注释标随退（不加 deprecated——避免连锁告警噪音；wallpaper_top_rows 留作壁纸顶区采样公共口，Android12 调研 P2「图标明暗随内容」刀的既定候选供件）。scene.rs 模块头注两处过时描述（「消费侧取 status_scrim 自插」）同批改如实。
- **NAV_ARMED_BG 钉活代码引线**：不标 deprecated 不删——注释钉死消费链与「键盘不可达 ≠ 死代码」的边界（2026-11-17 P0-① 透明化裁决本就明文保留 armed 不透明暗红）。`NAV_POWER_ARMED` id 注释同批补唯一消费方。防后续清理刀据「键盘不可达」误删现役交互面。
- **driver/hal 契约面正交组合（依赖单向可选）**：driver=生命周期契约（probe 认领/start 服役/stop 退役），hal=硬件访问契约（Mmio/IrqCtl/DmaAlloc/Clock），组合发生在消费侧——驱动实现方实现 Driver trait 并持 hal trait 对象（vprobe 接线形态；driver 的示例模块同款，故 driver→hal 是可选的单向箭头，hal 永不反向依赖）。trait 面不硬编 HAL：probe 的 `mmio_base` 裸指针是总线中立最小面，volatile 方式归实现侧自选（mock 可零 HAL 独立测试）；缝合成 DeviceCap 铸件（MMIO 窗 VMO + Interrupt + Bti）归波 2.2 后续刀。两 lib.rs 头注互指定谳（「2026-11-20 债务清理刀定谳」锚串，措辞兼容在途接线刀）。
- **Cargo.toml 互链核实已还**：五 crate 头注在各自创建刀即带研究报告路径（`.agents/research/2026-11-18-驱动子系统综合研究报告.md`），本刀核实后无需补。

## Alternatives considered

- 删 `status_scrim` 函数体与测试（弃——工作区「永不删除」纪律 + 波 4 状态栏重做可能复活动态衬底；deprecated 已足够拦新消费者）。
- Driver trait 面硬编 HAL（probe 签名改接 `&dyn Mmio`、crate 必赖 hal，弃——生命周期契约被硬件访问契约绑架，registry/mock 测试面被拖累；crate 级单向可选依赖（示例/实现侧消费 hal）是合法形态，并行在途接线刀已采）。DeviceCap 铸件才是正缝点，报告波 2.2 已立案。
- NAV_ARMED_BG 标 `#[deprecated]` 或删（弃——活代码假标注会诱导真删：launcher 二击关机窗是现役交互面）。
- 顺手删 launcher/src/icons.rs 孤儿文件（弃——超本刀作用域；文件删除是破坏性动作且并行会话有在途脏文件，挂账后续刀）。

## Consequences

- 契约面：新代码调用 `status_scrim` 得编译告警（note 指向本篇）——复活路径有文档锚；driver/hal 正交关系入两 crate 头注，后续 bus 层铸件刀有定谳可依。
- 待清债新挂账：`user/bins/berry-launcher/src/icons.rs` 是波 3 抽取 appshell 时未删的原件孤儿——main.rs mod 列表无 icons（`crate::icons` 经 `pub use appshell::icons` 解析），且 icons.rs:38 `use crate::{rpc_recv, rpc_send}` 在 crate 根无此符号、参与编译必红，基线绿反证其不编译；其 `#[path]` 携带的 status_icons.rs/wallpaper.rs 若同样无主一并待查，归后续清理刀。
- 验证：berry-appshell host 测 28 绿（含 scrim 保活钉板、deprecated 告警零泄漏）+ berry-driver/berry-hal host 测全绿 + `just build-user` 全链（none-target/musl 双面）——见同批汇报。
