# dpg_press 第五形态（F7 忙场臂）——gui8 相位赛假阳根治缓解

Status: implemented

一句话说明：gui8 两连 panic（同内核 rootfs 严格过）的定谳与最小修——gui8 相位=服务 spawn 波 onset 罩住 dpg_press 反向臂测量窗，「单核独占静默场」前提结构性不成立，wall 3.7-3.8×θ 落 F6 自立漂移带（2-10×）内**量级原理上不可分假阳与真漂移**；唯一可分信号=结构性静默前提破，而 `press_quiesce` 已测出却丢弃（返回 ()）——修=三处最小 diff：quiesce 返静默 bool、断言加 `|| !quiet` 第四豁免臂（F7，照同文件 press_flush「净场不可得不 panic」先例）、ok 行补 `w=` 打印（F6b「判据跟打印同变量」前馈）。侦查（wf_6d757ac2）先纠两处误读：rootfs 通过是**严格通过**（反向臂位不置早退、断言从未被评估，r=0.16θ）——「2.02× 靠豁免臂过」把前向臂台账 c=（设计靶即 2×θ，PRESS_TGT_MULT=2）误当反向臂墙钟；断言触发即证三臂全假（EFI 单核/loadgen 已拆场/rev_cyc<10×θ）。

## 裁决与判例

- **量级学自认不可分**：F6 在册「供给链代码回归的漂移是常数级（2-10×）」——第五形态 wall 3.7-3.8×θ 正落此带，任何只看倍数的规则都分不开；结构性信号（净场不可得）是唯一出路——`press_quiesce` 帽 4 轮静默窗测的就是它，帽耗尽仍不静默=前提破，降软与 F4/F5/F6/F6b 同哲理（「结构性前提破换软路径」等价交换）。
- **误放行面评估**：唯一漏检=真漂移恰逢忙场——但漂移是常数级必同样抬高静默靴 wall 被硬门抓（rootfs/bare CI 每靴都跑、quiet=true 时断言逐字节保留）；忙场靴侧 x 记账可见（x>0 进 ok 行）可日后升 CI 黄线。gui8 特征豁免（服务名/spawn 计数代理）被否决——等效永久豁免早期 boot=盲区+新增子系统耦合。
- **F7 是缓解非根除**（审查 P2 诚实记档）：波在 quiesce 之后、被判窗之内 onset 的竞速窗仍在——观测签名（波持续远超测量间隙）下被 quiesce 目击占绝对多数；gui8 补跑若再 panic 同签名则形态回炉（候选=断言前末窗静默复检）。
- 挂账：v2 供给自定标（plans/2026-11-17-ci-root-cure.md active）是长期正解但单独救不了本形态（臂间赛洞在册）。
