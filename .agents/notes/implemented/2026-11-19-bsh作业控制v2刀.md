# bsh 作业控制 v2 刀（& + jobs + kill %n + $!）

Status: implemented

一句话说明：owner 令「继续实施」（2026-11-19）兑现完善刀挂账 #1 的 v2 系列 job-control 刀——规格轮 workflow（wf_72246461：bsh 收集面/语义原语/契约碰撞三域侦察 + 语义/机制/风险三视角 + 综合）+ 实施轮 workflow（wf_4ac0324b：D1 berry-jobs 纯面 ∥ D2 berry-exec 授位一行 → D3 bsh 主体 → 两域对抗审查）+ 主线修复集成三段式；交付 `&` 后台作业（run_line 入口整行尾缀剥离）、jobs/kill 第 22/23 内建、`$!`、退出收杀；pid→handle 裁 bsh 自持 job 表（内核 ABI 无 pid 号位、ps 账本不登 bsh 子——三选一唯此路且零内核零 ABI）；前台 Ctrl-C 路径逐字冻结；`CLI ok n=11→12` 前缀式零滚新。

## 交付

- **D1 berry-jobs 纯面 crate**（user/berry-jobs/ 新建，no_std+alloc）：strip_bg 剥离律（全边缘：`a &`/`a&` 剥、`a &&` 次尾停、`a& &` 循环剥、`a&&&b`/`P=a&b` 恒不剥、裸 `&` 不剥、false 路径返原文切片零漂、角落 `& &`→("&",true) 钉板）、JOBS_MAX=8+alloc_id 最低空位、parse_job_ref 单形 %n、spawn/running/done/terminated 四渲染行字节单源；host 14 测族绿。
- **D2 berry-exec 授位扩面一行**：gift[0] 掩码 +RIGHT_DUPLICATE（内核双门论证：今日 dup 成功即证一切源柄已持 DUP 且 ⊇{SEND,TRANSFER}，扩后请求集仍 ⊆——零新失败模式；子件 stdout 句柄自此沿 spawn 链自举带 DUP 位）。不扩则 exec_bg 首调 dup -EACCES→trap 自杀 bsh（mech 稿死路论证）。
- **D3 bsh 主体**（main.rs 单文件 +448/−15）：exec_bg 五拒形（赋值/链/管道/重定向/内建除 run）+console 缺席+表满；通过面 run/裸名两分类（target 白名单与 127/126 文案单源复用 run 面；SpawnSpec stdout=console_h() 直打、stdin_feed 占位=EOF 即 /dev/null 语义）；job 表 static mut Vec<JobEntry>；jobs 先扫荡后列示（`jobs > f` 重定向自然成立）、kill %n terminate(143)+1s inline 收割（-EBADSTATE 走 done 真码保真）；interactive Line 臂 run_line 前 job_sweep 通报（bash 哑终端本真行为——轻敲 Enter 即刷 Done）；exit 前 job_exit_sweep（terminate(129) zsh HUP 同向+1s×8 上界——孤儿不可寻不可杀，放任＝永生占 PROCESS_MAX=64 且 berry-term respawn 下累积）；`$!` expand 特判臂（未设空串、恒粘）；BUILTINS 21→23 五联动；cli 步⑪（⑪a 绑定三形/⑪b 端到端 `run hello &`→jobs 逐字节→kill %1 reap 143→表清/⑪c 负形三件）——自验靶=bin/hello 常驻形（13B 后 10s 滚动长睡结构性不自退，Running 态非竞速）。
- **审查修复四件（主线）**：⑪b 毕复位 BG_LAST（自验不污染交互会话 `$!` 初态）；jobs 列示改作业号升序（kill 后低号复用不乱序）；exec_bg 展开后空注释如实化（POSIX 异步空列表返 0，非 run_line 空段跳过语义）；berry-jobs 文档论证修正+`& &` 角落钉板。
- **D2 停刀触发①字面命中的主线裁决**：svcmgr:447 手搭 dup(console)→talker 面不构成触发——talker 全源零 spawn 零 duplicate、console 别名仅 channel_send（SEND 位即足），结构性不可达 exec_bg 亦不可作任何 spawn stdout 源；授位链论证不受扰，E1 保持。

## 裁决与判例

- **`&` 检测层＝run_line 入口整行尾缀剥离**（否决 exec_one 段层案——`a && b &` 只异步末段成「半阻塞惊吓语义」；否决 split_chains 边界案——破坏 `P=a&b` 值域且与「单 `&` 非边界」立法相反）。链形后台 v2 诚实拒（POSIX 整链异步需子壳面——挂 3.0）。
- **后台 stdout＝console 直打＋E1 一行**（否决私有采集对泵案——三挂点泵+8KiB/件缓冲+≤10s 延迟+EOF 缺口常态化；否决弃置案——8 深队满自楔仍需排水）。
- **kill＝terminate(143) 直杀单档**（signal_send 协同投递只达 berry-libc 链子，no_std 子静默——假语义不如诚实拒绝；-N 旗标族同机制异码拒）；inline 1s 收割换自验确定性与即时反馈。
- **退出收杀反 bash 放任**：本系统孤儿不可寻不可杀（无 pid 面；bsh 死→HT_DRAINQ 关 hp→活孤儿 wedged 占 64 帽永生）——terminate(129)+有界收割是唯一不留债形态。
- **通报粒度＝下条命令前**（交互循环结构零改动使 C-4b「feed 循环期恒无前台子进程」契约原文免重述；wait_many 即时通报挂账——JOBS_MAX=8 已为单批前瞻留门）。
- **POSIX 偏差四笔记档**：`&` 仅单段；kill 无信号旗标；`$!` 载作业号非真 pid；退出收杀 129 非 bash 放任。
