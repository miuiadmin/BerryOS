# berry-ui 波 2 移植三路合流：圆角原语+disabled+clip、pattern 19 配方、组件画廊

Status: implemented

## Problem

波 2 把 ui-wave2 源树（`../ui-wave2` @ 37c02abbc）三面资产合流主树（worktree `wip/ui-wave2-port` @ 3272bbdeb「41 ViewKind 全部通电」基线）：①gfx 圆角原语（`Cmd::FillRectRounded` + raster 行 LUT）与 paint 消费面（Toggle/Chip/Card 直角或胶囊近似升级）；②disabled 三态；③clip 最小面（Scroll/List 溢出裁剪）；④pattern.rs 197 行 → 19 配方族；⑤组件画廊（gallery2 双轨测试 + WAVE2-GALLERY 联络表）。硬门两条：主树既有测试断言零改动；TLV wire 与存量 golden add-only（`berry-gfx/tests/golden.rs` 与源逐字节同文、Cmd 枚举只许尾部追加）。拦路四问：默认开圆角必破哪些钉板；disabled 要不要整套搬源 `StyleParams`/六值状态机；clip 要不要 per-slot 侧表；源 pattern 的「重挂同步」与「0×0 占位锚」在主树 add 白名单下还成不成立。

## Decision

1. **真圆角走进程级开关 `paint::set_true_corners`，默认 false = v1 近似档**：主树 `tests/widgets.rs` 逐值钉板 Toggle 胶囊三 fill 与 cmds.len()==16、`tests/widgets3.rs` 钉板 Chip/Card 直角 fill 序列——默认翻圆角必破既有断言（源树的解法是删 widgets1-7，主树不许）；feature 门要改 Cargo.toml（指派面外）。opt-in 开关是五文件面内唯一同时满足「圆角原语落地」与「既有断言零改动」的形态；默认档翻转挂后续刀（一行改动 + 重建钉板）。
2. **disabled 只立 paint 查表机制，写侧挂后续刀**：`PressedVis` 扩三态槽表（disabled > pressed > normal 优先级）+ theme 加 `BG_DISABLED`/`FG_DISABLED` const 对——机制与验收靠内联单测直建 Node 树走 `paint()`，不依赖写侧 API。源三处写侧（`set_disabled` 表、消息机 Disabled 锁死、hit 拒）在 lib.rs/hit.rs，指派文件面（五文件）之外；整套搬 `StyleParams` 四字段 + 六值状态机对主树是过度面，不取。
3. **clip 走「kind 即登记」最小面**：Scroll/List 走查即开裁剪（MARK_PUSH/MARK_POP 段标记 + eff 窗 = damage ∩ 祖先 clip 界），不搬源 per-slot `clip_on`/`set_clip` 侧表（lib.rs 面）。主树既有测试无 Scroll/List paint 场景，既有断言零波及；damage.rs 与源逐字节同文零改（对账预判成立）。gfx 侧裁剪栈帽 `CLIP_STACK_MAX=8`：超帽 push 折 no-op 保守（多画不少画）。
4. **pattern 适配三律**：源「重挂同步」（Collapse 开合、Refresh 触发、SwipeItem reveal、Chip 选中）全改 `set_props` 原位更新——节点 id 稳定、子树保持，源同名测试的「重挂换 id」断言就此反转；源「0×0/Stack 占位锚」技巧保留——对账预判「白名单已宽可简化」实测不成立（SwipeItem/Refresh 等组件 kind 不在 add 容器白名单，`_` 兜底 BadParent）；五态默认改查主树 `ItemState` 表，源 `FiveState`/七张 style 表机制退役。
5. **画廊 golden 首跑回填，不照抄源哈希**：主树 v1 直角与源圆角渲染必然不同，43 格 FNV-1a 64 位哈希以本树首跑回填钉板（渲染回归即红）；`gallery2_dump_cells`（PPM dump + cells.tsv）与 `gallery2_golden_hashes` 双轨同文件，零第三方依赖。验收轮重生成后哈希零漂移——圆角默认关、disabled 写侧未落，格子反映的是 v1 视觉（诚实标注，非巧合）。

## Alternatives considered

- 默认开真圆角（视觉即升级）：否——直接破 widgets/widgets3 三处钉板，「既有断言零改动」是硬门；opt-in 让画廊与宿主先吃原语，默认翻转与钉板重建同批挂后续刀。
- feature 门（`true-corners` feature）：否——需改 Cargo.toml，超出指派五文件面；且 feature 面会分裂测试矩阵（default/s7 之外再添一档）。
- disabled 整套搬源 API（`StyleParams` + `NodeState` 六值 + per-slot `StyleSlot`）：否——六值里 Hover/Focused/Selected 三值主树零消费面，四字段 `StyleParams` 与主树「色彩硬预混 const」纪律（`ACCENT_PRESSED` 先例）冲突；主树形态 = 查表扩一格。
- clip 搬全套 per-slot `set_clip` API：否——lib.rs 不在指派面，且主树现实只有 Scroll/List 两处溢出缺陷；泛化 API 等第三个需要裁剪的 kind 出现再立。
- 画廊哈希照抄源 cells.tsv：否——两树渲染面不同（源 dark token/圆角 vs 主树 light const/直角），照抄首跑即全红；首跑回填是钉板纪律的本来含义。

## Consequences

- 测试面只增不减实证：基线 361 过 0 失败 → 合流后 421 过 0 失败，增量 60 = gfx/paint/theme 9 + pattern 49 + gallery 2，基线清单零缺席；TLV 面 tlv2-7 全家 46 测绿（golden_v2…v7 钉板字面流零漂移）；gfx golden 3/3 绿；s7 档 lib 61/61 绿；画廊探针 43/43。
- wire 面零变更：`Cmd` 枚举三变体尾部追加（Present 之后），TLV 无新字段；`berry-gfx/tests/golden.rs` 与 `damage.rs` 双面对源逐字节同文。
- 遗留清单（后续刀）：真圆角默认档翻转 + Button/滑块半径定档；`set_disabled` 写侧三处（lib.rs 表、消息机锁死、hit 拒）；Slider/输入族 disabled；per-slot `set_clip` 泛化；弧族原语（Progress Circular/Check 勾/Radio 环真形）= 波 3+。
