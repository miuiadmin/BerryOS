# LAN 桌面沉浸化三件套落地——三键导航/BottomTabs 撤/白底撤

Status: implemented

## Problem

LAN 桌面底栏有多层视觉冲突：五键导航条大块（160px/190px 高）+ BottomTabs 三页签（144px 白底）+ 状态栏 scrim 深色带——三层叠在壁纸上，用户直呼「老安卓」「乱七八糟」。owner 连续裁定安卓 12 式三键 + 全沉浸，需要一次性收口。

## Decision

- **三键安卓 12 形**：返回 ‹（左 25%）· 主页 ●（中 50%）· 多任务 □（右 75%），96px/135 条高/176 间隔——旋转/关机撤出屏条（Web 桌面下旋转无消费者、关机走 berry API 更优）。NavNodes 字段别名到 back 保结构（匹配臂不可达即安全）。
- **BottomTabs 从桌面页整条撤**：`tabs_h=0` + `build_tab_bar` 不建实例（`bar_inst=bar_host` 占位）——sys 页切入时 `rebuild_tab_bar` 按需建，桌面页不显示。理由：三键已覆盖主页/多任务入口，两排图标重复且混淆。
- **白底 Rect 全撤**：`pattern.rs` 的 `bottom_tabs_slots` 白底 + `syspages.rs` 紧凑档 CARD_BG 白底——壁纸从顶到底一条直通。
- **导航键底色用壁纸蓝**（0xFF006BC8）而非透明——客机渲染管线不支持 alpha=0 透明像素（实测图标整体消失），壁纸蓝近似值在蓝系壁纸下视觉融入。

## Alternatives considered

- **五键保留只缩尺寸**：否——owner 明确三键对标安卓 12。
- **BottomTabs 保留但透明底**：否——图标仍占视觉空间且与三键重复。
- **导航键底块真透明**：否——客机管线无 alpha 合成（1-bit alpha 阈值），透明像素使整个 IconFace 不渲染。
- **白底改壁纸色 Rect**：否——壁纸色随壁纸变化漂移，直接撤更干净。

## Consequences

- 底部区域唯一可见元素 = dock（SmartDock 蓝底白图标）+ 三键导航——无多余图标、无白条、无暗带。
- 状态栏信号/wifi 用 OH systemui 官方 SVG、电池走程序化面（OH 无原生电池 SVG，owner 裁定不用 Material 顶替）。
- 图标库（icon_data 348 枚）保留在代码中但 dock/status 位图名全清空——OH SVG 的 Sketch 嵌套结构（defs/mask/use）经 resvg 光栅化 + alpha 阈值后大面积坍缩白块，待展平管线落地后再切位图。
- 方案文档见 [桌面沉浸化三件套](../../plans/2026-11-16-桌面沉浸化三件套.md)。
