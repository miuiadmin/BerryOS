# fwcfg-check 门禁化：假红根修 + selftest 9 腿 + test-host 接线（W1）

Status: implemented

## Problem

[fwcfg-check.sh](../../../tools/fwcfg-check.sh)（fw_cfg 具名键单源键表 [fwcfg-keys.toml](../../../tools/fwcfg-keys.toml) vs 仓内注入/消费面对拍）自诞生起零 `--selftest`、零 justfile/CI 接线——键表漂移（漏登记/死键）改动无机器咬合，属「有守卫零自检零接线」判例族（selftest_guard #214 只扫声明件，本件此前不声明故不在扫描面）。且对拍引擎（rg 全仓扫）在 base 实跑恒假红：`fwcfgface/src/tests.rs` 的解析 crate 合成 fixture（`opt/berry/trac`/`opt/berry/missing`——非等值匹配测试腿）被误当代码面在用键。

## Decision

- 引擎 rg → `git grep`（tracked 单源，`-I` 跳二进制）：对拍只对源码面有义，构建产物/未跟踪草稿不是注入面；且 rg 在 srv1 runner 缺件（#371 rsync 判例同款——CI-light 第七门 `selftest_guard --run` 会真跑接线行，引擎必须 runner 可依赖）。
- 排除面显式三件：`*.md`/`.agents`/`docs`（文档例文）、`fwcfgface/src/tests.rs`（合成 fixture）、`tools/fwcfg-check.sh` 自身（selftest 夹具字面量非注入面——检测器与被测面分离）。零命中显式红（扫描面构造性损坏拒静默缩面，sync-public 吞 rg 报错判例的对面纪律）。
- 新增键长上限门：全名 `opt/berry/<name>` ≤ 55B（键表公约——FW_CFG_DIR 项定长，前缀 10B 余量 45B），超限先红（QEMU 侧静默截断不可事后验）。
- `--selftest` 9 腿（合成沙箱 git 树，sync-public 同风格零网络零真仓）：对拍绿（fixture 排除 + rootfsN 归并）/漏登记红 + 点名/死键红 + 点名/键长上限红（56B）/键长边界绿（恰 55B）/.md 例文不进代码面/非 git 树扫描面损坏红。
- 接线 just test-host 双行（对拍执法面 + selftest）——同 sync-public `--check-members` + `--selftest` 双面纪律。

## 验证

真仓对拍绿（21 键两侧一致，trac/missing 假红消除）；selftest 9/9 绿；test-host 全链绿（见 PR body）。

## 风险

零 kernel/ABI/依赖面。git grep 只读 tracked 面——未跟踪新键（开发中未 commit）不进对拍，属可接受（commit 后 CI 面兜底）。selftest 腿全在合成沙箱，零真仓副作用。
