# wmd 监督一次重启（I2）

Status: implemented

## Problem

wmd 停摆根治刀（SPEC-wmdstall，四路勘察 2026-11-19）定谳链：wmd serve 单线程 inline 中继挂满 300s 自杀后，svcmgr 侧两个谎面敞着——gui-wmd 预拉 arm 是「常驻不 reap」孤儿 drop 形：死了没人 reap、ps 表恒 ALIVE（谎账）、更没人拉起 ⇒ 整场永久死。I2 阶段 = svcmgr 侧监督一次重启（SPEC §2，先例 launcher_supervise「一次重启」语义）。

## Decision

**方案 = 四件全落 user/bins/svcmgr/src/main.rs**：

1. **四常驻源 dup**：boot wmd arm 在 extras take 前对 wm_srv/push_srv/present_cli/hdi_cli 各 dup 一枚（四权掩码——WMD_CLI_DUP 常驻源同款「再 dup + 随行迁移」保位律）落 static（WMD_WM_SRV_SRC 等）。同通道续命论证：内核 v1 无对端关闭检测（channel.rs 诚实缺口）+ 两端互钉环 ⇒ wmd 死后端点对象恒活，重启 = 四源现 dup 重组 env 冻结 8/8 同形 extras——新 wmd 承接 WMD_CLI_DUP 控制面（重启后新 spawn 的 [ui] app 走新 attach 续通）与 inputd/WMD_PUSH_B 推送面（I3 inputd 门控修的前提）。spawn 装配序提取 `wmd_spawn(console, off, len, gifts)` 共用芯（launcher_assemble 同款），boot/重启两路同形。
2. **wmd_supervise**：稳态 loop poll `wait_one(hp, TERMINATED, 0)`（launcher_supervise 同形）命中 = 死亡面 → reap 全链收口 → **ps 谎账修**（ps_exit EXITED——psproto 无 STATE_DEAD 常量，EXITED 即死态 wire 真值）→ eco loud「wmd died」→ WMD_RESTARTED swap 一次重启帽内四源现 dup 重拉，重启成 ps_reg ALIVE 真值覆盖；帽后再死 = 终报不再试。重启败面（cpio 缺/dup/spawn）= loud 不 trap（launcher fs dup 先例——监督面自身永不自杀）；账本保持 EXITED（死是终态事实，SPAWNFAIL 属 boot 拉起面）。
3. **稳态 loop 并等集 +1**：whp 入 wait_many（lhp 同形 TERMINATED 源，数组帽 2+2N→3+2N 恰容）= 死亡沿即刻唤醒；poll 探活每圈先行本就兜底 10s 圈速。
4. **v1 接受注记（SPEC §2 K1）**：旧 per-app apps 表随 wmd 死清零；活着的 app/launcher 旧通道端互钉死端（陈 send 进无人读队列、recv 恒 EAGAIN——内核 v1 诚实缺口），自愈归客户端自身监督面（launcher 300s 帽挂账超范围）；guifbd wm 表跟随面**不重订阅**——guifbd 首收 'm' 后已 close stdin 交接端（wm 订阅刀结构性单发），二次投递无读者 = handle 滞帧泄漏，故新 wmd 零订阅者照常服务、guifbd 表跟随滞旧通道静默降级。

## Alternatives considered

重启建 fresh 四对（弃——WMD_CLI_DUP 控制面与 inputd push_cli 断裂，新 app attach/push 全死端，违 SPEC「救推送/新 RPC 面」本义）；重启后代发重订阅投 'm'（弃——上因）；psproto 加 STATE_DEAD 常量（弃——wire 只 ALIVE/EXITED/SPAWNFAIL 三态，加常量=协议面越界，EXITED 即真值）；重启路 dup/spawn 败 trap（弃——监督面自杀=被监督者杀监督者，launcher fs dup loud 先例）。

## Consequences

svcmgr `cargo check` 零新警（存量 unused_assignments 证 HEAD :4395 同款）；boot 健康相零新行零新句柄行为漂移（四常驻源 boot Ok 路静默落值，handle 表 heap Vec 无帽）；崩溃相新诊断行三枚（eco: wmd died / wmd dup / wmd restart——非 smoke 标记族，十段对拍不承 crash 行先例）。已知残余：wm 通道死队列陈帧由新 wmd 承接（stale ATTACH 应答入死端队列无害，apps 槽帽 8 内残留——K1 邻接接受面）；guifbd 表跟随降级面待 guifbd 侧订阅重臂刀。QEMU/gui8 双靴与 ≥60 分钟长稳验证归主会话串行（SPEC §4 硬门）。Related：[wm 订阅私有通道 RPC 面落地](2026-11-18-wm订阅私有通道RPC面落地.md)（'m' 单发结构事实）、[per-app wm 通道化与导航键排雷](2026-11-19-per-app-wm通道化与导航键排雷.md)（K1 attach 拓扑）。
