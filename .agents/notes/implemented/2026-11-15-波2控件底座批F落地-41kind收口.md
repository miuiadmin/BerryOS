# 波2 控件底座批F落地（Gauge/Qr/DragReorder 四面接通——41 kind 渲染收口）

Status: implemented
Type: note

为什么：六波方案步骤 3（[2026-11-15-体验大改造六波实施方案.md](../../plans/2026-11-15-体验大改造六波实施方案.md)）的控件接线末刀——paint return 分支最后三件（Gauge/Qr/DragReorder）通电，41 ViewKind 可用率 100%；本文记裁决与坑，供波3/波4 消费。

## 裁决

- **Gauge v1 粗条简化**：原设计环形仪表（ring8 底环 + 12 点顺时针部分弧）——弧原语 v1 缺席，走 Progress style 同律「数据携载、渲染统一条形」：上带 16px 粗条（TRACK_OFF 底轨 + ACCENT 填充 ×value/1000）+ 下带百分值文本（permille/10 折整数 + '%'，免 FP——750‰ → "75%"）。内在恒 64×64（GAUGE_D 单源）。
- **Qr 占位图案确定性**：三角落定位方块（TL/TR/BL 各 7×7 模块，切比雪夫半径 3 外环暗/2 中环亮/≤1 暗心——方框套方框）+ 数据区整数散列（module_count 种子 wrapping 乘搅打，< 40% 判暗）——同景跨帧逐 fill 恒等可 golden；真 QR 编码接入后 `qr_module_dark` 整体退役。内在 = module_count×4 方阵（21 模块 84×84）。
- **Qr 颜色消费口径**：dark/light u32 走 `crate::unpack_color`（r<<16|g<<8|b 低 24 位——pack_color 逆函数；desc.rs 注释的「RGBA」名义下 alpha 位忽略，gfx Color 无 alpha 通道）。
- **Qr cmds 满帽降级**：暗模块逐格 4×4 fill，berry-gfx MAX_CMDS=256 满帽停录不炸——21 模块全图案 ~218 fill 在帽内，大版本（25+）尾部截断为文档化降级面。
- **DragReorder on_reorder = 拖拽纵坐标**：DragStart/DragMove 逐样本派发（value = Msg 携 y wire 原值）——v1 记录 drag 位置；落位/交换语义挂波3/波4 消费面。item_index 不随手势变（无 props 写面——重排裁决在 app）。空表（total_items==0）手柄零操作（Select 零项同律）。
- **命令面全收口**：Gauge/Qr/DragReorder set_props 开口 + 值域执法三口单源（AST BadValue / add / set_props 经 widget_value_ok——`desc::qr_module_count_valid` 提 pub(crate) 共用）——41 kind 无「未开口防半落」残余，widgets.rs 哨位测试退役。
- **geom_same 三臂**：Gauge/DragReorder 内在恒定全 true（value/item_index 纯绘）；Qr module_count 入几何（方阵边长随版本变）、双色纯绘（set_props 换色零重测钉板）。

## 坑

- **批 C 出生红**：widgets4.rs Select golden 误钉左对齐 x=6，而 emit_widget_text 自批 C 起就是区带居中（实际 x=90）——该提交时未跑全套件带病合入，跨四批潜伏。批 F 收口套件全绿时修正为渲染真值（x=90）。教训：golden 断言要与共核实现的居中/对齐口径同源推导，别手拍。
- **final_size 的 `|` 链陷阱**：三件迁「内在型叶」臂时若直接从链尾摘走 `=> (avail_w, avail_h)`，会把同链的 Scroll/List/Stack/Spacer/Refresh/SwipeItem/Card 容器一并带走（随父填充被换成立内在）——必须先给容器组封 `=> (avail_w, avail_h)` 再开新臂。
- **widget_react Drag 臂字段绑定**：`Msg::DragStart { node, x, y, .. }` 与 `DragMove` 共用 or-模式，两变体余字段（axis/resampled）不同——`..` 必须保留，否则解构不齐编译炸。
