# Agent Note: 刀 A 合流解锁——波 4 双刀碰撞裁决、七槽真 UI 接线与入口收敛

Status: implemented

## Problem

波 4 双刀（wip/ui-wave4 与 wip/ui-wave3）在同一批应用槽上并行产出两套实现，主树镜像七槽仍是 appstub 秒退壳（GUI-8 视觉补全遗留），smoke 的 `APP ok n=` 是前缀通配（槽集漂移静默过），berry CLI 五入口默认分裂（Run/Shot/Start/Host 各持 tcg/phone/default）；ux-unify 的入口收敛改进悬在分支未摘。需要一刀裁决并合流解锁后续落地。本刀在 wip/land-a 会话完成，代码与详账随该支携行；主树侧此前无决策笔记，本篇补总账。

## Decision

1. **碰撞裁决八槽取优**：FILES/PHOTOS/CAMERA/CONTACTS/MMS/BROWSER 六槽取 wave4 真 crate（pattern 真消费者 + 七路验收），appdemo 取 wave4 控件画廊；SETTINGS 体取主树 settings crate（唯一带交互帧循环与事件消费的版本）。wave3 六 `-app` crate 与 settings-app 整支弃——其谱系不含 GUI 通道授权（5452649af），app 收不到 wm 礼物，「真 UI」仅构建期验证；弃侧唯一并入 = SETTINGS 接线段形态知识（非代码），已随本刀接线落地为七槽 spec 循环。
2. **真 UI 接线搭裁决 B**：SETTINGS 走 APPTOMB 食谱（musl + berry-ld RUSTFLAGS）入七 crate 构建循环，manifest 单源 crate 自有、contacts/settings 资产走 appstub 兜底；appstub ELF 构建行退役（零 bin/ 消费者，壳本体留应急）。接线必须与 svcmgr 裁决 B（boot 批 [ui] 入册不拉起 + `app <id> gui deferred` 记账）同批——常驻 park 形由 boot 批拉起 = app_reap_tail 永等 = APP ok 永缺。
3. **计数锁数诚实化**：`APP ok n=9`（八枚 [ui] deferred 记账 + APPQUIET 批拉起）/ `APPUI ok n=8`（[ui] 资产面）改锁实数，六处随动契约嵌注释；PS/CLI/FS/GFXF/PAGE 等非槽位单源族保持前缀并同页记因。
4. **入口收敛摘 hunk 不携枝**：ux-unify berry 面四结构体 8 行 default 翻转 desktop+auto；Shell/dispatch 主树已收敛（821d3f152）不重复摘；shot 确定性由 choose_accel deterministic=true 保恒 TCG。节流复核（APP_SPAWN_LIVE_MAX=4：boot 批零占槽、满表拒新不拒旧 loud、退出槽位稳态环必回收）语义完好零改动。

## Alternatives considered

- **SETTINGS 接线复制 wave3 裸接线形态**（否：无裁决 B 前置，park 形入 boot 批 = app_reap_tail 永等全线 FAIL）。
- **保留 appstub ELF 构建行作 fallback**（否：零消费者的构建行每次白付；应急恢复路径注释在案，恢复 = 两行）。
- **cherry-pick ux-unify 整枝再弃多余**（否：launcher 面与主树 spring 重做冲突大，四 hunk 单文件自包含手工摘更小）。
- **六槽两边合成**（否：wave3 侧 0 测 0 pattern 无 manifest，无互补面）。

## Consequences

- 刀 A 判据面两形全绿（APP ok n=9 / APPUI ok n=8 / 八槽 deferred 逐槽）；rootfs 单卷帽口径复核未超帽（rootfs0 恰 32MiB 帽整、总量余约 90.8MiB）；桌面链楔死定谳预存宿主环境面（e58c94ccf），非本刀回归。独立对抗审查（wip/land-a 根 A-REVIEW.md）复核成立：cherry-pick 双向保真、弃侧无漏并、锁数与生产侧谓词零漂移、11 入口默认点全数 desktop/auto、零手拼门逐格一致、提交纪律零越权。
- 每槽裁决表、计数契约细节与验证账的事实之家 = wip/land-a 根 A-RECON/A-IMPL/A-VERIFY 及同批分支侧详版笔记（.agents/notes/implemented/2026-11-15-刀A应用槽合流与计数锁数.md，随支携行）——本篇收主树总账，合流后互链不双写。
- 边界备忘：波 3 尖上另有非应用面工作（gui-wmd 焦点表、guiproto wm 事件通道族、launcher TABS_H_COMPACT）不在本刀范围亦未随 land-a——归波 3 桌面三栏线另行认领，防「wave3 尖已对账」误读。
