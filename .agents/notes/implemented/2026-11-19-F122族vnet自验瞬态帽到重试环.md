# Agent Note: F122 族 vnet 靴期「网面死窗」根因定谳与自验瞬态帽到重试环

Status: implemented

## Problem

vnet 靴期 flaky（历史 ~1/8 窗：TCP ok/LSN ok/TCPS ok 缺席、后续一切 TCP 面 RPC 恒 EIO、内核与其余套件照常——「网面死窗」）长期归为 F122 族概率面。2026-11-19 根因猎杀（workflow 7 agent：9 窗死/活串口证据分类+vnet 靴路径/svcmgr 时序码读+四假说对抗核验全 CONFIRMED）定谳**单一签名**：唯一真死窗（B2p）vnet 全部输出恰一行 `vnet: tcp 自验超时（roundtrip）state=Established`——握手已成功（state=Established 实证 SYN/SYN-ACK/ACK 通）、64B 数据回环在 `SELFTEST_CAP_NS=60s` 绝对帽内未归 → tcp.rs 自验 Timeout 分支 `trap()` 自陷 → vnet 永不进 serve() → TCP 面 EIO 全死。触发=TCG/宿主饥饿窗烧穿绝对帽（guest 单调钟下 60s 帽的工作量随宿主调度伸缩——握手 20s 帽过了而回环 60s 帽穿，饥饿非匀质）；宿主高载是概率放大器非必要条件（低载亦偶发）。`tx used ring 超时` 旧签名与本批证据零交集（史载形态不再现）。

## Decision

自验**整生命周期重试环**（tcp.rs）：connect+roundtrip+shutdown 为一单元，瞬态类失败（各相位绝对帽到：握手失败/回环超时/挥手超时）先重试 `SELFTEST_RETRIES=3` 次再 trap——瞬态饥饿再给机会（每 attempt `table.reset()` 清 mux 残留，诊断行携第 N 次）；协议破缺类（回显对拍失败/会话异常终止）维持首犯即 hard trap（重试无义，loud 语义保持）。标记契约不变：全重试耗尽仍 trap（`TCP ok` 缺席=smoke FAIL 兜底不漂移）。

## 验证

根修镜像入复跑窗 fixture 四连靴（W1-W4 串行，同载荷同场地）：**4/4 全活（三活标全在）、零重试触发、零耗尽、零 panic、各臂数值与历史活窗一致**（sock16k 1267-1331 B/s、echo 全量环回）——瞬态失败四窗内未复发（1/8 概率面下 4 连绿与修后预期一致；重试路径无正向触发样本，其正确性由码级论证+编译闭合承载）。历史对照：修前同场地 B2p 死窗签名已不复现。

## Alternatives considered

- 抬帽（60s→300s）：饥饿非匀质（握手过而回环穿实证）——抬帽只移概率不除根，且拖长真死网的全链等待；弃。
- 自验失败不 trap 转 deviceless 降级：静默吞掉真网死——违「标记缺失=smoke FAIL 兜底」契约；弃。
- svcmgr 侧重拉 vnet：治标（死因仍每次发生）且引 spawn 竞态新面；弃。

## Consequences

TCG/宿主饥饿窗的 vnet 靴期网面死窗根除（瞬态帽到获 3 次重试）；真协议破缺仍 loud。所有 e2e/冒烟/复跑窗的靴可靠性提升（历史 ~1/8 死窗率消除）；F122 族台账挂账可据此收口（「启动面 flaky 立案复核」面闭合——残余=饥饿概率放大器本身，归宿主调度域非代码面）。关联：[NET-05](../../../research/NET-05-客机TCP五刀复跑窗与外来应答免疫-v1.0.md) §4 复跑窗死窗记录、[F122 节](../../research/2026-11-17-四刀与合并事件遗漏检查.md)（双拉死原裁——本修收的是同族另一形态）。
