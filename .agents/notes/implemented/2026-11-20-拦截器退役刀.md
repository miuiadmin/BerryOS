# 拦截器退役刀（QMP 注入链整族删除·VNC 直通正名）

Status: implemented

## Problem

web 拦截器 + QMP 注入链是寄生拼装：浏览器 RFB PointerEvent 被代理截获改道 QMP `input-send-event`，为此背了五套失败语义（2s 守护/哑化+5s 节流重连/排水面/无界 outbuf 接受面/连接取证）与独立坐标分母真相（当日 480-vs-1080 坐标事故的结构面）。其立身判例「QEMU 11 VNC 丢绝对坐标」已被实验驳斥（[证据快照](../../research/证据快照/2026-11-20-VNC直通绝对坐标判例驳斥.md)：well-formed 客户端发 SetEncodings 后直通绝对坐标直达客机，TCP+ws 双形态实拍）——当年观测形态是 berry 裸客户端从不发 SetEncodings。

## Decision

删除刀（wf_2cbc7939 三 agent + 主会话收尾）：①`display/vnc.rs` 裸客户端正名——握手补发 SetEncodings（count=1 RAW，8B）置位 QEMU vs->absolute，input-only 不发 FramebufferUpdateRequest（零推送零排水），新增 loopback 钉板测；②`display/ram.rs` 原生指针路 QMP 主路退役——Inject 枚举/inject 字段/qmp_pointer（fbinfo 分母）全删，指针单臂直通 `self.vnc.pointer(x,y,buttons)`（坐标即 VNC 表面域原值直传，**宿主零几何缩放立法**）；③`web.rs` 拦截分支整删（is_ptr 识别/QMP 改道/哑化回退/ptr-evt 取证/帧解析助手，-137 行）——浏览器→上游复位纯字节管道；`commands.rs` 拦截器装配段整删（-48，含 dmface 单源解析链——随拦截器消亡而退役）；④`qemu.rs` 双注入 socket（qmp-inject/qmp-inject-native 两枚额外 -qmp）从 spawn argv 退役，路径函数与 device.rs 清残块随批删除；⑤`qmp.rs` QmpInjector 家族+pointer_msg+注入器四测整族删除（零消费者）；⑥gui8 新增 `--input-path {qmp,vnc}` 双臂——VNC 臂内建最小 RFB 3.8 input-only 客户端（四铁律入注：PointerEvent 6B 无 pad/leftover 粘包缓冲/零 FBUpdateRequest/SetEncodings 置位），给人手真走的路立法测试面（判例能立足多年的制度性根因就是这个缺失）。

## Consequences

宿主工具 164+2 测试全绿；gui8 QMP 臂 PASS（CI 面零扰动）；A1/A1b 直通实验（TCP+ws 拖拽实变）背书机制。验证缺口记档：VNC 臂首跑撞 ktest PP-4 时序断言环境假红（宿主残留负载 9——与 LOADGEN A5 同族，双阈值载窗重跑中）；真浏览器端到端（人在环路）= 收官门。架构后果：五套失败语义+坐标分母之谜+当日拦截器三修（[其笔记](2026-11-20-拦截器三修与审查修复.md) 标注的待退役过渡刀）全部消亡；坐标单源链=QEMU 表面几何→设备 ABS_INFO→inputd 归一。已知接受的损失：直通后点击路径无宿主日志面（ptr-evt 取证随分支删）；berry-dmface 依赖边摘除。Related：[根设计审计](../../research/2026-11-20-GUI输入显示全链路根设计审计.md)（本刀=其刀谱序 1）、[1080P 渲染提速双帽](2026-11-20-1080P渲染提速双帽.md)（同日姊妹刀）。
