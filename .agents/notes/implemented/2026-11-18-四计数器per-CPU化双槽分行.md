## 背景

04 号调度热路径审计机会三：四个最高频计数器全是单 `static AtomicU64`（`IRQ_TICKS` sched.rs:26、`SWITCHES`:30、`PREEMPT_CKPT_HITS`:177、`SWITCHES_TT`:2029），SMP 参与态下双核对同一 cache line 做 Relaxed RMW——忙对稳态每 tick + 每 switch×2 + 每 syscall 至少四次跨核行乒乓（MESI 独占权每次 RMW 迁移；行内多计数器同驻加剧）。

## 修面

判例同文件在册：`LB_TICKS` 用 `[AtomicU64; 2]` per-CPU 分行（偷到 CPU1 的子 tick 记到 c1）；`WaitBucket` 用 `#[repr(C, align(64))]` 逐桶防伪共享。四计数器同刀：

1. `static X: [AtomicU64; 2]`（const 块初始化），写侧按 `hal::smp::cpu_id()` 打本核槽 `slot_of(cpu)`；
2. 读侧求和：`switches()`/`switches_tt()`/`preempt_checkpoint_hits()` 返回两槽和快照；
3. `bump_switches` 跨点判定改读全局和（`soak_crossed`——打印频度按全局计，与旧单计数器跨点序逐位一致）；
4. 路由/求和/跨点判定律单源在 `berry-balface`（W3-Q82 交付的 on_irq_tick SMP 门纯面 crate，语义同族）：`PERCPU_SLOTS`/`SOAK_PRINT_EVERY` 常量 + `slot_of`/`slots_sum`/`soak_crossed` 三函数。

## 语义保持论证

- watchdog `switches > last`（user.rs，增长型）与 soakmon 周期采样：求和快照安全（两槽和有 ns 级非原子窗，增长型断言不受影响）。
- G1.5 `tel >= switches_tt`（user.rs:1891 附近，klock 窗内同窗双快照）：求和后仍同窗，配平语义保持（环写与计数同窗的配平点在 `note_switch` 非空臂，写侧仅改槽位）。
- fa ktest 尾 `ckpt >= 1`（main.rs，下界型断言）：求和快照下界保持。
- `switches=` 打印值 = 全局和（与旧 sw 同值同频度；旧形态 sw=fetch_add+1 恒 ≥1，新形态 soak_crossed 排除零值防 boot 前窗误打）。
- smoke `switches=` 金丝雀严格递增断言（smoke.sh 阶段 2）：打印值为全局和快照，跨点序与旧逐位一致（balface::percpu_partition_invariant_under_interleaving 钉板 25000 次交替递增零分歧）。
- 单核形态：cpu_id 恒 0，全部写落槽 0，槽 1 恒 0——求和恒等于旧单计数器（零漂移）。

## 域界（物理臂留 sched）

原子槽本体、`cpu_id()` 读、fetch_add 递增、UART 打印发射——纯面只钉「槽怎么路由、和怎么读、跨点怎么判」。IRQ 上下文不 panic 纪律：`slot_of` 对域外核号钉到低位槽（usize::MAX → 1）。

## 测试

balface host 钉板 18→22（+4）：slot 路由全域（含域外防御）/求和折叠（全零/单槽/双槽/回绕防御）/跨点对齐（恰 10000·20000 跨点 + 零值排除 + 常量冻结锚 10000）/分槽不变量（25000 次交替递增与旧单计数器跨点序零分歧端到端钉板）。

## 验证

balface 22 测全绿（隔离 target）；sched/kernel aarch64-unknown-none check 绿、警告数持平（26=26）；test-host 全量实测回填 07 口径行；台账随源重产。
