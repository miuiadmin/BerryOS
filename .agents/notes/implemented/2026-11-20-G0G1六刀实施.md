# Agent Note: G0G1 六刀实施——生态闭环引导装载与发布工程

Status: implemented

## Problem

生态闭环计划 Wave G0（刀 1-3：引导装载与可信链）与 G1（刀 4-6：可复现发布工程）共六刀。G0 建立从上电到内核入口的 A/B 槽位可信引导链；G1 建立从源码到签名的确定性发布管道。

## Decision

### G0 三刀

**刀 1（A/B 槽位仲裁）**：新建 `bootloader/berryboot/slot/` 纯面 crate（跨界 bootloader↔用户态）。BerryBootControl 52B 冻结布局（magic BRYC v3 含 boot_count——v2 规格缺口先修：双副本两份皆 CRC 有效但内容不同时无单调序号无解）。仲裁三律纯函数：①tries>0 且 priority 最高者当选、引导前 tries 减一；②tries==0→priority 置 0 换对侧；③mark_success 用户态半边（60s 健康后 successful=1+tries 重置）。berryboot app 引导链接入：EFI File Protocol 写绑定（berry-efi 扩 write@40/flush@80/set_position@56 + MODE_WRITE/CREATE）→ 读 BOOTCTL1/2.DAT 双副本→pick_copy 择权威→arbitrate→slot: 横幅→交替写对侧副本。mkimage 双槽产盘（--kernel-b/--initrd-b + BOOTCTL 工厂件 A pri=15/B pri=14）。13 host 测全绿（CRC IEEE 向量/全字节 corrupt 拒/双副本择权威/仲裁三律/三靴崩溃纯态走查 A,A,A→B/撕裂恢复走查/factory 字节镜像对拍）。

**刀 2（VBT 槽位化）**：签名锚按 slot_active 分派 KERNELA.SIG/KERNELB.SIG；旧单槽盘回退 KERNEL.SIG 零漂移；TRUSTPK 根钥共用。rollback_ok 防回滚纯接口（两槽 max 地板，候选低于即拒）——v1 无 OTA 候选=结构预埋。

**刀 3（BerryHandoff v3）**：v2→v3 尾追加 slot_active@176/ramoops_pa@184/ramoops_len@192/rng_seed@200（176→232B）。hofface SEGS_BASE_OFF_V3=232 三版本梯；bootloader app slot_active 递送链全穿透；kernel BerryHandoff v3 尾五字段+偏移执法四行。14 hofface 测+kernel check 绿。

### G1 三刀

**刀 4（密封构建）**：`tools/reproducible_build.sh`——SOURCE_DATE_EPOCH 钉 commit 时戳、`--remap-path-prefix ${PWD}=/berryos` 路径抹平、CARGO_NET_OFFLINE=true、umask 0022、TZ=UTC+LC_ALL=C。双构建 berry-kernel release SHA-256 100% 一致。

**刀 5（SBOM+协议阻断）**：`tools/sbom/` 纯 std 零三方——Cargo.lock 闭包解析+Cargo.toml license 富化+12 协议白名单。94 依赖全 PASS。--check 接入 test-host。

**刀 6（releng 流水线）**：`tools/releng_pack.py`——产物发现→尺寸门→mkimage A/B 双槽造盘→manifest（SHA-256+签名模式）。e2e 4 产物 PASS。

### 质量关（四轮）

1. **四镜 review**（9 agent）：实抓双 P1（kernel 版本分派 176 未滚 232 致 EFI 引导丢 rootfs+描述符物理写在 hpa+176 覆写 v3 尾字段）+P2（A 槽名契约分裂）+双 P3——全修。
2. **五路 sweep**（8 agent）：SBOM 16 件构建产物误入库+berryllock 漏 slot 条目+sbom 未接线——全修。
3. **P3 清偿**：kernel BerryHandoff v3 尾字段消费者面闭合+rollback_ok 文档更新。
4. **二十一级合龙**全入 main。

## Alternatives considered

- 自研 FAT32 块层驱动：EFI File Protocol 写面可满足（固件 FatDxe 承编码）——弃自研。
- boot_count 以 reserved[8] 域实现：侵入冻结布局且域语义污染——v3 增字段正解。
- cargo-cyclonedx 外部依赖：SBOM 工具自身引三方=递归供应链面——纯 std 自研。
- releng_pack 钉死 kernel 路径：发现序有跨 lane 污染但显式 --kernel 参数可规避——双路径制。

## Consequences

BerryOS 获得完整的 A/B 无缝降级引导链（断电/三连败自动切槽）+确定性构建管道+SBOM 供应链阻断+自动化发布流水线。bootloader 域从单槽只读跨入双槽可写可信引导。G2（刀 7-10 生态兼容）解锁——linux_runner 的 80 POSIX 系统调用可在 handoff v3 的 slot_active 基础上构建。

遗留面归属：rollback_ok 真候选→G2 OTA；mark_success 用户态→pkgmgr；CI 完整接线→G2 CI 面；inputfeed.rs→云桌面刀主。
