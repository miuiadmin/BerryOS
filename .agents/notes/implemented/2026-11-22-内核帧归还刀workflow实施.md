# 内核帧归还刀（Vmar::Drop 语义推翻 + drain 双相）——workflow 编排实施

Status: implemented

一句话说明：按 [实施设计](../../plans/mm/2026-11-22-内核帧归还刀实施设计.md) 与侦查定谳（wf_6d757ac2）落地帧泄漏本体修——A 线主罪（Vmar::Drop「刻意的正交不对称」不动 mapcnt → Vmo::Drop 的 droppable_pages 判据 mapcnt==0 全额跳过还帧，~469 页/轮 ≈ 1.75MiB）修=三件联动：①Vmar::Drop 重写（deregister_demand_root 先行断 dpg 反查、PT 锁窗内逐 Region 清账且 clear_leaves 先于 untrack_map、Reserved null vmo 跳过=前次 boot 崩一级崩因〔FAR=0x10 逐位对上 null+0x10 的 Vec len〕、free_asid 限根〔新增 is_root 字段——顺带拔除存量实锤 bug：旧 Drop 无条件 free_asid，ktest F5 清场每轮 close 子 Vmar 都在放父根活号=TLB 隔离击穿潜面〕、broadcast 发端）；②handle.rs drain 双相（phase-1 先落全部 Vmar 清账、phase-2 其余真销毁还帧——双相强制因果序：清账要 VMO 活、还帧要 mapcnt 归零；槽状态机单出口置 Free 闭死前次二级崩因候选①双放堆腐化）+ process.rs vmar 钉预放（已 start 链不预放则差一脚永不闭合）；③ktest 水位断言×2（F4d 空 drain 零帧差 + F6 主罪微缩复现水位差=2 钉板，口径=buddy 而非 VMO_COMMITTED_PAGES〔后者存量 drift 归 vmo.rs 刀〕）。实施=workflow 双域并行（wf_53547203）+对抗审查 FIX（1 P1 + 4 P2 主线修复回写全落）。

## 裁决与判例

- **P1（审查抓出）：对飞死锁面扩大 + F0-3 死线**——本刀令 Drop 在 idle/yield flush 与溢出回退语境 broadcast（旧 Drop 从不），而 tlbshoot 的 F0-3 缓解（REQ_PENDING 对飞自解）注释宣称「彻底根除」却在本树未接线（broadcast 从不置位）。修=移植 base-overhaul 三行接线（broadcast 置 REQ_PENDING[t] + wait_pending 循环首 swap 自服务块 flush_local_all+ACKS 推进）。判例：**注释里的机制宣称不是接线证据**——审注释宣称的机制必须在代码里找到真接线。
- **防线分层口径**（审查 P2 修正）：clear_leaves 先于 untrack_map 不是唯一防线——KL 全程串行（本 Drop/unmap/Vmo::Drop 销毁路径全部写者）是第一防线，叶序是纵深防御；unmap 的既有反序在 KL 下同安全，注释双向补明。
- **已知残形挂账 v2**（审查 P2 记档）：跨表长持 root-vmar 柄形态（父表+子表+钉 refs≥3）子进程 VMO 永久泄漏——「全链一个 drain 内闭合」条件=末柄在垂死进程自己表内；候选修法=Drop 清账后孤儿放行位/drain 泄漏分支延迟重扫。
- **正交性**：58016d0f 的 eager -ENOMEM 降级只罩失败路径，成功轮水位信号原样保留；刀落地后 SPAWN_NOMEM 面难自然触发（回归覆盖须 ktest 造枯竭）。
- **同批修**：release_vmar_pin_early「不归零」绝对断言改条件式（末持有者形态可就地 Drop，行为本正确）。

## 实施面

- kernel/src/vmar.rs：Vmar::Drop 重写 + is_root 字段（new_root=true/allocate=false）+ unmap/Drop 防线分层注。
- kernel/src/handle.rs：drain 双相 + VMO 泄漏兜底判据保留（清账解引用安全的活性保证）。
- kernel/src/process.rs：vmar 钉 Option<NonNull<ObjRef>> + release_vmar_pin_early + drain_pinned_process 三步序 + 块注改写（「全无 wake 面」改口 + 两条新不变量）。
- arch/aarch64/src/{tlbshoot.rs}：F0-3 接线（pub(crate)→pub sched_exit_check 一行——hal 侧无既有 pub 接口可达，任务钦定收割点的唯一实现路径）+ broadcast 置位 + wait_pending 自服务块。
- kernel/src/ktest.rs：F4d/F6 水位断言 + E3h teardown 契约注随 Drop 语义改写（unmap 前置不再是硬需）+ dpg 供给面证明块注（还池严格后于注销）。

- **实施期真崩与 UAF 法证轮（wf_69f7ccbe，主线 boot 冒烟抓出——前次实施「boot 崩 bug 待修」的真身）**：首轮 boot 冒烟 ktest 段崩——`ASPACE ok` 后 D-abort(current)，PC=`PageLedger::untrack_map+0xac`，FAR=`0x00A5_C0DE_0000_0001` **逐位等于 test_aspace 常量 MAGIC_A（定谳签名）**。机制定谳=**Rust move 悬空裸指针（非双放）**：MiniAspace::new 以栈局部 `&mut vmo` 映射（Region.vmo 捕获栈地址）→ Vmo 随 Self 构造/返回移动两次——对象活着地址死了；旧 Drop 从不 deref Mapped 区间故历届绿（隐患早有档案 dpg.rs:1096「栈对象移入堆会悬空」），新 Drop 清账解引用即踩死帧（读 test 断言机溢写的 MAGIC_A 当 slots.ptr）。三件结构性修（拒绝 null 守卫）：①aspace.rs `MiniAspace._vmo` Box 形+先入堆再映射（地址恒定，字段序=Drop 序保清账先于 VMO 销毁）；②user.rs `UserProcess._vmos` [Box<Vmo>;3]+`build` 返回 `&'static mut`（Box::leak——「v1 永不销毁」从注释契约变真保证；同修**第二机制**：boot 装配块尾 Drop 曾对新 Vmar 跑 clear_leaves 抹活舰队 AS 的 PTE→全舰队入口 I-abort 杀数 3>1——旧 Drop 不清叶故旧形未炸）；③vmar.rs Region.vmo 契约立法（四合法形：handle 表 Box/属主 Box/Box::leak/static；禁形：栈局部映射再移入）。
