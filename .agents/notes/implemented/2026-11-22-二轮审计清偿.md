# 第二轮审计清偿：19 项（2×P0/6×P1/11×P2）——上轮半修实锤与推送链重构

Status: implemented

## Problem

五新维审计（验修复实效/查修复回归/端到端演练/规范通读/CI 触发矩阵，24 原报→交叉复核 19 项）实锤：上轮 P0-2 是半修——控制面门 match_prefix 第二 pattern 漏 `$`，目录前缀匹配**从未生效**（.githooks/、.agents/tools/、宪法目录三面全直通）；E lane 产品活推送面零重道触发（纯产品推 45 分钟空等 note、混合轮被 CI-light 假绿收编）；双戳机检静默放过不合格式戳行——全仓唯一试点戳本身畸形。

## Decision

2026-11-22 全清偿。批 A 控制面门真修五件：`$` 补齐（前缀活验：.githooks/pre-commit 命中）；selftest 假绿堵（dirp2/=>false 负腿+命中面非空断言）；gate-selftest 沙箱 stub 断递归（env 闸方案被否——它连待测腿一起杀）；tools-only 负例腿 g2（假红 e-guard 提交必拒）；run_gate 剥 CP_* 继承。批 B 推送链重构：PR 先建后等（pull_request 面是产品改动唯一重道触发）；headSha 精确 supersession（免疫时钟偏斜）；混合轮轻道绿不判 green；快速路由与严格 argv（--help 曾真推分支）；gh 缺席 note；--dry-run/--poll/--timeout 注入。批 C：pre-push 身份闸改判远端落点 rref（refspec 旁路 HEAD:main 堵死+两负腿）；三清单补 CI 闸族六件与 .github/workflows/（自裁口子闭合）；删 MACHINERY 死条目；e-doctor 远程清单补 ci-light.yml（五件）。批 D：run-e 陈旧 marker 俱清哨兵（finished-重启失监督根治）+会话名掺工作区指纹（同机多 lane 串台）+selftest 腿。批 E：check-docs 第四红（不合语法 Verified 行报错不静默——自检当场抓到自家试点戳）+试点戳修合规形（六腿文本→八腿同批）+规则/16 口径对齐（7-40 hex+机读权威定位）。批 F：RUNBOOK 第 0 步前置推送+从远端克隆立法、e-guard 断言历史现场豁免、punch 决策类翻 park（fixpoint 判空不再被观察项堵）、ci-light 头注实况、pack-work absent 字段、主仓/lane unshallow。

- env 递归闸：否——实测拆掉 tools-only 腿（沙箱门直通）；stub 方案才对。
