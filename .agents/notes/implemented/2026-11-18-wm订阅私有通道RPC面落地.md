# wm 订阅私有通道 RPC 面落地

Status: implemented

## Problem

批B 收线的 wm 客户端面留两债：guifbd 表跟随无正拓扑（dup(WMD_CLI_DUP) 共享单 FIFO 应答互截——两路实证见[批B 笔记](2026-11-17-波3批B-guifbd带合成v1与wm面收线.md)），批B 落的 WinBand/WinApp/Hidden 三分类档因快照恒空而休眠；批C 双窗化（wid 提交）硬依赖快照激活。

## Decision

**方案 = [plan §2 骨架](../../plans/2026-11-17-wm订阅私有通道RPC面.md)四件**（workflow 编排：scout×4 → impl×4 → 对抗审查 5/5 CONFIRMED → 修复回写 → QEMU 终判）：

1. **wmd 订阅者通道升格表跟随 RPC 面**（table.rs sweep_evt 订阅臂五行改造）：TABLE_GET 恰 4B 帧即答全表快照（复用 send_snapshot 阻塞应答与 wm_srv 同律）；畸形/非 TABLE_GET/GETINFO/属主通道 TABLE_GET 四面静默律（事件通道无请求相关性，乱答毒化对端——三负例+一属主负例钉板）；订阅者 srv 端本已在 wmd wait 集（evt_handles），serve 循环零改动；TABLE_WAIT 冻结律不动（即答非驻留）。
2. **svcmgr 静默窗代发**（wmd arm Ok 路 WMD_CLI_DUP.store 后、gfxdemo take 前——机制性排除交叠窗，窗内 wm 队列唯一在途方=svcmgr）：w_dup 现 dup 四权别名 → wm_subscribe_rpc（blk_rpc 先例形，60s 帽=BLKD_REPLY_CAP，recv 开 256B/8 柄 ABI 满额窗——任何帧形态必被整体消费零滞队毒化）→ ack（1B ST_OK+恰 1 handle=订阅者 cli 端，内核 channel_create 两端恒授全四权、TRANSFER 随行迁移足额）经 fbx 交接对投 1B 'm'+handle；fbx_a 升格函数域（勘察抓的作用域坑）；全失败面单 loud 行 `wmsub: sub fail` + 跳过零新 panic；rootfs 相守卫继承 wmd arm 门（结构性零新行）。
3. **guifbd 表跟随复活**（guest.rs，lib 零改）：WmPrivState{AwaitHandle→Active,Disabled} 三态（无 Subscribing——订阅已代办）；'m' 接收=serve 第四路 poll_wm 非阻塞双出参 recv（10s→**70s** 帽，审查裁决：必须 > svcmgr 60s 代发全窗，钉「guifbd 禁用恒晚于 svcmgr 放弃」——否则 (10,60]s 窗 svcmgr 投递假成功、loud 被绕过、handle 令牌滞死端泄漏+wmd 订阅槽烧死）；Active 态单 evt 通道双向混流 drain（先 parse_wm_evt 后 parse_wm_snapshot_rep——执法域不相交：事件首字节 0x90..0x92 vs ST≤6；迟到应答接=全量真值幂等）；Table(v)≠version→dirty 单飞拉表（BUSY 留拍重试）；快照真值接入 entries/count/version + band_replan 第二调用点 + `WMSUB ok` latch 恰一次（打点=首快照接入拍，count=0 空表也算面活）；wait_many n=4（Disabled 态无槽 n=3 回落——关柄入集会使 wait_many 整体 -EBADF trap 杀全服务）；stdin_h()==0 守卫（版本混布防 recv(0) trap）。classify 两消费点零改动——WinBand/WinApp/Hidden 三档随表激活，批B 带缓存/重放面全复用。
4. **门面**：WMSUB ok 入 gui8 Boot A（纯恰一计数零序锚——勘察证 FBSERVE 序锚从未存在且跨通道无协议序=假红面）+ smoke-image ECO 51→52（九处标签 96→97 含 ci.yml 单源句）+ justfile 两处陈账滚新。

**审查两修复**（5/5 CONFIRMED 中实修三件）：①70s 帽（上述）；②svcmgr 超时路迟到 ack 收割——在途 SUBSCRIBE 不可撤，迟到 ack 若不收会落共享队列毒化 gfxdemo 首应答（本刀所杀缺陷类在自身超时面复活）——Err 路等 {sub_dup READABLE, wmd 子 TERMINATED}（有界二帽 60s）排干丢弃随行全 close；③ci.yml 现 51→52。平像帽 CONFIRMED 为关账项非缺陷：total 被链接脚本钉位恒 163840、真余量 19024B。

## Alternatives considered

guifbd 直持共享端+容忍 recv（批B 已否——消费即毒化）；svcmgr 不代发而 guifbd 自发 SUBSCRIBE（共享队列竞速面复活，否）；WMSUB 打点绑订阅 ack（ack 在 svcmgr——guifbd 无观察点，改首快照拍）；序锚门（假红面，否）；w_cli 原柄代发（gfxdemo take 后失持——用 w_dup 常驻源）。

## Consequences

**终判翻案与栈定谳（QEMU 验证三轮）**：首两轮全链 FAIL（guifbd 静默零输出死、wmd 启动序② 300s 帽 trap 级联、base-5 不达）——归因二分五连（HEAD 减刀/仅撤 guifbd/仅撤 svcmgr+wmd/撤 poll_wm 调用/ELF 对拍）锁定破点=poll_wm→wm_await 执行体；**根因=栈溢出**：批B 后 guifbd 32KiB 栈已贴线，wm_await 的 256B+32B 缓冲帧压线 → 静默死。修=svcmgr guifbd spawn `stack_pages 8→12`（+16KiB DRAM）。首轮 stack12 检验无效的仪器坑（值得记档）：**EFI 靴的 init svcmgr 来自内核内嵌 userbins（kernel/src/userbins include_bytes!）非 cpio 副本**——改 svcmgr 后只重烘 cpio 不重烤内核=跑的还是旧内嵌件；终验=内核吸新 userbins 重烤后 **gui8 双靴 PASS：BANDC/BANDR/WMSUB 三门恰一**+三元组精确计数+Boot B 零重写。四枚 TEMP-DIAG 打点随定位完成撤除。

guifbd 表跟随正拓扑成立：「单 wm 客户端」前提结构性恢复（guifbd 零共享队列接触）。**launcher×apps 共享队列互截（批B urgent 实抓）仍在**——本刀只治 guifbd 接线，per-app 通道化归后续刀。快照重排带槽窗口期旧缓存自愈（下次系统类提交覆盖）v1 接受。docs/规则/07 host 台账 guifbd 13 测陈账归 W1 lane 总账随动，本刀不越界滚。
