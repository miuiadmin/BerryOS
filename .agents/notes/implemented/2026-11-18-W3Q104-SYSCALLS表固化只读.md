# Agent Note: W3-Q104（03 号分派审计机会五 5b：SYSCALLS 派发表固化只读）实施记录

Status: implemented
创建：2026-11-18。PR 收口以沿革「W3-Q104」节为准。

## 问题
[03 号 syscall 分派审计](../../../research/内核深度进化/03-syscall分派审计.md) 机会五 5b 实锤：`SYSCALLS` 派发表（arch/aarch64/src/syscall.rs，256 槽函数指针表）是 .bss 里的 `static mut`——boot 期 `install` 填毕后终生只读，却保持可写页。分派面 = 全系统控制流劫持的最高价值目标之一（改一个槽指针 = 任意代码执行），审计判词「一页属性翻转 + boot 序一行，可行性极高」。

## 方案
**块拆分 + 页级 AP**。难点：高半内核映射是 L2 2MiB 块描述符，AP 位长在块上——直接改块权限 = 同块全体静态量（.data/.bss）一起失写，boot 必死。故：

1. `freeze_syscalls_table`（mmu.rs）：读 SYSCALLS 所在 L2 块描述符 → 新插一张 L3（`SPLIT_L3_SYSCALLS`，.bss.boot 低半与四张 boot 表同窗）把该块劈成 512 张 4KiB 叶 → 表页（spa 所在页 + 前后邻页，防表跨界）置 `AP_RO`（EL1 只读），其余 509 页 `AP_EL1_RW` 逐位保真原块 RW 语义 → `dsb ish` 后 L2 项块→表切换 → `dsb ish` + `vmalle1is`（旧块项是 global，按号失效够不着）。
2. 调用点（kernel main.rs）：`syscall::install()` 毕紧跟一行——install 填毕即冻结，全系统唯一写点（install 本体）在冻结前完成；窗位 = ktest 前 + smp_bringup/arm_slice/enable_irq 前（boot 单线程 DAIF 屏蔽窗，freeze 的 # Safety 合同）。
3. `page_descriptor_kernel`（paging.rs）：L3 叶描述符构造单源——ATTR_NORMAL/SH_INNER/AF 与块面逐位同源，AP 由调用方传入；nG=0（global，与块面一致）。`AP_EL1_RW` 升 pub（mmu 消费）。
4. `table_addr()`（syscall.rs）：派发表基址只读语义访问器（ktest 探针 arm 期望故障槽用）；`SYSCALLS` 升 pub(crate) 仅供 mmu 取址。
5. ktest `test_syscall` A0 探针（正向断言三件）：①`syscalls_table_ro()` 标记在位；②arm 期望故障槽 + volatile 写表头 → D-abort 权限错被槽捕获恢复（ELR+=4）→ `fault_armed()` 已消费 = 写确实被硬件拒绝；③读回 ≠ 探针载荷（写未落盘）。固化缺失时写静默成功、槽仍武装 → 断言红——「有固化零执法 = 静默腐烂」防线（R136 建议件族）。

## 设计裁决
- **邻页一并 RO**：表 4KiB 恰容 256 槽 ×16B 理论上单页即够，但链接漂移可能使表头/尾跨界——邻伴页固化换零边界论证负担。邻页静态量失写面经实查为 boot 期写毕即弃类；若后续 boot 红在无关静态量写入，先查本刀邻页固化面。
- **表项描述符保持可执行**（无 PXN）：与既有内核映射语义一致，NX 留 v2 安全批（paging.rs 头注既定裁决）。
- **freeze 不做读回校验**：boot 单线程窗 + debug_assert（块描述符位形）已够；读回校验在 ktest A0 探针（full 链）做。
