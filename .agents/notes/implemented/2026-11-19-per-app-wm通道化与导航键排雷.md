# per-app wm 通道化与导航键排雷及 berry 韧性

Status: implemented

## Problem

桌面点击最后一块石头=urgent 本尊：launcher 与 spawn 应用共享 dup(WMD_CLI_DUP) 单 FIFO 应答互截——点击 spawn 应用后 `launcher: submit ack bad st=0` 断链、桌面冻结（2026-11-19 凌晨桌面场实抓，批B 审查定谳在案）。连带三件：launcher 底部导航键 back 可自毁桌面窗（无自窗排除）/home 不清应用窗（残像素）；berry QMP 排水克隆非阻塞污染（OFD 共享实证）+拦截器无守护建连（楔死期线程卡死）+restart_in_place 残留 qmp-inject.sock。

## Decision

**K1 per-app wm 通道化**（guiproto add-only + gui-wmd 多客户端 + svcmgr 装配换轨）：

- **协议**：`OP_WM_ATTACH=0x69`（1B+随行恰 1 srv 端；ack 走**新通道** ST_OK+随行 wmd 侧 srv 别名=双向验证已通）/ `OP_WM_DETACH=0x6A`（5B srv_id）；golden 增两帧+带隔离核证。应答天然参数化回请求来源通道（勘察定谳）——多客户端隔离的结构基础，协议面零改。
- **wmd**：`apps[Handle;8]` 定容表+attach（帽满 ST_FULL 柄关收）+detach（u32 寻位+**到达通道兜底双臂**）+轮询段（一路一帧串行纪律；recv 错码=close+摘表**不 trap**——坏客户端不杀服务）；wait 集重造（需求总数外溢判定——修复勘察实抓的 evt_handles 截断死码，100ms 短帽首次真实武装）。
- **svcmgr**：`wm_attach_rpc`（控制端临时 dup+ack 在 cli 端收=零共享面零竞速窗；60s 帽；失败=拒起**禁回退共享 dup**）；app_launch/launcher_assemble 全换轨 `channel_pair()` 专属对；cli 自留 dup（R4——**内核真相裁定**：handle 表按进程私有+随行迁移必重编号（handle.rs:217/syscall.rs:3638 源码三处亲验），控制端 echo id 寻址真机结构性恒失配；DETACH 帧走 app 通道自身、到达通道命中摘除、寻址零 id 算术）；app_reap_tail/装配失败/launcher 死亡共 5 调用点注销；!wants_fs 占位=dup(cli) 自有别名（主会话裁决修复 I2 风险：旧占位是共享端点别名，自有别名保 input 位 [3] 槽语义零漂）。
- **WMD_CLI_DUP 角色收窄**为纯控制面（attach/detach/subscribe 代发+相判别器），本体永不消费数据面。

**K2 导航键排雷**（launcher）：self_wins=[u16;2] 双 CREATE ack 记账（全链零转型对齐协议面）；back 自毁排除（FOCUSED∧LAYER_APP∧非自窗 谓词形——桌面窗永不被 back DESTROY）；home 补 DESTROY 批（非自窗可见 APP 窗逐发逐收串行 RPC+条件化 wake FULL 重画）；recents 既有重拉语义零改。

**K3 berry 韧性**：排水全撤（选 A——OFD 共享实证：try_clone 设非阻塞污染主柄写路径，~35 事件哑化；RSS 爬坡接受面如实记档）；拦截器 `connect_guarded(2s)` 化+哑化后 5s 节流重连（**QMP 楔死自愈**——恢复后输入自动复活，终结名画动点不动形态）；ram.rs Inject 收敛 Off|Qmp 两态同款节流；restart_in_place 清理簇补 qmp-inject.sock remove_file（S4 缺口定谳：残留=重生 bind 失败致死链）。

**审查三 CONFIRMED 全修**：①parked 悬垂守卫（app 通道可合法驻留 TABLE_WAIT 单车位——拆除不清槽则下次表变更向已关柄发快照=EBADF trap 杀全服务；两关闭位同款清槽）；②spawn Err 臂占位别名泄漏补关（gui_ph0/1）；③wm_detach_rpc 带帽发送（死亡 app 满队 srv 队列不再拖死 svcmgr）+detach ack 非阻塞试发（`Port::send_rep_try` 新面——满/死跳过，成功记录面与 send 同）。第四条 REFUTED（节流测壁钟耦合——非真问题）。

## Alternatives considered

协议加相关性 ID（wire 冻结违）;wmd per-app wait_many 全入集（预算 29>16——截断+100ms 帽足）;attach ack 走控制通道（与活 app 在途 RPC 互截可致假失败——ack 走新通道零共享）;占位复活共享 dup（互截面回归——自有别名替代）;home 无条件 FULL 重画（零成收=纯浪费+覆盖存活窗险——条件化）。

## Consequences

验证矩阵：guiproto 65（golden 两新帧）/gui-wmd 25（多客户端隔离钉板反例+attach/detach/dead 全族）/berry-appshell 33/svcmgr check 零新警/launcher musl/tools-berry 170（重连节流新测×8 复跑）全绿；**gui8 双靴 PASS**（六标记恰一+三元组+Boot B 零回归——attach 链首验）；**桌面毒化死亡测试 PASS**（三连击图标格：`submit ack bad`=0+app spawn=1+launcher 存活——互截绝迹实证）。挂账：QMP 楔死 QEMU 侧定谳（C1-C4 候选+三角取证方案在 S4——berry 已韧性化）;relay 长中继 300s 停摆多客户端放大面;apps 槽泄漏 v1 安全向（帽 8+wmd 重启重置）;CONTACTS/MMS 页内输入回归随占位修复复活（活体验证留 owner 手机实测）。主会话凌晨桌面场连环取证定谳在案：数据盘缺席=input=0 操作员坑（mkfat 造盘修活）;QMP 楔死两版 berry 同死=QEMU 侧非刀回归。
