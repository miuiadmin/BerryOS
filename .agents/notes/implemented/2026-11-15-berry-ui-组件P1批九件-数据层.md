# berry-ui 组件 P1 批九件：ViewKind 16→25 数据层落地

Status: implemented

## Problem

组件清单（`docs/UI组件清单与实施规划-v1.0.md` §三 P1 多数集合）要在 `user/berry-ui` 继 Phase 1 七件后落首批 9 个 kind 件（Stack/Spacer/Divider/Check/Radio/Step/Seg/Badge/Sbar），约束与 Phase 1 同款：只动数据结构层（渲染/布局/手势不实现）、TLV tag add-only、拒面两面同律（流面 + builder 面）。拦路四问：容器/叶分界怎么划（Stack 是唯一容器）；清单草图的 Sbar thumb 比例值与 Slider permille 纪律怎么对齐；Step 的绝对值域（value/min/max/step）与 Slider 的比例值域（permille）是否同法拒面；命令面（lib.rs add 白名单 / set_props kind 门）要不要跟着收编。

## Decision

1. **TLV tag add-only 追加（协议零变更，Phase 1 同法）**：kind 字节域 16..=24 顺延钉九件（`KIND_STACK..=KIND_SBAR` pub const）——旧流值域 0..=15 不受扰，16..=24 旧读端本就 `UnknownKind` 拒。props 域逐件定死：Stack 1B（align u8 0/1/2）、Spacer 4B（flex）、Divider 12B（thickness·inset_start·inset_end 三 u32 LE）、Check 5B（checked u8 ∈ {0,1} + on_change）、Radio 9B（selected u8 + group + on_change）、Step 20B（value·min·max·step·on_change 五 u32 LE）、Seg 12B（segment_count·active·on_change）、Badge 5B（count + show_dot u8）、Sbar 9B（orientation u8 + thumb_start·thumb_end）。
2. **StackAlign/Orientation 两枚举落 desc.rs**（cross 的 CrossAlign 落 layout.rs 先例不照搬：那个落位因段C 摆位当拍消费，本批对齐面无消费者——Phase 2 布局刀用到再议迁位）。StackAlign 无 Stretch 档（叠层子恒全幅或按内在对齐，无「拉满」义，Start 是自然缺省）；Orientation 仅 Vertical/Horizontal。
3. **值域拒面复用 `AstError::BadValue`（变体零新增）**：Step 零步长（step==0——步进无义）/min>max/value 越界 [min,max]（绝对刻度域，与 Slider 的比例域不同源——检序钉死：零步长→min>max→value 越界）；Seg 零段/active 越段（Tabs 同律镜像）；Sbar thumb 任一端 > `PERMILLE_MAX` 或 start>end（零长合法）。bool 子域（checked/selected/show_dot）与枚举子域（align/orientation）域外仍走 UnknownProp（u8 载荷堪载）。两面同律：parse_props 流面 + builder begin 面（`validate_p1_nine`——`validate_phase1` 同型第二批，检序镜像）。Badge 不拒（count=0 = 隐藏、99+ 封顶是视觉面语义——数据层载原值不截断）；Spacer flex 与 Divider 三域不拒（占位/几何退化留消费面）。
4. **叶/容器分界**：八新叶（Spacer/Divider/Check/Radio/Step/Seg/Badge/Sbar）入「叶带子拒面」（AST build_node 与 DescBuilder::begin 两面同扩）；Stack 为容器（AST/builder 面可带子）。§8.2 块×kind 表不扩：九件全拒 SIZE/ALIGN 块（catch-all 天然拒，Stack 容器同拒——定尺寸面挂 Phase 2），A11Y 块全 kind 合法照旧。
5. **layout/paint 占位不做半实现（Phase 1 同纪律）**：intrinsic 九件一律 (0,0)（Stack 的 max×max 聚合、Spacer 的吃剩余空间挂 Phase 2——place_children `_` 臂 Root 型全幅叠放正是 Stack 语义，半聚合必与摆放失配）；final_size 一律随父 (avail,avail)；paint 两处穷尽 match（cull_walk/emit_walk_all）扩列入「无视觉容器臂」，子仍走查、组件自身零渲染。
6. **测试钉板 `tests/tlv4.rs`（tlv3 同款双轨，四轨不并常量）**：GOLDEN_V4_STREAM 字面量钉九件齐流样本树现产物（含 A11Y×Check、Stack 带子）+ 对称值档 roundtrip（Stack End/Sbar Horizontal/Badge 圆点/Radio·Check 未选/Divider 全零）+ BadValue/UnknownProp/截断/新八叶带子/SIZE×新 kind 拒面矩阵（两面同律）+ add() 命令面烟囱。`tests/reconcile.rs` 未知 kind 绊线 16→25 让位新域界（第三次同款挪法）。

## Alternatives considered

- Step 不拒 value 越界 [min,max]（只拒 min>max）：否——value 是绝对刻度不像 Slider 的 permille 自带比例义，越界值是结构性坏态；四检全落 BadValue 且检序钉死，两面可对拍。
- Step 零步长放行（+/- 按钮空转）：否——零步长步进器无义，与 Tabs 零页同族；数据层拒比消费面静默空转诚实。
- Badge count > 99 拒面：否——「99+ 封顶显示」是视觉面语义（显示层自钉 >99 画「99+」），数据层截断会丢信息且拒面无清单依据。
- StackAlign 复用 layout::CrossAlign：否——CrossAlign 有 Stretch 档且值域 0/1/2 撞位（CrossAlign 的 2 = Stretch，StackAlign 的 2 = End），复用即语义错配。
- 顺带收编 lib.rs 命令面（add 容器白名单加 Stack / set_props kind 门加九对）：否——Phase 1 已钉为已知边界（超数据层授权面），本批照钉；两边界合并到 Phase 2 接线刀一并收编。
- Sbar thumb 用 f32 比例：否——同 Slider 裁决，f32 破 Eq derive 与 crate 整数纪律，permille 整数替身。

## Consequences

- **命令面 P1 批边界（lib.rs 未动，钉为现行为）**：add() 可建九新 kind 节点（spec.kind 只拒 Root）但作父位全拒 BadParent（Stack 只能经 AST/builder 带子，命令面不能）；set_props 对九件一律 NodeBad（kind_ok 门不含九对）——Check 翻面、Radio 互斥、Step 增减挂 Phase 2 收编（届时扩 lib.rs 白名单/kind 门 + mask.rs props_diff 九臂——props_diff catch-all 已保守返全置，不炸不漏）。
- 事件 ID（on_change）纯数据面，hit 层派发未接线；Radio 互斥（同组互斥执法）、Spacer flex 分配、Sbar 滚动联动同挂 Phase 2。
- 值域执法仍只落两面（流面 + builder 面）：add() 命令面产物可能带越界值，编码可过、对端 apply_desc 拒——loud 在解码侧（Phase 1 同状）。
- wire 域界自此 0..=24，未知 kind 绊线在 25；P1 剩余 kind 件（Search 等）与模式件/服务件后续批继续顺延 add-only，旧流逐字节不变由 GOLDEN_V1..V4 四轨共保。
- 验证：`cargo check -p berry-ui`（默认与 `--features s7` 两口径）绿；`cargo test -p berry-ui --target aarch64-apple-darwin` host 184 测全绿（tlv4 新钉 7 测，177→184；s7 口径 187）；下游 berry-launcher musl check 绿（仅构造 Props，无穷尽 match 涟漪）。
