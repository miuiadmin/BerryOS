为什么：波3 设计稿《2026-11-15-波3桌面三栏与系统窗实施设计》§1 TabBar 条把 launcher 单窗内容改三页（BottomTabs + 桌面页原样 + 应用列表页 + 设置页）；本文记三项装配面裁决（berry-ui v1 原语约束下的取舍），供波4 应用与后续 sys 页扩展取用。实施清单 = [W3A-IMPL-SC.md](../../research/w3a/2026-11-15-W3A-IMPL-SC.md)（工作树根，SB/SA 同批先例）。

## 裁决

- **sys 页「覆盖即隐藏」，不走几何归零**：berry-ui v1 无 clip/隐藏原语（paint 对子树无条件发射——`emit_walk_all` 唯一守卫是收起态 Collapse；布局对子恒内在尺寸，w/h=1 归零挡不住子树绘制）。前稿 件⑤b 的「非当前页几何归零即不绘」是错误前提（其紧凑档条体本就溢出屏外未被察觉）。落法 = content 四段化（状态栏 + pages Stack 区 + BottomTabs 条 + 五键条），sys 页 = Stack 顶层**不透明底 Rect 整面盖住桌面**（Stack 子全幅叠放——`_` 摆位臂），离树 = `remove` 整页；桌面页（pager+dock）常驻保活——pager 翻页态零损，回桌面零重建。配套：sys 页在树时 `pager.on_msg` 不喂（可见性真相面——Msg 不劫持，只是不消费）。
- **BottomTabs 换选 = 条实例整条重建**：pattern `bottom_tabs` 的选中态（brand 染色 + 顶指示条）是建树期烘焙（无运行期改笔 API、label 节点不外露）；条宿主 = content 内恒定流槽 Stack，实例（Col 满 48vp 高）整条 remove+重建入宿主顶层——几何零漂、选中视觉零手拼。紧凑 @1x 镜像（48px 条/24px 图标/S8x16 标签/2px 指示条）与 pattern 同构（desktop.rs 双档纪律）。
- **a11y 帽 32 预算重立法**：五键化（3→5 键）后旧账面（4 状态 + 1 页容器 + 20 格 + 4 dock + 3 键 = 32）实为 34——`set_a11y` 表满 NodeFull loud，满注册表 boot 必炸（此前未被察觉因注册表 ≤9 app 且冒烟死于更早故障）。落法 = 只挂**有主格**（占位格 label 空、无 spawn 面——不占槽），帽 = 32 − 底座 16（状态 4 + dock 4 + 五键 5 + tab 三页位 3）− 页容器 1 = 15，行主序确定性截断（帽内诚实收口）；sys 页集随可见真相挂/摘（`rehang_view` 单源三拍共用：sys 切页/桌面翻页/建树尾）。press_map 同拍整表替换（帽 28——桌面页 = 波 2 批 A 落地形 20 格 (cell→label) 原样，即侦察 :31 挂账「翻页重登记」的清偿）。
