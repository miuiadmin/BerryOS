# 驱动波 2 三件套：统一 HAL + RTC 消费面 + 看门狗骨架

Status: implemented

## Problem

[驱动子系统综合研究报告](../../research/2026-11-18-驱动子系统综合研究报告.md)在册的波 2 清偿项在 2026-11-20 同日三路并行收口，共性是纯用户态新增 crate、零内核改动、且都是「半件在席、公共面为零」：P1-7——RTC 壁钟内核侧已有（fw_cfg 注入 epoch + 单调锚，`CLOCK_REALTIME` 出 ns）但用户态零公共消费库，launcher/appshell 各自单点自持 ns 口径换算，秒级/日期级历法换算全仓无处可拿；P1-10——看门狗全仓缺失（代码里的 watchdog 一词全是 svcmgr 进程错杀断言语义），且 QEMU virt 无 WDT 设备、硬件面短期无从谈起；§4.1/§4.3 波 2.2 架构前置——各驱动（vprobe/vblk/vnet）各自实现 MMIO volatile 读写、IRQ 注册、DMA 分配三面胶水，无统一硬件访问契约，新驱动被迫长第二套。同批第三路 devmgr v1（报告 §4.2 交付 1.1 的纯观察半边先行）以 bin 形态随 build-user 入 rootfs。

## Decision

三件各自成刀、同批验收（[驱动波 1 三件套](2026-11-20-驱动波1三件套.md)同款形态）；刀面细节归各单件笔记（一事实一归属），本篇只记整体取舍：

1. **统一 HAL** = 新增 `user/berry-hal`（no_std + alloc，`Mmio`/`IrqCtl`/`DmaAlloc`/`Clock` 四窄 trait + `HalError` 值不炸，全 trait dyn 兼容让 mock 与真实现同契约互换；与莓核刀 4.1 内核侧 berry-hal 同名异层——那颗服务内核 arch 抽象、本颗服务用户态驱动进程）——波 2.2 DeviceCap 三铸件的先行契约钉板件。见[单件笔记](2026-11-20-berry-hal统一硬件抽象层crate.md)。
2. **RTC 消费面** = 新增 `user/berry-rtc`（epoch 单源读数经 `CLOCK_REALTIME` syscall + 简化儒略日历法换算 `hhmmss_utc`/`ymd_utc`，闰年三类边界独立断言，向量 Python datetime 独立对拍钉板）——P1-7 的用户态半清偿，设备驱动本体（goldfish/PL031）与时区仍留。见[单件笔记](2026-11-20-rtc消费面与看门狗骨架双crate.md)。
3. **看门狗骨架** = 新增 `user/berry-watchdog`（`new`/`kick`/`is_expired` 三口纯软件超时窗，单调钟时基——壁钟可跳不作看门狗时基，到期即咬含等号口径显式钉板，host 假钟 thread-local 隔离）——P1-10 的软件半先行，真硬件 WDT 随真机波次。见[单件笔记](2026-11-20-rtc消费面与看门狗骨架双crate.md)（与 RTC 同篇双 crate）。

同批姊妹件 devmgr v1（`user/bins/devmgr`，bin 形态）——MMIO 槽枚举 + did→驱动静态匹配表 + svcmgr ps 账本服务状态报告，不授权、不拉起、零触碰 svcmgr；独立小工作区 musl 链（exclude 先例）入 justfile build-user 构建行 + rootfs-manifest.toml 条目。见[单件笔记](2026-11-20-devmgr-v1设备枚举与服务状态报告.md)。

## Alternatives considered

三件串行排队（弃——三刀面零交叠、零内核依赖，三路并行同批验收一次锁基线）；三面胶水等莓核刀 4.1 内核 hal 落地再统一（弃——同名异层契约面互不相交，用户态先行钉契约即早消第二套胶水增量，莓核刀序本就排后）；看门狗等真硬件 WDT 设备（弃——QEMU virt 无设备，软件骨架先行钉三口契约，真硬件刀只换 kick 内芯不动契约）；devmgr 直上 v2 千行主体（弃——DTB 建池依赖重，纯观察半边先行即早建设备清单观察面，备选细节归其单件笔记）；汇总笔记取代三篇单件笔记（弃——同波 1 裁定：单件留刀面与备选细节，本篇只收整体取舍与验收面，重叠互链）。

## Consequences

2026-11-20 主仓工作树终审验收全绿：`just build-user` 全链通过（rootfs.cpio x62 ELF tlsscan 三查全过；devmgr 331KB 静态 aarch64 ELF 经 rootfs-manifest 条目入卷，`bsdtar -tf rootfs.cpio` 实见 `bin/devmgr`）；`RUSTFLAGS="" CARGO_TARGET_DIR=cargo-target cargo test --release -p berry-hal -p berry-rtc -p berry-watchdog --target aarch64-apple-darwin` 计 16 测零败（berry-hal 8 + berry-rtc 4 + berry-watchdog 4）；devmgr host `cargo test --lib` 10 测零败（单件笔记验收面，本批终审以 bin 产物入 rootfs 复核其构建链）。三 crate 入 user/ workspace members（同批混装各自追加互不吞并），devmgr 入 exclude；研究报告缺口标记同批更新（P1-7 用户态半、P1-10 软件半、§4.1 框架先行件、§4.2 交付 1.1 观察半边）。下一刀（各单件笔记已记）：vblk/vnet 按 HAL trait 重接线（配 berry-driver 生命周期框架）；launcher/appshell 时钟换算迁 berry-rtc 单源；svcmgr 监督喂狗接线 berry-watchdog；devmgr 的 svcmgr 接线（授窗 + gift + `DEVMGR ok` smoke 标记——报告 §4.2 验收谓词）。
