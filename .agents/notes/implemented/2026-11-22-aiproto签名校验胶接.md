# aiproto R20：.bmod 签名校验胶接面

Status: implemented

一句话说明：E lane R20（独立净推单元——新枝自现基线，与批件 PR 零文件交集）——`berry-aiproto` 补 [`Bmod::verify_signature`]：Ed25519 校验胶接 berry-crypto（仓内 path 依赖、wycheproof 向量在册的真原语），覆盖域单源仍是 [`Bmod::signed_span`]（校验不复制偏移——签名语义一处事实）；host 20 测（真密钥对 roundtrip / 张量字节篡改拒 / 错公钥拒 / 恢复后原签名过）。首跑 R1 时记档的「校验归消费侧」注记由此兑现为库面单源 API。

## 裁决与判例

- **胶接不复制**：校验函数一行——签名覆盖域的偏移事实仍单源在 signed_span；消费侧（airtd/装载器）调本 API 而非自拼偏移（错拼覆盖域 = 验签形同虚设的静默漏洞面）。`A: (run decision, 2026-11-22) 校验进 aiproto 胶接而非留 airtd（越早单源越少偏移复读面）. Reversal: 删一函数一依赖。`
- **path 依赖引入评估**：berry-crypto 是仓内成员（非外部件、禁外部依赖纪律不触）；aiproto 由零依赖变一仓内依赖——`.bmod` 容器面从此带 crypto 编译依赖，none-target 可编（crypto 本身 workspace 在编）。若 airtd 侧要更瘦的解析-only 场景，feature 门控随后续刀（注记在案）。
