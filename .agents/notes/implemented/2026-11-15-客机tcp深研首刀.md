# Agent Note: 客机 TCP 深研首刀——栈路线裁决（维持状态机 + extend 收发面）

Status: implemented

一句话说明：深研实测（吞吐差 21-64 倍、入站 >MSS 单段黑洞、8 槽整帽）之后「这套手写 TCP 栈要不要换」的裁决记录——为什么选在既有面上分刀 extend，而不是重写、引 smoltcp 或维持不动。

## Problem

用户路线指令「系统内建 VNC 服务的前提是客机 TCP，先把 TCP 协议研究出来」。[NET-01 深研](../../../research/NET-01-客机TCP栈深研与裁决-v1.0.md)给出三层证据：状态机在宣告语义域内对抗无证伪（harness 15/15），但吞吐停等模型只有客户端 486 B/s、服务端 309 B/s（与 VNC 帧流 10-30KB/s 差 21-64 倍）；入站 >MSS 单段黑洞三例实证死锁；多会话整 8 槽（1 listen + 7 数据）；POLL 数据可见性受 RPC 节拍束缚。缺口全部定位在 vnet IO/服务面几何与协议模型，不在状态机语义——后续路线必须裁决：栈本身要不要动。

## Decision

四层裁决（详 [plan](../../plans/2026-11-15-客机tcp深研首刀.md) 裁决节）：

1. berry-tcp 状态机**维持**：harness 15/15 在宣告语义域内无一处证伪 + 41 宿主单测绿，是资产不是负债；两毛刺（未来 ACK 越 snd_nxt 被接受、零窗照发）列已知限制，LAN/SLIRP 域无害。
2. 收发面 **extend 三刀**：首刀 = 入站大段容忍与准入一致性（正确性死锁）；二刀 = 发送窗消费 + in-flight>1 + MSS/RPC 多段化（吞吐进 10KB/s 域）；三刀接收侧随二刀联动。
3. 服务面（vnet serve/netdproto）**patch 后置**：泵节奏提频/推模型、会话空闲超时、netdproto 请求序号——三项与黑洞正交，混入首刀会扩大回归面。
4. VNC 服务化**后置到二刀后重评**：首刀解除黑洞后停等 486 B/s 仍差 VNC 帧流 21 倍以上，「客机 TCP 承载 KB 级帧流 + 交互级延迟」的前提二刀前不成立。

## Alternatives considered

- **重写 berry-tcp（推倒重来）**：否。证伪证据为零——重写丢弃全部已验证语义资产（重传退避/乱序丢弃/重复段/RST 七态/挥手全臂），回归面扩大到五网络标记链全部；且深研走查行号全一手（NET-01 §1.1），既有栈可控性高于自新实现。
- **引入 smoltcp（现成 Rust TCP 栈，MIT OR Apache-2.0）**：否。v1 立栈时已评估并只借其状态机/IO 分离的组织思想、不借码（[TCP栈设计草案-v1.0 冻结档](../../../docs/TCP栈设计草案-v1.0.md)）；此刻引入的成本 = musl+berry-ld 客机工具链移植 + no_std 依赖面 + 128M 内存预算重核 + smoke 标记链全量重验，而深研缺口全部在 vnet IO/服务面（几何/泵/停等模型），不在状态机——换核心修不到病灶。
- **维持现状只 patch 服务面（不 extend 收发面）**：否。入站黑洞是正确性死锁（对端单写 >128B 即整连接死锁且 FIN 连坐，三例实证），服务面调参救不了；吞吐差两个数量级也非泵节拍可弥合；VNC 前提（KB 级帧流）结构性不成立。
- **extend 既有面（选中）**：病灶定位精确——黑洞与几何在 vnet（首刀），吞吐在协议模型停等（二刀），节拍与回收在服务面（三刀 patch）；每刀独立可验，首刀面窄到 berry-tcp 逻辑臂零改动，回归面被五标记链 + sm-harness 钉住。

## Consequences

- 首刀已落地并经独立验证波复核（[NET-02](../../../research/NET-02-客机TCP首刀落地与对抗复验-v1.0.md)）：黑洞解除（256B/1400B 单写全达逐字节对拍）、准入「宁拒不腐化」预检（8KB 压满拒段 2 次后全量恢复零错位）、几何五点同抬；实施细节决策另见[落地三决策](2026-11-15-客机TCP首刀落地三决策.md)。
- 吞吐按设计不动（停等 486 B/s 域），VNC 服务化继续后置；二刀（发送窗消费 + in-flight>1 + 多段化）成为 VNC 前置主刀，三刀合取才进 10KB/s 域。
- 已知限制清单移交真网卡域重开：未来 ACK 越界接受、零窗照发、序号回绕 plain 比较、无 RST 回陌生四元组（NET-01 §4 矩阵）。
- 风险如实：SLIRP 分段行为未穷尽（拒收线锚 1460 兜底一切观测形态）；停等域对延迟敏感（12s 延迟实测 21 B/s）；真丢段域 RTO/乱序臂在 SLIRP 回路结构性不可注入（证据 = 宿主 harness，NET-01 已知边界）。
