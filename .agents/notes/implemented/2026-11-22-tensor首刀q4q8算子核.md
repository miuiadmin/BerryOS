# ai-runtime §二 Tier 0 首刀：量化算子核 berry-tensor

Status: implemented

一句话说明：E lane R2（DAG `ai-runtime §2` 有界片段，继 §一.1 格式件之后）——契约二.1「确定性全平台量化软核」首片落地：新 crate `user/berry-tensor`，Q4_0/Q8_0 块布局单源（llama.cpp 兼容字节形——生态工装可直接产 `.bmod` 张量段）+ f16 位级手写解码（零依赖无 half crate，含次正规域与 NaN 静默位）+ 整块去量化 + 量化×量化点积（块内 i32 整数内积、块尾 scale 后乘、f32 顺序累积——Tier 0 确定性基线），零 unsafe 零依赖零分配；host 12 测。SIMD（dotprod/i8mm/AVX2）与 MatMul/RoPE/FlashAttn 图算子随后续刀，本刀钉语义基线供对拍（验收标准 2：Tier 0↔Tier 1 余弦 ≥ 0.999 的锚）。

## 裁决与判例

- **块布局钉 llama.cpp 兼容形**：`.bmod` 张量段（berry-aiproto 解析）的物理字节形与生态事实标准对齐——模型工装零转换直产；偏离的收益（更优 packing）不存在于首刀面，兼容性是单向门（改形=破坏互操作）。`A: (run decision, 2026-11-22) 布局钉 llama.cpp 兼容形（行业标准项）. Reversal: 常量与解码函数单点改。`
- **确定性优先于速度（Tier 0 定位）**：顺序 f32 累积无重排无并行——Tier 0 是 Tier 1/2 的精度与语义基线，不是性能面；SIMD 改写以此对拍保序。整数域走 i32（32×7×127 上界富余）。
- **assert 而非 Result（分层 loud）**：berry-aiproto 对外部字节流返回 `Result`（不可信面）；本 crate 输入是已过 `.bmod` 结构执法的合法张量段——长度失配是程序员错误，`assert!` 即时响零静默截断。
- **f16 次正规直搬语义**：f16 次正规（exp=0）在 f32 仍是次规范可精确表示（2^-24 级），位域直搬无精度损失——测试钉最小/最大次正规边界。
