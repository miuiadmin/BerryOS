# Agent Note: 客机 TCP 五刀①——burst 收割饥饿清偿（外来应答免疫）实施记录

Status: implemented

## Problem

四刀 burst 记差（NET-04 §3，verify 波 4/4：send(2000) 部分写 500→收割→续写 send#2 快返 500 且零入槽→recv EAGAIN 30s 帽、下游 60s TIMEOUT 应答毒化 echo 相）的根因形状经 scout workflow（6 agent 对抗核验）+ 十轮复现靴定谳：`sock_send_pipe` 收割相弹出 `parse_tcp_reply` 拒收的外来消息即 bail(500,EIO) 部分写快返——零入槽、兄弟 op 成孤儿；外来消息源=共享 netd 通道漂着的他请求迟到应答（wave10/14 已知债活性面，run9/10 P5 探针活体实证：K 窗 stale 弃置一条+burst 后第二连接 connect 恒 EIO=F147 跨套接字毒化活体复演）。

## Decision

收割免疫（修法主轴，[plan](../../plans/2026-11-17-客机tcp五刀burst收割饥饿.md)）：外来应答弃置续收而非 bail——新增 `FOREIGN_DROP_MAX=16` 弃置界与 `netd_rpc_raw_valid`/`netd_rpc_valid`（issue 一次+帽内循环收割、253B 满幅 scratch 判形、弃置即消费出通道、越界 None loud）；`rpc_st`/`rpc_data`/`rpc_sid`/`dns_query`/`rpc_poll` 五单发面换用（rpc_poll 为审查补——Server 臂最热 4B 收割面原是超幅外来帧 EINVAL 钉死队首的永久毒化点）；K 窗 parse 拒收与陈值弃置入 foreign 计数（>16 bail）；`netd_rpc_raw` 头注并 F147 口径（同形陈应答 v1 无关联号不可辨、每具误伤恰一次——成文边界非欠账）。三镜对抗审查（9 agent）实抓一处自引入角落回归并当批闭合：seq 形外来帧对 v1 请求面结构性外来，253B 标准形状经 min(253,252) 截断会伪装合法 v1 形落成功路（drain 交付陈回显=静默脏数据）——判形收紧（seq 必 None，合法应答恒 v1 零损失）+超幅过检帧改弃置（不再截断）。

## 验证

私有 fixture e2e（/private/tmp/berryos-b5fix，bsh 进程内 burst 臂+确定性注入臂+P5 探针族，run13 终验）：注入 stray DNS 查询（应答弹入 K 窗收割）——`stale ×1` 弃置续收 + 同轮另有一条 `parF ×1`（真 parse 拒收形，genesis 形状活体）亦弃置续收——**iss/hit/app 各 ×8 全链完成，burst 2000/2000 全量绿，valDrop 零误拒**；修前对照（scout VP-1 CONFIRMED）：同形态 bail(500) 快返+孤儿 op。审查 facts 侧锤实：vnet 应答上界 253B 逐出口核（scratch 满幅无 EINVAL 死路）、弃置界 16/17 语义一致、弃置路与 BUSY/重发零交互。偏差两条如实记：①plan 验收线的 mock 通道单测不可行（libc 无 host 测试基建——模块头明载符号劫持），e2e 注入臂即测试面；②同窗 2.0× 与 echo 16KB 1.5× 复测未随本波（需 A/B 基链重建，归 owner 复跑窗）；③fixture 双 socket 相邻开的 sock 臂 connect EIO（run9 起恒在）与本刀缺陷面正交，记 fixture 悬账。

## Alternatives considered

- 消灭漂应答源头（稽查哪类 RPC 迟到并逐一封）：时序依赖不可穷举，且免疫修法使其 moot——弃。
- seq 关联号扩展到全部 v1 op（彻底可辨）：wire 形改动破八 op 红线，结构性改动归 dup 通道债属地——弃。
- bail 各路主动收口孤儿 op（预取兄弟应答）：帽外交错收割引入新竞态，边界成文（F147）已足——弃。

## Consequences

K 窗与全部单发壳对共享 netd 通道的外来消息免疫（弃置即消费顺带清偿毒化面一条）；burst 记差面闭；F147 承接的孤儿弃留边界成文收口。吞吐复跑（同窗 2.0×+echo 16KB）归 owner 复跑窗；P4（netdproto 形别出参）按需再启（现行判形 libc 侧局部闭）。
