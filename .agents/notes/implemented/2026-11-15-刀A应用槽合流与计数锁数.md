# Agent Note: 刀 A 应用槽合流——wave4/wave3 对账取优、计数锁数与五入口收敛

Status: implemented

## Problem

波 4 双刀（wip/ui-wave4 与 wip/ui-wave3）在同一批应用槽上并行产出两套实现，主树镜像里七槽仍是 appstub 秒退壳占位（GUI-8 视觉补全遗留）；smoke 的 `APP ok n=` 是前缀通配（任意计数过，槽集漂移静默）；berry CLI 五入口默认值分裂（Run/Shot/Start/Host 四入口 tcg/phone/default 各持一词，Shell 已收敛 desktop/auto）。对账裁决（刀 A 侦察，A-RECON.md 落账）给出取优清单后需要一刀合批落地：八槽唯一应用集 + 主树镜像真 crate 接线 + 计数锁实数 + 入口收敛 + 节流语义复核。

## Decision

1. **八槽取优**：FILES/PHOTOS/CAMERA/CONTACTS/MMS/BROWSER 六槽取 wave4 真 crate（cherry-pick 1ec2afa41 + f3a89e893，`-x` 留源注记）；SETTINGS 体取主树 [settings crate](2026-11-15-波4-settings真应用首件.md)（唯一带交互帧循环与事件消费的版本，wave3 settings-app 静态手绘页全弃——其谱系不含 5452649af GUI 通道授权，拉起即 wm_cli_h()==0 静默退）；appdemo 取 wave4 控件画廊。wave3 六 `-app` crate 无互补面（0 测/0 pattern/无 manifest/验收句仅存源码注释），整支弃置；SETTINGS 槽唯一并入 = wave3 的接线段形态知识（非代码）。
2. **接线搭裁决 B 落**：SETTINGS 接线必须与 svcmgr 裁决 B（boot 批 [ui] 入册不拉起 + `app <id> gui deferred` 记账，f3a89e893 带到）同批——常驻 park 形由 boot 批拉起 = app_reap_tail 永等 = `APP ok` 永缺（W4-RECON §1.7 铁律）。装配走 APPTOMB 食谱先例（musl + berry-ld RUSTFLAGS → staging → mkapp 五道门禁），manifest 单源 crate 自有，icons/views contacts/settings 两槽走 appstub 资产兜底；appstub ELF 构建行退役（零 bin/ 消费者，壳本体在册留应急）。
3. **计数锁数诚实化**：smoke-image.sh ECO_MARKERS 与 markers.sh ROOTFS_MARKERS 的 `APP ok n=`/`APPUI ok n=` 改锁实数 9/8（9 = 八枚 [ui] deferred 记账 + APPQUIET 批拉起；8 = [ui] 资产面），「加/减应用槽随动契约」六处同批清单嵌注释（含槽位数破 10 先扩 APP_SLOTS 与 svcmgr 单数字位断言的前置）。保持前缀的族记因同页：PS（boot 批进程组合非槽位单源）、CLI/FS/GFXF/PAGE（步数单源在产侧）。
4. **五入口收敛摘 hunk 不携枝**：ux-unify 6e676da3e 的 berry 面四结构体 8 行翻转（→desktop+auto）手工摘取；Shell/dispatch 主树已收敛（821d3f152）不重复；shot 确定性由 `choose_accel(pref, deterministic=true)`（commands.rs:197）保恒 TCG。整分支不携（launcher scrim/时钟面与主树 spring 冲突大）。
5. **节流复核零改动**：APP_SPAWN_LIVE_MAX=4 语义复核成立——裁决 B 后 boot 批零占槽（deferred 即返 + 非 [ui] 批内同步收口），帽预算全归 launcher SPAWN；预检在 spawn 前锁槽、满表拒新不拒旧 loud（`eco: app <id> app slots`）、退出槽位稳态环必回收（wait_many 唤醒集 2+2×4 与帽同源）；七应用串行全活场景第 5-7 枚逐一点击逐一声 eco 拒 = 设计行为（帽值语义 = 桌面 4 页点击并发宽余量）。
6. **前置阻塞顺手修**：主树 HEAD kernel 构建断——2900c356c 声明 `pub mod oneshot` 并消费 `tighten_deadline` 但 `sched/src/oneshot.rs` 漏提交（作者工作树未 add）；自终结者支线 merge 2e775c12b blob 恢复律单源 + host 钉板两件（签名与消费点精确匹配，律测 7/7 绿）。

## Alternatives considered

- **SETTINGS 接线复制 wave3 裸接线形态**（否：wave3 形无裁决 B 前置，park 形入 boot 批 = app_reap_tail 永等全线 FAIL——对账 §二明载「接线应搭裁决 B 车落」）。
- **保留 appstub ELF 构建行作 fallback**（否：零 bin/ 消费者的构建行 = 每次构建白付；应急重建路径注释在案，恢复 = 两行）。
- **计数锁数顺带锁 PS n=**（否：PS 计数随 boot 批进程组合浮动（裁决 B 后已 -1），非槽位单源——锁它会把无关批次漂移变成 smoke FAIL 噪声；契约注释里明记归属）。
- **cherry-pick ux-unify 整枝再弃多余**（否：其 launcher 四文件与主树 spring 重做冲突面大，四 hunk 单文件自包含手工摘更小）。
