# 命令行终端与 shell 完善刀（bsh v2 语义四件 + berry-term 哑终端化 + 箭头键出向）

Status: implemented

一句话说明：owner 令「使用 workflow 模式全面地完善我们的命令行终端，还有 shell」（2026-11-17 原话）的落地刀——规格轮 workflow（wf_9c09e30e：bsh/berry-term/契约面三域侦察 + 风险/价值/同源三视角设计 + 综合成[刀谱](../../plans/2026-11-17-命令行终端与shell完善刀实施设计.md)）+ 实施轮 workflow（wf_5f90bdc5-0a7：B∥T 并行落码 → K 串行 → 两域对抗审查）+ 主线集成修复复核三段式；交付 bsh v2 语义四件（`>>` 追加/`||` 链/unset 内建/管道参数面）+ berry-term 哑终端化（本地第二编辑器退役、自动 respawn、软换行）+ 上/下箭头历史（KeyPump 三帧单字节 ESC 序列出向）+ berry-termio 纯 crate host 单测护栏；零标记滚新（`CLI ok n=` 6→10、`TERM ok n=` 2→3 前缀式——步数单源在 bsh，smoke/bcts/markers 七面零改动）。

## 背景

命令行体验刀（2026-11-15）与终端优化刀（2026-11-17 键盘物理链 + berry-term v1）后，两端各有明确欠账：bsh 语法面冻结 v1（`>>`/`||`/unset/管道裸名无参），berry-term v1 自带约 60 行第二套行编辑器与子 bsh 各持一份行状态（Tab 补全后失步、Ctrl-C 无路径、ANSI 不解析、箭头键 KeyPump 表外不出向）。本刀以规格轮三视角（risk/value/unify）合成裁决：**「不长第二套」以删除第二套兑现而非抽 crate 共享**——berry-term 哑终端化（全字节透传子 bsh、显示单源=子回显字节），失步类结构性根除，Ctrl-C/Tab/prompt 接续/清屏/箭头历史五族降解面同根同治。

## 交付

- **bsh v2 四件**（user/bins/bsh/src/main.rs 单文件，editor.rs 按 B5 刀谱零改动）：`>>` 三态切分（count==2 且相邻为追加，get_file 读旧＋拼接＋put_file 整写回——libc 无 O_APPEND/SEEK_END 游标外寻，v1 文档化缺口绕开；Err(ENOENT)=空起步）；`||` 链（split_chains 纯函数升 run_line 为 (段,操作符) 左起闸——跳过段不求值不碰 status，无 `||` 输入与旧 `split("&&")` 逐字节恒等）；`unset` 内建（BUILTINS 19→20，与赋值同优先层、字面名、静默 0）；管道参数面放开（split_pipe_seg 纯函数，PipeSeg.args 字段首次由交互路径装配——`cat x | grep y` 可用）。PROMPT 双写收口（main.rs 硬编码改 editor::PROMPT 引用）。
- **berry-term 哑终端化**（user/bins/berry-term/src/main.rs）：KeyAct 四态与本地行缓冲删除，on_key 收敛为任意字节→child stdin 透传；显示 = TermCore 解释子回显字节（\b 删尾、BS-空格-BS 三连净删一格、\r 丢弃、ESC[2J 清屏、ESC[H 及未知 finals 吞、ESC 状态机跨批次持久——与 bsh editor.rs 同形，ESC 态中再收 ESC 复位丢字节同形对齐）；软换行（完成行 64B 切块入环、尾段 TAIL_MAX=320 全容输入行回显、K 块视图随尾长收缩）；子退出自动 respawn（2s 冷却、存活 <2s 记一击、三击熔断停自动 + Enter 手动恢复清零、respawn 时限并入稳态 deadline）。
- **berry-termio 纯 crate**（user/berry-termio/ 新建）：no_std 零依赖零 alloc 定长数组承载行环/尾段/回显解释器/视图计算纯面；host 单测 17 + pipe_sim 流仿真 2（19 全绿）——补上 berry-term 运行时零机器执法的护栏洞（berry-complete「纯面外迁」先例）；user/Cargo.toml members +1、justfile test-host +1 行接线。
- **箭头键出向**（drivers/bins/gui-inputd/src/lib.rs + drivers/berry-virtio/src/input.rs）：berry-virtio 冻结 KEY_UP=103/KEY_DOWN=108（add-only）；gui-inputd translate_seq 三帧单字节 ESC[A/B 连发（先于单字节路径、miss 零漂移、release 零帧、与指针帧混批溢出留队延迟一拍不丢失）；guiproto/内核/bsh editor 四面零改动——bsh editor 的 ESC 状态机与 berry-term 透传天然消化。keypump 族 +6 host 测（gui-inputd 41 绿、berry-virtio 26 绿）。
- **自验面**：cli_selftest 增四族步（RAM 树 `>>` 三跑/左结合判别形 `run fail && __Y=1 || __Z=2`/unset 五断言/切词对拍+带参管道真码链）CLI ok n=6→10；term_selftest 增 `^C` 回显步（谓词并「^C 后 prompt 重显在流」项）TERM ok n=2→3；berry-term pipe_selftest 扩探针（收集流喂 TermCore 三断言：清屏后旧内容不在可见行集/`^C` 行在册/尾段以 prompt 收尾）。

## 裁决与判例

- **哑终端化裁决（三稿一致）**：显示单源=子回显字节，第二份行缓冲物理不存在——失步类根除；代价（每键一通道往返、显示依赖回显解释器）经 bsh 回显词汇表逐字节核实封闭（纯文本+\n+BS 三连+ESC[2J/ESC[H+`^C\n`+prompt 重显）+ berry-termio host 单测对冲。
- **审查轮 critical 判例（主线修复）**：pipe_selftest 探针与 term_collect 早退竞速——`^C\n` 与其后 prompt 重显可能分属两条通道消息，谓词只看 `^C\n` 会在重显消息抵达前早退收场 → 探针三「尾段以 prompt 收尾」恒假 → berry-term boot 期误 park（健康系统被误杀）。修法：谓词增「首现 `^C\n` 之后再有一处 `bsh> `」项（bsh 侧 term_selftest 同构修复 + 断言 `<3` 收紧 `<4`——基础三处无 ^C 重显也恒真，收紧后才真执法）。判例：**收集早退谓词的物证粒度必须到「最晚物证」**，中间物证齐即收会把后续消息留在通道里。
- **左结合判别形**（审查 note 修）：原 `run true && run fail || __Y=1` 左右结合两树同果无区分度；换 `run fail && __Y=1 || __Z=2`——左结合下 __Y 跳过/__Z 执行/st=0，右结合下全跳过，只有左结合实现能过。
- **respawn 归属辨析**：bsh 是 berry-term 的内部实现资源（spawn_child 内部建制、Child 句柄自洽），其生死管理归 berry-term 自身；svcmgr app_supervise 监督的是 app 进程本体——两层监督对象不同，不翻「app 监督归 svcmgr」裁决。
- **TAIL_MAX 溢出可达性纠偏**（审查 minor）：Tab 多候选列示单行平铺可超 320B——「正常路径不可达」头注断言过宽，如实改记「可达降级=该行尾段显示截断，下个 \n 恢复」。
- **挂账不做的硬理由**（刀谱挂账移交 16 项全在册，要点）：kill 绑 `&` job-control 刀（无 `&` 无目标；**已于 2026-11-19 兑现**——[作业控制 v2 刀笔记](2026-11-19-bsh作业控制v2刀.md)）；export 绑 spawn env 面契约刀（argv 块无 env 面，export 了子进程也收不到；**已于同日深夜兑现**——[export 面刀笔记](2026-11-17-export内建与spawn-env面刀.md)）；free 绑遥测 v3（MemstatRec ABI 形状先定）；引号/`${}` 统一分词器专刀（expand 是全部分发路径共用 seam）。

## 验证

- **宿主链**：berry-termio host 19 测绿（17 lib + 2 pipe_sim）；gui-inputd 41 绿 + berry-virtio 26 绿（keypump 族 +6）；`just test-host` 257 组全绿（自证门 selftest_guard 60 件零漏接线）；bsh/berry-term musl 单件构建零 error 零 warning（berry-ld 链，隔离 CARGO_TARGET_DIR）；abi-check PASS；build-user 全链绿（rootfs 63 条目、mkcpio split 2 卷 ≤32MiB——G6 体积预算达标，bsh 479KB/berry-term 458KB 增量自动溢入 rootfs1 余量）；内核构建绿。
- **QEMU smoke**：boot 相 32/32 绿（16:53，load 5.3）；全套两次被环境面拦——①echod 18080 被并行手核 lane 反复抢占（EADDRINUSE 假红，smoke 自托管锁只串 smoke-vs-smoke）；②load 16 时 LOADGEN A4 竞速 panic（同内核 load 5 全绿——TCG 载荷竞速铁案，本刀零内核改动）；③load 5 窗口跑到 rootfs 相 600s 帽断在 SKT——**并行 TCP 会话当晚提交 4fd349267（F122）自证定谳**：svcmgr 双预拉 vnet/gui-inputd 致 F87 族五标记卡死（16:52 构建的 rootfs 装的是修复前 svcmgr），与本刀文件域零交集。净室归因探针（HEAD + 仅叠本刀文件）补验 bsh 链标记，结果见下。
- **净室归因探针**（HEAD 4fd349267 干净基线 + 本刀九文件叠加，隔离 target dir 构建内核与 rootfs 双卷，noktest=1 + echod/evsclient/sktclient 全套辅助件）：**本刀可验标记全到齐**——BSH ok/PIPE ok n=6419/HEXYL/EXIT/U2/U3/B1 n=4/U4/TAB/INT/POLL/EVS ok n=2（客户端对拍同步绿）/FS/PS/APP ok n=10/**APPUI ok n=9**/**INPUT ok + gui-inputd up slot=29 + kb=slot 28**。APPUI n=9 含 TERMINAL = berry-term 扩展管道自检（clear+`^C` 探针经审查修复后的「^C 后 prompt 重显」谓词）客机实跑通过——**审查 critical 修复端到端在客机兑现**；kb=slot 28 = K 域 KEY_UP/KEY_DOWN 常量与 translate_seq 认领面绿。
- **CLI/TERM 两标记的取证补丁**：链序里 SKT 卡在 cli/term 之前——净室 HEAD 同卡（sktclient 660s 超时、EVS 同机制却过）定谳卡点在并行 TCP 会话**已提交**的 EVS/SKT 重做面（a1eddf293 当日提交、NET-04 复验在途），与本刀零交集。补救两路：①宿主纯函数实测——split_chains/split_redirect/assignment_of/split_pipe_seg 逐字摘出对拍 cli ⑥⑦⑨ 纯部 + 恒等契约九形 + 前导操作符/三态/边缘共 **30 断言全绿**（HOSTCHECK ok n=30，/tmp/termcut-hostcheck）；②TERM 的实质机制（`^C`→`^C\n`→prompt 重显经真子 bsh 字节流）已由 berry-term 管道自检客机兑现（同机制异入口）。主 smoke 全套（rootfs/RX 相逐字断言）待宿主安静窗口由 owner 复跑——11-15 刀同款挂账形态。
- **环境面如实记**：①berry-appshell 2 例测试序竞速 flaky（共享诊断行注册表 + 互斥锁毒化级联，三连跑全绿定性，HEAD 既有非本刀文件域）；②docs-guard 被并行会话在途文档过渡态拦停（索引行删了未回——绕开跑 build 其余三件）；③bcts@0 冻结件 `TERM ok n=2` 精确串对新树回放必红——冻结件历史快照语义，G1 裁决前缀式步数单源在 bsh、冻结件零改。
