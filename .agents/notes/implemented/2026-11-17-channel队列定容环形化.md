# W3-Q95 channel 队列定容环形化（02 号机会三刀 a）

- **编号**：W3-Q95（kernel/sched/ipc 核心代码 lane）
- **状态**：implemented
- **依据**：[research/内核深度进化/02-IPC快路径-Top5优化机会-v1.0.md](../../../research/内核深度进化/02-IPC快路径-Top5优化机会-v1.0.md) 机会三（队列机械）；[docs/阶段沿革.md](../../../docs/阶段沿革.md) 三百九十节
- **日期**：2026-11-17

## 问题

`ChannelEnd.queue` 为 `Vec<Message>`（kernel/src/channel.rs）：pop 用 `remove(0)`、recv 失败回滚用 `insert(0)`——两条都是队首 O(n) memmove。3b3 H2 定长内联化后 Message ≈440B 全内联，满队 recv 一次搬 ~3.1KB（7×440）、回滚路径再搬一次；「深度 ≤8：O(n) 可忽略」的旧注记写在内联化**之前**的形状上（双 Box 时代 Message 只有指针）。每发 IPC 恒付，真机 <1200 cycle 预算下占比百分之十几（审计推断口径）。

## 方案

定容环形替换 Vec，机械三件全 O(1)：

1. **chanface ring 模块**（纯函数单源，host 钉板）：
   - `ring_ok(head, len)`：不变量判（head < DEPTH ∧ len ≤ DEPTH）——tail 不另存，经 `ring_tail_of(head, len)` 导出，可漂移状态少一份；
   - `ring_slot_of(head, i)`：逻辑位 → 物理槽（`(head+i) % DEPTH`，FIFO 序单源）；
   - `ring_next_head`/`ring_advance`：pop/push 指针步进。
2. **kernel channel.rs 消费面**：`queue: Box<[Message; CHAN_DEPTH]>` + `head` + `qlen` 三字段（单核 IRQ 屏蔽串行，无需原子——审计方案原文）：
   - `push`：tail 槽写入 + qlen+1；
   - `pop`：队首槽 `mem::replace` 读出 + head 步进（槽内置空防旧令牌 alias）；
   - `push_front`：head 环形退一 + 槽写入；
   - 预储 `try_box(array::from_fn)`——`[expr; N]` 要 Copy（Message 非 Copy），`from_fn` 逐槽构造；`Box::new` 分配失败 abort 违 ABI §8.0「永不 panic」，走 heap.rs 3b3 H2 已在册的 `try_box` fallible 面（`Box::try_new` 本体锁 allocator_api，unstable 不可用——编译实证 E0658）。
3. **判据面零改动**：容量门（`queue_full_of`/`queue_readable`，W3-Q9）与序守卫（`push_ok`/`pop_ok`/`push_front_ok`，W3-Q49）全吃 `qlen`（元素计数非物理下标）；`front()` 判空从 `Vec::first()` 换 `pop_ok(len)` 门（同一谓词单源）。

## 序语义等价性

pop 头出 = `remove(0)`、push 尾进 = `push`、push_front 复原名 = `insert(0)`——逻辑序上与 Vec 机械**逐位等价**，钉板三路：

- 全序列对拍（满→弹 3→回滚→排空，逐步 logical() 与 Vec 模型比对）；
- 全相位环绕（8 个 head 相位 × 三轮满↔空 + 交错 push_front）；
- LCG 伪随机 500 步（push/pop/回滚按容量门随机混走，不变量每步校验）。

## 守卫面复用

- chanface 既有 17 测全绿维持（判据面零触碰的自证）；
- ktest H 段八组（深度满 -EBUSY、回滚保序）走 QEMU 面，CI smoke 执法；
- Drop 政策维持：环形槽 Drop 与 Vec 逐元素 Drop 同构（`Box<[Message; N]>` 整体 drop 逐槽），「未收割令牌随队泄漏」政策不变。

## 踩坑

- `Box::try_new` unstable（allocator_api，rustc 1.97 编译红 E0658）——kernel 已有 `heap::try_box`（3b3 H2 基础件）就是为此在册的，直接用；
- `[Message::new(); N]` 数组语法要 `Copy`（E0277）——`core::array::from_fn(|_| Message::new())` 绕开；
- `ring_advance` 与 `ring_next_head` 同式（+1 mod DEPTH）但语义分名：前者是 push 落槽后的 tail 步进、后者是 pop 后的 head 步进——kernel 侧 re-export 按实际消费裁剪（未消费的不 re-export，防 unused import 警告；两函数都在 chanface pub 面备查）。
