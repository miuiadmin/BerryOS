# Agent Note: W3-Q100 三平凡号 TABLE→NONE 降档（03 号 syscall 分派审计机会二）

Status: implemented

## Problem

03 号 syscall 分派审计（KERN_LOCK 分类面）发现三个平凡号整对占着 KERN_LOCK（CAS+KL_HELD 写+CNTVCT 诊断读）：0x61 clock_read（事件循环 deadline 换算高频号）、0x87 signal_take、0x40 sched_util_snapshot。copy 链 §A113 读者义务自 S-4 4-2 起由 per-AS PT 锁同窗接管（walk+copy 同窗铁律），KL 后继义务已偿清；三号零 caller_table、零堆、零帧分配，共享面仅 Relaxed 原子读（EWMA/pending/rtc epoch）无锁需求——TABLE 档是纯虚开销。

## Decision

- **降档**：install() 三处 `reg()` 自 SVC_CLASS_TABLE 改 SVC_CLASS_NONE——SVC 入口对这三号不再走 KERN_LOCK 包络（CAS/写 KL_HELD/诊断读整对归零）。
- **「NONE 实装号归零律」修订为后继审计律**：svcface 新 `NONE_DOWNGRADED_NRS` 白名单 `[0x61, 0x40, 0x87]` + `none_class_audited()` 恰等律（多一号少一号都红）——此后降 NONE 须过 §A115 四问（copy 链去向/堆帧分配/caller_table/共享面锁需求），白名单即审计底账；host 钉板 `none_installed_class_audited` + `none_audit_catches_drift`（svcface 7→8 测）。
- **口径滚新**：`anchor_classes` 三锚改 NONE；`class_of_full_domain_bounded` 口径 43 非 NONE/213 NONE；kern_lock.rs 分类注释同步（实装号落 NONE 前置 = §A115 四问复审）；0x88 power_off 局注口径顺修（UART/PSCI 诊断面未过审保守留 TABLE）；svc_registry_check 三方对拍 46 号 PASS。

## Consequences

- 三热号 SVC 入口锁开销归零（clock_read 是事件循环 deadline 换算高频号，收益最直接）。
- 降 NONE 从「自由裁量」变「白名单执法」：REGISTRY 与 install() 任一侧漂移都被 none_class_audited 恰等律咬出，与 svc_registry_check 三方对拍互补。
- 后续平凡号降档（03 号审计余量）走同律：先 §A115 四问，过审即白名单加号 + 注记审计依据。
