# CP-06 首份 A/B 数据: ktest 负载生成器与 timer_slack × band 四组对比

Status: implemented

## Problem

06 号综合定谳终判「下一程的瓶颈不在机制在证据与消费」——五维中策略维 5 分、观测维 7.5 分的共同扣分项 =「首份真实 A/B 报告(CP-06)未动」(research/调度深度调研/06-综合定谳-v1.0.md §1.7-③):timer_slack(CP-11)与 band(M4)两条机制线都已落码,但零负载数据——「差异化调度好在哪/代价是什么」没有任何可 grep 的数字,band 并线(M4 入场券)的三件套之一「loadgen + 尾延迟断言」也因无负载形态而悬空。

## Decision

ktest 形态负载生成器 `test_loadgen`(kernel/src/ktest.rs:8861,注册 :125 末位新号),三先例合体(BANDM4 M4F 真 spawn 面 / test_band 本地环+真 band API / HDRWAKE 忙等口径):

1. **受控 spawn**:`loadgen_spawn(pattern, count, burst_ns)`——真 `spawn_intent` ×12(interactive 0x02/utility 0x03/burst 0x04 各 4)入真 PER_CPU_RQ,M4F 式走查验证在席后 `rq_unlink_kt` 摘出;现役带任务自然打 `[band]` 串口行(intent→band→带参数 boot 可见)。
2. **手驱真机械驱动器**(run_group):运行环 = 本地 Runqueue(真 RQ 无 pick 出口——test_band 先例),enqueue/pick/tick 走真 class 面(`class_of_task` 分派 + `pick_next_filtered` eligible 过滤 + `Fair::tick` LAST_VCT 回落位);睡眠 = 真 SLEEPQ + 真 `timer_slack_defer` 顺延律(block_current 入队点同款「一次落定」);oneshot = 真 `tighten_deadline`+`arm_at`(忙等检出);band = 真 `configure`/`consume`/`period_check`/`throttle_all`/`unthrottle_all` 手驱消费点(执法未并线热路径——入场券纪律,ktest 手驱 = 证据面可用形态)。
3. **四组 A/B + 汇总行**:A1 基线 / A2 band / A3 slack 10ms / A4 双开,同负载(ia burst 100µs+睡 10ms、ut burst 10ms+睡 1ms、burst 恒跑;各 6 轮、sub-unit 250µs);lat = 首切 − 请求唤醒时刻,每型 20 样本 nearest-rank 分位;串口出 `KTEST LOADGEN A*` 组行 + `cmp` 四联汇总行。断言面含数学下界(A3/A4 ut p50 ≥ 顺延量)、零牺牲(thr_ia 恒 0)、差异化在位(A2/A4 thr≥1)与全套收口(环空/SLEEPQ 空/真 RQ 零残留/util 清零/timer 掩蔽)。
4. **首份数据报告**:research/调度深度调研/AB-01-CP06首份AB数据-ktest负载生成器-v1.0.md(两跑全量 + 五条判读 + 工具边界)。核心数字:slack 顺延精确 +10ms 落地(ut p50 0.75ms→10.7ms)、interactive 四组全 0.35-1.06ms 零牺牲、band 限流 ut p99 放大 3.2×(≈37ms)、burst 吞吐 +75%(让出的 CPU 全喂 burst)。

两个实踩修正(留给后来者的坑):轮次间 burst_left 忘重臂 → 醒后 grant=min(0,unit)=0 零长轮,负载塌缩成「每任务一真轮 + N-1 空转轮」(指纹:ranUT=40ms 恰 4×1 真轮)——睡眠腿须重臂;band quota 须按**期内占有率**定(≈0.49 实测),40ms/60ms 期永不越线(翻期清账),20ms/60ms 才期中必越。

## Alternatives considered

- **boot spawn 面(rwake 族)真 IRQ 口径**:测量保真最高,但需 sched::init 后 fw_cfg 门控 spawn + 全套 boot 序列协同——归后续刀(AB-01 §5-2);本刀选 ktest 手驱形态 = 零依赖证据面先行(06 号「门前的刀全是零依赖的证据面刀」判词的直接执行)。
- **wake_matching 真唤醒路径 + 真 RQ 中转**:多一跳「真 RQ→本地环」迁移噪声;改用 sleepq_insert/unlink 纯队列原语 + 本地环直入,分量更干净(ktest 纪律:test_fast 已警告 fast_wake 在 null CURRENT 挂死面)。
- **HDR 环记延迟**:现成(record_wake_lat)但全局槽不分 pattern;首份用平行数组 + nearest-rank(每型 20 样本),HDR 接入归样本量扩组刀(AB-01 §5-3)。

## Consequences

- CP-06「首份 A/B 报告未动」清偿;ktest boot 多 `KTEST LOADGEN` 十行(smoke 只查标记存在,零影响——MARKERS 列表未动)。
- band 并线(M4)入场券三件中 loadgen+尾延迟两件首次齐——并线后复跑 AB-01 §2 基线即可对拍。
- 工具边界如实入册:忙等检出(≤250µs 偏置)、手驱消费点、n=20 p99=最大样本——绝对值不可直接外引,差分结论可用。
- 负载任务 12 枚 Box::leak 常驻(ktest spawn 政策同形,v1 无 reap);boot 后段 dpg_press panic 行属并行会话 dpg.rs 在途件(其日志同红且零 LOADGEN 行,实证归属),与本刀无关。
