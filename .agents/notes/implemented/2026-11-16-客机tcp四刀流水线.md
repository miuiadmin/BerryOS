# Agent Note: 客机 TCP 四刀流水线——量子栈四拆、seq 尾随旁路与 K=2 的裁决

Status: implemented

一句话说明：四刀为什么把吞吐杠杆从「窗/RTT 域」改判到「客机内同步等待/唤醒量子栈域」，以及为什么选「netdproto u8 尾随 seq 旁路 + K=2 恰满环 + vnet 挂起 op 完成即答 + tx 整批单 poll」这组四拆，而不是载荷域内嵌序号、K=3+ 环扩、WScale 联动或通道帽抬升。

## Problem

二刀多段在途逻辑在活链只拿到 1.23×（< 1.8× 门），当时归因「SLIRP 通告窗 128」。[四刀前 probe](../../../research/NET-04-客机TCP四刀流水线与对抗复验-v1.0.md) 用 QEMU filter-dump 直测 wire 证伪该归因（SYN-ACK win 65535 无 WScale、数据期恒 65535），真闸 = 客机内量子栈：tx_send 逐帧同步 poll（每帧一次唤醒量子，TCG 下 1ms 步睡实际醒在 25-270ms）+ 泵收帧唤醒滞后 + serve 单请求同步到底 + libc 请求-应答严格串行。四刀要在「八 op 对外语义红线 + 五标记链零回归 + harness 旧臂零漂移」下拆这组闸——拆哪几层、seq 配对放哪、K 取多少，各有真实候选。

## Decision

- **四拆同步律（缺一即哑）**：只拆 libc ≈ 0 增益（serve 单请求到底 + arm 门拦截）；必须同批 ①libc Client 臂 K 窗（issue/harvest 两相 + seq 配对收割 + 陈值弃）②vnet session-0 RT 挂起 op 化（入环即注册、完成即答、挂起期短 tick 泵）③arm 门容量化（`tx_inflight()!=0` 独占拒 → 环空槽 < ceil(len/MSS) 即 BUSY 背压）④tx 批量完成（整批帧单次页写/单门铃/单 poll——不批量则每段一帧完成量子，K 窗收益被逐段串行等待吃掉）。
- **seq 形态 = u8 尾随旁路，RT 专属，请求/应答双面**：请求 `[op][dlen][data][seq u8]` ≤ 253、应答 `[st][dlen][data][seq]` ≤ 253 / 2B `[st][seq]`（BUSY 背压必携原 seq）。载荷域内嵌否决三由：seq 字节进回显流破 echo 逐字节契约、应用载荷契约污染（EVS/SKT 同源载荷将被改约）、有效载荷 250→249 白损。三形消解 = v1 恰长 → −4B sid → −1B seq（同字节 dlen 权威，结构上互斥——「尾 4B 恰似合法 sid」的 seq 形帧必须 fall-through 落 seq 形，单测钉板）。
- **K=2 定值三几何**：发送侧 2×250=500 ≤ 环容 TX_SLOTS×MSS=512（恰满零扩环）；入站侧 echo 流 ≤ guest 自通告 WINDOW=512（K=2 恰在界内，K=3 即 750 双面撞环扩+通告窗联动双前置）；回绕距 256 ≫ K 无歧义。K 常量 `RT_PIPE_K` 落 netdproto 双侧共源（libc/vnet 同值单源）。
- **流位对齐纪律（超时 op 不弃记录）**：vnet 挂起 op 超时应答后记录保留至 echo 收齐才弃置——迟到 echo 字节被死 op 吸收而非错位下一 op；libc 侧对偶 = 收割时 seq ∉ 在途集即弃（v1「晚到应答毒化下一请求」债在单客户端 K 窗面收窄清偿）。
- **拼段准入几何**：echod/SLIRP 可把 K 个在途 op 的回显拼成单段（≤500B）——session-0 收流缓冲必须 = K×TCP_DATA_MAX，否则拼段被首刀「宁拒不腐化」准入闸拒收 → 对端重传同形再拒 = 死锁面（几何不变式：未收回显 ≤ 挂起 op 数 × 单 op 帽）。

## Alternatives considered

- **WScale/通告窗联动**：对出站零杠杆（probe 实证窗已 65535 无缩放）——降级入站/服务面专属（guest 自通告 512 是 K≥3 的 echo 流节流前置），本刀不碰。
- **K=3/K=4 + 环扩 TX_SLOTS=8**：3802 B/s（K=4@263ms 旧模型）只作静默窗天花板——K≥3 需环扩+通告窗联动双前置，且静态增量吃 boot 面；K=2 已覆盖验收线域。
- **通道帽 CHAN_MSG_MAX 抬升（kernel 属地）**：与本瓶颈无关出局——它是 op 载荷 >250 的另一条路径，届时与服务端面 seq 形（257 > 256 几何受阻）同批再裁。
- **载荷域内嵌 seq / 应答不携 seq**：见 Decision 三由；应答不携 seq 则 BUSY 无法配对重发、迟到应答无法与在途 op 区分。
- **libc 侧 ACK 等待完全去同步（纯异步）**：libc 单线程无事件循环资产，伪造异步面 = 重造 epoll——收割相已经是「阻塞帽等一应答」的最小同步面，K 窗重叠度由 vnet 完成即答承担。

## Consequences

- 吞吐物理基础改写进入正式文档：NET-03 §2 根因改判（snd_wnd=128 证伪 → 65535 无 WScale + 量子栈）与 §6 优先序改排（⑤新增 tx 批量、②降级、③降前置、④出局）由 [NET-04](../../../research/NET-04-客机TCP四刀流水线与对抗复验-v1.0.md) 同批承载。
- v1 串行消费者（bsh/tcptest/advcli 镜像 RPC）字节面零漂移按构造成立（无 seq 请求恒无 seq 应答）；named RT ST_OK 细化「入环受纳，ACK 归泵收口」是可扩不可破扩面（消费者可观察面不变）。
- 顺带批随刀收口：F72 snd_wl1/wl2 窗新鲜度护栏 + ACK 域上界拒（幻 ACK 弹槽面闭合，多 op 在途放大该面）+ EVS 250B 入标记链（覆盖 250B 全域多段路径，黄金哈希同批换）。
- dup netd 通道并发多消费者债收窄非清偿（wave10/14 口径不变）；服务端面流水线留待通道帽裁决后再议。
- verify 波同批续修两 bug（echo 相崩溃根因，详 [NET-04](../../../research/NET-04-客机TCP四刀流水线与对抗复验-v1.0.md) §3）：表会话 DRAIN 割幅帽 TCP_DATA_MAX（rt 缓冲幅 500 复用致应答 encode 越帽 trap）与命名 RT send_data 暂存容量闸（入环即答后连发越过 TX_CAP 暂存即 trap——泵等环空，帽内）；教训入册：「入环即答」语义变化的容量边界须对暂存面（环槽/窗/暂存三门控）逐项重审，标记链单段形态（EVS 250B）不覆盖连发路径。
