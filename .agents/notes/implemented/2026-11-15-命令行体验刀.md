# Agent Note: 命令行体验刀——bsh 六内建与终端管道契约钉板

Status: implemented

## Problem

owner 一句话需求「完善 shell 和终端和 bsh，命令行」落地时缺两块：其一，bsh 内建十二件对基本命令行习惯有硬缺口——clear/uname/uptime/sleep/type/history 全无（which/date 已有 bin 件，kill 另属信号面）；其二，GUI 终端应用（berry-term）依赖的「程序驱动 bsh」管道契约只有侦察结论（bsh 交互循环天然管道化，stdin_feed + stdout 私有对端零新原语成立）没有自验面，契约漂移无人执法。同时三路侦察定谳 GUI 终端自身有三堵结构性墙（键盘物理链断线/inputd 单订阅者/.bap 授能缺端），全是波3 面——本刀的切法是内建补齐加管道契约钉板，GUI 壳挂账移交。

## Decision

1. **六内建进 render_cmd 分发面**（console 与管道双形态同源）：clear = 11B ANSI 清屏+光标归位（带参照打幂等）；uname = `<sysname> <machine> <release>` 单行（版本源 = libc `uname` 的 `.berryver` 烙印 semver，ADR #83 单源——初版自拼 crate 版本经验证轮发现两源漂移风险后换源，mirror 结构 6×65B + extern 真身，A7-4 钉板同手法）；uptime = `up <N>s`（CLOCK_MONOTONIC 秒，boot 起算）；sleep = 100ms 步进 usleep 环阻塞 0..=60 秒（v1 不可打断，拒面全 usage 2）；type = 首词身份三档（内建表/rootfs bin/ not found 码 1）；history = editor 历史环 newest-first 逐行 `N  cmd`（经 run_line 只读透传，管道子 bsh 恒空——editor 历史属本进程交互面）。
2. **BUILTINS 单源化**：render_cmd if-else 链的隐式命令集升 `const BUILTINS: &[&str]`（18 项），type 身份查询/RealSrc Tab 候选/cli_selftest 在册断言三消费同表——RealSrc 原 12 项硬编码退役，不长第二来源；help 文案按 192B 控制台原子消息帽（A60）拆三行（134/122/60B）。
3. **`CLI ok n=6` / `TERM ok n=2` 两自验步**（rootfs 相第 55/56 标记）：cli_selftest 六步逐内建行为面对拍（clear 11B 精确对拍/uname 前缀/uptime 数值域/sleep 1s 时钟差分/type 三分支 + BUILTINS 在册/history 环回读）；term_selftest spawn 子 bsh（`--no-selftest` + stdin_feed 喂 `echo berryterm\nuname\n` + fs_gifts 四元 + stdout 私有对端），早退谓词环收齐提示符 ×2/回显行/两结果行（混流同一字节流 = 哑终端契约逐项钉板）再 terminate(130)/reap 130 收口。链位 sig 后 fat 族前（A 系契约位，零盘面 EFI 路亦打）。
4. **smoke 挂线四处同批**：markers.sh ROOTFS_MARKERS 54→56；smoke.sh 计数注释 86→88 + 标记明细注释块（RX 合相/FAT 子目录/持久化相走动态数组自动继承）；smoke-image.sh ECO_MARKERS 39→41 + 总计数 84→86（EFI 路可达即链位前移的动因）；新标记对全表现役标记互非子串正反双向机查零碰撞。
5. **`--no-selftest` argv 旗 + interactive() 抽取**：子 bsh 跳过 boot 自验链直进交互循环（不带旗 = 分钟级全链阻塞 + term 步无界递归），与常规链尾路径共用同一台机器；vars/status 由调用方持有，`$?` 跨链尾→交互语义零漂移；svcmgr 常规拉起零参零漂移。

## Alternatives considered

- **GUI 终端应用先行**（否：键盘物理链三处断线——QEMU 无 virtio-keyboard 设备、inputd 泵无解码分支、guiproto 无 key 事件出向编码；inputd 单会话单订阅者（多读者 dup 混流）；.bap 授能面缺 wm/input/gfx 端且 APP_SLOTS=9 恰满——三墙的解法（焦点路由/软键盘/OP_WM_FOCUS 接线）恰为波3 计划既有面，本刀先钉管道地基）。
- **bsh 核心抽库 berry-sh 供 GUI 终端嵌入复用**（否：stdin_feed + stdout 私有对端的管道驱动已零原语成立，TERM ok 自验钉的就是「同一台机器」语义；抽库是大迁移，风险与当期收益不成比例——真需要嵌入面时再议）。

## Consequences

- **挂账五件移交波3**（设计稿契约 4）：键盘链三件（QEMU 键盘设备/inputd 解码分支/guiproto key 编码）、inputd 多订阅者焦点路由、.bap GUI 授能与 APP_SLOTS 9→10、宿主 `berry console` 串口直连（待 tools/berry 波11 脏面落库后另刀）、berry-term 本体——本刀管道契约即其地基。
- **uname 版本源已换源落地**（验证轮发现）：初版自拼 bsh crate `CARGO_PKG_VERSION`，验证 agent 发现仓库已有版本单源（根 workspace semver 经 `.berryver` 烙印，boot banner/sysver VMO/libc uname 四面同值，P2-5 规则 14）——两源独立升版即漂。已改 libc `uname` 真身消费（mirror 结构钉板），后续根 workspace 升版时 uname 内建零改动随单源走。
- **$? 盯点两处**：type not-found 定码 1 非 127（127 是命令执行派发面的 not found，type 是查询面自有码，POSIX 对齐从简如实记）；sleep v1 不可打断（无异步信号抢占面），信号抢占立法后交互期 Ctrl-C 面需回核。
- **guest 终验已达成（净室探针形态）**：CLI ok n=6 与 TERM ok n=2 经绿基线 worktree（509000eb6 + 本刀五件、cli/term 临时前移链首的净室验证件——主树链序不动）在 AAVMF QEMU 130s 内实机落串口（BSH ok → CLI ok n=6 → TERM ok n=2）。同场复现既有 u3 竞速（`bsh: u3 selftest bad: step=N <seg> spawn failed`，N/段每轮不同），多基线（509000eb6/f52d834b4/主树）与新旧 bsh 双版本复现 = boot 期进程表余量竞速（app 批/apptomb 往返与 bsh 链交错），非本刀回归；主 smoke 全绿门待宿主安静窗口由 owner 复跑（本日 4 台并行 QEMU 下 TCG 饿死，600s/900s 帽均不可达）。静态面全绿——净室构建零 error 零 warning、互非子串机查零碰撞、既有文案逐项对拍零漂移、新 bsh 逐字节进包验证。
- bsh 二进制 454,144→464,840B（+2.4%），rootfs 末卷余量 ~30MiB 无压力。
