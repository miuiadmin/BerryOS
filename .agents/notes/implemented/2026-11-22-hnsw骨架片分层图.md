# ai-runtime §四.1 第二片：HNSW 图骨架 berry-hnsw

Status: implemented

一句话说明：E lane R7（DAG `ai-runtime §4` 续片）——契约四.1「分层可导航小世界图」的图结构面落地：新 crate `user/berry-hnsw`，splitmix 确定性分层指派（种子 = 节点序号，位级 log16 指数硬币——core 无 ln，指数域直取近似，分层是概率面半层偏差只动分布）+ 每层贪心下降（1-best 局部最小）+ 层 0 全展开束搜（朴素 ef 形——ef 只裁输出宽度）；距离经泛型闭包注入，图结构与 berry-vqvec 量化距离彻底解耦（测试用 1D 标量度量）；检索 tie-break 节点号升序——同图同查询恒同结果（vault 审计账本的复现前提）；host 6 测（确定性双建图逐层邻接全等、格点精确最近邻、半格点等距 tie-break、容量/坏号 loud、空图检索）。

## 裁决与判例

- **朴素建图形先行（诚实注记）**：贪心入口直连 + 容量赶最远，非 ef-construction 束建 + 多样性剪枝——1D/低维度量最近邻全命中已钉，高维召回升级随后续刀（design.md 建造清单挂账条目化）。`A: (run decision, 2026-11-22) 朴素直连形先行（更简、确定性可测；束建启发式按需升格）. Reversal: insert 单函数改。`
- **确定性 = 无环境熵**：分层种子 = 节点序号（splitmix 混合），非随机源——同插入序列恒同图，图字节级可比对（测试逐层邻接 Debug 全等）；vault 检索进审计账本的机器前提。
- **距离闭包注入（结构/度量解耦）**：图不知道向量形态——berry-vqvec 的量化距离（或任何度量）在消费侧接线；测试用 1D 标量度量让最近邻可手算钉板。
- **分层指派位级近似**：core 无 ln/ln16——用 f32 指数域 floor(log2) 折算 log16（尾数修正 < 0.25 层忽略）；分层是概率分布面，不影响正确性只影响层 occupancy。
