# berry-ui 组件 P1 尾五件：ViewKind 29→34 数据层落地

Status: implemented

## Problem

组件清单（`docs/UI组件清单与实施规划-v1.0.md` §三 P1 多数集合）在 `user/berry-ui` 继 Phase 1 七件、P1 九件、P0 尾四件后收尾 P1 集合最后 5 个 kind 件（Tip/Refresh/SwipeItem/DatePick/TimePick），P1 集合的 kind 件自此齐账（Search/Sheet/Toast 等非 kind 件不在本批域）。约束与前三批同款：只动数据结构层、TLV tag add-only、拒面两面同律（流面 + builder 面）。拦路五问：Tip 的文本放哪（Button label 先例 vs 协议外置）；Refresh 的容器/叶分界（清单明示包裹 List——唯一带子件）；SwipeItem 的 reveal 两端要不要 Sbar 式 start≤end 区间律；DatePick 的日历语义检到哪层（月长感知做不做）；TimePick 的 12 小时制下 hour 存什么。

## Decision

1. **TLV tag add-only 追加（协议零变更，前三批同法）**：kind 字节域 29..=33 顺延钉五件（`KIND_TIP..=KIND_TIME_PICK` pub const）——旧流值域 0..=28 不受扰，29..=33 旧读端本就 `UnknownKind` 拒。props 域逐件定死：Tip 变长 2..=66（len u8 + text + placement u8）、Refresh 9B（refreshing u8 + offset·on_refresh 各 u32 LE）、SwipeItem 16B（action_count·reveal_start·reveal_end·on_action 四 u32 LE）、DatePick 24B（year·month·day·min_year·max_year·on_change 六 u32 LE）、TimePick 13B（hour·minute·on_change 各 u32 LE + use_24h u8）。
2. **Tip 文本走内联 TextBuf（Button label 同律非本批新约）**：提示文本短小（≤ `TEXT_INLINE` 64B），内联零 alloc Copy 值面 + TLV 流自含；与 Input/Edit 的「内容不入 Props」不冲突——那是长文本/用户输入走协议的律，提示是静态短标签。placement = Top/Bottom/Start/End（wire u8 0..=3，域外 UnknownProp；Start/End 取布局走向语义）。
3. **Refresh 容器 + offset 千分域执法（本批唯一容器件）**：AST/builder 面可带子（包裹 List 等——golden 钉 Refresh→List 嵌套正例），命令面同前批容器边界不收编。`offset` 0..=1000 permille（Slider 免 FP 纪律同源）越域 `BadValue`（got = offset）——任务面未列此拒，但 crate 凡 permille 域必执法（Slider/Progress/Sbar 三先例），不立例外。refreshing wire u8 ∈ {0,1} 域外 UnknownProp。
4. **SwipeItem reveal 两端独立无序（不抄 Sbar 区间律）**：起末端滑出量各自展开（两侧动作区互不构成区间端点），拒面只有任一端 > 1000 → BadValue（got = 违规端值）；零动作合法 = 纯行项（List 零项同律，action_count 无值域）。动作内容不进数据层——`action_count` 只记数（Select 选项计数面同律）。
5. **DatePick 结构域检不做月长感知**：拒面四律（检序即此序，两面镜像）——month 非 1..=12、day 非 1..=31、min_year > max_year、year 越界 [min_year,max_year]。2 月 31 结构合法（数据层不立法历法，消费面钳——测试钉正例）；年域 [0,0] 合法（min==max 单点退化，数据层不立法历法纪元）。
6. **TimePick 存 24 小时制原值**：hour 0..=23 / minute 0..=59 越域 BadValue（got = 违规值）；12 小时制（use_24h=false）下 hour 仍存 0..=23——上下午折叠是视觉面语义，消费面自换算（数据层免双义）。use_24h wire u8 ∈ {0,1} 域外 UnknownProp。
7. **四叶一容器分界 + 占位不做半实现（前批同纪律）**：Tip/SwipeItem/DatePick/TimePick 入「叶带子拒面」（build_node 与 DescBuilder::begin 两面同扩）；Refresh 容器不入。§8.2 块×kind 表不扩：五件全拒 SIZE/ALIGN 块，A11Y 全 kind 合法照旧。intrinsic 五件一律 (0,0)（Tip 文本度量、Refresh 子聚合、SwipeItem/DatePick/TimePick 行高——全挂 Phase 2 布局刀）；final_size 一律随父；paint 两处穷尽 match 扩列入「无视觉容器臂」。值域先验 `validate_p1_last_five`（同型第四批，begin 面与 parse_props 流面同律）。
8. **测试钉板 `tests/tlv6.rs`（tlv5 同款双轨，六轨不并常量）**：GOLDEN_V6_STREAM 字面量钉五件齐流样本树现产物（含 A11Y×Tip、Refresh→List 容器带子）+ 对称值档 roundtrip（Tip 空文本 End/Refresh 帽值 1000/SwipeItem 零动作双端 1000/DatePick 年域 [0,0]/TimePick 0:00 12 小时制）+ BadValue 矩阵（五件全覆盖 + 2 月 31 正例对照，两面同律）+ UnknownProp（placement/refreshing/use_24h 域外）+ TextTooLong + 截断（五件各一刀，短 ≥2B——cc 单字节回填不了 need 帽）+ 四新叶带子 + SIZE×新 kind 拒 + add() 烟囱。`tests/reconcile.rs` 未知 kind 绊线 29→34 让位新域界（第五次同款挪法）。

## Alternatives considered

- Refresh offset 不执法（任务 BadValue 清单未列）：否——crate 凡 permille 域必执法（Slider value/Progress value/Sbar thumb 三先例），本件开例外即破「值域拒面」单律；测试钉 1001 拒 + 1000 正例双侧。
- SwipeItem reveal 抄 Sbar 的 start ≤ end 区间律：否——Sbar thumb 是同一轨道上的区间两端（有序），SwipeItem 是两侧独立动作区（无序）：start=1000/end=1000（双全开）与 start=1000/end=0（单侧全开）皆有义，区间律会误拒后者。
- DatePick 月长感知（2 月拒 31、闰年立法）：否——历法语义是消费面知识（数据层无 locale/时区语境）；结构域检（1..=31）+ 消费面钳是「数据层只载约束」的 Input max_len 同律。
- TimePick 12 小时制存 1..=12 + AM/PM 位：否——双义域（hour 存储面随 use_24h 换义）破 roundtrip 单义性；0..=23 恒存 + 视觉面折叠，use_24h 只是显示制式开关。
- Refresh 叶化（指示器独立件 + 容器另建）：否——清单语义就是包裹件（「可带子——包裹 List 等」）；叶化会把「指示器状态」与「被包裹内容」拆两个节点，app 面多一跳绑定。
- 顺带收编 lib.rs 命令面（add 容器白名单加 Refresh）：否——前三批已钉为已知边界（超数据层授权面），本批照钉；边界合并到 Phase 2 接线刀一并收编。

## Consequences

- **命令面边界（lib.rs 未动，钉为现行为）**：add() 可建五新 kind 节点（spec.kind 只拒 Root）但作父位全拒 BadParent（含 Refresh 容器）；set_props 对五件一律 NodeBad（kind_ok 门不含五对）——Tip 换文本、Refresh 状态回写、SwipeItem 滑出量推进、DatePick/TimePick 换值挂 Phase 2 收编（mask.rs props_diff catch-all 已保守返全置，不炸不漏）。
- 事件 ID（on_refresh/on_action/on_change×2）纯数据面，hit 层派发未接线；Tip 浮层定位、Refresh 拉动手势（swipe 复用候选）、SwipeItem 滑动回弹、DatePick/TimePick 滚轮交互同挂 Phase 2。
- 值域执法仍只落两面（流面 + builder 面）：add() 命令面产物可能带越界值，编码可过、对端 apply_desc 拒——loud 在解码侧（前三批同状）。
- wire 域界自此 0..=33，未知 kind 绊线在 34；P1 集合 kind 件齐账（Tip/Refresh/SwipeItem/DatePick/TimePick 落地），P1 剩余为服务件/模式件（Sheet/Toast/Scaffold/BottomNav/Drawer——非本批 kind 域）——后续批继续顺延 add-only，旧流逐字节不变由 GOLDEN_V1..V6 六轨共保。
- 验证：`cargo check -p berry-ui`（guest aarch64-unknown-none 默认口径）与 `--features s7`（host）两口径绿；`cargo test -p berry-ui --target aarch64-apple-darwin` host 全绿（tlv6 新钉 7 测，23 测试二进制零失败）；下游 berry-launcher check 绿（仅构造 Props，无穷尽 match 涟漪）。
