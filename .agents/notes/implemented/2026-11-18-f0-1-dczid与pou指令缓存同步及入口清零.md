# F0-1：`DCZID_EL0` 零化、PoU 指令缓存同步与用户入口寄存器清零

Status: implemented

## Problem

全栈审计检出 ARMv8-A 硬件契约与页装填路径四处底层缺陷：

1. [vmo.rs](../../../kernel/src/vmo.rs) `zva_probe_cached` 误读 `CTR_EL0`（把 bit 26 `CWG[2]` 当作 `DZ` 使能位、把 `DminLine` 当作零化块宽），未读架构规定的 `DCZID_EL0`（`DZP` bit 4 与 `BS` bits[3:0]）；在 `DZP=1` 禁 `DC ZVA` 但 `CWG[2]=1` 的虚拟化或异构核上会触发 EL1 未定义指令停机，在 `DZP=0` 但 `CWG[2]=0` 的核上又误退化慢速软件清零。
2. 内核经高半直映 `KERNEL_VA_BASE + pa` 写用户代码页后直接装入有效叶 PTE，全程缺失 `dc cvau` 与 `ic ivau`/`ic ialluis` PoU 指令缓存一致性同步，物理帧回收复用或多核并发取指时可取到陈旧指令行。
3. [syscall.rs](../../../kernel/src/syscall.rs) `pager_supply_one` 与 [dpg.rs](../../../kernel/src/dpg.rs) `dpg_pager` 先调 `Vmar::supply_page` 装入有效零页叶 PTE 并广播 TLB，随后才将源 VMO 字节拷入目标物理帧，开启对核在未拷贝完的全零帧上提前取指或读半成品数据的竞态窗口；且 `sv == vd` 自源同柄时存在双重 `&mut Vmo` 借用隐患。
4. [task.rs](../../../arch/aarch64/src/task.rs) `user_entry_trampoline` 仅装载 `x0`、`x1`、`sp_el0`、`elr_el1`、`spsr_el1` 即执行 `eret`，将 `x2..x30` 中的内核函数地址与栈残值直接暴露给首个 EL0 入口。

## Decision

1. 在 [lib.rs](../../../memface/src/lib.rs) 单源落地纯函数 `dczid_block_size`、`ctr_pou_plan`（区分 `IDC`/`DIC` 硬件自动一致位及 PIPT vs VIPT 指令缓存策略）与 `cache_line_span`，配齐宿主机单测钉板；[vmo.rs](../../../kernel/src/vmo.rs) `zva_probe_cached` 改读 `dczid_el0` 并委托 `berry_memface::dczid_block_size` 解码。
2. 在 [mmu.rs](../../../arch/aarch64/src/mmu.rs) 新增 `sync_icache_pou(kva, len)`：按惰性缓存的 `CTR_EL0` 在 `IDC == 0` 时逐行 `dc cvau`，`dsb ish` 后在 `DIC == 0` 时按 PIPT（`ic ivau`）或 VIPT（`ic ialluis`）失效指令缓存并以 `dsb ish` + `isb` 收口。
3. 在 [vmar.rs](../../../kernel/src/vmar.rs) 新增 `Vmar::supply_page_init`，强制在持 `pt_lock` 且叶 PTE 仍为 `0`（不可翻译）时先执行帧内拷贝闭包与可执行映射的 `sync_icache_pou`，最后才写入有效叶 PTE；`Vmar::map` 装叶前同步接入 `sync_icache_pou`。`pager_supply_one` 改为先以共享引用 `&Vmo` 读源缓冲，再经 `supply_page_init` 原子落页，既消除双重 `&mut Vmo` 别名，又完整保留 `DPGN ③` 源未提交时供给零页并返 `-EBADSTATE` 的契约。
4. 在 [task.rs](../../../arch/aarch64/src/task.rs) `user_entry_trampoline` 的 `eret` 前显式将 `x2..x30` 清零。

## Alternatives considered

- 在 `pager_supply_one` 源 `read` 失败时直接中止不落零页：拒绝——用户态 `sys_pager_supply_pages` 收尾无条件唤醒缺页线程，`DPGN ③` 明确契约受验子须读到零页并以码 `9` 退出，而调用方收到 `BERRY_ERR_BAD_STATE` 且不置 `zfod`。
- 不区分 `CTR_EL0.L1Ip` 一律只跑 `ic ivau, kva`：拒绝——VIPT 指令缓存在高半 `kva` 与低半用户 `va` 索引位不同色时会漏刷异色组，跨地址空间填页时对 VIPT 走 `ic ialluis` 才能根除别名残留。

## Consequences

消除 `DC ZVA` 误判导致的 EL1 未定义指令风险、代码页装填指令缓存失步、按需供给半填页并发可见窗及 EL0 初始寄存器内核地址泄露；稳态 `vmo_commit1p` 热环保持 64 次 `dc zva` 零额外指令开销，`berry-memface` 12 项宿主机单测与内核 `ktest` `test_vmo` 装叶前未映射断言全部通过。
