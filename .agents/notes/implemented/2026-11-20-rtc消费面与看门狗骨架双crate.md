# 驱动波 2 清偿双件：RTC 用户态消费面 + 软件看门狗骨架

Status: implemented

## Problem

[驱动子系统综合研究报告](../../research/2026-11-18-驱动子系统综合研究报告.md)在册的两项波 2 清偿缺口，共性是「内核/协议半件在席、用户态公共消费面为零」：P1-7——RTC 壁钟内核侧已有（fw_cfg `opt/berry/rtc` 宿主注入 epoch + 单调锚，`berry_clock_read(CLOCK_REALTIME)` 出 ns；[波一刀 B](2026-11-13-wave1-knife-b-statusbar-trust.md) 后 launcher 帧循环已每轮回读续摆），但用户态零公共消费库——launcher/appshell 各自单点自持（直取 syscall + `hhmm_utc` 的 ns 口径 5B "HH:MM" 面），秒级/日期级历法换算全仓无处可拿；P1-10——看门狗完全缺失，且 QEMU virt 机本就没有 WDT 设备（报告明言全仓 watchdog 一词全是 svcmgr 进程错杀断言语义），硬件面短期无从谈起。

## Decision

同批两刀、各自成 crate（[驱动波 1 三件套](2026-11-20-驱动波1三件套.md)同款验收形态），均 berry-softime 家族：`cfg_attr(not(test), no_std)` + host 测试、syscall 面 `cfg(not(test))`（berry-fsclient 纪律——host 测试二进制零 svc 面）：

1. **`user/berry-rtc`（消费面）** = `read_epoch()`/`read_epoch_opt()`（经 berry-sys `CLOCK_REALTIME` 单源 syscall，ns→s 截断；缺席 → None，unwrap 口径 0 兼双义）+ 纯函数历法换算：`hhmmss_utc`（恒 8B 等长 "HH:MM:SS"）、`ymd_utc`/`ymd_utc_text`（年-月-日，核心 = 简化儒略日算法——Howard Hinnant civil_from_days 形状：+719468 平移到 3 月起年 → 146097 日/400 年 era 分解 → `(5·doy+2)/153` 月序，闰年判定收进 era 算术无分支表；u64 epoch 恒非负 → 负值支路整体裁掉）。向量全部 Python datetime 独立对拍钉板，闰年三类边界（4 年闰/100 年不闰/400 年闰）各占独立断言。
2. **`user/berry-watchdog`（骨架）** = 纯软件超时窗：`new(timeout_ms)` 装表即锚定、`kick(&mut self)` 喂狗（内部取单调钟锚点）、`is_expired(now_us)` 查询（注入时刻——库零 IO 纪律同 berry-partition 读盘闭包）。时基 = 单调钟 µs 单源经 berry-sys（REALTIME 绝不作看门狗时基——壁钟可跳，跳后要么假超要么永超）；到期判定含等号（恰 1000ms 已超——「到期即咬」口径显式钉板）；host 测试注入 thread-local 假钟（每测试线程天然隔离，并行测试零竞争）。

两 crate 均入 user/ workspace members；真消费接线挂账后续刀，本刀纯新增零行为变化。

## Alternatives considered

取时走 svcmgr RPC 而非直 syscall（弃——`CLOCK_REALTIME` syscall 已在席且 launcher 先例即直取，RPC 多一跳零增益）；日期换算走月累积查表法（弃——简化儒略日算法无表无分支、闭式算术教学可见性更好，且 u64 域免闰年分支即免整类边界 bug）；`kick` 改带 `now_us` 参数（弃——三口契约按任务书钉死为无参 kick，内部取时 + 查询注入的混合面已够教学演示，真硬件刀只换 kick 内芯不动契约）；假钟用全局 static（弃——cargo test 并行多线程下共享 static 必然互踩，thread-local 每线程一份零锁零竞争）。

## Consequences

2026-11-20 主仓工作树验收全绿：`RUSTFLAGS="" CARGO_TARGET_DIR=cargo-target cargo test --release -p berry-rtc -p berry-watchdog --target aarch64-apple-darwin` 计 8 测零败（berry-rtc 4 + berry-watchdog 4，含任务书场景 new(1000)→kick→999ms 未超→1001ms 超）；两 crate 另验 aarch64-unknown-none（workspace 缺省 target，build-user 全量构建纪律面）可编，rlib 落盘。新增源文件 4 件（两 Cargo.toml + 两 lib.rs），members 追加 `"berry-rtc", "berry-watchdog"`（该行同批有并行 lane 的 berry-hal 追加——各自独立追加互不吞并）。挂账下刀：launcher/appshell 的直取 syscall + `hhmm_utc` 自持换算迁经 berry-rtc 单源（ns 口径与 "HH:MM" 5B 形态随之归一裁并，一事实一归属）；监督进程（svcmgr 对 launcher 卡死检测）喂狗接线 berry-watchdog；真硬件 WDT 驱动随真机波次。`read_epoch` 的 0 哨兵与真值 1970-01-01 兼双义，消费面需区分时用 `read_epoch_opt`。
