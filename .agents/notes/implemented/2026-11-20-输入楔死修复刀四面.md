# 输入楔死修复刀（观测面+自愈面+撤互截+aged 验收门）

Status: implemented

## Problem

云桌面真机场放久后触控全死（新靴 22-30s armed 内注入实变、13 分钟间歇注入全活、约 10 小时闲置后 abs/btn/键盘全零反应且 screendump 像素零变），而 gui8 冒烟恒绿——armed 即测即退的结构性盲区（[rejected 判例](../rejected/2026-11-20-云桌面多客户端架构根治.md)明文记录）。死时零串口痕迹：launcher 帧循环活着（状态栏时钟分钟级精确=分钟摆字帧在跑）、inputd 进程活着（零 G1.5 零 trap 行）、无任何错误诊断行。scout 四路定谳排除面：wm TABLE_WAIT 悬挂是正交信标非凶手（旁注纯内存不改 wire）；inputd 静态面无时变死态（唯一无界楔点 send_rep EBUSY 环判结构性不可达）；键盘零反应是活面固有属性（pump `on_key` 默认空实现，回退摘掉了消费端）。

## Decision

四面修复，每面独立成立（无论真凶是谁都必须修）：

1. **pump 输入面自愈**（`user/berry-appshell/src/pump.rs`）：单在途 INPUT_POLL 的死相=应答丢失后 `input_pending` 永真永不再挂、无客户端超时无自愈——`INPUT_STALE_CAP_NS=60s`（两个服务端 30s 帽周期）超时即非阻塞排空+复位+重挂，diag 行 `input poll stale-reset n=… drained=… age_ns=…`。strand 是一切候选机制的共同终末通路，客户端超时直接治形态。残余竞态两向入注（迟到旧应答至多一条自纠；服务端被饿 60s 形态下新鲜应答被弃一批，一次性自愈）。`input_logged` 假阴性旗退役（events/EAGAIN 行改 100 应答采样，错误路径保持必打）。
2. **inputd 观测面**（`drivers/bins/gui-inputd/src/main.rs`）：60s 周期 tally 行 `gui-inputd: tally h= p= e= q=/`（收割对账=两泵 u16 游标 wrapping 差、polls_served、SEND_EBUSY 累计、两泵待取深）+ 每 10 拍 wm 态行——两级定位面：行缺席=环停转，行在场计数冻结=收割/应答停。send_rep EBUSY 分支幂次节流打印+静态累计。观测纯旁路零控制流扰动。
3. **撤 app INPUT_A dup**（`user/bins/svcmgr/src/main.rs` ④ 段）：单 FIFO 多消费者应答互截禁例（[全冻刀 fix#2](2026-11-20-应用内全冻与导航三键零反应根治.md) 首撤随全量回退复活）再撤——app 侧 `input_h()` 结构性恒 0 静态页降级；占位 dup 与 wm 装配不动；清理面死分支保留注明（重做刀回装即复活）。
4. **gui8 aged 用例**（`tools/gui8-smoke.py`）：`--aged-minutes N` 默认 0——click ready 门后注入前静置 N 分钟，堵 armed 即测即退盲区；旗域校验（非有限/负值拒绝；`--normal-boot` 组合显式拒绝）。

## Consequences

验收：`just image` 全链绿；gui8 常规 PASS + `--aged-minutes 2` PASS（双 boot A: CLICK ok n=1 延迟注入成立）；真机场（phone 档 hvf）注入验活屏幕实变、tally 行实拍在席。对抗审查 16 agent（4 find+12 verify）：11 confirmed=1×P2+10×P3 零 P0/P1——P2（aged 旗静默忽略）与全部 P3 已修复批收口（注释精化×5、volatile 对称化、死分支注明、[files 头注](../../../user/bins/files/src/main.rs) 勘正、旗域校验）。

**当晚二捕（观测面首战 30 秒破案）**：真机场「进应用即卡」再发——serial 实拍 `release count=0 nh=0`（launcher fail→park 永死行）+ tally 计数冻结（h 冻结 p 冻结）+ 泵队列 32 满 + stale-reset 零。定谳：非时变真凶，是[全冻刀](2026-11-20-应用内全冻与导航三键零反应根治.md)已修成宽容的 `count<1→fail` 断言随架构刀全量回退复发（回退清单过宽带走好修）。修=宽容复原（`rel.count != 0 && nh != rel.count` 才 fail；count==0=他客户端跨代清账排空本端别名，本帧 PRESENTED 已先断言=早归还良性；随行 handle 不论归属全量 close）。验收：单测 34 绿 + gui8 PASS（首跑撞 LOADGEN A5 时序断言环境假红，负载落窗重跑绿）+ 真机场进应用三步演练（点图标开→再点有反应→后续点击证活）+ tally 健康（q 排空零 EBUSY）。真凶（放久死触发器）仍在逃：逮捕面已预埋——tally 行定死亡时刻与停转层级、stale-reset diag 即时坐实 strand、EBUSY 计数、宿主巡检哨定时注入探针。已知限制：app 静态页降级（输入交互归 inputfeed 重做刀私有通道面）；观测面行可迟到 90+10k s（巡检按 ≥2× 周期立案）。插曲记账：仓库默认 `./target` 陈旧整树连发 E0432 假红（清 3GiB 根治）。Related：[云桌面多客户端架构根治（否决）](../rejected/2026-11-20-云桌面多客户端架构根治.md)（前刀与重做门）、[主线基座输入差異调查](../../research/2026-11-16-主线基座输入差異.md)（同病未结前档——其三嫌疑已被新靴活证据击杀，案卷应翻 historical）。
