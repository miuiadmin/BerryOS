# inputd 在途 WAIT 悬挂强制重发（I3）

Status: implemented

## Problem

wmd 停摆根治刀（SPEC-wmdstall，四路勘察 2026-11-19）S3 定谳的 inputd 侧实锤弱点：降级重探测 `wm_probe_if_degraded` 的 outstanding 门控在「wmd 死于 WAIT 在途」形态下门永闭——上一条 WAIT 随 wmd 进程蒸发永无应答 ⇒ `outstanding` 永真 ⇒ Q11-③ 重探测一次都不发 ⇒ 降级安全网在该主形态零作用。配合 I2 同通道重启（推送面对复活），门永闭 = 重启后推送链仍不复通——I3 是复通链的最后一块。

## Decision

**方案 = 三件全落 drivers/bins/gui-inputd/src/main.rs（guest mod）**：

1. **悬挂判据与强制重发（SPEC §3 本体）**：新 `WAIT_HUNG_CAP_NS = 15s`（超龄帽 10s + 裕量——健康稳态「表安静、唯一 WAIT park 在 wmd 席上」在途超 10s 属正常，裕量把强制重发压到快照判降级之后）+ `WmCache::wait_ns` 在途龄打点（`wm_send_wait` 置位）。在途超 15s 视为悬挂 → 强制清 `outstanding` 重发一次 WAIT(0) + 一行诊断（`wm WAIT 在途悬挂`）；单发帽 `forced_sent` 按悬挂段计（上次应答以来至多 1 次，任一应答回充）——不对死通道连发。wmd 活则立即答现快照（版本推进即重归 park），死则入死通道惰性无害；I2 重启后队列承接即复通（T5 仿真证：≤10s 盲窗后 parked 归位）。
2. **重臂侧同版本不重臂（回声环截断——SPEC「自持回声环防线保留」的真实现）**：`wm_on_reply` Ok 路改「版本推进才重臂」。机理：wmd `table.wait` 同版本到达即位移旧 parked（位移者现答现快照、不 bump version）——强制 WAIT(0) 的现值应答（version == 本端已持）若照常重臂 WAIT(现版本)，会位移仍在席的旧 parked → 位移应答 → 再重臂 → 再位移……RTT 频自持回声环（静止桌面被点燃成常转 ping-pong）。SPEC 指望的单发帽不足以截断（环一旦点燃自持、无需二次强发）——反事实仿真：无截断时一次强制重发 120s 内 1048 次位移，有截断 0 次。截断后安静表转 10s 探测保活（快照每拍刷新，旁注/粘滞锁在长安静期不再超龄降级——功能面改进）；旧 parked 仍在 wmd 席上，表一变即由 bump 应答归位、本端按版本推进重归零流量 park 态。
3. **tally 迁沿记账单源化**：`degraded` 清位从 probe 按龄早退路径移除、单源收口在 `wm_on_reply` 版本推进分支——防保活期超龄振荡（每 10s 一拍）逐拍重打 tally 行；tally「每安静段恰一行」的既有节律与内容零漂移（markers.sh 零 inputd 行引用，构造核对过）。

## Alternatives considered

只按 SPEC 单发帽不加重臂截断（弃——仿真证回声环点燃自持，静止桌面全灭）；强发 WAIT(现版本) 替代 WAIT(0)（弃——同版本即位移，点燃更快）；悬挂判据做成可区分 wmd 死活（弃——内核无死端信号、安静表无版本变化面，15s 龄原理上不可区分，只能重臂侧兜底）；探测/重臂状态机抽 lib.rs 做 host 测（弃本刀——guest mod linux 门控结构性不可达，SPEC §4 测矩阵未含，挂账审查相裁量）。

## Consequences

gui-inputd host 台账 41 测零破（justfile test-host 行）+ musl check 零新警；`push == 0` 单通道路径零字节变动（46 标记面构造保证保持）。新可观察行为：安静表 >15s 每段恰一行「wm WAIT 在途悬挂」+ 10s 探测保活流量（约 300B/10s）；僵尸（应答被丢——I1 §1.6 send_rep EBUSY 丢帧面）≤10s 自愈。已知残余：死通道悬挂段强发一次后仍归于零发（单发帽语义；探测死通道本无收益，复通靠 I2 重启）；同版本应答不清 `degraded` 使「僵尸恢复后接安静表」的段内不再重打 tally（forced 行兜诊断）；wmd 侧 `table.wait` 位移路径从 inputd 行为面变为结构性死码（防御面保留不删）。Related：[wmd 监督一次重启（I2）](2026-11-19-wmd监督一次重启I2.md)（同通道重启=I3 复通前提）。
