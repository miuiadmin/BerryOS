# devmgr v1：MMIO 槽枚举 + 驱动匹配 + 服务状态报告

Status: implemented

## Problem

[驱动子系统综合研究报告](../../research/2026-11-18-驱动子系统综合研究报告.md) §4.2 交付 1.1（devmgr 最小面）是波 1 制度化的主体件：设备发现至今靠驱动自扫 MMIO 槽（vprobe 先例）+ svcmgr 点名拉起，无统一「设备清单 → 驱动归属 → 服务在席性」的观察面。devmgr v2 五件事（DTB 枚举 → 资源池 → 匹配 → 授权 → /svc 注册）是千行级主体且依赖 DTB walker 建池，v1 先落纯观察半边：MMIO 槽枚举 + 驱动匹配表 + 服务状态报告 + 缺失告警，不授权、不拉起。

## Decision

新增 `user/bins/devmgr`（约 470 行），四层取舍：

1. **lib/bin 双面（guifbd 先例）**：lib = 枚举/匹配/报告纯面——`SlotReader` trait（真机 MMIO volatile 与测试 mock 数组同契约注入）+ 静态 `DRIVER_TABLE`（blk=2→vblk / net=1→vnet / input=18→gui-inputd / gpu=16→guifbd）+ `SvcLedger` 账本视图 + `render` 单源渲染，host `cargo test --lib` 10 测；bin = guest 接线（窗 volatile 读 + psproto RPC）。独立小工作区（musl std 链，`exclude` 入 user/ workspace——std bin 进 members 会在 none-target 全量构建炸响，stdhello 先例）。
2. **服务状态 = svcmgr ps 账本**：v1 无 `/svc` 命名空间（v2 设计位），现役等价物 = berry-psproto PS_LIST 应答里的账本行名 × ALIVE。通道契约 = ps 同款 env 块 gift[2]（`gift2_h()`），缺席 = 状态降级 unknown 不致命（枚举报告仍完整输出）。账本行名与驱动名分立两字段——gui-inputd 的注册名是 `inputd`（svcmgr `ps_reg` 实录，8B 帽内短名）。
3. **零触碰 svcmgr**：两硬墙——svcmgr 平像 160KiB 恰满帽零余量（CP-08 双改 by design）、ps 账本 18 行恰满 256B 帧帽（19 = 268 绝壁）；加 spawn 段即撞双墙。v1 拉起契约文档化：窗 = `SpawnSpec::mmio_vmo` 授能（vprobe 同款，EL0 永不自造物理窗），通道 = gift[2]；svcmgr 接线（授窗 + gift + smoke `DEVMGR ok` 标记）留独立刀。
4. **接入面**：justfile build-user 加构建行（gui-inputd 段后，ps/guifbd 同链）；rootfs 条目走 tools/rootfs-manifest.toml（svcmgr `cpio_find` 点名制不识即零扰动——rootfs 64 条目/boot 链/smoke 全零漂移）。manifest.toml 按任务书字面交付但注明：vblk 实无 .bap manifest（manifest.toml 是 mkapp 应用包件，系统服务族从不配），该文件 v0 词表纯自描述、mkapp 链不消费；真接入 = rootfs-manifest.toml 条目。

## Alternatives considered

改 svcmgr 加 devmgr spawn 段 + ps 通道 gift（弃——平像帽与帧帽双硬墙，且超「v1 只做枚举+报告」最小面，接线刀另立）；devmgr 入 workspace members（弃——musl std bin 不可能在 aarch64-unknown-none 编译，exclude 是 stdhello/appdemo 家族先例）；发明 `/svc` 查询协议（弃——v2 设计位，v1 用 ps 账本现役等价物，零新协议面）；未知 did 直接 trap（弃——vprobe 是 boot 链断言件 trap loud 守门在前，devmgr 是管理器全景观察者，WARN 不死两职责互补）；bad magic 降级跳槽（弃——窗口几何错是全局性异常非单槽事件，整枚举 Err + exit 1）。

## Consequences

2026-11-20 验收全绿：`just build-user` 全链通过（rootfs.cpio x64 条目，devmgr ELF 331KB 入 rootfs0 卷，tlsscan 全过）；host `cargo test --lib` 10 测零败（mock 总线盖空线/混合总线/坏魔数/legacy 槽/三态账本/未知 did/单复数语法）。报告形态（host 测试对拍钉板）：`devmgr: 3 devices: [slot 4] blk → vblk ✓, [slot 7] net → vnet ✓, [slot 30] input → gui-inputd ✗` + `devmgr: WARN: … not registered (state: absent)`；无通道时状态符降 `?` 并前置说明行。下一刀：svcmgr 接线（授窗 + gift + `DEVMGR ok` smoke 标记——报告 §4.2 验收谓词）；再远：v2 DTB 枚举建池 + berry-driver `ProbeResult` 全记录消费做认领仲裁（[berry-driver 笔记](2026-11-20-berry-driver统一Driver-trait框架crate.md)已留接口位）。
