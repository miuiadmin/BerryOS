# 模拟器性能止血刀——点击复活/wgpu 呈现修通/两段式采集/光栅行级/开机自测门控

Status: implemented

## Problem

owner 痛点（2026-11-18 钦定「最严重问题」）：模拟器「点不动、帧率起不来、卡成 PPT」。前会话（agy）诊断并获批准的止血三件零落地即死于配额；本刀以四路勘察现场重核后实施——勘察修正旧诊断三处（「vgpud」不存在=命名幻觉，真身 guifbd 进程内双后端；「宿主盯死面」方向反了，vgpu 路仍 CPU blit 同一 fb 窗、RamSource 镜像恒活、死面只在外接 VNC 侧；「33fps 铁锁」宿主码无此常量，节拍帽=16ms 轮询）。契约：/tmp/fps-firstaid/SPEC-fps.md（仓外快照）。

## Decision

**四阶段 workflow**（scout×4→impl×4→对抗审查 2 条全 REFUTED→修复回写→串行验证），对应重构计划 G0-3/G0-4 提速加强版：

1. **I1 host 窗口面**（window.rs+wgpu_pres.rs）：点击吞掉根因=last_fit 唯一赋值点在 present 成功即提前返回后永远走不到的死分支——修为 wgpu 成功路正确落值（scale::fit 单源、poll_rotate 补清、select_profile 保持）；wgpu 呈现三连修=SHADER_BLIT 接进 binding-2 overlay（原每帧 7.4MiB 白烧+工具栏隐形）、uniform rect letterbox+TOOLBAR_H 预留（原全窗拉伸与 pointer 映射几何分叉）、r/b 通道序+alpha 覆盖写（原按钮文字全透明）；ui/rgba 双 7.4MiB 每帧分配字段化持久+overlay 六元签名条件重传+frame_seq 客帧不变跳 upload_full；softbuffer 段逐字零漂移；build_pipeline 单源化进 headless 测试网（Metal 真跑校验）。
2. **I2 host 输入采集**（qmp/web/ram/device）：原生窗口点击 QMP 化——QmpInjector 从 web.rs 迁出共用（guarded 2s 守护、失联永久哑化走 RFB msg5 保底），修第二层丢失（QEMU 11 VNC 对裸 RFB 丢绝对坐标——浏览器路已被 9c77f180b 拦截器救、原生路本刀补齐）〔2026-11-20 勘正：该判例已被驳斥——丢绝对坐标仅发生在不发 SetEncodings 的裸客户端形态，浏览器路本就直通可达，见 ../../research/证据快照/2026-11-20-VNC直通绝对坐标判例驳斥.md；拦截器随之退役在途〕；ram.rs 两段式读（512 签名点 4B 先读、变化才全帧——微基准 8.3MB→2KB/拍、296.9µs→143.2µs）。
3. **I3/I4 客机面**：raster.rs fill/fill_round 行级切片写（运行时对齐分支）+smooth_argb cy 行级外提（I3 的 cx 定点递推被 I4 A/B 九几何载具证伪——行间状态漏播种第 2 行起 75% 字节错、单行钉板全绿掩盖——终态回直除+外提，对 HEAD 逐位一致+汇编写实 3→2 sdiv/px，S3「每 px 两除」锚不成立、性能主张全部降级待 telem 实测）；launcher 开机自测门控——规格字面 !smoke 门会炸三门（gui8 靴 B/normal-boot/smoke-image 都断言 PAGE n=2 却无 smoke 旗），改 **rtc 键缺席臂**：四种 smoke 形态拓扑上零 fw_cfg rtc、宿主 berry 恒注 SystemTime——smoke 照打标记、真实桌面开机不再自动翻页抢输入。
4. **审查卫生项**（驳斥裁决采纳）：QMP 不排空响应的「流控自毁」论被 QEMU 11.0.3 源码+百万事件饱和探针推翻（monitor 无界 outbuf、永不因积压停读）——正确性依据注释诚实化 + pointer() 内 ≤64KiB 有界顺手排水（压 QEMU 侧 RSS 爬坡）。

## Alternatives considered

wgpu overlay 弃用改 QEMU 侧 UI（不可行——工具栏/菜单是宿主功能面）; mmap 零拷贝采集（引 libc 直依——两段式纯 std 先行，mmap+帧序号边沿另刀）; guifbd 页直映 10×（RIGHT_MAP+映射生命周期=中等刀非止血）; 光栅 NEON 显式向量化（首刀纯 Rust 行级+外提，NEON 归后续）; 拓扑单 GPU 化（BERRY_NO_VGPU 逃生阀已在，宿主窗不受脑裂伤害不必动）; 性能虚标（I4 汇编级证伪后全部转实测口径）。
