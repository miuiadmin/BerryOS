# berry-ui 六缺陷修复批（B1/B2/B5/B6/B7/B8/B9）

Status: implemented
Type: note
Date: 2026-11-15
Scope: user/berry-ui（src/{lib,layout,paint}.rs + 伴随钉板）

## 为什么

深度审计发现 6 bug + 多个渲染问题，本批按优先级修复最关键面。共同根因：
波 2 控件底座各批「半成品接线」——数据面（desc.rs）先立、布局/渲染/生命周期
面滞后，产生两面漂移与状态泄漏。

## 改了什么

| 项 | 面 | 修法 |
| --- | --- | --- |
| B1 | lib.rs add() 白名单 | 补收 `ViewKind::Refresh`（desc.rs AST/builder 面本就按容器受理——两面漂移收口） |
| B2 | lib.rs remove() | input_bufs 条目槽位命中被删子树 → 剔除（紧凑表就地压实）；focus 指向被删子树 → None（a11y 槽位匹配同律） |
| B5 | layout.rs place_children | 新增 List 臂：行序子 y = i×item_height、宽吃满、行槽高 = item_height（原落 `_` 兜臂全叠 (0,0)） |
| B6 | layout.rs intrinsic | Tabs 子高聚合 Σ → max（place 面 z 叠放，Stack 同形；Σ 会虚高内容区） |
| B7 | paint.rs Button | Outlined/Text 三态查表（Filled 同律 disabled > pressed > normal）：disabled 框/标签 FG_DISABLED；pressed 描边/标签 ACCENT_PRESSED |
| B8 | paint.rs Seg/Tabs | 末段宽吃整数余数 b.w − sw×(cnt−1)（整除零漂移、非整除补齐右缘） |
| B9 | paint.rs Input/Edit | caret 垂直与文本居中同式 (h−16)/2（Input 48 高 +14→+16；Edit 首行带 h=40 → +12） |

## 为什么这么改（关键取舍）

- B2 槽位匹配而非全 id 匹配：与 a11y 清理同律——gen 推进后旧 id 悬空，
  槽位命中即「本子树成员或既有残项」两清皆正确；防槽位复用后 input_text
  串读新节点内容。
- B6 复用 child_agg 两次（vertical 取宽 max + horizontal 取高 max）而非
  新 helper：最小改动面，聚合口径仍单源。
- B7 pressed「暗色」= ACCENT_PRESSED 单源（本模块唯一按压暗档常量），
  不另立灰色暗档防色板双源。
- B8 只动末段宽、不动分隔线位（sw×i 仍是正确段界）。
