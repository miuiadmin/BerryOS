# 总攻批3 生命周期终态——重开=聚焦+僵尸窗销毁+LRU 驱逐+位置敏感工程解

Status: implemented

## Problem

总审计（仓外快照）app-lifecycle 路三缺陷与 input-chain 双击闪现消费端半刀的收口刀（总攻批 3，commit 3ae47c81a）：① P2「重开=杀重启」——同 id 活实例的窗仍在场（覆盖态点回图标/多任务键重拉）时，svcmgr `app_serve_spawn` 的同 id 回收再开路先杀旧再拉新，用户切回意图被读成重启，应用内容全丢；② P1 僵尸窗——强杀/崩溃 app 的窗滞留 wmd 表（死亡对账 DETACH 摘表/轮询段 Dead 只摘通道不销窗），占 WM_WINDOWS_MAX=15 槽且滞焦；③ P3「驱逐序 FIFO 非使用序」——槽满驱逐按 spawn_ns 入表序选老，正在使用的 app 被静默踢；④ 双击闪现（[双击长按 referee 语义](./2026-11-21-双击长按referee语义.md)挂账的消费端半刀）——双击第二击撞覆盖态收盖（开→关）或撞 svcmgr 同 id 回收（开→关→重开）即闪现。随批清偿批 2 提交漏装债：pattern.rs 五处 on_msg 穷举臂。

## Decision

四面主修+两项随批：

- **重开=聚焦（svcmgr+launcher 两面）**：svcmgr 侧 `app_serve_spawn` 同 id 命中前置窗在场判据 `app_alive_win_present`——经 `WMD_CLI_DUP` 临时 dup（RIGHT_SEND|RIGHT_RECV，用毕即关，sub_dup 先例；svcmgr 单线程独占，cli 侧 FIFO 无第二读者，应答互截禁例结构性不达）发 OP_WM_TABLE_GET：预排液（上轮帽到滞留控制通道 cli 侧的陈旧快照帧先清）+10s 短帽（复用 WM_DETACH_CAP_NS——同值同理由：伙伴服务 RPC 不用 60s 族长帽，失败一次不阻回收决策）收全表快照；判据 = 可见 ∧ APP 层表项 ≥2（launcher 恒恰一枚桌面自窗且状态栏是 SYSTEM 层——APP 层可见窗数 1=仅桌面、≥2=至少一枚应用窗在场）；任何失败面（wmd 未起/dup 败/发送败/帽到/畸形）= false 保守归窗不在场走现状回收路（查询失败零新行为面）。窗在场 = 切回意图：eco `alive` 行 + 已活形回执 err=3（appproto 耦合律零改——ok=0 携非零理由码即合法帧，库头「err 值域 v1 无分类面」明文留位），活实例 last_touch_ns 就地刷新，拉起面整段跳过（sig_guard/app_launch/槽位写入全零动作）；窗不在场/查败 = 维持回收再开。launcher 侧 `spawn_by_id_inner` 增 `(false,3)` 特判臂 `focus_alive_app`——经 wm_cli_h() TABLE_GET 查表定位应用窗（可见 ∧ 非自 ∧ APP 层，焦点窗优先表序兜底——已活形态下应用窗即覆盖窗）发 OP_WM_FOCUS；像素面零动作（v1 无合成器共享 fb——已活窗像素本就在屏，FOCUS 只授焦点态：back 键路由面/输入路由面）；返回 true（「已活且已切回」记账语义成立），`note_spawn_ack` 对 (false,3) 不递增 spawn_ok（CLICK 标记面与覆盖态门零漂）；查无窗/聚焦败 eprintln 诊断（TOCTOU 形窗已亡，下一击走回收再开路自愈）。多任务键重拉经同路 = 真切换主场景。
- **僵尸窗销毁（wmd）**：窗表 `Win` 增 `owner` 域（CREATE 到达通道记账）；app 通道两条死亡对账路随行 `destroy_owned` 逐窗 `destroy_internal`（evt 通道关联关闭+refocus+recompute+bump 广播——launcher/订阅者表跟随自动收新表重画）：`app_detach`（DETACH 摘表 = 死亡面主形态，svcmgr 收口强杀/崩溃 app 后主动发）与 `poll_apps` 轮询段 Dead（病态死亡兜底路——强杀恰留满队未读应答时 wm_detach_rpc 放弃即靠本面收口）。wm_srv 窗恒不触发（boot 定值柄不在 apps 表，其死亡 = wmd 整体重启链，不归本对账）。强杀 app 的窗不再僵尸占 15 槽、不再滞焦。
- **LRU 驱逐（svcmgr）**：`AppSpawnTail` 增 `last_touch_ns`（拉起时与 spawn_ns 同值起算）；槽满驱逐选老序源从 spawn_ns 让位 last_touch_ns——alive 路刷新 = 正在使用不误踢；无刷新源时恒等 spawn_ns，驱逐序退化回入表序 FIFO 行为零漂；spawn_ns 降为入表序审计面。
- **双击闪现收口（launcher 兜底面）**：`LoopHost::spawn_dedup` 幂等窗——最近一次点击路 spawn 成功的 app+其 ok 回执时刻（on_click/on_sys_click 成功支路落账，多任务键重拉不入账）；同格 Click 在 SPAWN_DEDUP_WINDOW_NS=2s 窗内整击吞掉（先于 covered_tap 收盖——收盖恰是开→关闪现的第一路；也不二次 APP_SPAWN 撞 svcmgr 同 id 回收）；back/home 一击即撤窗（退回手势 = 蓄意离场声明，其后再点图标 = 蓄意重开，窗不得吞）。正解 = already-alive 路承接活实例第二击，本窗只兜其未接住的残余竞速（第二击先到、回执仍为 ok 形的应用冷启动建窗竞速窗）。
- **位置敏感工程解（二分定谳）**：app_serve_spawn 体内直放窗在场查询（+1.3KB）触发确定性 dpg 子崩——位置敏感非语义（垫料@别处 1.7KB 无害/语义中和无害/纯体积即崩；机制疑 ELF 装载边界，深查立内核刀挂账）；解法 = already 判定抽 `#[inline(never)]` 转发函数 `app_spawn_alive_gate` 钉文件尾——spawn 主体体积回基线，probe 逻辑体落文件尾安全区（后续[回收循环泄漏止血批](./2026-11-22-回收循环泄漏止血批.md)的 spawn_nomem_exit 同款纪律）。
- **批 2 漏装清偿**：pattern.rs 五处 on_msg（SwipeItem/DragReorder/Sheet/Drawer/Refresh）补 DoubleClick/LongPress no-op 臂——批 2 提交漏装该文件（工作树在席故本地面绿），本批入库。
- **回收门 v2（gui8-recycle-gate 换载具三段制）**：图标首击 it → 同图标二击 alive（聚焦路零 recycle 零新 it）→ back 键销窗不杀进程（真泄漏形载具——窗不在场才走回收）→ 同图标三击 recycle；断言 it→alive→recycle→killed→it 行序 + 零 noEOF + 三击时延帽（烧帽回归 +60s 必爆帽；旧两段制的多任务键二击在本刀后恒走聚焦路，门必须分形断言两路）。

## Alternatives considered

- **窗在场判据只查 svcmgr 本地表（同 id 活 = 窗在场）**：back 销窗未退的真泄漏形（窗亡进程在）会被误判聚焦而聚焦无目标窗——wmd 表是窗面唯一真相源，弃。
- **聚焦 = 重发 SUBMIT/重画**：已活窗像素本就在屏（共享 fb），重画多余且涉 app 协议面——OP_WM_FOCUS 只授焦点态，弃重画。
- **双击闪现根修 = launcher 改吃 DoubleClick 不吃 Click**：referee 刀 add-only 取舍下 Click 首击二击照产，消费端无依据区分单双击意图——幂等窗保两次 Click 语义零漂（审计 fix 文两选项中的另一项，弃）。
- **位置敏感先深查内核 ELF 装载边界再上语义**：深查立内核刀挂账（长周期）；工程解（inline(never) 文件尾）零语义风险先行解封本批语义面，弃先查后上。
- **驱逐维持入表序 FIFO 不动**：审计 P3 已判缺陷（正在使用的 app 被静默踢）——LRU 升级收口，无刷新源时退化 FIFO 零漂，弃不动。
- **回收门维持两段制**：本刀后同位二击/多任务键重拉在窗在场时恒走聚焦路不再回收——门换三段制（back 销窗前置）才能同时断言聚焦与回收两路，弃旧形。

## Consequences

- 重开语义终态：同 id 窗在场 = 切换不重启（内容不丢）；窗不在场/查败 = 回收再开（现状路零新面）。eco 分诊新增 `alive` 行（已活回执可见化——与 it/killed/nomem 同面排障）。
- gui-wmd host 38 测（含僵尸窗销毁 2 新）全绿；gui8 全跑 PASS + 回收门 v2 + 酷刑 v3（18 步含聚焦/双击，85 拍零积压；alive=0 为覆盖态收盖语义正确性——collapse 即销窗，alive 路候 recents 重拉形态激活）。
- 批 2 Msg 扩域的 swipe.rs on_msg 臂与 click_timing.rs 七测仍为工作树在途件（referee 刀代码余量，随代码侧收尾入库——本批只清偿 pattern.rs 五处）。
- 挂账：位置敏感 dpg 子崩机制（疑 ELF 装载边界）立内核刀深查；本刀后 20 轮连点门暴露帧面泄漏——[回收循环泄漏止血批](./2026-11-22-回收循环泄漏止血批.md)接刀。
