# 跨根收口合并：main 显示线并回 wip/sched-1.1（fork 点定谳法）

Status: implemented

## Problem

main（根 f7eb5535，2026-08-03）与 wip/sched-1.1（根 afd68392，2026-11-14 整树导入的孤立根）无共同祖先，两线并行三天（main 落 refresh 刀1-6 + cbox 刀1-3；sched 落 TCP 四刀/SMP/遥测/调度演进），整树硬合的冲突面实测 348-350 全 add/add。owner 裁定立即收口（「要合，不然越分叉越大」），经逃生阀 `BERRYOS_ALLOW_CROSSROOT=1` 执行。

## Decision

fork 点是已知的（sched 导入时 main 的形态 = e1a31fc21，2026-11-12 tip），据此把 350 冲突分域定谳：

- **机械 315**：7 件 main 单改取 main、308 件 sched 单改或双静取 sched（双静抽样证实 main 侧 fork 后零改动）。
- **ABI 链 6**：abi.toml 并集（0x42 cbox_drain 与 sched 四号零撞号）→ `gen_abi.py` 五面再生 + NO_GATE 豁免 + 文档计数锚 40/39，abi-check PASS。
- **双改 35**：merge-file 三方 + 三批 subagent 逐块解 + 主线复核。
- **关键工程事实**：merge-file 的自动合并区在犬牙交错文件上会**静默丢 ours 静区内容**（ktest 1800 行/主侧 580 行实证）；正解 = 以 HEAD 真源全量重建 + `git apply -3` 移植 main 自 fork 的增量补丁（净增量重放形态）+ multiset 两向审计（35 件从数千行残差收敛到 197 行已记录改写）。多亲提取用 `git rev-list --parents`、事务状态认位置参数两坑沿用防线笔记。
- **治理并账**：ADR #65 撞号按让先落者律让号（API 治理章程预留改 #87）；fwcfg 键表收编 main 三旋钮（panel-model/mode/fault，24 键对拍过）；索引去重重数（126 份三不变量绿）；docs 根 5 个 ours 已升版的 stale 旧件移除（历史在 main 亲可溯）；justfile test-host 增 cbox 两测；launcher L-SYS 版本治理回 0.2.0。

验证：`just build` 全链绿（内核+musl bins+mkapp+docs-guard 八门）；abi-check 五面单源 PASS；fwcfg 24 键对拍过；berry-cbox 10 测 + berry-guiproto 65 测全绿。QEMU smoke（EFI 相 + 刀6 双 boot 段新标记）留低载窗补跑挂账。

## Alternatives considered

- 净增量重放 refresh 刀（35 文件）但不接历史：分叉继续增长，不满足 owner「焊死分叉」诉求，弃。
- graft/replace 假接根：两树 fork 点就差 660 文件，假基不减冲突面，弃（防线笔记同判）。
- 全取一侧：另一侧三天增量全灭，弃。

## Consequences

- 两线自本合并起共享历史，此后跨线改动走普通 merge/rebase（防线三闸保留——它们只拦「新的」无共同祖先合并，对已相关历史零影响）。
- main 侧三日增量全部在位：refresh 刀1-6（@Hz/softpanel/arbiter/FRAME_TIMING/latch-at-vsync/LFC）、cbox 刀1-3（内核 RAM 表+0x42 排液+账本+symbolize）、ADR #65 立法。
- 已知挂账：① pump 泵侧 FRAME_TIMING actual 轨注入与 SUBMIT 掩码收窄未跟进（launcher 刀4 暂以 note_presented 估计退化运行）；② QEMU smoke 全相低载窗补跑；③ 索引.md ABI 行计数口径（43/42 含 1.1 号）与 abi.toml（40/39 纯 v1）并存属既有口径差非本批引入。
- merge-file 静默丢内容判例入技能：跨根或大歧文件合并必须「真源重建+增量补丁+审计」，禁直接信任三方标记流。
