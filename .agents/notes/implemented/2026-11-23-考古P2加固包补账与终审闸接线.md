# 考古 P2 加固包补账与终审闸接线清偿

Status: implemented

## Problem

两笔欠账同批清：其一，commit 67d75e7b（考古 P2 八件加固包）改了闸行为（punch_slice validate_no_renumber）、FROZEN 集与三钩子头注，并向规则/16 §5 立法「P2 加固包」整条域条款，却未按 AGENTS.md 规则 3 同批落 notes/——「为什么立这八条」只活在 commit message 与 survey 研究文档里（姊妹批 P0 清偿 75d2f7d8 有同批笔记，本批漏了）。其二，2026-11-23 终审（code-quality/docs-consistency/config-integrity/test-coverage/constitutional 五镜）揭出该批的「一次落齐」声明有两处不实：punch 重排闸只落了函数与自检、全仓零执法调用方，且其正则对无 T 编号的现行 punch 格式恒空判；规则/16 DAG 条款引用的 `--sync` 机器写点不存在。本篇补第一笔的决策账，并记录第二笔的接线清偿。

## Decision

八件裁决各一句为什么（考古出处：[impossible-os 全史考古](../../research/2026-11-23-survey-impossible-os全史考古.md)；落地 commit 67d75e7b）：

1. punch 重排闸：条目 ID 是 punch-list 当审计面的身份——删了重排会静默丢失已完成账（他们深水期 105 段 park 死账的成因族），编号只增不挪。
2. 跨树 sweep 冻结：大规模路径/符号迁移一次吞多模块、假绿难审——高危类过 owner 确认才动。
3. 钩子变量红线：GIT_DIR/GIT_INDEX_FILE 串进钩子会让门在错误的仓上跑（2026-11-22 审计实抓过串仓）——一律 unset 后发现式定位。
4. facts-only 闸律：会话态闸（transcript 扫描）在他们那是全场冻结事故——任何新闸只准看已落盘 facts。
5. 闸数预算：闸雪球是自动化期最大成本项之一——新增阻断闸须退役一个旧的或记显式豁免。
6. 首跑观察欠条：新机制没端到端见过一次完整闭环等于没验证（他们多个检测器落地即哑无人察觉）。
7. 多刀粒度：同机制多修一把梭毁 bisect 与单片回退——≥3 个独立修拆同批多提交。
8. 自拆面审计：守护被自己的修复拆台（看门狗死循环形态）——能停掉 run 的路径全数入 FROZEN。

终审接线清偿（同批，2026-11-23）：punch 重排闸真接线——pre-commit 在 staged 命中 `.agents/plans/` 时调 `punch_slice.py --renumber-guard` 对拍 HEAD 版与暂存版，validate_no_renumber 升格为三层判据（编号删除、已勾/park 同 ID 重建的内容对拍、无编号行的整行指纹 fallback——剥 park 令牌保 owner 解 park 合法流），gate-selftest 增腿 j 端到端；规则/16 P2① 措辞改回真实语义。`--sync` 勘误为「写点待建」并落 punch-list 接线欠账条。同批终审修复：e-supervisor 整批回退原子性（commit rc 必查、undone 持久化跳已撤 sha、回退提交 subject 前缀防互撤死循环、任一笔失败整批 reset --hard 放弃）、产品塌陷仪表补 >2:1 臂与全套自检腿（零产品/清账/滑坡/repair 写清真跑）、e-guard 的 punch_slice 迟到装载（缺席=拒停，钩子进程不再背依赖件加载故障面）与 FROZEN 补全道 CI 闸族五件清 dup、e-doctor 双清单补 punch_slice、pre-push 假身份闸补 rsha=zero 新建远端分支旁路（区间退化同 bot 段）并把 BERRYOS_ALLOW_CROSSROOT 阀收域回跨根 main 段、gate-selftest 增假身份腿（有效区间拒/zero 旁路拒/干净过）并把沙箱提交邮箱换中性值（旧 gate-selftest@local 命中自家 /selftest/ 模式，把旁路钉进了契约）、gate-selftest 沙箱 subshell 退出码传导修复（die 在 subshell 内只退 subshell，外层照印 PASS——全部腿对退出码假绿）、control-plane 清单与 FROZEN 集镜像五件 CI 判定门、规则/16 §1 与 .githooks 注释的「AGENTS.md 规则 10」指针改指本地追加第 11 条（install.sh 同批改指本地第 10 条）、SKILL/RUNBOOK 停机语义补 DAG 双轨、e-heartbeat 落 supervisor-last.log 不吞诊断并把 product-starved 接进 nudge 分支。

## Alternatives considered

- punch 重排闸的执法点：选 pre-commit 暂存面对拍（快照语义与文档门同律），不选 e-guard 停机面——重排发生在提交时，停机时检查已晚半拍。
- validate_no_renumber 升格为 ID→内容映射而非维持集合差：docstring 点名的「删 T3 重建 T3」形态集合差检不出；已勾翻回 open（合法重开）不触发内容判，两形态都保住。
- --sync 不在本批实装（终审 fix 给了二选一）：真回写器要处理双戳联动与首个 opt-in 语料，按「多刀粒度」与「首跑观察」两条自家立法走欠账而不是赶工落哑件。

## Consequences

八件加固的立法因果回到 notes/（规则 3 账清）；「自证系统撒谎」的两处（未接线的闸、引用不存在机制的契约）当日清偿；终审 merge-readiness 三件（基线三分叉合并序、public 分支面出口安检归属、heavy CI 基线红窗）不属本批代码面，归主会话合并操作与 owner 裁决。
