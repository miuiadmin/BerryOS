# 波3 批B guifbd 带合成 v1 与 wm 面收线

Status: implemented

## Problem

波3 设计 §8:115 批B 四件套（surface_id=wmd window_id 激活、带缓存静态定容、SERVICE>SYSTEM 序带重放、wm 表快照面）悬账；[裁决方案②档二](../../plans/2026-11-17-图标透明与系统栏跟随综合裁决.md)钦定批B=guifbd 侧带合成 v1，增补一立法重放必须 1-bit 透明键跳写 A==0（防透明系统栏把应用涂黑）。本刀以 workflow 编排实施（scout×4 → impl×3 → 对抗审查 4 维 find + 逐条 verify），四份勘察与实施规格存仓外快照 /tmp/gui-batchB-scout/（SPEC-batchB.md 为契约源）。

## Decision

**surface 六档分类**（lib.rs 纯面 `classify_surface`，分类冻结在 SUBMIT 入途拍）：0xFFFF=SysFace（不裁+双写带缓存——launcher 全提交是带像素唯一源，「launcher 挂了带也活」）；hdi COMMIT 两处=InternalRefresh（不裁不缓存不重放——槽内容属任意应用，防 P5 污染缓存，不再冒用 0xFFFF 值域）；0/未知 wid=AppCompat（裁剪逐字保留+重放叠加，撤裁剪归批C）；快照内 SYSTEM/SERVICE 可见窗=WinBand（不裁+写该窗带槽）；快照内 APP 窗=WinApp（不裁+重放）；不可见窗=Hidden（空 targets 呈现——记账照常零像素，跳 vgpu 上传防隐藏像素复活）。

**带缓存**：boot 一次性堆分配（Vec try_reserve_exact + Box::leak——绝不能入 Srv：guifbd 栈 32KiB bounce 已占半）；常量定容帽 BAND_SLOTS=4、BAND_H_CAP=160px、4MiB 启动门（`band_cache_bytes` 纯函数，800 宽=1.95MiB/1080 宽=2.64MiB）；guifbd berry-libc 依赖提档 heap-4m（默认 1MiB 堆装不下，launcher 同款先例）。缓存只从 bounce 抄（fb pack 已丢 alpha 禁从 fb 抓）。

**带重放**：CPU blit 行弹毕、vgpu submit_frame 前的接缝；重放区=原始 targets∩带.rect（非裁后集——FULL 帧恒触发保标记确定性，且重放区⊆原始 damage 界⊆vgpu 上传集）；SERVICE 槽先于 SYSTEM 槽（fallback 槽随 SYSTEM 序）；逐像素 A==0 跳写（`replay_rows_u32`，与 raster.rs argb 1-bit 键同律）。

**补不透明键 0xFF（审查根因 B 的修复）**：现网全部 SUBMIT 生产者经 berry-gfx Rgbx pack 出帧，X/alpha 字节结构性恒 0——缓存逐字节照抄则全 A==0、重放恒零写（对抗审查 CONFIRMED：两道 smoke 门必假红）。guifbd blit 是无透明语义的原样字节拷，「已呈现即不透明」：缓存抄录时 `|= 0xFF00_0000`，补键后重放像素集与原 fb 像素集严格一致（零漂移），BANDR 写数确定性 ≥1。批C 真 ARGB 生产者（带 glyph 化 A==0 背景）落地时由该刀翻转补键规则——其时两侧同改。

**wm 客户端面收线（审查根因 A 的修复）**：原实施经 svcmgr 交接对二次投递 'm'+dup(WMD_CLI_DUP)，对抗审查 CONFIRMED 架构级缺陷——dup 与 launcher 装配/gfxdemo 原柄/[ui] apps 同属一条 ChannelEnd，wmd 应答无相关性 ID、单 FIFO 先 recv 者得：guifbd 在途 recv 弹走他客户端应答（EINVAL 误判通道死）且其孤儿 TABLE_GET 快照毒化后续 RPC（launcher parse 失败 park → Boot A 崩）。guest 侧无耐受修法（消费即毒化，无 push-back）。裁决撤回：svcmgr 'm' 投递块整撤（WMD_CLI_DUP 语义复原为本体永不消费）、guest.rs wm 状态机整面移除、WmFace 留空快照持有者（快照恒 count=0 = 一切 wid 按 AppCompat 保守档、带集恒为 fallback 底带）、serve 循环复原三路 n=3。持久修复另刀：[wm 订阅私有通道 RPC 面](../../plans/2026-11-17-wm订阅私有通道RPC面.md)（wmd sweep_evt 应答订阅者通道上的 TABLE_GET，wire 零改，须开 gui-wmd 面）。

**标记**：`BANDC ok`（带缓存首 seed）/`BANDR ok n=`（首重放写数）两枚 one-shot latch 恰一次，只进 gui8-smoke Boot A 与 smoke-image ECO_MARKERS（生态 51）；WMSUB 随 wm 面收线摘除（gui8 门与 smoke-image 条目同批撤）。BANDR 首触发源经 QEMU 验证改判为 **seed 自验证拍**（BANDC 首拍同批对刚 seed 的行域跑一次真实 band_replay——幂等同像素回写零视觉漂移，每靴确定性验证 plan/rows/写全链）：原设想的「APPDEMO 首个 AppCompat 提交触发」被既有缺陷堵死（见 Consequences），等待集含 BANDR 必假红。

**验证**：guifbd host 测 23/23（既有 13 零破 + 新增 10 条带面纯函数测：classify 六档/plan_bands 选带帽与 fallback/replay 定序与 FULL 恒触发/A==0 哨兵/4MiB 门临界）；musl check 零警告；svcmgr 复原后 check 零新警；gui8 --self-test PASS（含批B 正负样本）；BANDC/BANDR 与全部既有标记互非子串程序化核对。

## Alternatives considered

wm 客户端端送达三选：抬帽 8→9（kernel chanface+libc+ktest+svcmgr 四处同步，env 8/8 冻结注记明言另刀）被否；fx 交接对二次投递被选（实施后被审查否——共享队列根因，非投递通道之罪）；wmd 侧反向建联无先例未深入。BANDR 不可达两修法：撤门（verdict 4 案，标记降级为不验）vs 补不透明键（verdict 3 案）——补键胜：保住门且「launcher 挂了带也活」真正兑现（P5 refresh 覆带后重放可复原）。wm 面残存形态：10s 超时落 Disabled（保留机器但每靴噪声一行）vs 整面移除（另刀复活时再接）——移除胜。guest 侧耐受 recv（识别非己应答不消费）：被 verify 否——通道无 unread/push-back，消费即毒化。

## Consequences

**既有缺陷实抓（本刀 QEMU 验证暴露，非本刀引入——移交 owner，urgent）**：launcher 与点击 spawn 的应用共享 wm 客户端队列（同一 ChannelEnd 别名），send 侧唤醒纯广播无按等待者路由——并发阻塞 recv 互截应答。gui8 Boot A 实抓 `appdemo: wm getinfo rep bad st=0` 后 park（GETINFO 期望 12B，吞到 launcher 经中继的 SUBMIT ack 8B 形）。即现树任何点击拉起的应用都可能随机吞错首应答而 park（时序彩票）；gui8 三元组门不含 app 帧证据故长期不可见。修复归 [wm 订阅私有通道 RPC 面](../../plans/2026-11-17-wm订阅私有通道RPC面.md)（该刀动机已补两路实证）。

带集恒为 fallback 底带（快照恒空）：底带获缓存+重放（launcher 挂了底带活），顶带仍仅靠 AppCompat 裁剪保护（P5 refresh 覆顶带为既有行为，未治——批C 撤裁剪时一并解）。WinBand/WinApp/Hidden 三档休眠不可达（lib 纯面已测钉，wm 面另刀接入即激活）。批C 落地时有连带义务：翻转补键规则（真 ARGB 生产者）+撤兼容档裁剪+0xFFFF 退役。审查另发现仓外线索移交 owner：波1 splash gui_mode6 清屏块（0e387139e 加）未在 HEAD 现树，疑跨根合并丢失。

ramfb 相口径滚新（遗漏检查补记）：b1bc 立的「全部改动在 vgpu 分支内」零漂移句已按批B 现实重定义——带裁剪/缓存/重放是两后端等价的新功能面（ramfb 相同执法、BANDC/BANDR 新输出），红线现行语义 = vgpu 钩子面 None 恒短路零开销（guest.rs 模块头 2 与 B1-b 段两句已同步改写）。验证镜像成分披露：gui8 双靴 PASS 所用 18:09 镜像烤自当时工作树（内核含兄弟在途 input 双件，后随其刀入库）；批B 代码面与其零交互（present/hdi/console 三路既定面，无 input 域），结论不受染。
