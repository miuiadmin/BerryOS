# 三轮系统审计：七域 62 项遗漏盘点与批量清偿

Status: implemented

## Problem

收口与二轮台账清偿后，做全系统子系统级（非收口向）遗漏盘点：workflow 七域并行审计（内核核心/调度/用户态库/服务与 shell/工具链 CI/驱动启动/文档规划），锚点 cb73b5025，共 62 项发现。需要分级清偿：机械项即修，架构裁量项归位。

## Decision

本轮批量清偿 28 组（本提交）：ABI 单源口径族（abi.toml 0x83 补 implemented + 四元组 docstring 澄清 v3 提前实现不计入口径 + svcface/berry-sys 头块计数 45 统一 + 索引/应用API全景计数随迁 45 口径）；内核注释族八处翻正（telemetry 0x84 已翻真、mm/gic SMP 措辞、vmo Result 范围、channel 抢占理由、install 沿革补 0x84、oneshot 兑现文案 ×2、gen_abi cbox_drain 重复入单合并）；调度 API 参考 v1.11 补 F3/F4 五条目 + Task 构造器 arg1 签名 + 175→180 滚新；调度彻底计划 CP-05/§8.3 刷新与 CP-01 三条销账注记；placement_hint_ungated 幽灵消费点如实注记（写面在库、eas_wake_pick 不读 hint——接线归 owner）；CLI 登记补全（symbolize/crash-log/version/stats/record/play/swipe 入 README，console/vnc/home 入速览）；标记家指针两处改指 markers.sh；selftest 计数 44→48 三处；fatcat.py 翻退役、elf2pe.py 补 Rust 孪生指针；驱动清单两册补 gui-inputd；justfile gui8 boot 批注释、rootfs-manifest PM 段、显示 v1.1 刀5 反向断言翻正；模拟器方案修窗件1 销账与 §A149 链注。验证：just build 全链 EXIT=0 + abi/selftest/docs-guard/check-docs 四门绿。

## Alternatives considered

- 全部 62 项一次清偿：架构裁量类（几何三源、CI 策略、测试钉板族）需要 owner 意图，代裁有错向风险，弃。
- 只报不修：机械项证据行级在握、修复成本低于转述，弃。
