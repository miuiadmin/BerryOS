# Agent Note: 弹簧刀落地——berry-ui 定点弹簧第二动画面与 SwipePager 初速度接入

Status: implemented

## Problem

UI-02 六大系统 UI 差距深研（维三「动画深度」）裁决：berry-ui 此前只有定长时间线动画（五属性 × 四档缓动），缺可中断恢复的物理感弹簧面——重定目标只能重起时间线（位置与速度双跳），SwipePager 松手吸附固定 QuadOut 240ms、松手速度不参与。弹簧刀在 wip/ui-spring 会话完成实施与独立验收，代码（16f335a26 + 验收 3ea583e2a）已随谱系入主树，但决策笔记未同批落——本篇补账（欠账成因：该刀会话聚焦代码与验收报告，笔记面漏写）。

## Decision

1. **定点弹簧第二动画面**：anim.rs 纯新增 SpringProp——Q16.16 纯整数质量-刚度-阻尼半隐式 Euler（质量 1 折入常量），SpringPreset 两档（Smooth：ω=12、ζ=1.0 临界阻尼；Bouncy：ω=16、ζ=0.625 欠阻尼过冲约 8%）；构造入参 = 目标 + 初速度（px/s，速度环 96ms 窗差分输出可直入）；retarget 只换目标、位置/速度积分态原样续接（中断恢复主干）；子步 16ms、单 tick 子步帽 16 步防长帧爆积分；终止 = 位移 ≤0.5px 且 |速度| ≤20px/s 双阈值吸附目标。
2. **挂载面扩展不动 AnimProp 枚举**：AnimProp 语义 =「驱动哪个属性」，Spring 是驱动方式——枚举字面变体在 exhaustive match 纪律下只能落死臂；载荷变体 Spring(SpringProp) 递归类型无 indirection 不可编译，Box 被热路径零分配约束禁用。等价落法 = SpringProp.prop 指认五属性之一 + lib.rs springs 第二表（spring_add/spring_tick，与 anims 同帽同错位），spring_tick 经临时 Anim 走同一 apply 单源落点（Transform/Layout 双型与 s7 staging 面全复用）；存量 interp/Easing/Anim 逐字零改动。
3. **SwipePager 初速度 opt-in**：松手吸附从固定 QuadOut 改可配置 SnapMode——默认 QuadOut 行为零变化（值级断言钉板：起拍持 from、中点 −83、240ms 终点精确），VelocitySpring 档以松手速度入参切 SpringProp（Smooth 预设），零速度/Cancel 回落 QuadOut；页宽冻结与建树语义零改。
4. **wire 面零改**：Spring 是引擎内动画参数非 wire 态，TLV/golden 结构性无改（全套 golden 复跑绿为经验加固证据）。

## Alternatives considered

- **AnimProp 枚举加 Spring 变体**（否：exhaustive match 死臂 + 递归类型/Box 两条硬约束，见 Decision 2——任务书原案「枚举扩 Spring 变体」改落挂载面）。
- **Box<SpringProp> 载荷避开递归**（否：热路径零分配纪律，guest no_std 面同样禁）。
- **浮点解算**（否：no_std 纯整数纪律；Q16.16 + i128 中间量沿用 interp 风格）。
- **松手吸附默认切弹簧**（否：默认档行为零变化是硬要求，速度档走配置面 opt-in）。
