# Agent Note: 波3 批A——协议与服务端底座（guiproto 帧型 + wmd 四件）

Status: implemented

## Problem

波3 七件套（launcher 双窗化/带合成/沉浸旗/返回键路由/TabBar/softimed/appshell）的消费面全部踩在两块缺失的底座上：其一，wmd 表项无属主概念（table.rs 表项只记几何与状态，窗事件无处投递）——返回键路由（R2 投 WM_EVENT_BACK）、表变更通知（softimed 显隐订阅、guifbd 带合成的表快照）都要求「窗有主人、主人有通道」；其二，guiproto 只有波2 立法的 op 常量（OP_WM_BACK 0x67 等）与输入帧面，事件帧型（BACK/TABLE/ACK）、沉浸与 IME 旗位、SET mask 位全缺。不先立底座，批C/E 的消费面无从接线。

## Decision

批A（2026-11-15，workflow 两段：实施+验证）落两件，全部 add-only：

1. **guiproto**：WM_CREATE_F_IMMERSIVE(1<<1)/WM_CREATE_F_IME_WANTED(1<<2) 建窗旗、WM_SET_F_IME_WANTED(1<<3) mask 位、WM_WIN_F_IMMERSIVE/WM_WIN_F_IME_WANTED 快照位、事件帧型三件（WM_EVENT_BACK=0x01 携 wid、WM_EVENT_TABLE=0x02 携 version、BACK_ACK=0x03 单字节——属主事件通道专用 kind 段 0x01..=0x03，与 op 域数值重合经通道域分离豁免）+ 六编解码对与长度常量。host 测 47→49 全绿（+2：位值钉板/往返/黄金字节/拒面/越界）；TLV golden 零漂移（三个黄金测试原样过）；既有 wire 帧字节零变化（HEAD 对照净室复跑 47 全保 + 拒矩阵三野值样本随位认领上移、语义保持）。
2. **wmd 四件**：表项属主事件通道（CREATE 恒建 channel 对、end1 随 8B ack 随行 handle gift——帧字节零变化，旧客户端 gfxdemo 对拍零破；表项记 evt handle，DESTROY 关联关闭）；OP_WM_BACK 分派（有通道 = 非阻塞投 WM_EVENT_BACK + 起 500ms 臂；建联失败 = 直接 DESTROY）；500ms 单槽 PendingBack（记 wid/version_at_arm/deadline——表变即解除防误杀 R3 优雅退出、到期且表未变才 DESTROY + refocus_after_removal 复用、serve 单线程回环三查零新增线程）；表变更广播（全部 bump 点向全体属主非阻塞 send WM_EVENT_TABLE，-EBUSY 即丢——真值恒经 TABLE_GET）。TABLE_WAIT 冻结立法（注释在位，零新增驻留者）。

验证：gui-wmd musl 链净室构建零 error 零 warning；smoke 零回归按构造论证闭环（全仓 rg 证 OP_WM_BACK 现网零发送面、广播走专用 gift 通道不污染 RPC 应答流、gfxdemo 唯一客户端的 CREATE ack 随行 handle 落 8 槽收窗无破坏、wait()/inputd 驻留者面零改）。

## Alternatives considered

- **延帧扩展 CREATE ack（新字段进帧体）**：落选——parse_wm_create_ack 恰 8B 执法，延帧必破旧客户端；随行 handle gift（nhandles+1）达成同语义且帧字节零变化。
- **WmSetReq 加 IME 字段**：落选——公共 struct 被 gfxdemo 字面量构造，加字段破其编译；复用 vis 槽字节（0/1）最小面，代价是 VIS+IME 双位同帧共享值（分值两帧，v1 语义文档化）。
- **事件帧走 wm_srv 主通道（op 域混传）**：落选——污染 RPC 应答流（严格串行无请求号的既有契约会被异步事件偷取应答）；专用属主通道 + kind 段隔离。
- **500ms 硬定时（中断/线程）**：落选——serve 单线程 deadline 三查（收割 ACK/到期检查/等待集挂第三路）达成「最早检查点」语义，零新增线程与唤醒面；硬实时代价（中继阻塞顺延）如实登记移交。

## Consequences

- 批C（launcher/softimed）与批E（appshell）的接线面就绪：WM_EVENT_TABLE→TABLE_GET 拉表、BACK 全链 R1-R3、ime_wanted 显隐；批B（guifbd 带合成）**挡在波1 合并序**（rescue/ux-splash 的 guifbd 差异 -2386/+988，须先完成波1 并入）。
- 移交四件给后续批：wm_layer_known 未收宽 SERVICE=2（softimed 建窗前置）；OP_WM_FOCUS 服务端分派仍 ST_BAD（焦点切换策略面）；BACK_ACK 无归因域+单槽覆盖（波4 需归因则升版扩帧）；孤儿通道对不回收（常驻客户端时代复评）。
- VIS+IME 槽共享是波4 appshell 的编程约束（双位分值需两帧）；拒矩阵三野值样本上移是位认领的必然伴随（golden 未动）。
- 设计稿翻 active、§8 前两项勾账、§11 偏差与移交节在册。
