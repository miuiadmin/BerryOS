# Agent Note: W3-Q101（03 号分派审计机会一 1a：kern_acquire 诊断账面门控维护）实施记录

Status: implemented
创建：2026-11-18。PR 收口以 [沿革三百九十七](../../../docs/阶段沿革.md) 为准。

## 问题
[03 号 syscall 分派审计](../../../research/内核深度进化/03-syscall分派审计.md) 机会一 1a 实锤：`kern_acquire`（arch/aarch64/src/kern_lock.rs）CAS 成功后无条件付三件纯诊断账面——①KL_HELD_SINCE 写（内含 `timer::cntvct()` = 一次 MRS CNTVCT）；②NAME_HOOK 间接调用取任务名（static mut Option<fn> 无法去虚化）；③KL_HELD_TAG_PTR/LEN 两写。三者均系 S-6 ③b 自旋看门狗「持者点名」诊断面，代码自记「定谳后随探针退役」且 run11 已定谳（快速取放活锁归因闭合）。净效果：每号 TABLE 类 syscall 为已结案尸检恒付费，审计判约占固定包络两至三成。

## 消费面审计（门律的安全性论证）
KL_HELD_SINCE/TAG 的读者唯一 = `lock_bark`（同文件，自旋超限看门狗）——其**首行 par 门**：`if !par_enabled() { return; }`。单核生产态（par_enabled() == false）bark 恒返 = SINCE/TAG 零消费。零消费 ⇒ 零维护合法：门关时账面写全跳过，诊断数据陈旧无读者。SMP 态门恒开 = 维护门与消费门同步开，bark 读到的 SINCE/task 名永远新鲜。KL_HELD 镜像**不动**（`kl_held()` 位感知退化判据依赖——pi.rs/vmar.rs/process.rs 消费面，非诊断面）。

## 方案
门 = `争用臂 ∨ SMP 态`：
- `kern_acquire` CAS 失败臂置 `contended = true`（本核本次取锁经历过争用）；
- 取锁成功后 `if kl_diag_gate(contended, par_enabled())` 门内维护 SINCE + NAME 镜像；
- 门律单源 `berry_lkface::kl_diag_gate(contended, par) = contended || par`（const fn，host 钉板）；
- `KL_SPIN_BARK_MASK`（2^23）自 kern_lock.rs 字面 `(1 << 23)` 迁册 lkface 单源；
- contended 语义：单核态 ktest lockdep 系直接改写 KERN_LOCK 的合法面存在，争用事实出现即补维护——防「单核突发争用 → 看门狗数据源陈旧」观测盲区。

### 关键不变量
- KL_HELD 维护序不动：acquire 置（无条件）/ release 先清再放（先清防别核新值被迟到清写覆盖）。
- SMP 态（par=true）行为零变化：门恒开，账面维护与旧形逐位等价。
- 单核无争用态：省 1 次 CNTVCT 读 + 1 次间接调用 + 3 写；KL_HELD 一写保留。
- 快路径 lockdep 记账（feature 门）不动。
