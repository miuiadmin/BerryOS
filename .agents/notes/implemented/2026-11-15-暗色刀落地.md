# Agent Note: 暗色刀落地——berry-ui 主题档运行态与 settings 暗色开关

Status: implemented

## Problem

UI-02 六大系统 UI 差距深研（维八「暗色模式」）裁决根因为工程量缺：theme.rs 已有双档 token 但引擎无运行态换档入口，paint 组件 v1 固定色板 29 色直写不查主题档，settings 无暗色开关，且 dark 档 `BRAND_PRESSED` 与 `BRAND_DARK` 同值（按压不可区分缺陷）。暗色刀在专属 worktree `wip/ui-dark`（基点 `3af18dda1`）完成实施与独立验收（[DARK-IMPL.md](../../../DARK-IMPL.md)、[DARK-VERIFY.md](../../../DARK-VERIFY.md) 五门全过），代码 `bee09f110` 随 `0834d0dba`（并 `wip/sched-1.1`）入主树谱系，但决策笔记未同批落——本篇补账。

## Decision

1. **主题档运行态**：`Ui` 增 `theme: Theme` 字段（默认 Light，旧行为零漂移）+ `set_theme_mode` 换档即 FULL damage（同档重设幂等零脏帧）；`paint`/`emit_walk_all`/`emit_node` 三签名追加 `tokens: &Tokens` 内部实参（公共签名零改），取值单源 `Tokens::pick(theme)`。
2. **29 色组件色板整块迁 theme.rs**：`WidgetColors` 29 槽组 + `WIDGETS_LIGHT`/`WIDGETS_DARK` 双档常量（light 档逐色同值钉死旧色板——值级零漂移门；dark 档镜像另补 `BRAND_PRESSED_DARK` 0x63B2FF 与 `SUCCESS_DARK` 两档，brand_pressed 同值缺陷在 `Tokens::pick` dark 臂修复）；paint.rs 固定色板块退役，豁免数只减不增（30→1，仅 Image 臂黑色哨兵携 `[paint-exempt]` 登记），grep 门 = `tests/dark.rs::paint_fixed_palette_exempt_gate`（未登记色即红、豁免增即红）；新增固定色的合法路径立法 = 先在 theme.rs 立双档 token。
3. **settings 暗色开关三面即时生效**：第五行 `"Dark theme"` Toggle（`EV_THEME=5`，初值与装载档同源）——引擎面 `set_theme_mode`、chrome 面 clear 底随档换 + 7 个 chrome 文本节点 `set_props` 换 fg（纯 PAINT 帧）、持久化面 `theme_io::save` 落 SETTINGS.JSN（canonical 恰两形 10/11B、fail-closed 全字节精确匹配、坏件自愈重写、`fs_h()==0` 装配双门静默短路退化为内存态）；manifest 增 `fs = ["rootfs"]` 授能。
4. **light 零漂移三道自证 + 全绿**：像素级 gallery2 43 格 FNV-1a golden 全等且 `cells.tsv` 重写字节级零改动；值级 29 槽钉死旧值；往返级 dark 往返后 light 命令流与首帧 Debug 全等。主门 334 测全绿 0 红（基线 331 + dark.rs 新 3），musl/no_std 构建面全过，遮罩律（20% 白遮罩 `c+(255−c)/5`）逐通道手算精确命中。验收级补录：TLV golden（tlv2..7 + reconcile）零漂移、改动面恰 13 文件全属本刀域（AnimProp/spring/swipe 零触碰）；s7 实验轨 1 红经临时基线 worktree 复跑证为基线同红（SPRING-IMPL 在案，非本刀引入）；验收唯一小修 = settings main.rs 尾随空白，修后 musl 重编过链。

## Alternatives considered

动态取色（ wallpaper 取色 / 语境取色）明示不做——UI-02 维八裁决与 OH 同立场，本轮只做静态双档。settings `theme_io` 3 测的宿主执行面结构性不可达（settings 为 berry-libc musl 独立小工作区、本机无 qemu-user）——只过 `cargo test --no-run` 编译门，开关-引擎链路运行时行为由 berry-ui 面 dark.rs host 三测代偿。dark 档按压遮罩方向 OH 官方页未立法——取 light 档黑遮罩律的对称 20% 白遮罩（暗底向黑不可辨；Material/iOS 暗档同向），文档化近似、值非 wire 契约、测试只钉「可区分」。

## Consequences

组件取色自此必须走 token 按档取（豁免门在案，新增固定色先立双档 token）；dark 值表为文档化近似可迭代（首帧暗色观感未过人眼验收，调整点在 theme.rs `_DARK` 常量族）。本刀交付时装配线仍以 appstub 平像打 SETTINGS 包——真 settings ELF 的接线归波4 wiring 面收口（已由波4 settings 真应用首件接手）。
