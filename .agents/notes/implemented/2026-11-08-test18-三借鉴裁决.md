# Agent Note: 18 号测试三借鉴的裁决（②否决 ④⑤挂账）

Status: implemented

## Problem

遗漏审计（2026-11-08 四视角扫描）发现 research/18 号 §3 可借鉴②④⑤三无悬空——同报告①有 rejected 笔记、③随 P1-d 落地、⑥⑦转引记账，唯此三条无任何痕迹。

## Decision

- **② 特性幂集测试矩阵（moss cargo-hack --feature-powerset）：否决**——本仓零依赖纪律不引 cargo-hack；特性面现状（lockdep 独立 feature 面）单一无组合爆炸面，幂集成本 > 收益；若未来 feature 面超过 3 个且出现组合 bug，重开条件成立。
- **④ QEMU 重试边界纪律（swift-os 仅无裁决重试一次）：挂账待裁**——前提先澄清：BerryOS 现状是**降级为警告**（非重试）通道，swift-os 是重试通道——两条噪声治理通道是否并存是待裁问题本身，随 CI 冒烟噪声实际痛点触发（无痛点不立法）。
- **⑤ 文档示例可执行性门（docs-test）：挂 P3**——命令速览示例命令入 CI 验活，收益真但优先级最低，随 CI 面下一次大修评估。

## Alternatives considered

- 三条全落地：被拒——②违背零依赖纪律且无组合面痛点；④⑤无痛点驱动属过度立法。

## Consequences

18 号七条借鉴全部有归宿（①rejected/③落地/⑥⑦转引/②④⑤本篇裁决）；重开条件各一条。
