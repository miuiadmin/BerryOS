# berry-ui 组件第三刀：Badge/Sbar/Tip/Collapse/Chip/Fab/Card 七件四面接通

Status: implemented

## Problem

第三刀七组件通电：显示三件（Badge 角标 / Sbar 滚动条 / Tip 工具提示，无交互）+ 组合四件（Collapse 折叠组容器 / Chip 胶囊标签 / Fab 圆钮 / Card 卡片容器）此前是数据壳——布局 0×0 占位、paint 无视觉分支、set_props kind 门全拒、事件 ID 不接线。开场即半成品：baseline 八个编译错（layout.rs 引用 lib.rs 根常量 TABS_MIN_W/TABS_BAR_H/SBAR_LONG/SBAR_THICK/BADGE_DOT_D而常量块未写）。另有并行会话同场做波2 批 A（Tabs/Sbar/Badge/Scroll/List），两刀在 Badge/Sbar 重叠——半成品含批 A 的两个失配 stub（Sbar intrinsic 恒横 200×4 不随 orientation、Badge 数字档固宽 32）。约束同前两刀：不动 desc.rs、不动 mask.rs、渲染只用已有原语组合、固定色值起步、两面（默认 + s7）全绿。

## Decision

1. **布局（layout.rs）**：显示三件 = 内在型叶（Text 同列不吃 avail）——Badge 圆点 16×16 / 数字档宽 = 位档×8+8（1/2/3 位，>99 显 99+ 三字节档）/ count=0 隐藏 0×0；Sbar **内在随走向互转**（竖 4×200 / 横 200×4——修批 A 恒横 stub）；Tip = len×8 ×16（S8x16 与 BUTTON_CHAR_W 单源）。组合四件：Collapse = Col 同形容器（十字轴吃 avail、主轴内在 = header 32 + expanded 时子 Σ 高）；Chip = 标签×8+16 留白 ×32；Fab = 空标签 56 圆形 / 扩展 56+8+len×8；Card = 子聚合 max×max（Stack 同形）final 随父。**place_children 新 Collapse 臂**：expanded → 子在 header 下方 Col 型游标排列（宽吃满、高按内在累进）；收起 → 子不摆位。
2. **收起态三面同守卫**：layout 不摆位之外，paint cull_walk/emit_walk_all 以 `kids_live`（Collapse 且 !expanded → 跳过子走查）与 hit.rs hit_walk 同判——**不可见即不可命中**。子 bounds 陈旧（冻结在展开态位），三面一致跳过；收起瞬时旧界 damage 由 Collapse 自身新旧界收（子旧位 ⊆ 容器旧界）；再展开 place 臂 force 重摆。
3. **渲染（paint.rs）**：Tip = 实色衬底 TIP_BG（v1 无 alpha 的半透明近似）+ ON_ACCENT 文本；Collapse = TRACK_DIM header 带 + 三带三角形箭头（展开三横带顶宽底窄 = 朝下 / 收起三竖带左高右矮 = 朝右，t=a/3、s=a/6 随 a=12 推导）；Chip = 直角胶囊底（v1 无圆角原语）+ 居中标签 + 选中态色变（TRACK_DIM/ON_SURFACE ↔ ACCENT/ON_ACCENT）；Fab = oct3 八角 ACCENT 圆 + '+' 文本占位图标（icon 资源面挂 D28）+ 扩展标签带；Card = **双 fill_rect 阴影**（整界 CARD_SHADOW + 面底右下内缩 off=elevation×2px——视觉足迹恒在界内）。Badge 数字改走 fmt_u32 共核（批 A 手拼两位数弃）。
4. **交互（lib.rs widget_react Click 臂）**：Collapse → 翻转 expanded + on_toggle（value = 翻转后 0/1——几何面折叠/展开经 set_props 单漏斗同帧生效）；Chip → 翻转 selected + on_tap（Toggle 同形）；Fab → on_tap（Button 同形 value=0 无状态件）。内容区点击归子（子 topmost 先命中），header 区（无子覆盖）命中容器 = 折叠开关自然语义。
5. **命令面（lib.rs）**：add 容器白名单收编 Collapse/Card（place_children 两臂已落）；五新叶入显式叶带子拒列；set_props kind 门加七对；widget_value_ok 加 Card elevation≤3（desc::CARD_ELEVATION_MAX 单源）；**props_geom_equal 锁步改**——Sbar 补 orientation 比较、Badge 改位档比较（badge_width_class 0/1/2/3 单源 layout 同律），随 intrinsic 修正联动（几何判别式必须与内在输出类同锁步，否则纯绘误判让内在陈旧）。Sbar thumb 域先验批 A 已落。
6. **测试**：追加 widgets3.rs ⑧..⑫ 五测（批 A ①..⑦ 后接）——显示三件 FULL golden（10 填充 + 3 字形 run 逐值）、Collapse 折叠三面守卫（子摆位/渲染/命中随 expanded 增减 + 箭头朝向换形）、Chip/Fab 点击值级与视觉、Card 双 fill 阴影与 elevation 纯绘（A 零重测/s7 保守臂双面分录）、七 kind set_props 开口与拒面（Sbar 域 / Card elevation / kind 失配 / 叶父位）。既有钉板两处随接线翻：tlv7.rs Collapse 父位拒 → 收编正例（+Card）；widgets.rs 「Scroll 未开口」哨位迁 Select（批 A 开口 Scroll 后代表件失义）。

## Alternatives considered

- Collapse 收起时给子摆零尺寸而非跳过摆位：否——内在型叶（Text 等）final 恒内在不吃 avail，无法强制零尺寸；跳过摆位 + 三面守卫一致跳过是零特例解。
- Card 阴影按 Material 真形画在界外（面底满界 + 阴影外扩）：否——纯绘变面 damage 只记节点界，界外条幅不进重绘集 → 陈旧像素；改界内内缩条（阴影满界 + 面底缩 off）保 damage 正确性，elevation 遂成纯绘面。
- Badge 数字档固宽 32（批 A 初值，两位数档预留）：否——任务钦定随文本；一位数两侧空 12px 观感差，位档 16/24/32 由 badge_width_class 单源。
- Sbar 内在恒横（批 A stub）保双会话零冲突：否——orientation 是 props 契约字段，paint 已两态渲染，intrinsic 不随走weis横竖互转必与渲染失配；与批 A 的常量仲裁（SBAR_LONG 100→200）按任务钦定值定稿，对方会话已对齐（其笔记「坑」节互认吸收）。
- 新建独立测试文件（widgets4.rs）避并行冲突：否——批 A 已先占 widgets3.rs 名位；追加段共享 helpers（paint_full/fills/glyphs/pump_one）合「一文件一族」惯例，分段注释划界，冲突由编辑工具先读后写语义兜底。
- Collapse 展开动画（anim 复用）本刀落地：否——挂 Phase 2 动画刀（数据层笔记既定）；本刀 expanded 即时切换。

## Consequences

- 七件从数据壳升至完整可用；可用 ViewKind 20 → 27（41 kind 余 14 件待接）。
- berry-ui 234 测全绿（widgets3.rs 批 A 7 + 本刀 5）；cargo check 0 错。源面改动（lib/layout/paint/hit/tlv7）被并行批 A 会话同批吸收进 463482569（批 A 笔记「并行会话同文件互踩」节互认）；本刀余 widgets.rs 哨位迁移 + widgets3.rs 追加段两文件未提交。
- Collapse 收起态子 bounds 陈旧是文档化契约：三面守卫（摆位/渲染/命中）一致跳过；消费面读子 bounds 前须知 expanded 位（app 自管或经 on_toggle 驱动）。
- 刻意债务五处（文档化迁出锚）：Chip 胶囊圆角 + Card corner_radius 视觉（横向原语刀——raster 圆角 LUT）、Fab icon 资源接线（D28 资源缝）、Tip placement 消费面（定位浮层）、Collapse 展开动画（anim 复用）。
- props_geom_equal 与 intrinsic 的锁步纪律立为先例：后续批改内在输出类（如 Select 选项行高）必须同步改几何判别式，否则纯绘误判让内在陈旧（Sbar/Badge 双例已钉）。
- props_diff（s7 B 面）仍欠三批组件臂——保守失配臂双面分录钉板（前两刀同款，挂 S7 后续刀）。
