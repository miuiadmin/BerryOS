# Agent Note: W3-Q99（02 号 IPC 审计机会二刀 b：PI 传播相静态边缓存）实施记录

Status: implemented
创建：2026-11-18。PR 收口以 [沿革三百九十四](../../../docs/阶段沿革.md) 为准。

## 问题
PI recompute 每跳全扫：每 donor 解 donor_edge、每候选反查 holder_table + holder_has 全槽扫——最贵项 O(donor×候选×槽) × 8 跳帽。三窗（SQ 已持 → RQ → KL 子窗）冻结下，边资格判据面（donor 的 wait_obj/wait_signals/peer 指针、cand 的 proc_tag 与表内容）跨全部 8 跳静态——传播只写 pi_inherited 与 changed 标志，不触任何边资格字段。边资格跨跳不变 = 缓存合法。

## 方案
首跳建相时把命中 (donor → cand) 真边收入 `PI_EDGE_CACHE` 有界数组（帽 64），余跳只迭代边对。溢出全回退原路径（`cached = false`，8 跳全走 `propagate_full`——与缓存形前版本逐字等价的原始扫描）。边应用序 = 建相发现序 = 原「外 donor 链序、内 cand SLEEPQ→RQ 序」同序展开——同轮实时可见律中间态逐位保持。

### 关键不变量
1. 建相趟纯收集零应用（不改任何 pi 字段）——两形同初始态起跑，溢出回退侧由此逐位等价。
2. d_eff = max(prio_effective, pi_inherited) 实时读——链式传播命门，缓存形同律。
3. 形 B 共享表护栏（proc_tag==0 runnable 不捐）在建相趟同位置执法。
4. `NonNull<Task>` 指针对只作边身份，使用点才解引用；三窗冻结 + retain 钉住纪律下跨 8 跳有效。
5. static mut 形态与 SLEEPQ/KEY_HEADS 同款（单核 IRQ 屏蔽窗内访问），writable_globals 在册（auto_group 判 kernel/src/pi.rs 归 other）。

## 验证
- host 钉板 `piface::propagate_cached`（与 kernel 缓存形逐律对齐的值域面，cap 参数化暴露溢出回退）：六测——反转/链式两跳/无真边/溢出回退对拍/自捐环/deep chain 轮帽对拍，全部两形终态逐位一致。
- ktest J10/J10b：链式两跳（J9c 同款拓扑重打）+ 持有环 max 单调收敛——缓存形在 kernel 真路径上的钉板。
- test-host 264 组 2681/0 全绿 EXIT=0（隔离 .target-host-w3q99）；kernel no_std check 零 error；docs-guard/abi-check/wg --check 90 面/台账 1157 对拍 ok。
