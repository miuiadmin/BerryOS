# VNC 八至十一波 fix 刀（survey F42-F63 兑现）

Status: implemented

## Problem

第三轮 [survey](../../research/2026-11-15-vnc八至十一波遗漏检查.md) 裁定 13 条「fix 线修」+ 5 条「顺手可带」（F42/F43/F47-F53/F56-F58/F60 主修，F54/F55/F61/F63/F62(d) 随批），全部落在 VNC 八至十一波归属面：最重的是 F42——`proxy_ws_plain` 拆链双向不对称（browser-EOF-first 时 pump 线程退出不拆上游、up-EOF-first 时 join 先于 shutdown 永阻于 browser 读），每泄漏一条 = 连接线程 + 槽位 + QEMU ws 连接，默认 cap 16 耗尽后新连接 503；其余为 Attach 态 RES 换档遗留 stale `vnc web`（F43）、事件循环出错泄漏 WEB 子进程（F51）、`--lan` 文本模式丢 `--open`（F52）等实缺陷与 help/文档漂移（F47/F48/F49/F53/F56/F57/F58）、`--lan` 面零冒烟覆盖（F50）、/tmp 波次残留含明文口令样串与自签私钥（F60）。

## Decision

- F42 按 survey 建议取完整方案而非最低限度：两 socket 克隆入共享 `Arc<Vec<TcpStream>>` shutdown vec，任一方向结束先双拆（`Shutdown::Both`）再 join——与 wave11 TLS 泵 `pump_direction` 同一纪律，join-then-shutdown 时序从结构上不可再现；F55 的上游 EOF 回归断言（AtomicBool + 轮询）随批钉进 `lan_ws_proxy_end_to_end`。
- F43 没有照搬 survey 的「Attach 分支顶部」措辞：kill 点放在 `restart_profile` 返回 `Ok(new_run)` 之后——旧 run id 恰在此刻退役，而 restart 失败路径（旧 host 存活、run id 不变）的 WEB 子进程仍有效，顶点杀会误伤一个还能用的服务。借用面用字段级 `stop_web_child(&mut self.web_child)`（`stop_web` 保持原签名转发）：`a` 在分支内持续被借用，`&mut self` 过不去，字段级借用与 `&mut self.session` 不相交合法。
- F51 改 rc 捕获收尾：`run_app` 结果先落 `rc`，两收（session/WEB）无条件执行后再 `rc?`——`Device` 有 Drop、`Child` 没有，错误路径不再孤儿化子进程。
- F61 选 value_parser 方案（`web::parse_web_port` 拒 0，`--max-conns` 专用解析器先例）而非 main.rs 手写门或回读实际端口：拒绝 0 从根上消灭「URL/QR 打 :0 死链」，回读为无人请求的 OS 临时口增加管道面。
- F62(d) WEB 键 argv 显式带 `--run <本会话 run 路径>`（Host 分支 `Device::run_path()`、Attach 分支 `a.run`，poll_rotate 同型 match）——多活 run 时 `find_run(None)` 取最新 VNC run 未必是本窗口会话。
- F50 新配方 `berry-vnc-lan-smoke`（justfile）：rc=2 拒面三路 → 文本模式起服断言页 200/`/ws` 无 Upgrade 404/`POST /api/power` 无门 403/QR 块在场且 QR 行不含口令 → 内联 python3 裸 TCP ws Upgrade 断言 101 + RFB banner（单测全是合成上游，此处是合并版单口代理 × 活 QEMU 的唯一自动化位）→ `--json` 二次起服断言 `lan.bind=0.0.0.0` 与 `lan.upstream=ws`；`berry-vnc-tls-smoke` 尾部追加同族断言 `lan.upstream=wss`（复用既有 TLS run，零额外 QEMU）。
- F50 落地途中两个环境事实（配方内注释同款记录）：其一，隔离 BERRY_HOME 必须钉 /tmp——`$TMPDIR`（/var/folders 长基座）下 run 目录的 unix 套接字路径超 macOS sun_path 104 字符上限，`berry host` 子进程起不来（稳定 rc=6「host exited before announcing run」）；其二，just 配方体内 heredoc 体与终止符必须缩进到配方层级——列首 0 的体会被 just 当顶层行解析（报 token 错），缩进后 just 剥公共前导、shell 收到合法 heredoc。
- F50 的 `/ws` 404 探针捞出一条 survey 未登记的存量缺陷并同批修复：`respond_request` 的 404/400 以「状态码 404」当 head_only 传入，非空 body（`not found\n`）承诺 Content-Length 12 却只发头不发体——GET 也一样，curl 记 partial（exit 18），浏览器静默容忍所以三波未显。修法：head_only 跟随请求方法（HEAD），与 200 路径同一语义；`http_round_trip` 加 GET 404 的 CL=体长与 HEAD 404 零体两条钉。
- F47/F48/F49/F53/F56/F57/F58 文档面逐条按 survey 修法兑现（about 自有壳页措辞、两处 keysym 旧口径刷代点、Desktop.app TPN sha 断言补时点限定并记待重打包、`--lan`×`--tls` hint 改旗标级互斥、`--host` help implies→requires、wave5 样例 URL 刷根路径、AppDir 检查计数补口径时点与存量档 FAIL 事实）。
- F60 清理执行：先核身（`web-qr-sample.txt` 明文 `#password=` 样串、三套 certs 目录 ca-key/server-key 私钥、四个 0B 空壳）+ lsof 确认无进程持有，再删 `/tmp/berry-w10quick`、`/tmp/berry-w9probe`、`/tmp/berry-w9v2`、`/tmp/b10v`、`/tmp/berry-w10-e2e`、`/tmp/berry-w10-nopass`、`/tmp/berry-lan-probe` 七处（约 268M），复扫全空。
- 顺手清了两条测试面编译警告（`display/vnc.rs` connect_to 与 `vnc_cfg.rs` 暴露面测试的 `let mut` 冗余，均 VNC 属地文件）——单测面恢复零警告。

## Alternatives considered

- F42 最低限度方案（pump_in 退出时拆上游 + 两 shutdown 移到 join 前）：能堵两个泄漏方向，但两条路径仍各自为政；共享 shutdown vec 与 TLS 泵同构、审读成本更低，弃最低限度。
- F43 顶点杀（survey 原文「分支顶部」）：一行更少，但 restart 失败路径误杀仍有效的子进程；精确点位只多一层缩进，弃。
- F61 main.rs 手写 rc=2 门：与 `--lan` 族其余手写门同型，但 value_parser 让 clap 在解析层统一报错（`--help` 亦可自文档），且与 `--max-conns` 先例对称，弃手写门；「回读实际绑定端口」方案弃（为无人请求的场景加管道）。
- F50 ws 探针单次 recv（环回几乎必合段）：与 F63 修的正是同类分段侥幸，探针与单测同纪律用读循环，弃单读。
- F49 重打包 Desktop.app/AppDir-linux 使断言回真：跨平台重链（Linux musl 交叉 + 容器）超出本刀「文档漂移」范畴，与 F58 的存量档重建同批留 owner，弃重打包取时点限定。

## Consequences

- 单测 120 绿（基线 118 + `lan_ws_proxy_connect_failure_tears_down` + `web_port_parsing`，F54/F61 面），零警告；`just berry-build`（docs_guard PASS）、`node .agents/tools/check-docs.mjs`（267 篇 0 告警）、`berry-smoke`/`berry-vnc-smoke`/`berry-vnc-tls-smoke`（均隔离 BERRY_HOME 实跑）与新 `berry-vnc-lan-smoke` 全绿。
- GET 404/400 响应形状变化：现在按 Content-Length 足额发体（此前承诺不发）——严格客户端（curl 类）不再见 partial，浏览器面无感。
- `--port 0` 从静默死链变 rc=2 用法错；`vnc web --help` 的 about 与 `--host` help 与实际语义对齐。
- LAN 代理拆链有了回归网（上游 EOF 断言 + 建链失败臂测试），F42 类回归从此红灯可见。
- survey 的 F44（`/api/power` 无口令 run 鉴权面）、F45/F46（沿革撞号）、F59（拆分清单翻状态）、F62(a)(b)(c)、F64-F67 维持只记录，归各自属地。
- 本刀零 git add/commit；全部改动留在工作树待 owner 与八至十一波交付物一并落账。
