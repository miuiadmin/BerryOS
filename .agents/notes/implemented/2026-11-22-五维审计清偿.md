# 五维遗漏审计与清偿（31 原报 → 20 合并，3×P0 全修）

Status: implemented

## Problem

workflow 五维审计（CI 可移植/引用一致/闭环演练/配方对照/账面 + 交叉复核亲手验证）对已交付纪律系统查出 20 项：三 P0——e-doctor 自检腿 2 用真 PATH 断言 tmux/gh/claude（ci-light 首推必红）；控制面门在 pre-commit 里被文档门早退旁路（只改治理工具的提交整门不跑，规则 16 立法与实况不符）；E lane 一键发射会把工作分支建在 origin 旧基（缺宪法四件，首跑 fetch 回拨即楔死）。

## Decision

2026-11-22 全额清偿：批一（推送前）——e-doctor 腿 2 改 stub PATH 封闭化 + REQUIRED_TOOLS/FILES 补员（just/cargo/receipts/debt 等七件）+ 远程四件红灯（cat-file -e @{u}:SKILL 等，防「发射先于推送」）；pre-commit 控制面门搬到文档门早退之前（无条件先跑，旁路堵死）；FROZEN/MACHINERY/control-plane 三清单补员（claude-audit/三债网/.agents/tools//facts.py/gate-selftest.sh/MANIFEST 行）——facts.txt 特意不入冻结集（runner 的刷新义务 vs 冻结面冲突，审计建议的误收自纠）；punch-list 三重双记账收敛为真实残差 + 推送前置于发射；SKILL FROZEN 散文枚举改 e-guard 单源指针；规则 16 表述限定；.gitignore 收 cargo-target-build/。批二（发射前）——heartbeat 闲态真传 --idle（machinery 回退从死代码变活路径，附 2400s 帽）+ 只读观察者排除修正 + 删死函数；run-e 陈旧 marker 判定（tmux 全灭后自愈不再挡死 start）；ci-light push 分支面加 wip/auto-*（lane 等绿链触发面，否则每轮空等 45 分钟）；ci.yml test-host 半边挂账记账；RUNBOOK provider 漂移修 + owner/lane 同步回路句。配方外四件裁定存档进 punch-list（preflight/PreCompact=显式放弃、notify=观察后定、stop_audit=四门等价）。

## Alternatives considered

- 在 runner 机补装 tmux/claude 修 CI：否——自检该验 check() 逻辑而非宿主舰队，stub PATH 封闭化才对。
- 三张治理清单手工同步：否——已再漂移一次（本审计实抓），单源生成列为后续小刀。

## Consequences

审计修正在提交前落位（含本笔记同批）；E lane 发射的硬前置 = 纪律线推送（e-doctor 远程四件红灯执法）；lane 推 wip/auto-* 即时触发 ci-light（轻道 ~2 分钟可判绿）。
