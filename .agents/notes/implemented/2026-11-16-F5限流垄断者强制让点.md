# F5 限流垄断者强制让点：THROTTLE 从「只挡再出选」到「真执法」

Status: implemented

## Problem

SMP-01 号报告 §3.5 遗留（[SMP-01-双核全路径验证](../../../research/调度深度调研/SMP-01-双核全路径验证.md)）：`HELD_THROTTLE` 位使任务不可再出选（`berry_ringface::eligible` 位过滤——`my_cur` 自豁免只覆盖 Running 臂，救不了限流位），但**不挡继续跑**。单任务独占核时 `on_irq_tick` 的出选恒 None（sched.rs 片燃尽支 go=None 路）⇒ 不切换 ⇒ 被限流的 cur 续跑到 block/yield/exit——带预算（band）与逐任务预算（S5-c deadline）双双被架空，垄断者无视限流。单核同形（非 SMP 退化）。

## Decision

三件最小面（判据单源 + 切换舞 + 醒源护栏），全部 sched/ 内：

1. **判据单源** `sched::throttle_yield_due(cur)`（sched.rs：只看 `HELD_THROTTLE` 位不问写者——band 越线 `throttle_all` 与 S5-c `Fair::tick` 的 `throttle_admissible` 两位写者的统一执法面）。pub 供 ktest 决策面钉板。
2. **强制让点** `on_irq_tick` 片燃尽支出选 None 臂：RQ 窗内判据真 ⇒ cur Ready 化（在环保留不摘环——翻期解限后原环原位回场；清 Running = 解除 Running-elsewhere 自锁，否则本核 pick 恒滤、对核偷不得，翻期也回不来）⇒ 窗外切换舞：CPU0/单核切 `IDLE_TASK`（block/exit 的 pick-None 臂同形；环非空 ⇒ idle_loop「有活」热旋支每 tick 跑 `band_period_sweep` 翻期解限回场）、副核 `set_current(null)` 切 `sec_park_ctx`（block/exit park 臂同形，`park_recheck` 承接）。配额跨线早于片燃尽的形态（quota < quantum 配置）让点推迟到片终点——上界一个本带 quantum（CBS 期内超卖同界），生产 utility 形 quota==quantum 同拍重合。
3. **醒源护栏** `band::nearest_throttle_wake()`（armed 且 throttled 镜像真的槽中 `DEADLINES` 最小值 = 最早翻期解限时刻）并入 `sched::nearest_deadline`（min 合并；`any_armed` 门零武装零成本）。缺此面则强制让点后深 park（mask CNTV 无 tick）把「让点」变「永久饿死」：`band_period_sweep` 永不再跑、限流永不翻期、无人再醒。三个 park 武装点（idle_loop 两态 + secondary_main park 环）与 tick 入口收紧共用此单源。

ktest `THRYLD ok n=4`（kernel/src/ktest.rs 末位新号）〔2026-11-18 醒源刀后 n=5——T5 增逐任务面〕：T1 真 `FairBand::tick` 烧穿配额置位 cur；T2 判据四面（限流垄断者须让点 / unit 垄断者续跑零漂移 / 限流者在环时他者出选 / S5-c deadline 位同判据）；T3 醒源 min 律；T4 翻期回场。

## Alternatives considered

- **idle 注入 / tick 面强制 park 切点（v2 议原案）**：报告 §3.5 原判「真执法需 idle 注入或强制 park 切点，v2 议」。本轮取最小形——不动 idle 注入面，只在既有片燃尽支的出选 None 臂加判据分支，全部切换舞复用 block/exit 的 pick-None 两臂现形（第八/九入口外的同族变体，断言/记账/integrity_check 同款）。
- **片中途即时强制让点**（consume 越线当拍即切，不等片终点）：被否——引入片边界外的新抢占点，需复制 preempt_count 禁切窗门全套；且越线上界本就有 CBS 语义（≤1 quantum），收益不成比例。
- **判据查 `band::state(band).throttled` 槽镜像**：被否——S5-c deadline 限流不在槽镜像里；统一面是 Task 上的位（两位写者一位表达，判据只看位）。

## Consequences

- **dpg_press 第三形态降软**（kernel/src/dpg.rs 反向臂硬 panic 门扩 `|| berry_sched::any_armed()`）：F5 生效后 utility 带进入真实配额占空比，每翻期整批解限（`unthrottle_all` 的 high_weight VD 重臂 = 回场优先），缺页供给墙钟被回场 Burst 合法推高（对角 A/B 实证：判据关 DPGPRESS ok / 判据开 Σ≥4×阈）——「wall ≈ 自证停顿量级」的单核静默场前提与 SMP 多消费者形态同构性破，走该测试自有的软路径先例（AM-2e）。θ_p 语义零改动。【推】机制归因=回场 Burst；实证=对角 A/B 数字，未做逐笔仪器化。
- **既有环境暴露澄清（非本刀引入）**：dpg_press 硬 panic 形在「ktest 收口后、舰队懒重武装前」的未武装窗内对宿主争用敏感（CNTVCT 挂宿主墙钟，负载 5-7 时停顿 10⁷ 量级）——F5 关的对照二进制同负载同炸（Σ=18.7M），且该窗内带未武装 ⇒ F5 全程未激活（断言布尔自证）。是否把单核硬形一并降软归测试 owner 裁决，本刀不扩权。
- 单核回归：boot 全绿（32 标记 + ktest done + THRYLD），SMPLZ/BAND-SMP/EASPROD-SMP/SLACK-SMP（并行 F6 刀）共存无扰。
- 双核形态（副核 park 臂 + 醒源）推理自洽但本轮未跑 `-smp 2` 实证（报告 §五 已挂 smoke-smp 补跑）——【推】SMP 醒源链：两核同停泊同截止醒 ⇒ CAS 单赢家解本环 ⇒ 输家核 pick 扫 lazy_enforce 愈合残留（SMP-01 F1 面）。
