# Agent Note: 重放与并集解对现行面的静默覆写（集成三修复 + 键表吞头再犯）

Status: implemented

## Problem

2026-11-16/17 跨根收口窗口连出四起同族事故：行级机械合并（union 并集/净增量重放/整取）把「已演进的现行面」当「基底零漂移的旧面」静默覆写，或把结构化清单当纯文本行集破坏——每一犯当时都不报警，事后靠构建红或人工对拍抓获：

1. 根 Cargo.toml members 数组被 union 脚本叠出三个连续尾 `"wakeface",]`（并集解事故族第八犯，05615c1e7 修复 = 按 base 逐字重建 + 追加六新成员——行级并集不懂数组结构，尾追型并集在数组上必然叠尾）。
2. #354 重放（8e71e8ee）：ux-splash 净增量重放自旧基底 148c8acf 起算，合入时点 origin 的 berry CLI 四件已进 VNC/设备面，整取覆掉现行面——berry host check 42 编译错实证；acad332ba 取回 767 行（commands/device/main ← base，window ← #397 tip），连带裁决 --boot-mode 注入半成品（零外部消费者、从未编译通过）弃置挂账波1 合并刀 B。
3. bootmode 键漏登记（28b727502 补记）：fwcfg-check 被 base 重写弄坏的窗口期恰逢 ux 刀 1 splash 半入链——门禁断窗 = 漏账通道，#400 复活对拍后抓获。
4. 键表 [[keys]] 表头吞并（51f6d8fdc，2026-11-17 抓获）：跨根收口合流把 bootmode 的 `[[keys]]` 表头当重复行吞掉——panel-fault 与 bootmode 同表重键，tomllib 严格解析即炸（Cannot overwrite a value :192）；fwcfg-check 键表侧是 sed 抽名口径，键名集合照样 25 键一致全过，结构盲。

## Decision

同批四件清偿：键表补回 bootmode 表头（tomllib 严格解析过）+ bootmode 注记补「注入方待补：波1 钦定 berry CLI --boot-mode 未落地」挂账互链；fwcfg-check 键表侧前置 tomllib 严格解析结构门 + selftest 加同表重键红腿（9→10 腿）——结构破不再依赖人眼；ux-splash-replay 笔记「整取零漂移」论断追更正指针；命令行刀谱收官翻 done。家族律三条：结构化清单（members 数组 / [[keys]] 表）禁行级并集——行集运算不理解结构，吞表头与叠尾是同一病的两面；重放/整取前必须对拍 tip——「基底零漂移」是时点断言，lane moving target 常态下合入时点必然失效；门禁解析口径必须覆盖结构有效性——键名集合相等 ≠ 文件健康。

## Alternatives considered

- 只修键表不加结构门：下一次并集再吞表头还是静默过——本犯正是门禁盲区的直接产物，只修数据不修检测器 = 留同族复发面。
- 结构门上完整 schema 校验（字段齐/极性必填）：过度工程——现行破损形态只有表头吞并与同表重键，tomllib 严格解析恰好全覆盖且零维护成本。

## Consequences

fwcfg-check 从「键名集合对拍」升为「结构门 + 键名对拍」两段（selftest 9→10 腿，改引擎必跑已绿）。并集解事故族判例链 +1：第八犯 Cargo members 叠尾、第九犯键表表头吞并——同族异位，皆行级机械合并产物。--boot-mode CLI 挂账归属三处显式承载（acad332ba 提交信息、键表 bootmode 注记、波3TabBar 笔记）。
