# Agent Note: 跨模块 ABI 合龙、进程外 W^X 编译及深水区六子系统架构裁决

Status: proposed

## Problem

在对已落盘的 25 份模块总体设计与 4 份重构计划执行交叉对账时，[全栈 25 模块跨界接缝与深水区六盲点复核审计](../../research/2026-11-18-全栈25模块跨界接缝与深水区六盲点复核审计.md) 暴露出两层尚未闭合的缺口：

1. **跨模块契约接缝摩擦**：各模块新增系统调用（缓存维护、SMMU 隔离、CSPRNG、调试寄存器、PMU）尚未汇入统一防撞号段表，且 `timed` 缺少更新/斜率校准内核 `CLOCK_REALTIME` 的写原语；`mm` 强制硬件 `W^X` 与 `berry-wasm`/`berry-webview` 动态代码生成之间缺少进程外安全编译隔离机制；存量 `am`（`0.5.0`）与 `cbox`（`0.5.1`）仍停留在单核与 FAT12 单客户端串行写文件假设且缺失 ANR 死锁抓栈；合成器 `Swapchain` 与 `SceneStream` 双模关系及 `imed` 命名待统一。
2. **商业级主力终端最后六块功能盲区**：缺少运行期应用包管理与差分热更/零残留卸载服务（`pkgmgr`）、缺少多源融合定位与粗细精度隐私分权（`location`）、缺少物理断网防偷传输入法与多屏扩展桌面/全局搜索/免驱矢量打印（`input-productivity`）、缺少有向图优雅关机与每应用 `mAh` 能耗归因账本（`power-thermal`）、缺少统一通话框架与跌倒 SOS 紧急救援（`telephony-sos`）、以及缺少全栈解析器 Fuzzing 与块设备断电撕裂验证靶场（`verif`）。

## Proposal

一次性完成跨模块接缝收口与最后六大深水区模块立项，将 BerryOS 全栈总体设计矩阵定格在正交完备的 **31 模块**：

1. **锁定 ABI v2 全局唯一号段表与进程外 `aotd` `W^X` 编译链（[全系统 31 模块终态合龙总纲与 ABI v2 号段总表](../../plans/2026-11-18-全系统31模块终态合龙总纲与ABI号段总表.md) + [app-interop 总体设计](../../plans/app-interop/design.md) `1.1.0`）**：统一分配 `0x07..0x8A` 无碰撞系统调用号位（含补齐 `0x64 berry_clock_adjust`、`0x1E berry_vmo_seal`、`0x88/0x8A` `PowerResourceCap` 门控与 `0x41/0x45..0x48` `RIGHT_DEBUG` 调试族）；规定客户端沙箱严禁动态申请可执行写页，Wasm/JS 机器码统一由零网络隔离进程 `aotd`/`jitd` 编译、PoU 刷指令缓存并 `vmo_seal` 永久封死写权后只读映射。
2. **原地升格 `am` 2.0 与 `cbox` 2.0（[am 总体设计](../../plans/am/design.md) + [cbox 总体设计](../../plans/cbox/design.md)）**：废除 RAM 8 槽墓碑上限与 FAT12 三窗排液妥协，全面接入 `BerryFS` 多会话并发持久化、LZ4 冻结换出池、真实流活跃度租约核验，并打通输入/生命周期超时触发的跨进程 `PiEdge` 顺藤摸瓜 ANR 全线程抓栈与 ASLR 内联符号还原。
3. **补齐深水区六大子系统终态规格**：
   - [pkgmgr 总体设计](../../plans/pkgmgr/design.md)：流式 Merkle 边下边验零双倍占盘安装、`/data/pkg/cas/` 内容寻址去重、前台运行零打断热更与五方两阶段零孤儿原子卸载；
   - [location 总体设计](../../plans/location/design.md)：双频 GNSS + 本地离线 Wi-Fi 瓦片 + IMU 隧道航位推算紧耦合滤波，以及抗多次采样三角反推的 S2 球面 5km 网格 `LocationCoarseCap` 句柄级物理隔离；
   - [input-productivity 总体设计](../../plans/input-productivity/design.md)：永久剥夺 `NetCap` 的 100% 离线输入法 `imed` + 密码框硬件旁路 `SecureKeypad`、手机一线连 4K 异构 DPI 独立 VSync 多屏桌面、10ms `BerrySpot` 秒搜与 `SceneIR` 原生矢量 PDF 免驱打印；
   - [power-thermal 总体设计](../../plans/power-thermal/design.md)：1 秒五阶段有向图优雅关机刷盘、五维硬件分摊每应用 `mAh` 功耗账本、80% 旁路护电池与六级 PID 热失控保护；
   - [telephony-sos 总体设计](../../plans/telephony-sos/design.md)：蜂窝与加密 VoIP 平权接听 `callmgr`、通话录音强制双端提示音护栏、跌倒/车祸检测与 5 连击电源键免解锁自动播报经纬度 SOS 及锁屏只读医疗急救卡；
   - [verif 总体设计](../../plans/verif/design.md)：纯核 `proptest`/`loom` + 全解析器与多核 ABI Fuzzing + `CACHE_FLUSH` 屏障间任意子集断电撕裂竞技场 `torn-arena` + 24 小时混沌手势风暴四层验证金字塔。

## Alternatives considered

- **备选一（允许网页与 Wasm 沙箱进程直接申请 RWX 页或自行执行 `RW -> RX` 翻转以简化 JIT 实现）**：落选原因——一旦渲染沙箱存在任何一处类型混淆漏洞，攻击者即可直接写入任意 Shellcode 执行而绕过硬件 ROP 防线；进程外无网 `aotd` + `vmo_seal` 虽增加一次只读句柄传递，但能从物理页表层彻底根绝沙箱内动态注入可执行代码。
- **备选二（大致位置仅对真实经纬度叠加随机高斯白噪声，不做球面固定网格吸附）**：落选原因——独立同分布零均值随机噪声在用户居家静止期间经数十次重复查询求均值即可将误差收敛至数十米内从而暴露真实住址；每应用私有盐值 S2 网格中心吸附在数学上令重复采样信息增益恒为零。
- **备选三（允许第三方输入法申请网络权限以拉取云词库，仅在隐私政策上做合规约束）**：落选原因——键盘敲击流包含用户最高机密，任何软件层自律承诺均无法证伪密文夹带上传；由微内核 `Job` 层物理不发 `NetCap` 并改由本地不出端 `airtd` 大模型提供上下文纠错与语音转写，体验更好且绝对零外泄。

## Consequences

- **全栈顶层规范收官**：全仓 31 份模块 `design.md` 全部达到 `Version >= 1.0.0` 现行态，术语统一登记入 [GLOSSARY.md](../../GLOSSARY.md)，所有系统调用号位、守护进程边界与跨轨握手节点完全闭合。
- **实施落地路径**：按 [深水区六维补完与跨模块接缝收口实施计划](../../plans/2026-11-18-深水区六维补完与跨模块接缝收口实施计划.md) 四波十六刀汇入总控里程碑执行。
