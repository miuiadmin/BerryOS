# Agent Note: 终结多端缝合审美，确立全面复刻 iOS 18 / iPadOS 18 视觉与流体交互唯一范式

Status: proposed

## Problem

尽管底座与合成器架构已立定真离屏交换链、8-bit 预乘混合与矢量字体方案，但 BerryOS 在上层 GUI 产品思想与视觉规范上仍残留严重的历史割裂：存量规范同时混杂了安卓三大金刚（AOSP VectorDrawable）、Material Design `56dp` 左对齐顶栏、以及「安卓 + 鸿蒙 + iOS 三方共性控件」折中方案；加之缺少曲率连续几何、增艳毛玻璃光学公式、字距排印表与物理阻尼参数，工程师在实现时只能凭经验拼凑正圆锯齿色块与空壳演示应用，导致做出的界面呈现明显的廉价感与「四不像」割裂感。

## Proposal

遵循用户「视觉上全面复刻 iOS」的核心拍板，立定 [iOS 视觉与流体交互复刻标准](../../../docs/iOS视觉与流体交互复刻标准-v1.0.md)，同步升级 [GUI 合成与 SDK 终态标准](../../../docs/GUI合成与SDK终态标准-v2.0.md) 与各模块总体设计，并将存量冲突规范翻转状态取代：

1. **视觉与材质唯一北极星（iOS 18 基准）**：废除一切多平台混搭妥协，全系统几何统一为 $G^2$ 连续曲率超椭圆（Continuous Squircle）与同心圆角律；半透明层统一走「Dual-Kawase 模糊 + `1.8x` 饱和度矩阵提拉 + 语义纱幕 + `0.5pt` 微晶内高光与前景 Vibrancy 透色」四阶光学管线；色盘严格锁死 iOS 18 `#F2F2F7/#FFFFFF` 浅色分组与 `#000000/#1C1C1E/#2C2C2E` 纯黑无阴影深色海拔体系；排印严格对齐 SF Pro 11 档字阶、紧凑负字距与等宽数字 `tnum`。
2. **导航、灵动岛与兼容开关裁定**：淘汰 Material `56dp` 顶栏，全面采用可随滚动折叠进 `ChromeMaterial` 毛玻璃的 `34pt` 大标题导航栏、`InsetGroupedList`（`0.33pt` 缩进极细线）与弹性 `51×31pt` `UISwitch`；顶部引入 **灵动岛（Dynamic Island）** 实时活动胶囊与右上角下拉圆角模块化控制中心；底部默认采用 iOS `134×5pt` Home Indicator 全手势横条，同时在系统「设置 → 显示与导航」中保留「经典三键导航」兼容切换开关（以抗锯齿 SF 细线条矢量图标取代旧 AOSP 位图）。
3. **iPhone 竖屏先行 + 宽屏自动切 iPadOS 18 双形态连续体**：`< 600pt` 像素级复刻 iPhone 竖屏体验；`>= 600pt`（平板或桌面宽屏窗口拉伸）自动切换为 iPadOS 18 浮动扩充 Dock、`UISplitViewController` 毛玻璃侧边栏与 `Split View` / `Stage Manager` 台前调度自由圆角多窗口，用同一套纯正苹果设计语言自然承接键鼠桌面生产力。
4. **砍伪存真与 Xcode Simulator 级外框**：将无真实后端的凑数空壳应用移出默认主屏，集中打磨设置、文件、备忘录（含按键放大气泡 iOS 拼音软键盘）、相册、时钟/计算器（联动灵动岛）与终端/活动监视器六款真精品；宿主模拟器窗口直接做成带 `55pt` 同心超椭圆钛金属设备外框与触控板原生手势映射的 Xcode Simulator 形态。

## Alternatives considered

- **方案 A（维持「安卓 + 鸿蒙 + iOS 三方最大公约数」自创混合风格）**：否决。缺乏成熟系统级视觉设计师时，「取三家交集」在工程上必然退化为无曲率连续、无材质层次、各页面风格互搏的简陋色块拼接，正是造成此前 GUI 观感低劣的主因。
- **方案 B（仅锁死竖屏手机窗口，桌面宽屏用黑边居中填充）**：否决。BerryOS 同时承载开发者终端与桌面生产力场景，直接复用 iPadOS 18 的 `SplitView + Stage Manager` 台前调度既保持了 100% 统一的果味视觉基因，又无缝解决了宽屏键鼠多窗并排办公诉求。
- **方案 C（一刀切删除三键导航能力，不留任何按钮导航选项）**：否决。按用户裁决，默认态 100% 采用纯净 iOS Home 横条与流体手势，同时在设置中保留经典三键开关并重绘为统一细线矢量符号，兼顾默认颜值纯粹性与部分桌面鼠标/无障碍用户习惯。

## Consequences

- **正面收益**：全栈 UI 从此拥有零歧义的像素级对标标尺（任何间距、字号、色号、圆角曲率、阻尼系数均有精确公式与真机参照，彻底告别工程师拍脑袋配色排版）；模拟器第一眼即呈现旗舰级商业 OS 质感。
- **规范与工程收口**：`Berry设备平台-TransparentFloatingShell-v1.4.md` 与 `BerryUI-TriPlatformControls-v1.15.md` 翻转为 `superseded` 并指向新标准；光栅核补齐超椭圆 SDF 与 `1.8x` 饱和度矩阵，六波重构计划增设宿主机 iOS 18 视觉样板对拍门禁并聚焦六款真系统应用交付。
