## 一句话说明

补完日常 shell 最后三个「不能」（脚本执行/分号/注释）外加 $0 最小面：`bsh <file>` argv 第三路（跳自验链、get_file 读、environ 播种、逐行 run_line、job_exit_sweep 后按末行 status 退）＋source/. 双名内建（当前上下文逐行执行，门序镜像 cat 三段门，深度帽 8）＋berry-lex Op::Semicolon（chain_groups 扩三元 ChainOp::Seq 无条件闸——与 POSIX 顺序表等价已证）＋词首 `#` 注释至行尾（XCU 2.3 规则 8 先于规则 9；strip_bg 同步注释感知防 `# … &` 误剥）＋`$0`（scan_dollar 数字零臂→Piece::Arg0＋Vars.arg0，交互="bsh"/脚本=脚本名，$1..$n 挂 3.0）；CLI ok n=15→16 前缀式零断言滚；恒等契约重划界为「无 `;`/无词首 `#`/无 `$0` 输入零漂移」（语料三零实测命中）；护栏复用引号刀 IDENTITY 载具形；语法能力新增按 shell设计 §4 版本律落 MINOR（标准文档连名滚 v1.3）。三件一齐落不留半语义中间态，与 v2.5 同款「3.0 bsh-syntax 干净子集」定位。

## 裁决

D1 argv 第三路：main() 解析 skip(1)——`--no-selftest` 旗任意位保持；首个非旗参＝脚本路径（余参静默忽略，$1.. 挂 3.0 记面）；有脚本参即跳 boot 自验链直进脚本路（同 --no-selftest 机理——TCG 分钟级阻塞＋smoke 契约保护；svcmgr 零参与 term_selftest 子 bsh 单旗形零漂移）。
D2 run_script 门序镜像 cat 三段门：valid_path 拒→eprintln usage＋exit 2；fs_h()==0→「fs not available」＋exit 1；get_file Err→errno_text＋exit errno_code（ENOENT=127 余 1）；读面复用 get_file（FILE_SIZE_MAX 帽即脚本帽，不另立 8KiB/64 行——那是 BSHRC 专用）。
D3 脚本模式播种 environ→vars（抽共享 fn，interactive/run_script 同调——否则 run 子进程 env 恒空）；不装载 BSHRC.CFG（POSIX 非交互不读 rc；rc_load 装载点零动，守「写端适配读端」铁律）；交互/脚本起点差异记面。
D4 逐行循环：split b'\n'＋剥 \r＋trim＋空行跳过＋run_line(…,&[])；注释行零特判（行首 # 即词首，词法层统一吞）；未闭合引号行打诊断 status 2 续跑（POSIX 中止语义偏差记面）；收口 job_exit_sweep（同 exit 内建先例 :4037/:4442）＋std::process::exit(末行 status)（空脚本=0）；脚本内 exit 内建＝恒码 0 现行为保持记面；脚本路不武装 Ctrl-C（与自验链同形记面）。
D5 分号＝Op::Semicolon（text()=";"，lex Normal 臂 `>` 臂后 else 前——无 maximal munch 冲突）；chain_groups match 加 Op(Semicolon)→ChainOp::Seq 臂、ChainOp 加 Seq 第三变体（闸＝无条件；run_line 闸 match 穷举编译器执法）——产 (段,引导操作符) 三元序列即任务语 split_chains（旧名沿革 :3561 在册，保现名零涟漪）；扁平单趟与 POSIX 层级 list 顺序/短路等价（闸只读 $?）；`;;`/前导/尾随 `;` 沿用空组静默跳过（宽容偏差家族记面，case 挂 3.0）。
D6 词首注释：Normal 态 `#` 且 lit_q.is_none()&&pieces.is_empty()（Out 私有谓词；ws()/op() 均清 pieces——`a#b` 词中字面、`"x"#y` 闭引号续词、`a ; # c` 操作符后注释，四形推演钉板）→break 丢弃至行尾（单行输入与第四态零差，3.0 多行升 State::Comment 挂账；EOL 错检零改）；交互/脚本同一 run_line 零分叉。
D7 strip_bg 注释感知：ends_outside_quotes 加词首 # 截停（词首判＝行首/未引号空白/`&|>;` 后；引号开闭字节续词）——注释内尾 `&` 不剥（`# … &`＝前台＋整行注释 POSIX 形）；私有 fn 零 API 涟漪；exec_bg_items 链拒 match 补 Op(Semicolon)（`a ; b &` 拒整链后台——POSIX 仅后台末段，同族偏差记面挂 3.0）。
D8 source/. 双名同臂入 BUILTINS（25→27；POSIX 正名 `.`＋bash 别名 source，design.md:93 兼容律；Tab/type/exec_bg 内建拒经 contains 自动收编）；单参形镜像 cat：无参/多参/valid_path 拒→usage 2、fs_h()==0→码 1、get_file Err→errno 码；共享 vars/&mut status 当前上下文逐行 run_line（bsh 无子 shell，POSIX dot 语义零机制新增）；SOURCE_DEPTH static 帽 8（镜像 JOBS/jobs() :264-271 SAFETY 形）超帽诊断＋status 1；sourced 内 exit＝杀整 shell（POSIX 本真记面）；source 不改 $0。
D9 $0 最小面：scan_dollar 加 `$0` 数字零臂→Piece::Arg0{quote}（余数字维持 `$` 字面——$1..$n/$#/shift/set -- 全挂 3.0）；Vars 加 pub arg0:&'a str；三视图补臂（render 推 arg0／fields push_expansion／word_texts 还原 "$0" 字面）；bsh 侧 ARG0 static＋shell_arg0() 访问器（镜像 bg_last/jobs 先例），main 起点单次置位（脚本路=脚本名、交互/自验路="bsh"），lex_vars :3528 装配；vars 表不注入 "0" 名（防 env/export 面污染）。
D10 恒等契约重划界：「无 `;`/无词首 `#`/无 `$0` 输入零漂移」（v2.5 契约的三字符扩面）；语料三零实测：bsh 267 自验喂入＋smoke 6 脚本 18 inject＋berry-lex 72 测字面量（$0 本次 grep 零命中）；护栏复用引号刀 IDENTITY 载具形（改前金样采集→改后 render/fields/word_texts/strip_bg/chain_groups 对拍逐字节零差；开发载具不入树）。
