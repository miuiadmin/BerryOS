## 裁决记录

1. **双编辑器归属＝哑终端化（三稿一致，案 A）**：本地编辑器退役、显示单源=子回显字节——失步类结构性根除（第二份行缓冲物理不存在）、berry-term 代码净减、Ctrl-C/Tab/prompt 接续/历史显示四族降解面同根同治一次收口；代价（每键一通道往返、显示依赖回显解释器）经 bsh 回显词汇表逐字节核实封闭＋berry-termio host 单测对冲。
2. **editor.rs 不抽 crate（三稿一致）**：「不长第二套」以删除第二套兑现而非抽象共享——抽 crate 保留两实例失步只收窄非根除，且动 bsh 自验链对抗审查回归面；PROMPT 单源随 B5 直接收口。
3. **引号/`${}` 裁出本刀（risk/value 砍 vs unify 收，2:1 砍）**：expand 波及全部分发路径词边界（strip_prefix 裸空格纪律）与操作符识别全线，unify 稿自认其为最大回归域；独立分词器设计刀先立骨架再上引号，避免半语义面。
4. **unset 收入（risk/unify 收 vs value 砍，2:1 收）**：value 砍单理由（env 传递阻塞）只适用 export；unset 是纯 shell 内减法零内核零契约依赖，补齐赋值/覆盖/撤销的生命周期闭环。
5. **软换行收入但可降级（risk 收 vs value/unify 砍，骨架裁定）**：两稿砍单理由（TEXT_INLINE/MAX_NODES 全局联动）针对「抬常量」方案，risk 的行内 64B 切块方案不抬任何常量——理由不命中；哑终端化后尾段=活动行，子行帽 256B 只显 59B 是真实可感缺口；berry-termio host 单测覆盖视图计算对冲回归面；明记降级预设兜底复杂度。
6. **子退出重启＝自动 respawn＋退避＋三击熔断，熔断后 Enter 手动恢复（value/unify 自动 vs risk 手动，2:1 自动为基嫁接 risk 手动为恢复路径）**：value 的两层监督归属论证成立（bsh=berry-term 内部资源，svcmgr 监督 app 进程本体）；纯手动在误敲 exit 后留死页体验差；熔断＋手动恢复兼得风暴防护与可恢复性。
7. **箭头仅 UP/DOWN 两键（value/unify 两键 vs risk 四键，2:1 两键）**：bsh editor 非 A/B finals 一律吞，LEFT/RIGHT 出向零消费语义——冻结常量与翻译表保持最小面。
8. **箭头出向形态＝三帧单字节 ESC 序列连发（三稿一致）**：guiproto 零改、x 字段保持单义、bsh editor ESC 状态机零改、哑终端化后 berry-term 零特判；键码语义帧语义干净但双消费面自译＋两域分注重写，为两枚键不值。
9. **`>>` 落法＝读旧＋拼接＋整写回（三稿一致）**：berry-libc 无 O_APPEND、可写 fd SEEK_END 用自身游标均为 v1 文档化缺口（fs.rs 头注现场核实）；get_file/put_file 件已在（main.rs:3868/3905）零新协议面；FAT 读改写翻倍成本 KB 级可受。
10. **管道切词在展开后的段文本上空白分词（risk/value vs unify 展开前切词逐词展开，2:1）**：与 do_pipe 现结构（先 expand 再校验段）最小 diff；与 render_cmd 词边界（裸空格分词）同纪律；变量值含空白拆多参＝POSIX 同形（无引号面记面）。

- **B2 `||` 与求值序**：跳过段不求值是 and_selftest ② 同款钉板面，新自验步显式断言「跳过段赋值不落表」；恒等契约（纯 `&&` 输入与 split 同果）由 split_chains 纯函数对拍执法。
- **B4 触 do_pipe/pipe_capture 双端**：pipe_capture 零改（args 已在），PIPE ok 三跑对拍＋U2/U4 既有管道自验是回归网；新带参步补交互路径覆盖。
- **K 域批帽交互**：一箭头三帧恰满 INPUT_EVENTS_MAX=3 一批，与指针帧混批时留队下轮（延迟一批不丢失）；host 单测钉 FIFO 序。
- **体积**：bsh 约 +2-4KiB、berry-term 约 ±2KiB、berry-termio 仅库面——rootfs1 余约 21MiB 充裕；主验证核对 vols=2。
- **并行时序**：批 1a/1b 文件域互斥（B：bsh 两文件；T：berry-term＋berry-termio＋user/Cargo.toml＋justfile；K：gui-inputd＋berry-virtio）；justfile 与 user/Cargo.toml 仅 T 域触碰；K 严格排 T 后；主线验证前与 TCP 四刀/guifbd 批B 会话确认 kernel/ktest.rs 与 tools/smoke-image.sh、kernel/src/main.rs 收口范围（后两件为事实底册之后新入脏——EFI 路验证以其收口版为基线，勿把他方中间态当基线跑绿）；smoke 判读用状态裁定（TCG 载荷竞速记忆在册），低载窗执行。
