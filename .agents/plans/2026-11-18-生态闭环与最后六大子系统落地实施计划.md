# 生态闭环与最后六大子系统落地实施计划

Type: plan
Status: active
Updated: 2026-11-18

一句话说明：承接已全量合入主线的 [全系统 40 模块终态合龙总纲](2026-11-18-全系统31模块终态合龙总纲与ABI号段总表.md) 与六大深水区模块总体设计（`bootloader`、`releng`、`compat`、`widgets-intents`、`nfc-accessories`、`screen-governance`），按严格工程依赖拓扑分七波二十二刀完成落地，闭环整机引导、商业发布、Linux 兼容、灵动岛微视图、外设硬件钱包与政企双域治理。

## 背景

[全栈 25 模块跨界接缝与深水区六盲点复核审计](../research/2026-11-18-全栈25模块跨界接缝与深水区六盲点复核审计.md) 与 [全系统 40 模块闭环与最后六大子系统架构裁决](../notes/proposed/2026-11-18-全系统40模块闭环与最后六大子系统架构裁决.md) 确立了 BerryOS 架构版图最终 40 个模块的完整矩阵。为了确保商业化量产交付无断档，必须以无环依赖拓扑将这最后六大子系统转化为可逐刀验证、指标量化的工程实施方案，与存量 34 个模块共同受五大全局同步锚点（M-Alpha 至 M-Omega）严密约束。

## 步骤

### 第一波（Wave G0）：引导装载与可信链交接（刀 1–3，承接 `bootloader`）

1. **刀 1（`BerryBootControl` A/B 槽位仲裁状态机）**：编写 `bootloader/src/slot.rs` 与 ESP FAT32 读写驱动，实现 `active_slot`、`priority`、`tries_remaining` 与 `successful` 双副本 CRC32 容错仲裁逻辑；达成在 QEMU 模拟断电与连续 3 次看门狗超时下，自动无缝降级切换备用槽位的容错验证。
2. **刀 2（Verified Boot 可信度量与防回滚链）**：在 `BerryBoot` Stage 2 引入静态 Ed25519 验签模块与 SHA-256 硬件加速；校验内核载荷、Boot Ramdisk 及 BerryROFS Merkle 根签名；读取安全存储中的 `min_rollback_version` 阻断旧版回滚；向 TPM 2.0 PCR-0/PCR-4 扩展度量值。
3. **刀 3（`BerryHandoff v2` 帧构建与 16KiB Ramoops 持久区）**：统一构造 4KiB 单页物理对齐的 `struct BerryHandoff` 结构体（含 64 段物理内存切片表、GOP Framebuffer 基址与格式、硬件真随机数种子）；在内存控制器标记并保留 16KiB Ramoops 区为 `NO_ZERO_FILL`，确保跨 Panic 热重启日志 100% 完整交付给 [meihe](meihe/design.md) 内核入口。

### 第二波（Wave G1）：可复现发布工程与供应链合规（刀 4–6，承接 `releng`）

4. **刀 4（确定性密封构建环境与路径抹平）**：编写 `tools/reproducible_build.sh` 包装器；强制注入 `SOURCE_DATE_EPOCH`、`-ffile-prefix-map=${PWD}=/berryos`、`SORT_BY_NAME` 链接脚本与统一 `umask 0022`；在两台异构主机（不同目录、不同用户名）比对编译生成的二进制，达成 SHA-256 重现率 100%。
5. **刀 5（CycloneDX 1.5+ SBOM 提取与开源许可证阻断）**：接入 `cargo-cyclonedx` 自动化生成整机依赖 SBOM；在 CI 中部署静态开源协议扫描器，对微内核（`meihe`、`mm`、`ipc`、`cbox`）与基础 C 库执行严格审计，GPL/AGPL 传染型代码污染率为 0%。
6. **刀 6（镜像自动化打包与 HSM 生产签名流水线）**：编写 `tools/releng_pack.py`，流水线式组装 `berryboot.efi`（$\le 2\text{MiB}$）、`boot.img`（$\le 16\text{MiB}$）、`system.img`（$\le 128\text{MiB}$）与 `recovery.img`；集成 Ed25519 签名工具与 A/B 差分 OTA 载荷打包器。

### 第三波（Wave G2）：三级生态兼容与受限态仿真（刀 7–10，承接 `compat`）

7. **刀 7（微内核受限态硬件陷阱切换原语）**：在 `meihe` 内核中落实 ABI v2 系统调用 `0x4A berry_restricted_enter` 与 `0x4B berry_restricted_kick`；在 AArch64 / x86-64 上打通受限态（Restricted Mode）用户上下文保存、Syscall 陷阱拦截与 Normal Mode 唤醒返回，往返开销压制在 $\le 85\text{ns}$。
8. **刀 8（用户态 `linux_runner` 与首批 80 个 POSIX 系统调用）**：编写 `user/compat/linux_runner` 守护进程，拦截 Linux ELF 二进制发起的 `sys_read`、`sys_write`、`sys_openat`、`sys_mmap`、`sys_clone` 等核心系统调用并转换为 BerryOS 通道 IPC；跑通静态编译的 Git、Python 3.12 与 BusyBox。
9. **刀 9（Wayland-SHM 图形与输入桥接）**：落地 `compat-wayland-bridge`，将 Linux GUI 应用的 `wl_surface` 与 `wl_shm` 转换为 BerryOS [compositor](compositor/design.md) 的 `SurfaceId` 与共享 VMO 交换链；键盘与触摸事件实时注入，窗口圆角与阴影原生混合。
10. **刀 10（Hypervisor 极简 MicroVM 基础设施）**：在内核与 HAL 落地 `0x77 berry_guest_create`、`0x78 berry_vcpu_create` 与 `0x79 berry_vcpu_run`；在用户态实现精简 `vmm`，支持冷启动极简 Linux 客机内核并以 VirtIO 导出网络与块设备。

### 第四波（Wave G3）：声明式微视图、灵动岛与意图自动化（刀 11–14，承接 `widgets-intents`）

11. **刀 11（声明式 `SceneIR` 小组件二进制序列化与只读密封）**：定义 `SceneIR` 紧凑二进制格式；应用沙箱仅通过共享 VMO 提交快照数据并调用 `0x1E berry_vmo_seal` 封死写权；[compositor](compositor/design.md) 统筹离屏光栅化，应用进程无需在桌面后台常驻。
12. **刀 12（`widgetd` 生命周期与 Timeline Provider 时间线调度）**：编写 `widgetd` 守护进程，维护桌面小组件 2x2、4x2 网格排布、数据过期时间线预测与智能叠放（Smart Stack）翻转权重计算。
13. **刀 13（灵动岛四态流体弹簧动画）**：在系统顶栏落地 Dynamic Island 交互模型；以 `Spring2D` 临界阻尼弹簧驱动 Compact、Minimal、Expanded、LockScreen Banner 四态切换，保证 120fps 流畅无撕裂。
14. **刀 14（`intentd` 意图路由与快捷指令自动化执行器）**：建立 `intentd` 守护进程；解析应用清单 `app.manifest.json` 中的公开意图；打通全局聚焦搜索、AI Agent 及终端命令 `bsh intent invoke` 语义直达。

### 第五波（Wave G4）：硬件钱包、近场通信与高精外设（刀 15–18，承接 `nfc-accessories`）

15. **刀 15（NCI 协议栈驱动与 eSE ISO 7816 通道）**：在用户态编写 NFC 控制器驱动与嵌入式安全元件（eSE）直连服务；实现标准 APDU 双向数据包收发与安全通道握手。
16. **刀 16（`walletd` 守护进程与断电 5 小时快捷刷卡）**：落地系统卡包服务 `walletd`；实现交通卡、门禁卡与 CCC 3.0 数字车钥匙；协同电源管理模块实现设备因低电关机后 5 小时内仍保持射频前端微安供电，确保地铁碰卡正常出站。
17. **刀 17（主动式手写笔预测与 Direct Overlay 极速上屏）**：接入触控数字化仪 240Hz 采样通道；解析倾角、方位角与 4096 级压感；结合卡尔曼滤波向前外推 8ms 墨迹轨迹，通过合成器专属透明 Overlay 达成跟手延迟 $\le 4\text{ms}$。
18. **刀 18（UWB 空间感知与 5cm 级精准测距）**：接入超宽带（UWB）射频驱动；实现飞行时间（ToF）与到达相位差（PDoA）运算；提供厘米级室内寻物指引并严密防御车载钥匙中继攻击。

### 第六波（Wave G5）：屏幕行为治理与企业双域隔离（刀 19–21，承接 `screen-governance`）

19. **刀 19（`governanced` 守护进程与专注模式流体切换）**：实现工作、个人、睡眠、驾驶等专注模式状态机；联动桌面页面切换与通知白名单动态过滤；严格放行国家法定 110/119/120 紧急呼叫与灾害预警。
20. **刀 20（屏幕使用时间本地加密防篡改记账）**：绑定内核单调时钟与前台窗口焦点，秒级精确统计应用活跃时长；数据落入 `/data/system_ce/<uid>/screentime.db`；杜绝修改本地壁钟破解使用限额。
21. **刀 21（企业工作域 Work Profile 与 DLP 剪贴板隔离）**：划分 UID 2000 独立企业空间与独立 CE 凭据密钥；配置安全网关阻断工作数据向个人域剪贴板流转（DLP）；实现 100ms 瞬时毁钥远程数据擦除（Enterprise Wipe）。

### 第七波（Wave G6）：跨子系统联合总验收与六大门禁（刀 22）

22. **刀 22（全系统 40 模块商业级终验与六门禁通关）**：
    - 执行全栈端到端测试，验证引导装载（$\le 45\text{ms}$）、确定性构建重现（100%）、受限态 Linux 仿真（POSIX 98% 通关）、小组件渲染（1.8ms）、手写笔墨迹（$\le 4\text{ms}$）与专注模式切换（$\le 120\text{ms}$）；
    - 全面通关 G-BOOT、G-REL、G-COMP、G-WDG、G-NFC、G-GOV 六大商业验收门禁；将 [全系统 40 模块闭环架构裁决](../notes/proposed/2026-11-18-全系统40模块闭环与最后六大子系统架构裁决.md) 翻转为 `implemented`。
