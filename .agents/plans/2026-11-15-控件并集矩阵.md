# 三家控件并集矩阵（Android/iOS/OH → BerryOS 组件体系 v2）

Type: spec
Version: 0.1
Status: draft
Updated: 2026-11-15

一句话说明：owner 2026-11-15 指令「对比安卓、iOS、鸿蒙三家，他们有的我们都要有，相似的合在一起，最终比他们丰富——人无我有，人有我强」——本矩阵给全量控件清单、三家归属、BerryOS 落地形态与刀位映射；控件规格数值基线见 [2026-11-14-survey-openharmony-ui-specs.md](../research/2026-11-14-survey-openharmony-ui-specs.md)（OH）与 Material 3 / Apple HIG 官方组件目录（本矩阵只列名目与语义归并，数值规格逐组件另行钉）。

## 归并原则

1. **相似合体**：三家同名异形控件合为一个 BerryOS 控件，命名取语义中立形（例：iOS Navigation Bar = Android TopAppBar = OH Navigation → `TopBar`；iOS Tab Bar = M3 NavigationBar = OH Tabs → `TabBar`）。
2. **独占保留**：单家独有且高价值控件单列（例：M3 FAB、iOS 的 Context Menu 长按菜单）。
3. **人无我有**：BerryOS 增强件——模拟器场景特有（宿主 CLI 直控截图/旋转/性能注入）、no-alpha 纯色预混体系（深浅色单源）、press_map 零 RPC 按压反馈（三家都是窗口合成器侧实现——我们在 UI 库层做，响应 <1 帧）。
4. **v1 已落**的标 ✅（components.rs / berry-ui 原语层）；刀位指分刀方案后续刀。

## 数值规格单源

高度/圆角/间距/色板逐控件数值以 OH 调研为基线（vp×3 换算），M3/HIG 差异点在组件 doc 注释标注；本矩阵不复制数值（一事实一归属）。

## 刀位映射

- 刀4(本轮)：TopBar 返回语义链 / TabBar 切换动画 / Switch / Button / press 缩放 / 线性加载条 / 状态栏 SYSTEM 层
- 刀5：FAB / Chip / 分段 / 对话框 / 弹层 / Snackbar / 头像 / 加载圈 / appdemo 全示范
- 刀6：徽标 / 文本框 / 深浅色全 token / OOBE 复用组件
- 刀7：滚动 / Carousel / 侧栏 / 步进 / 日期时间 / 下拉刷新
