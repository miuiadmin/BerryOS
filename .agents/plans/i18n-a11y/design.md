# i18n-a11y（全球化排版、精准时区时钟与系统级无障碍辅助技术）总体设计

Type: spec
Status: active
Updated: 2026-11-18
Version: 1.1.0

一句话说明：`i18n-a11y`（由网络加密校时与时区服务 `timed`、零拷贝国际化本地化库 `berry-i18n`、双向复杂文本整形器与系统无障碍守护进程 `a11yd` 组成）是 BerryOS 走向全球市场与兑现科技人文包容的基石——确保任何时区、任何书写方向、以及视障/听障/运动障碍用户都能一等无差别地使用整个系统。

## 背景

[整机生态十维盲区全景审计](../../research/2026-11-18-整机生态十维盲区全景审计.md) 指出：现役系统时间仅由静态起点加单调时钟合成（无 RTC 持久化与网络授时、无 IANA 时区与夏令时转换），UI 与文本管线仅假设中英文从左向右（LTR）静态字符串（缺复数/日期货币本地化与阿拉伯语/希伯来语 RTL 镜像），且无障碍语义树尚无读屏器（Screen Reader）与辅助交互消费者。本规格依据 [整机十维缺失拼图全栈终态架构裁决](../../notes/proposed/2026-11-18-整机十维缺失拼图全栈终态架构裁决.md) 与 [全系统 31 模块终态合龙总纲与 ABI 号段总表](../2026-11-18-全系统31模块终态合龙总纲与ABI号段总表.md)，立定零性能损耗的全球化与无障碍系统级契约。

## 范围

- **覆盖**：硬件 RTC（PL031 / 真机 PMIC RTC）+ 安全网络时间协议（NTS, RFC 8915）渐进频偏校准守护进程 `timed`（独占 `0x64 berry_clock_adjust` 壁钟校准原语）与全局只读共享 IANA 时区数据库 VMO（`tzdb.vmo`）；零拷贝编译期校验本地化资源包格式 `.blp` 与 `berry-i18n`（CLDR 复数规则、单位/数字/货币/多历法格式化、免重启热切换）；Unicode UAX #9 双向文本算法（BiDi）、复杂文字连字整形（HarfBuzz 子集等价纯 Rust 整形核）与逻辑方向（`InlineStart`/`InlineEnd`）自动 RTL 布局镜像；系统级无障碍服务 `a11yd`（神经网络 TTS 读屏、探索式触摸手势重写、实时语音字幕 Live Captions、开关控制与合成器硬件级色觉滤镜/视口放大镜）。
- **不覆盖**：字形贝塞尔轮廓最终瓦片光栅化（归 [gfx 总体设计](../gfx/design.md)）；端侧 TTS 与 ASR 模型底层张量算子推理（归 [ai-runtime 总体设计](../ai-runtime/design.md) `airtd`）。

## 契约

### 一、抗篡改安全授时（`timed`）与共享只读时区库契约

1. **单调守恒与渐进斜率校准（Slew vs Step，绑定 `0x64 berry_clock_adjust`）**：`CLOCK_MONOTONIC` 永远严格单调递增不回跳；`timed` 启动初期读取硬件电池后备 RTC（模拟器读取宿主挂钟同步通道），凭独占持有的 `TimeResourceCap` 调用新增内核原语 `0x64 berry_clock_adjust(time_res, offset_ns, slew_ppm_q16, flags)` 建立初始 `CLOCK_REALTIME`，联网后经带 TLS 密钥协商认证的 **NTS（Network Time Security）** 获取权威 UTC（防止恶意路由器篡改系统时间绕过 X.509 证书有效期校验！）。当偏差 $< 500\text{ms}$ 时通过 `slew_ppm_q16`（最大斜率微调 $\pm 500\text{ppm}$）平滑追赶而绝不令 `CLOCK_REALTIME` 发生跳变倒退；非特权进程调用 `0x64` 一律硬拒 `-EACCES`。
2. **零解析全系统共享 `tzdb.vmo`**：系统将编译压缩后的 IANA 时区跳变表与当前活跃时区标识驻留在一块全局只读共享内存页；任何应用调用本地时间转换无需发起跨进程 IPC 或打开文件系统读取 `/usr/share/zoneinfo`，纯用户态二分查找即可在 $< 50\text{ns}$ 内算出任意历史/未来时刻的夏令时偏移，且 `tzdb` 可随轻量数据OTA热更新。

### 二、零拷贝多语言包（`.blp`）与 RTL 双向镜像契约

1. **编译期强类型键与零堆分配格式化（`berry-i18n`）**：应用与系统文案编写采用兼容 Fluent 语义的声明式消息源文件，经构建链 `berry-xtask` 预编译为页对齐二进制本地化包 `.blp`（编译期静态检查所有语言分支占位符类型一致，根绝运行期漏翻崩溃）。运行期按当前系统语言直接按需映射对应语言页；用户在设置切换系统语言时，桌面广播 `LocaleChanged` 信号，所有响应式 `ui-sdk` 视图在单帧内无闪烁原地重绑刷新，**零应用重启**。
2. **全链路逻辑坐标与 BiDi 双向排版**：
   - 废除组件库内部写死 `left`/`right` 边距与对齐，[ui-sdk 总体设计](../ui-sdk/design.md) 布局引擎全面采用逻辑流向 `InlineStart` / `InlineEnd`；当语言切换至阿拉伯语、希伯来语或波斯语（RTL）时，导航栏返回箭头、列表图标缩进、开关滑轨方向与侧滑返回手势边自动 100% 水平镜像；
   - 文本排版层实装纯 Rust `no_std` Unicode UAX #9 双向分段算法（正确处理 RTL 段落中内嵌英文数字、URL 与数学公式的视觉顺序）及 OpenType `GSUB`/`GPOS` 连字与音标定位表（支撑阿拉伯语词首/词中/词尾连写及东南亚复杂文字）。

### 三、AI 赋能系统级无障碍辅助引擎（`a11yd`）契约

```mermaid
flowchart LR
    App["应用语义树 (ui-sdk Role/Label/State/Action)"] --> Comp["berry-compositor (无障碍焦点框 + 触摸探索拦截 + 着色滤镜)"]
    Comp <--> A11y["a11yd (读屏状态机 / 开关扫描 / 盲文 HID)"]
    A11y -->|"超低延迟流式合成"| Airtd["airtd (端侧微缩自然人声 TTS / 实时字幕 ASR)"]
    Airtd --> Audiod["audiod (Accessibility 高优音轨 + 背景自动闪避)"]
```

1. **原生免配置读屏体验（BerryVoice）**：一旦开启读屏（支持首次开机向导长按双音量键 3 秒盲操盲启，且驻留 DE 直通启动层确保锁屏密码界面即可语音播报！），合成器自动切换触摸管线为「触摸探索模式（Explore-by-Touch）」：单指划过之处高亮无障碍语义焦点框并由 `a11yd` 驱动 `airtd` 在 `< 40ms` 内播报控件角色、标签与状态，单指双击激活触发语义 `Action`；遇到无标签纯图标历史遗留图片时，`a11yd` 自动调用端侧轻量视觉模型即时补全图标语义描述。
2. **合成器零开销视觉与听觉辅助**：
   - **GPU 着色级视觉辅助**：全屏平滑手势放大镜（Magnifier）、红色盲/绿色盲/蓝黄色盲道尔顿色彩校正 3×3 矩阵、高对比度轮廓增强与「减弱动态效果（Reduce Motion，将跨屏大位移缩放自动降级为柔和交叉淡入淡出）」全部在合成器单遍完成，无需应用写一行适配代码；
   - **全局实时字幕（Live Captions）**：针对听障用户或静音会议场景，`a11yd` 可订阅 `audiod` 系统环回混音流交由 `airtd` 流式 ASR 生成低延迟悬浮双语字幕条。

## 验收标准

1. **时区与防篡改校时门禁**：涵盖跨夏令时跳变边界（Spring Forward / Fall Back）与历史闰秒边界的 500 组 IANA 测试向量转换准确率 100%；伪造无合法 NTS 签名的恶意时间包 100% 被 `timed` 丢弃。
2. **RTL 热切换与复杂文字门禁**：在运行态将系统语言由简体中文切换为阿拉伯语，桌面与全部内置应用在 `< 16ms` 内完成布局左右镜像与阿拉伯连字正确渲染，零截断、零乱码、零进程重启。
3. **盲操全流程通关门禁**：在关闭显示器画面（仅凭音频输出与触摸手势注入）条件下，测试脚本可通过 `a11yd` 读屏焦点导航独立完成「锁屏输入密码解锁 → 打开设置 → 连接 Wi-Fi」完整闭环。

## 适用边界

- 极生僻古文字字库不在基础固件默认内置体积内，按语言字体扩展包随用户启用对应地区语言时按需挂载至 `/data/fonts/`。
