## 背景

owner 一句话需求四个词（shell/终端/bsh/命令行）指向客机命令行体验整体完善。三路侦察（2026-11-15，agents 并行）定谳四个结构性事实：

1. **bsh 交互循环天然管道化**：main.rs:344-393 从 fd0（`std::io::stdin()`）逐字节读、editor 纯喂键状态机（TabSource trait 已解耦）、输出走 fd1——`SpawnSpec.stdin_feed`（feeder 泵，berry-exec lib.rs:343-346）与 `stdout` 私有对端（run_capture 族先例，bsh main.rs:5297-5449）让「任意程序以哑终端形态驱动 bsh」零新原语成立。
2. **GUI 终端应用三堵墙**（本刀不做，挂账移交）：键盘物理链断线（QEMU 仅 virtio-tablet 无键盘设备、inputd 泵无解码分支、guiproto 无 key 事件出向编码）；inputd 单会话单订阅者（serve 循环 sub_delivery 单 Option、POLL 唯一 drain 者——多读者 dup 混流，launcher 是唯一 input 订阅者）；.bap 应用授能面缺 wm/input/gfx 端（app_launch 仅 stdout+fs 两元，svcmgr main.rs:5957 起）且 APP_SLOTS=9 恰满。三墙的解法（焦点路由/软键盘/OP_WM_FOCUS 接线）恰为波3 计划既有面。
3. **bsh 命令缺口核实**：内建 12 个（help/exit/env/echo/run/cat/ls/mkdir/rm/cd/pwd/inputpoll）+ rootfs bin/ 51 件（uu 23 件含 date/df/du/grep/which）；clear/history/uname/uptime/sleep/type/kill 全无（which/date 已有 bin 件）。
4. **回归钉板面**：23 个 selftest 钉 23 个 smoke 标记（链序硬契约 main.rs:224-337）；smoke.sh RX 相 12 处逐字 grep（`not found` 文案、f42t、i130t）；rootfs0.cpio 恰满 32MiB 单卷帽、末卷余量约 30MiB（新增无压力）；bsh 两文件与 smoke 三件当前零脏（并行会话脏面在 kernel/svcmgr/tools/berry/berry-ui 家族，本刀不碰）。

## 契约

### 契约 1：内建六件（render_cmd 分发面新增，console 与管道双形态同源）

| 命令 | 行为 | 拒面（usage 2） |
| --- | --- | --- |
| `clear` | 输出 `\x1b[2J\x1b[H`（ANSI 清屏+光标归位，7B）——消费面 = 哑终端/宿主终端模拟器；serial.log 里转义字节无害 | 无参命令，带参照打（幂等面，不拒） |
| `uname` | 单行 `<sysname> <machine> <release>`（= `BerryOS aarch64 0.2.0` 形态）。版本源 = libc `uname`（`.berryver` 烙印 semver，ADR #83 查询面单源——原「内核无版本号单源」前提过时，实施后修正换源，见实施偏差 5） | 带参拒 |
| `uptime` | 单行 `up <N>s`（N = CLOCK_MONOTONIC 纳秒换算秒，A7-2 语义 boot 起算） | 带参拒 |
| `sleep <s>` | 阻塞 `<s>` 秒（100ms 步进 usleep 环——A7-4 pause 同形， berry-libc 无长睡原语）；v1 不可打断（无异步信号抢占面，诚实文档化） | 非数字/负数/缺失/超 60s 帽（防 smoke 挂死）均 usage 2 |
| `type <name>` | 身份三档：内建表命中 `is a shell builtin`、rootfs bin/ 命中 `is /bin/<name>`、双落空 `not found`（exit 码 1——type 是查询面自有码，非 127）。v1 单名字面：多词（`type echo ls`）与含 `/` 的名字整串作一名查询（落 not-found 档），不按 POSIX 逐操作数分词——记面不隐式 | 缺参 usage 2 |
| `history` | 回显 editor 历史环（8×256B newest-first，std 版行帽——内核时代 96B 口径已随 C-4 迁移放宽；编号从 1 = newest，随会话重排）逐行 `N  cmd`；历史属交互循环 editor 状态，经 run_line 只读透传，非交互调用方传 `&[]` = 空环 | 带参拒 |

内建表单源化：render_cmd 的命令集从 if-else 链隐式知识升为 `const BUILTINS: &[&str]`（type/help/Tab 补全源三消费同表——Tab 源在 editor TabSource，实施时核 editor.rs 现有候选表是否已硬编码同名单，若是则同批单源化，零行为漂移）。

help 文案更新：两行 192B 帽纪律内加新命令名（A60 帽先例，超长再拆第三行）。

### 契约 2：`TERM ok n=2` 自验步（哑终端管道契约钉板）

新 selftest `term_selftest` 两步（挂 selftest 链尾部，M3DEMO 后——零盘依赖但顺序保守）：

1. **管道驱动**：spawn 子 bsh——`SpawnSpec{ name: “bsh”, stdin_feed: Some(b“echo berryterm\nuname\n”), stdout: <私有对端>, extra_gifts: fs_gifts() 同参 }`（run_capture_fs + stdin 三元组先例 bsh main.rs:5405-5447）；collect 收齐断言：`bsh> ` 提示符在场 ×2、命令回显行在场、`berryterm` 结果行在场、`BerryOS aarch64` 结果行在场——哑终端契约（提示符/回显/结果混流同一 stdout 字节流）逐项钉板。
2. **EOF 收口**：feeder 泵 data 尽 + 零长 EOF 后子 bsh 不退（bsh 主循环空读续读不退——main.rs:358 continue 分支）——验证面 = 收齐输出后 terminate 子进程 reap（process_terminate 0x3B，C-4b 先例）收口 130/TERMINATED；「子 bsh 恒驻不暴走」由 collect 帽（10s 活动帽既有面）担保。

`CLI ok n=` 自验步（新）：六内建行为面各一断言（clear 输出 11B 字节精确对拍、uname 前缀、uptime 数值域、sleep 1s 时钟差分、type 三分支、history 环回读）——链位与 TERM 同批（CLI 前 TERM 后或并入同函数打单标记，实施按 selftest 惯例一函数一标记，两标记都进）。

## 实施偏差

- **链位（设计稿内部矛盾裁定）**：契约 2/3 双处写「挂 selftest 链尾部，M3DEMO 后」，但契约 3 又要求「TERM 步在 EFI 路可打（零盘依赖）——smoke-image.sh canon 生态计数联动核实」——两处互斥：M3DEMO 在 fat 族后，EFI 无盘路被 fat_selftest park（`-> !`）挡断其后全部自验（ECO_MARKERS 无 DF/DIR/CD/M3DEMO 佐证）。按仓库 A 系契约惯例（零盘面自验一律排 fat 族前 = EFI 亦打，U2/MMP/CLK/SIG 全族先例）落位 sig_selftest 后、fat 族前：EFI 路两标记皆打，smoke-image canon +2；严格按「M3DEMO 后」则 EFI 永不可达、smoke-image 挂线恒红。
- **子 bsh `--no-selftest` argv 旗（设计稿未载明的必要机制）**：不带旗的子 bsh 先跑全量自验链（TCG 分钟级——与风险节「链尾增量 <5s」及 collect 10s 帽结构性矛盾），且子链中自身 term_selftest 再 spawn 子 bsh = 无界递归（直至 PROCESS_MAX 出帽 park 级联）。加旗跳链直进交互循环；interactive() 从 main 尾抽成 `-> !` 函数双路共用同一台机器（vars/status 调用方持有，`$?` 跨链尾→交互语义零漂移）；svcmgr 常规拉起零参零漂移。
- **term 收集用早退谓词环 term_collect 而非 collect() 直用**：子 bsh 恒驻无 EOF（契约 2 自认），直用 collect 每 boot 白熬 10s 静默尾（主 smoke 五 boot ≈ +50s 墙钟；DEADLINE_ROOTFS=420s 对 CI 实测 ~390s 的余量收窄）。term_collect 用同款 recv/wait_one 原语 + 同值 TIMEOUT_NS 活动帽 + COLLECT_MAX 帽，四断言字节齐即收——契约 2「collect 收齐」语义保持，收口时点提前。
- **stack_pages=16 而非 32**：任务书「查 svcmgr 或既有 selftest 里 spawn bsh 的先例；无先例则取 32」——先例在册（svcmgr 拉 bsh 现值 16，全自验链都在 16 页内跑），按「bsh 自身现值」取 16 并在 term_selftest 头注注明先例出处。
- **uname 版本源换源（验证轮发现 + 主会话裁决落地）**：实施初版按本稿契约 1 用 `env!("CARGO_PKG_VERSION")`（bsh crate 版本）；验证 agent 发现仓库已有版本单源——libc `uname` 的 release 读 `.berryver` 烙印 semver（ADR #83 查询面，boot banner/sysver VMO 四面同值），本稿「内核无版本号单源」前提过时，两源独立升版即漂。修正：uname 内建改调 libc `uname` 真身（`Utsname.fields` 私有 → bsh 侧 mirror 结构 6×65B + `extern "C"`，A7-4 sigaction 镜像钉板同手法），拼 `<sysname> <machine> <release>` 单行；cli_selftest ① 断言形态不变（前缀 + 非空版本）。净室构建复验绿（464840→465464B，+624B）。
