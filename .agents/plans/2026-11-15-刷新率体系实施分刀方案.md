## 0. 目标与总门

- 目标：规范 §11 验收线逐阶段兑现；开工顺序 = 刀1 → 刀2 → 刀3 → 刀4，刀5 可与刀2-4 并行（内核侧独立），刀6 依赖刀4。
- 总门（每刀收口必跑）：`just smoke` + `just test-host`（worktree 本地 `CARGO_TARGET_DIR` 隔离——兄弟会话全局 target 顶替事故判例在册）；涉镜像跑加 `just smoke-image`；GUI 面加 `just gui8-smoke`（改内核/二进制后 `GUI8_REBUILD=1` 或先 `just image`，预烘镜像陷阱判例在册）；文档批跑 `node .agents/tools/check-docs.mjs`。
- 纪律：协议面 host 编解码测试先行（ADR #54）；TLV/wire add-only 禁改定长（ADR #60 ⑥）；多会话并行只碰自己显式路径；内核刀（刀5）动 ~/.cargo-target 前按写让行协议通告。

## 2. 刀1 率通路五段贯通

落点：`kernel/src/main.rs`（display 串解析保率域，`split('@')` 改两段取值 + 非法 loud 回退 60 + 诊断行）、`kernel/src/handoff.rs`（boot info VMO display 域尾插 `refresh_hz: u16`）、`user/berry-guiproto/src/lib.rs`（`OP_PANEL_CAPS = 0x44` 编解码 + host 测试先行；hdi 域版本抬升）、`user/bins/guifbd/src/main.rs`（档位周期表 const 单源落位 + boot 率域进软面板初值 + PANEL_CAPS 应答 + `SOFT_VSYNC_NS` 私常量废除改查表）、`user/bins/berry-launcher/src/frameloop.rs`（`VSYNC_NS` 废除，改服务端注入）、`user/berry-ui/src/lib.rs`（连接后 PANEL_CAPS → `set_vsync(period_ns, phase_ns)` 注入；`DEFAULT_VSYNC_PERIOD_NS` 注释改「无服务端回退缺省」）。

步骤：① guiproto 编解码 + host 测试（先写测试后动 wire）；② 内核解析与 boot 域（add-only 尾插）；③ guifbd 档位表 const + PANEL_CAPS；④ berry-ui/launcher 注入收敛；⑤ 全仓 `rg '16_666_666|16_666_667|8_333_333'` 清点——周期常量唯一豁免 = 档位表。

验收：`opt/berry/display=720x1280@30` 启动，PANEL_CAPS 应答 current_hz=30、period_ns=33_333_333，berry-ui 帧钟周期随之（串口/遥测可见）；缺省无 @Hz = 60；非法 @Hz=77 → 回退 60 + 诊断行到席；smoke/test-host 全绿零回归；T1 之前置（能力面钉板测试）绿。

## 3. 刀2 软面板件

落点：guifbd 软面板模块（新文件，v1 与 serve 循环同文件内模块起刀；主树三文件重构后归 lib）：能力面（Tiered 档位表全量宣告含 class 位与首启阶段位掩 + FreeRange 宣告 `{min=1, max=480, granularity=1, per_frame}` 两类同批）、事件面（vsync 载荷三元组 `{seq u64, ts_ns u64, refresh_ns u32}`——REG_VBLANK 事件与 VBLANK_WAIT 应答双面；FreeRange 下 refresh_ns 逐帧可变）、控制面（FREE/DETERMINISTIC 模式 + 切档请求/ACK `{effective_ns, new_refresh_ns}` + 生效延迟 2 帧；current_hz 值域随宣告类——Tiered 查表 / FreeRange 区间任意整 Hz 连续可变）、故障注入面（fw_cfg `opt/berry/panel-fault` 旋钮：丢帧率/抖动幅度/切档丢帧）。

步骤：① 模式机与时钟合成（FREE = 现行软 vsync 迁入；DETERMINISTIC = 种子化定步时钟）；② 事件载荷扩展（拍点 seq 单调、切档生效 ts 后新 refresh_ns）；③ 切档 ACK 通道；④ fw_cfg 旋钮解析；⑤ gfxdemo smoke 序扩一档 PANEL 消费面。

验收：T2 回放门（DETERMINISTIC 同输入 → (seq, ts_ns) 逐位相等）host 单测 + guest smoke 双面绿；FREE 模式零唤醒不变量不破（无 armed 无 parked 零调度——现行 serve deadline 语义保持）；故障注入三旋钮各有到席证据行。

## 4. 刀3 仲裁器

落点：guifbd 仲裁模块（票簿 + 裁决 + 切档执行），berry-ui VoteBallot 不动（票面已合格）。

步骤：① A1-A3（票生命周期/全局区间/候选集）+ A11 平台兜底；② §6.2 Intent 映射表 + A4 选档；③ A5 迟滞非对称（T_DOWN_DWELL_MS=1000 可配）+ DIM 偏好降档；④ A6 触摸加速（inputd 事件钩 + 500ms 窗）；⑤ A7 静止停帧（票/damage/armed 三条件，现行零唤醒基线收编）；⑥ A9 切档执行接软面板 ACK。

验收：T1 决策表单测全分支（每条 A 规则一正一负；Intent 六值 × sticky × 区间冲突 × 触摸窗 × DIM 全组合钉板）；T4 切档平滑门（丢 vblank ≤ 1、seq 连续、ACK 一致）；guest smoke：VOTE 120 票 → PANEL current_hz 120 且串口证据行；触摸 → boost 到席；静止 → 停帧证据行。

## 5. 刀4 呈现预告与回执

落点：guiproto（`OP_FRAME_TIMING = 0x07` 编解码 + host 测试；present 域版本抬升；FRAME_CALLBACK 16B 定长不动）、guifbd（SUBMIT `rate_hint`/`target_present_ns` 两域从忽略转 A10 预告消费；FRAME_TIMING 应答 `{frame_token, presented_ns, seq, refresh_ns, flags}`）、berry-ui（jank/deadline_miss/spinup_late 遥测接 FRAME_TIMING 消费——第一个读者落地）。

验收：T3 拍点误差门可跑（presented_ns 序列统计 p99 达标：60Hz ≤ 500µs / TCG ≤ 2ms）；T6 seq 贯穿门（app 帧号 = 回执 seq = vblank seq）；A10 预告升档「不迟一帧」决策表单测；遥测行在 guest smoke 到席。

## 6. 刀5 忙核 hrtimer + slack（内核，独立刀）

落点：`kernel/src/timer.rs`（授片处取 min(最早超时, 片终点) 落地——超时摘除不再只靠 10Hz slice tick；slack 域 + 同窗合并）、`kernel/src/sched.rs`（slice 交接点联动）、ktest（忙核唤醒误差用例）。

步骤：① 授片 min 落地（timer.rs:16-18 自注承诺兑现）；② sleep/定时携 slack_ns（默认 50µs；拍点类 0；LTPO 聚合窗 1ms 可配）；③ 同窗唤醒合并；④ ktest 误差用例（忙核满载下绝对定时唤醒误差统计）。

验收：忙核满载 p99 ≤ 500µs（真机）/ ≤ 2ms（TCG）实测行；slice tick 语义零回归（S-6 跑步机判例在册——deadline 夹取单调性不破）；smoke/ktest 全绿。注意：本刀写全局 target 前按写让行协议通告兄弟会话，或全程 worktree 本地 target。

## 7. 刀6 latch-at-vsync + 双缓冲 + LFC + 应用面

落点：guifbd（PREPARE/COMMIT 语义实装 = §7 P2/P5：target_present_ns 向上取整到拍点 latch、双缓冲、切档深度策略；FreeRange per_frame 变节拍 P6：逐帧拍点 = max(上一扫描开始 + min_interval, target)）、仲裁器（A8 LFC：vrr 三态 + max ≥ 2×min 门 + 整数倍重发；FreeRange 分支：区间直取 + 粒度对齐）、berry-ui（AP2 固定时步 dt=1/120s 基准 + 渲染插值；AP3 时长整帧量化；AP4 帧回调附 deadline/预期拍点）、launcher 动效迁移、DETERMINISTIC/故障注入全量开启 + 240/480 仿真产品档宣告。

验收：T2/T5 全绿（165/180 混合 cadence 应激 + FreeRange per_frame 26fps 逐帧锁相：固定时步动画时长不变、无累计漂移）；240/480 全门（拍点误差门按 §10-T3 高刷档收紧值跑）；Legacy-Present（P1）退场——blit-at-SUBMIT 路径删除或降级为深度 1 特例；gui8-smoke + VNC 肉眼验收切档平滑。

## 8. 刀7 真硬件（v3 预置，立项另批）

HOST_LOCK 对接口（TE IRQ 接入点）、PSR/自刷新、LTPO 面板能力宣告、AOD 1Hz 组合拳、带宽预算（含 DSC）。本档只留接口占位，开工须 owner 另批立项（硬件在环验收另立）。
