# BerryOS 渲染与 GPU 加速、帧感知对数调度、桌面 SDK 及现代存储全栈彻底升级计划

Type: plan
Status: active
Updated: 2026-11-18

一句话说明：承接微内核底座重构（[meihe 总体设计](meihe/design.md)、[ipc 总体设计](ipc/design.md)、[mm 总体设计](mm/design.md)、[hal 总体设计](hal/design.md)），将 [gfx 总体设计](gfx/design.md)、[gpu-accel 总体设计](gpu-accel/design.md)、[desktop 总体设计](desktop/design.md)、[storage-image 总体设计](storage-image/design.md) 与 [sched-rt-gfx 总体设计](sched-rt-gfx/design.md) 拆解为拓扑有序、每刀 `*face` 纯核测试先行的六大波次共二十把可独立验收手术刀。

## 背景

[渲染管线与桌面 SDK 及镜像存储深度审计](../research/2026-11-18-渲染管线与桌面SDK及镜像存储深度审计.md) 系统性锁定了模拟器呈现、2D 光栅、GPU 加速、窗口合成、UI 开发体验、桌面物理动效、调度队列复杂度以及镜像与存储栈的全部深水区短板。遵循「规范先行、一步终态、绝不叠打过渡补丁」准则（因果见 [场景图 GPU 硬件卸载与对数调度及 CoW 存储架构裁决](../notes/proposed/2026-11-18-场景图GPU硬件卸载与对数调度及CoW存储架构裁决.md)），本计划按严格依赖拓扑组织推进：**先锻造构建图与模拟器零漏帧 120Hz 观测底座（R0 族）→ 升级 16×16 瓦片 NEON 矢量/毛玻璃/CJK 图形核（R1 族）→ 落地 $O(\log n)$ 红黑树队列与 `FrameToken` 帧感知调度闭环（R2 族）→ 打通保留式场景流与三阶真 GPU 硬件渲染卸载（R3 族）→ 交付细粒度 Signal 响应式 `ui-sdk` 与中文输入法（R4 族）→ 收官四端自适应弹簧桌面、零 OCR AI 语义总线与 `BerryROFS`/`BerryFS` 现代存储体系（R5 族）**。

## 步骤

### 第一波：统一构建编排与模拟器零拷贝 120Hz 硬件呈现底座（R0 族 · 3 刀）

1. **R0-1 统一用户态/驱动 Cargo 工作区与 `berry-xtask` 并行构建图刀**
   - **动作**：合并 `user/` 与 `drivers/` 同目标三元组（`aarch64-unknown-linux-musl`）碎片工作区以共享编译产物缓存；新建纯 Rust `tools/xtask` 编排器接管内核、用户态、`.bap` 并发打包与镜像组装，将 [justfile](../../justfile) 精简为薄入口别名。
   - **可观察验证**：全量冷构建耗时下降 `≥ 60%`，单文件改动增量产像耗时 `≤ 3.0s`，构建产物 SHA-256 可复现性门禁全绿。

2. **R0-2 `WgpuPresenter` 全平台后端解封、持久绑定与 D-Bus `ScanoutMap` 零漏帧通道刀**
   - **动作**：升级 `tools/berry` 显示层启用 `wgpu::Backends::PRIMARY`（Metal / Vulkan / DX12），消除每帧 `rebuild_bind_group()` 重分配，实装基于共享内存切片与 `DamageRect` 数组的微秒级局部纹理上传；接入 QEMU `-display dbus,p2p=on` `ScanoutMap/UpdateMap` 零拷贝流，彻底废除 `RamSource` 512 点稀疏哈希采样；恢复 1:1 整数/Lanczos2 锐利窗口缩放并补齐 `spawn_kernel` `fwcfg_plan` 同源注入。
   - **可观察验证**：单像素闪烁 1,000 次宿主 GPU 纹理读回 100% 零漏帧；1080×1920 桌面静止态宿主进程零 `pread` 调用、CPU 占用 `< 1%`；连续动画突破 33fps 稳定跑满 60/120fps。

3. **R0-3 macOS Apple `Virtualization.framework`（`--backend vz`）原生窗口与宿客 `vsock` 高速桥刀**
   - **动作**：在 macOS 宿主实装 `VZVirtualMachine` + `VZEFIBootLoader` + `VZVirtioGraphicsDeviceConfiguration`（原生 Metal `IOSurface` 扫描输出）+ `VZVirtioSocketDeviceConfiguration`（`vsock` 承载剪贴板同步、宿主输入法直传、免重启热转屏与 `< 200ms` `berry dev --watch` 热重载推送）。
   - **可观察验证**：macOS 下 `berry shell --backend vz` 冷启动至桌面首帧 `< 600ms`，横竖屏连续切换 20 次虚拟机零重启、运行中应用 100% 存活。

### 第二波：`gfx` 2.0 瓦片分箱、NEON 预乘混合、SDF 毛玻璃与矢量 CJK 引擎（R1 族 · 4 刀）

4. **R1-1 `berry-gfxface` 预乘色彩数学、紧凑 `SceneIR` 与 16×16 瓦片遮挡分箱纯核刀**
   - **动作**：新建零依赖 `berry-gfxface` 实现 `PremulRgba8` / sRGB 线性化 LUT、`Affine2D`、八大绘制原语编码器及 16×16 瓦片分箱与自顶向下不透明整瓦片截断剔除器。
   - **可观察验证**：宿主机 Miri 与 100 万次随机极端几何 Fuzz 零越界零 Panic；全屏不透明窗口覆盖壁纸时底层壁纸瓦片执行计数严格为 `0`。

5. **R1-2 ARM64 NEON / x86 SIMD 行跨度（Span）快路与 `SrcOver` 混合算子刀**
   - **动作**：重构 `berry-gfx` 光栅执行层外提全部边界检查，实装无分支行切片写入与 `aarch64` NEON / `x86_64` SSE4.1 4/8 像素并行预乘 `SrcOver`、双线性 Alpha 图像缩放算子。
   - **可观察验证**：1080×1920 全屏清除耗时 `≤ 0.15ms`（提速 `≥ 13×`），全屏半透明混合 `≤ 0.30ms`，NEON 与标量参考实现逐像素最大误差 `≤ 1`。

6. **R1-3 SDF 超椭圆抗锯齿圆角、解析高斯投影、渐变抖动与 Dual-Kawase 实时毛玻璃刀**
   - **动作**：实装连续曲率 Squircle 圆角与 1px 内高光描边、无临时缓冲 `erf` 解析圆角投影、带 Bayer 4×4 去色带的多色标渐变，以及「1/4 降采样 → 2 趟 Dual-Kawase → 双线性上采样融合饱和度与微噪点」的 `BackdropBlur` 算子。
   - **可观察验证**：1080×1920 半屏毛玻璃控制中心单帧 CPU 耗时 `≤ 0.80ms`，圆角与斜线边缘平滑零阶梯锯齿，黄金像素共识测试入 CI。

7. **R1-4 按需只读映射 TrueType/OpenType 轮廓光栅、多级 LRU 字形图集与 CJK 断行引擎刀**
   - **动作**：实装纯 Rust `no_std` TTF 轮廓扫描线 8-bit 覆盖率光栅器与 `1024×1024` 分档 LRU 字形图集；内置只读 VMO 共享系统精简 CJK + Sans 矢量字库；落地 `berry-textlayout` 支持 UTF-8 中英文混排 UAX #14 断行、省略号截断与光标双向定位。
   - **可观察验证**：全系统桌面与应用原生渲染平滑抗锯齿中文与多字号英文，多进程共享同一物理字库页零私有重复拷贝。

### 第三波：$O(\log n)$ 增强红黑树运行队列与端到端帧感知闭环调度（R2 族 · 3 刀）

8. **R2-1 `berry-rbtree` 子树增强侵入式红黑树与 `berry-minheap` 双堆队列容器刀**
   - **动作**：新建宿主机 100% 性质验证的零分配侵入式红黑树 `berry-rbtree`（按 `vruntime` 排序并实时维护 `subtree_min_vd`）与四叉最小堆 `berry-minheap`；替换 `sched` 中 `Runqueue` 的循环链表全环扫描与 `lazy_unthrottle_deadlines` 线性遍历。
   - **可观察验证**：宿主机 100 万次随机增删改旋转不变量全绿；QEMU `-icount` 实测就绪任务从 8 增至 2,048 时单次 `pick_next` 指令数增幅 `< 3.5×`。

9. **R2-2 触控至合成全链路单拍 `FrameToken` EDF 实时借用与大核亲和刀**
   - **动作**：固化 `gui-inputd`（中断唤醒 `RT/LC`）与 `compositor`（VSync `Deadline`）启动调度档位；实装合成器按拍铸造受控预算（如 6ms）`FrameToken` 随输入/帧请求授予焦点窗口 UI 线程，事务提交或预算到点当拍自动剥离回落 `Fair` 层。
   - **可观察验证**：后台 8 满载计算线程 + 1 死循环故障 GUI 应用干扰下，前台 120Hz 列表滑动掉帧率 `< 0.2%`，故障应用无法饿死合成器与桌面手势。

10. **R2-3 窗口可见性四阶自动省电冰封与 `berry-power` Jank 预警闭环刀**
    - **动作**：接通窗口焦点/遮挡事件驱动 `appd` 执行「前台交互 → 背景限帧 → 后台宽限 3s → `SuspendToken` 同步冰封 → 内存压力转 `L3` 墓碑」全自动状态机；唤醒 `berry-power` 常驻 `Port` 循环，接入帧耗时 >75% 截止期的早期突发提频与空闲停帧全机零唤醒深睡。
    - **可观察验证**：8 个后台隐藏应用静置 5 秒后 60 秒内产生 CPU 唤醒严格为 `0`，点击多任务卡片 `< 16ms` 瞬时解冻恢复。

### 第四波：保留式 `SceneStream` 合成与三阶真 GPU 硬件渲染卸载（R3 族 · 3 刀）

11. **R3-1 `compositor` 保留式 `SceneStream` 免位图表面与双模混合合成刀**
    - **动作**：在 `compositor` 落地按 `SessionId` 能力隔离的保留式 `SceneIR` 子树合并与配额执法，使常规 SDK 应用无需分配 8.3MB 像素缓冲即可由合成器单遍直接光栅合成，并与 `Swapchain` 直通表面（带 `Acquire/Release` Fence）同树无缝叠加。
    - **可观察验证**：同时打开并驻留 10 个系统 GUI 应用，总图形物理内存占用 `≤ 16MiB`（节省 `> 90%`），冻结后台应用在窗口缩放与多任务预览中实时高清无黑块。

12. **R3-2 Tier 1 `berry-paravirt-gfx` 半虚拟化共享环与宿主 `wgpu` Uber-Shader 硬件光栅刀**
    - **动作**：实装宿客共享 `AtlasSlab` 与 `GpuPrimInstance` 无锁环，编写同源 WGSL Uber-Shader（Dual-Kawase 模糊 Pass + 实例化 SDF/文本/图像合成 Pass）嵌入 `tools/berry` `WgpuPresenter`，将模拟器图形像素计算 100% 卸载至宿主机显卡。
    - **可观察验证**：1080×1920 @ 120Hz 与 4K @ 60Hz 复杂毛玻璃多窗拖动下，客机 `compositor` 单帧 CPU 耗时 `< 0.25ms`，宿主 GPU 帧耗时 `< 2.0ms`，软硬截图 PSNR `≥ 48dB`。

13. **R3-3 Tier 2 `Virtio-GPU 3D`（`BLOB` 零拷贝 + `berry-vkproto` 轻量流）与 GPU 超时热回退自愈刀**
    - **动作**：实装中断驱动的 Virtio-GPU 1.2 `RESOURCE_CREATE_BLOB` 零拷贝显存映射与预编译 SPIR-V 三管线 `SUBMIT_3D` 序列化器；内置 50ms Fence 超时看门狗，GPU 无响应时零黑屏无缝降级至 Tier 0 NEON 瓦片软后端并后台异步重连恢复。
    - **可观察验证**：消除 `TRANSFER_TO_HOST_2D` 拷贝；人为注入 GPU 挂死故障，60ms 内桌面无感切至软光栅继续流畅交互，解除故障后自动切回硬件加速。

### 第五波：零 VDOM 响应式 `ui-sdk` 2.0、动态页堆、中文 IME 与全套官方应用焕新（R4 族 · 4 刀）

14. **R4-1 用户态 `berry-libc` 动态 `Vmar` 分箱页堆与 `Port` 原生 `berry-async` 执行器刀**
    - **动作**：以线程本地 Magazine + 按需映射 `VMO_OPT_ZFOD` 页堆替换 256KiB 静态 `.bss` 堆，支持大块 `free` 即时 `unmap` 归还物理页；构建单线程零阻塞 `berry-async` 执行器融合 VSync、输入、定时器与异步文件/网络通道。
    - **可观察验证**：单进程动态分配并释放 32MiB 数据后系统空闲物理帧 100% 归位；慢速异步 I/O 挂起期间同线程 120fps 动画零掉帧。

15. **R4-2 `Signal<T>` 细粒度响应式内核、声明式 `view!` 组件体系与无上限池化文本刀**
    - **动作**：在 `berry-ui` 落地零虚拟 DOM 的 `Signal / Memo / For` 直连脏节点机制、SSO + `TextPool` 无上限 UTF-8 文本池（废除 64B 硬墙）、带多项式速度拟合与弹簧越界回弹的 `ScrollView` / 十万级 `VirtualList` 及完整 `vp` 响应式 P0–P2 组件集。
    - **可观察验证**：10 万行 `VirtualList` 极速滑动帧耗时 `< 2ms`；50KiB 中英文混合文档正常折行渲染；TLV `.bui` 热替换保留当前 `Signal` 状态原地刷新。

16. **R4-3 沙箱拼音输入法服务（`imed`）与一次性能力令牌剪贴板/Picker 刀**
    - **动作**：实装零网络权限的独立 `imed` 软键盘与双拼/全拼词库引擎，打通焦点输入框 `InputContext` 预编辑、光标跟随候选框与 `SafeInsets.ime_bottom` 弹簧顶起避让；实装系统粘贴气泡与文件选择器一次性只读 VMO 铸造协议。
    - **可观察验证**：在终端、短信、浏览器与文件重命名框全程流畅输入中文词句，未点击系统粘贴确认前应用零途径读取剪贴板。

17. **R4-4 七大核心系统应用基于 `ui-sdk` 2.0 全量重写与双胞胎遗留包清退刀**
    - **动作**：以 ≤ 1/5 代码量全量升级 `settings`、`files`、`photos`、`camera`、`contacts`、`messages`、`browser` 与 `berry-term` 为全中文矢量排版、暗黑自适应、支持异步 I/O 与墓碑状态保存的旗舰示范应用；按 Curia 归档/退役纪律清退 `*-app` 七个静态手绘旧包。
    - **可观察验证**：八款预置应用在手机竖屏与桌面多窗双形态下全交互可用，应用业务层 `unsafe` 块数为 `0`。

### 第六波：全场景弹簧桌面、零 OCR AI 语义总线与 `BerryROFS` / `BerryFS` 现代存储（R5 族 · 3 刀）

18. **R5-1 可打断 `Spring2D` 桌面转场、实时多任务卡片流、毛玻璃控制中心与四端自适应壳刀**
    - **动作**：在新一代桌面壳实装 $C^1$ 速度连续的图标↔窗口形变启动/收拢过渡、边缘预测返回、实时引用场景树的 `RecentsSwitcher` 多任务分屏/清理卡片栈、智能反色状态栏、磨砂玻璃控制/通知中心、全局 Spotlight 检索及 `Watch / Phone / Tablet / Desktop-PC`（含自由多窗标题栏与贴边吸附）四档断点切换。
    - **可观察验证**：100 次连续高速点击打开中途手势打断反向滑回压测零跳变零卡死；外接宽屏模式三窗口自由拖拽缩放与毛玻璃叠层满帧运行。

19. **R5-2 零 OCR 能力受控 AI 语义场景动作总线（Semantic Scene Bus）刀**
    - **动作**：在 `compositor` 实装硬件边界内自动剥离密码/隐私节点的 `< 10µs` 结构化语义快照导出、最高层不可伪造流光呼吸 `TrustRing` 指示器与绑定 `ConsentGate` 审批的一次性 `ActionToken` 注入闭环。
    - **可观察验证**：AI 代理免截屏在 1 毫秒内准确理解复杂设置/通讯录界面并在用户确认后完成跨应用组合操作，密码框内容在导出流中 100% 物理缺席且审计环留痕完整。

20. **R5-3 `BerryROFS` 块级验签按需只读根卷、`BerryFS` 写时复制崩溃原子文件系统与 A/B 热回滚镜像刀**
    - **动作**：实装纯 Rust `mkrofs` 与内嵌 SHA-256 Merkle 树的 4KiB 页对齐 `BerryROFS`（取代全量内存 `rootfs.cpio`）；实装双超级块 CoW B+Tree 文件系统 `BerryFS`（UTF-8 长路径、多级子目录、Extent 大文件、原子 `rename`/`unlink`、`/app/data/<id>` 根句柄硬沙箱与块配额）；合龙 GPT 四分区与 `BerryBoot` A/B 双槽看门狗自动回滚。
    - **可观察验证**：`-m 64M` 低内存配额下冷启动直达 1080P 桌面并流畅多开 5 应用；10,000 次随机断电写截断注入后 `BerryFS` 100% 免 `fsck` 自洽挂载零损坏；损坏新系统槽自动回滚旧槽启动成功。
