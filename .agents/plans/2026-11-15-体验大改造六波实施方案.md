一句话说明：owner 2026-11-15 批准的执行序——六波交付：波0 基线落账、波1 开机双模式（动画默认+命令行滚屏）、波2 berry-ui 控件底座（34 kind 渲染接线+输入焦点协议）、波3 桌面三栏与系统窗（状态栏常驻/返回键路由/TabBar/软键盘）、波4 预制应用翻新（7 个 appstub 长出真 UI）、波5 收尾核账。

## 背景

owner 需求四件：控件体系对标 Android/iOS/HarmonyOS（他们有的都要有、相似合并、人无我有/人有我强）；开机双模式（BerryOS 大 Logo + macOS 式白色胶囊进度条跟真实里程碑平缓爬升、满了立刻进桌面；参数切 Linux/macOS 式滚日志）；桌面三栏（状态栏应用内常驻可全屏隐藏、顶栏含返回键、iOS 式底栏切页）；预制应用全部翻新（卡片/按压/控件齐全）。

owner 四项裁决：开机动画默认参数切滚屏；底栏系统页与应用内都要；文本输入本轮做全（焦点协议+Input+软键盘）；开工前先把工作区约 80 路径分组提交落账。

本方案组合既有伞形文档不另起炉灶，并裁定其执行序：刀谱细节见 [2026-11-14-模拟器体验统一分刀方案.md](2026-11-14-模拟器体验统一分刀方案.md)（七刀）、[2026-11-14-boot事件细化刀6实施设计.md](2026-11-14-boot事件细化刀6实施设计.md)（26 格事件词汇表，唯一权威）、[UI组件清单与实施规划-v1.0.md](../../docs/UI组件清单与实施规划-v1.0.md)（约 70 件对标集合）、[应用规范-v1.0.md](../../docs/应用规范-v1.0.md)（44vp 状态栏等立法目标态）。

现状底册（2026-11-15 三路侦察+主树实测）：berry-ui 34 件 ViewKind 仅 9 件真渲染（paint 只发 Rect/Text/Image/Icon），圆角/alpha/clip/焦点/主题 token 全缺；开机 splash 半成品停在分支 rescue/ux-splash（7fd1709c，worktree `.dsh-worktrees/boot-events/`），主树 EFI 残屏静止数十秒直到桌面首帧；状态栏是 launcher 内容层、应用全屏 SUBMIT 即被盖（guifbd blit-at-SUBMIT 无合成、wmd SYSTEM 层从未用）；官方 7 应用全为 appstub 秒退壳。

硬约束：7fd1709c 判例否决内核热路径进度插值（平滑算法只活 guifbd、条区局部重绘）；TLV tag add-only（GOLDEN 六轨钉板）；smoke 标记互非子串（新标记小写 kebab 无 ` ok` 形态）；APP_SPAWN_LIVE_MAX=4；本轮 UI 文案限 ASCII（无 CJK 字形）；并行会话 git 纪律（显式路径提交、禁 `git add -A`）；几何单源 OH phone 档 1080×1920@3x 经 WM_GETINFO 协商。

## 步骤

1. 波0 基线落账：按当日 git status 分组提交约 80 路径（A=tools/berry VNC 套件+justfile；B=VNC 波次文档；C=launcher 五键导航条；D=berry-ui desc.rs 尾巴；E=boot/GUI 调研方案文档（含本文）；F=docs 调度 lane；G=berry-fsclient 文档注释，若属他路活 lane 则不碰）；worktree `.dsh-worktrees/boot-events/` 内刀6 半成品（guifbd/svcmgr/launcher 改动+KNIFE6 文档）同批收口提交。验证：两树 git status 净；`just smoke` 绿；`node .agents/tools/check-docs.mjs` 绿。
2. 波1 开机双模式：worktree 先完成刀6 步骤1（内核 26 格重编号，词汇表唯一权威）+步骤 4-6 集成门（`just run-rootfs` 串口 `\x01SPLASH` ≥20、smoke 全绿）达可合状态；主树单次 merge rescue/ux-splash（kernel/src/main.rs 手工并；guifbd 取主树三文件结构、分支 splash 改动人工移植进 guest.rs，参照 KNIFE6-IMPL-GUIFBD.md 条目①-⑧）；新增 `tools/gensplashlogo.py` 烘 BerryOS 词标行 RLE 段表双产物（kernel/src/splash_logo.rs + user/berry-gfx/src/splash_logo_data.rs，黄金 SHA256+selftest 挂 just test-host）；胶囊条=行宽 LUT 两端半圆（bar_h=max(h/150,12)，槽 #2A2A2E 白填充）；平缓算法活 guifbd 过渡屏（事件目标值 P_tgt=min(cell*1000/26,961)、一阶惯性追逐 TAU=600ms 单调不减、重绘节拍 ≥66ms 只写条区+百分比格、armed 后首 SUBMIT 补满先画后 blit 立即揭幕、`LAUNCH ok` 兜底）；verbose=内核 mirror 至 splash::detach+guifbd poll_console 剥 `\x01` 续滚至 LAUNCH ok；入口统一五入口默认 desktop profile+accel auto，GUI 家族默认注入 noktest 但先核 tools/smoke-image.sh 断言面。验证：smoke/smoke-image/gui8-smoke 全绿；`berry shot --boot-mode splash` 三时刻截图条宽单调；`--boot-mode verbose` 无 ≥5s 静止段；VNC 目测进度满瞬间进桌面。
3. 波2 控件底座：渲染接线五批（2a Button/Toggle/Slider/Progress/Tabs/Sbar；2b Scroll/List/Check/Radio/Seg/Badge/Divider/Spacer 含 clip/Radio 互斥/Spacer flex；2c Stack/Step/Select；2d Input/Edit/Canvas 含光标/placeholder/焦点环；2e Tip/Refresh/SwipeItem/DatePick/TimePick）；命令面同批收编（user/berry-ui/src/lib.rs 父位白名单+kind 门+set_text 扩）；横向原语（raster 行 LUT 圆角+Cmd::FillRect add-only radius 变体；语义色 token 预混两套；paint/damage 双面 clip；文本多行）；模式件 user/berry-ui/src/pattern.rs（TopBar 56vp/BottomTabs 48vp/ListItem 48vp 五态/Nav 页栈/AppBar）；主题 token user/berry-ui/src/theme.rs（OH 官方表常量单源）；press_map 帽 16→28+launcher 建树尾全量登记；输入焦点协议（guiproto add-only：OP_WM_FOCUS/OP_WM_BACK/WM_LAYER_SERVICE=2/INPUT_EVT key·text/OP_INPUT_INJECT 授权注入口）。验证：`cargo test -p berry-ui --target aarch64-apple-darwin` ≥250 测绿（每件 ≥2 测）；gfxdemo 画廊页截图+`GFX ok` 零回归；TLV golden 零漂移；launcher 按压反馈截图。
4. 波3 桌面三栏与系统窗：launcher 双窗化（状态栏+五键导航条迁 layer=SYSTEM 窗 44vp）；guifbd 带合成 v1（缓存 SYSTEM/SERVICE 带、APP SUBMIT 后按 SERVICE>SYSTEM>APP 重放带缓存，动手前读 docs/显示与加速体系设计-v1.0.md 对齐 B 系）；沉浸旗 WM_CREATE_F_IMMERSIVE（应用全屏隐藏状态栏示范位），几何避让仍走 AVOID_SYS；I2 返回键路由（导航条返回→launcher 查 wmd 焦点→桌面翻页/应用 OP_WM_BACK→Nav 栈 pop、根页优雅退出、500ms 无响应 wmd 兜底 DESTROY）；TabBar 三系统页（SwipePager 桌面页+应用列表页 List+Search+设置页 Toggle/Slider/Radio/Seg，底部 BottomTabs 于五键 SYSTEM 窗之上）+battery 接 simbattery 真值；服务件 softimed（SERVICE 底窗 QWERTY-lite ASCII，显隐=焦点窗 ime_wanted，按键经 OP_INPUT_INJECT 与真实输入同一事件面）+Dialog/Menu/Toast v1 落 berry-appshell（新 crate 抽 launcher 五模块样例）。验证：VNC 三连截图（应用内状态栏常驻/返回回桌面）；TabBar 三页切换；设置页真改 boot 模式默认；软键盘升起-敲键回显-返回键先收键盘再退应用；gui8-smoke 扩门 SYSBAR/BACK 新标记互非子串；smoke 零回归。
