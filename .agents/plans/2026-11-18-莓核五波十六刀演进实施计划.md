# 莓核（Meihe）五波十六刀演进实施计划

Type: plan
Status: active
Updated: 2026-11-18

一句话说明：将 [meihe 总体设计](./meihe/design.md) 及三大核心子模块规格（[mm 总体设计](./mm/design.md)、[ipc 总体设计](./ipc/design.md)、[hal 总体设计](./hal/design.md)）v2.0.0 拆解为严格按依赖排序、每刀独立可编译、独立 QEMU 可验、独立可回滚的「五波十六刀」工程执行序列，把莓核从 G0/G2 过渡态推向 16 核真机级终态微内核。

## 背景

依据 [莓核全核深度体检报告](../research/2026-11-18-莓核全核深度体检报告.md) 锁定的 26 项架构病灶与 [莓核二代终态架构六大核心裁决](../notes/proposed/2026-11-18-莓核2代终态架构六大核心裁决.md)，`docs/` 下六大跨层内核标准（[系统调用 ABI 设计](../../docs/系统调用ABI设计-v1.0.md)、[内存管理设计](../../docs/内存管理设计-v1.1.md)、[IPC 设计](../../docs/IPC设计-v1.0.md)、[能力模型设计](../../docs/能力模型设计-v1.0.md)、[安全与硬件隔离设计](../../docs/安全与硬件隔离设计-v1.0.md)、[驱动模型设计](../../docs/驱动模型设计-v1.0.md)）已完成 Curia `Type: standard` 升格与现役事实对齐；代码演进严格遵守「先止血防破窗、再通快路、后拆大锁扩多核、再落容器弹性、最后收口真机 HAL 与目录卫生」的依赖铁律，每波收官同步递增对应 `docs/` 标准版本号。

## 步骤

### Wave 0：P0 止血、全量回收与硬件隔离底板（零新增系统调用号）

1. **刀 0.1（ASID 活跃位图 + TLB 去对飞化 + `Vmar::allocate` 补锁）**：在 `mm/src/asid.rs` 实装 65,536 位活跃位图与 `free(asid)`（宿主机单测覆盖 8-bit 255 号回卷避让活进程）；移除 `Vmar::supply_page` 上的冗余 `tlbshoot::broadcast()`，在合规 ARMv8 路径改为纯硬件 `tlbi aside1is` + `dsb ish` 免 SGI 关中断互等（HVF 兜底路径改为开中断/轮询挂起消费），补齐 `Vmar::allocate` 的 `pt_lock`。验证：`just test-host` + 双核高频 `unmap`/`protect` 对飞压测与 300+ 进程生灭 `ktest` 绿。
2. **刀 0.2（进程退出 Teardown-Before-Drain 全量物理页与页表回收）**：在 `kernel/src/vmar.rs` 实装 `teardown_all()` 与 `Vmar::Drop` 递归释放 L1/L2/L3 页表帧及 `free_asid`；修改 `process.rs` 的 `drain_pinned_process` 先跑 `teardown_all()` 清零 `mapcnt`/`demand_pins` 再跑 `HandleTable::drain()` 正常 `release`。验证：`ktest` 与 `smoke` 跑千次进程映射退出后 `mm::frames().allocated_pages()` 净增为 `0`。
3. **刀 0.3（`ChannelShared` 去环 + `SIGNAL_PEER_CLOSED` / `ERR_DEAD(-52)` + 强杀睡眠钉住配平）**：重构 `kernel/src/channel.rs` 为单共享控制块 `ChannelShared` + 环形槽（免 `Vec::remove(0)`），翻开 `tools/abi.toml` 中 `ERR_DEAD` 的 `rust = true`，对端关光置 `SIGNAL_PEER_CLOSED(1<<4)` 并对死端 `send`/`空队 recv` 返 `ERR_DEAD`；将阻塞等待临时 `ObjRef::retain` 移入 `Task::sleep_pins` 并在 `kill_all_tasks_by_pinned` 统一释放，异常杀退出码改为负故障码。验证：循环万次 `channel_create` + `close` 零堆增长 + 强杀阻塞线程零引用泄漏断言。
4. **刀 0.4（能力门控补洞 + `MsgBilling` 迁 TCB + 显式 `VMO_OPT_ZFOD` + W^X 与内核栈守卫页）**：`process_start` 补检 `RIGHT_TRANSFER`、`process_create` 补授 `RIGHT_INSPECT`、`power_off`/`telemetry_open`/`cbox_drain` 挂能力门控、`hdlface` 权限升 `u64`；`BILLING_RECV_*` 迁入 `Task` TCB 按任务自身运行周期结算；将自动污染的 `mark_zfod` 改为显式 `VMO_OPT_ZFOD`；核齐用户态 ELF 段页边界后开启页表 `AP_USER_RO`/`UXN`/`PXN`、VIPT `ic ivau` 及内核栈 `4KiB` 未映射守卫页。验证：`just abi-check` + 全量 `SMOKE_PHASES=boot` 绿 + RWX 拒面与守卫页自检断言。

### Wave 1：`Port` 观察者多路复用与同步 RPC 定向让片

5. **刀 1.1（对象内嵌 `ObserverList` + `ObjType::Port` + 废除 `WAIT_ANY` 全局哨兵）**：新增纯核 `portface` 宿主机钉板包；在 `tools/abi.toml` add-only 注册 `port_create`、`object_wait_async`、`port_wait`；在可等待对象头部内嵌侵入式观察者链，`object_wait_many` 改用栈上 16 节点挂链，彻底删除 `WAIT_ANY` 与 `WAIT_ANY_WAITERS` 全表扫描。验证：常驻 `console`/`guifbd` 在场时无关通道 `channel_send` 的 Fastpath 命中率 > 95% 断言。
6. **刀 1.2（`channel_call` 原子请求-应答与同带定向让片 + `berry-libc` 事件循环统一）**：新增 `channel_call` 原语（内核 `txid` 匹配 + 同带剩余片定向借予直切 + 应答天然终止借入计费）；将 `berry-libc` 的 `epoll`、`poll(timeout)` 与信号通知桥接至内核 `Port`，删除 `net.rs` 1 秒 `sleep_tick` 轮询；补齐 `0x83`/`0x40`/`0x84` 的共享 VMO 环形映射通道；同批将 `IPC设计` 与 `系统调用ABI设计` 升格为 `docs/` `Type: standard`。验证：IPC 同级 ping-pong 延迟基准大幅下降 + 网络与事件循环套件全绿。

### Wave 2：去 `KERN_LOCK` 细粒度锁拆解与 16 核 SMP 扩展

7. **刀 2.1（核无关锁秩重构 + `CpuMask(u16)` + `MAX_CORES = 16` + 策略表 18 槽修复）**：拆分 `Task::held_locks: u8` 为 `sched_flags` 与八秩 `LockRank`（升级 `berry-lkface` 与 `lockdep`）；将 `SMP_CPU`、`dpg::DEPTH` 等统一改为 `[PerCpu; 16]`，`REAPQ` 与 `HT_DRAINQ` 改为每核本地排空；修复 `sched/src/policy.rs` 为 `SNAP_SLOTS = 18` 且出窗立清 `HAZARD[cpu]`。验证：QEMU `-smp 4`、`-smp 8`、`-smp 16` 启动并过 `lockdep` 自检与策略并发换表万次压测。
8. **刀 2.2（PMM PCP + Slab Magazine + 原子 `ObjRef` + 细锁剥离 `KERN_LOCK`）**：`ObjRef.refs` 升 `AtomicUsize`；`BuddyAllocator` 落每核 PCP 弹匣与独立细锁；`SlabHeap` 落每核 9 档无锁 Magazine 与空页高水位退回 buddy；为 `HandleTable`、`Vmo`、`ChannelShared` 启用各自细锁并撤销 `SVC` 入口 `KERN_LOCK` 及全核 `RQ` 预取。验证：多核并发 IPC / 内存分配吞吐线性度基准 + `lockdep` 全程零违约。
9. **刀 2.3（跨核多原语有界增量 PI + 唤醒路径 `eas_wake_pick` + 轻量 `RtClass`）**：重写 `kernel/src/pi.rs` 为沿 `Channel`/`Port`/`dpg` 显式阻塞边跨 `0..online_cpus()` 增量传播（≤8 跳，必要时发 `SGI_RESCHEDULE`）；在唤醒入队路径接入 `eas_wake_pick` 消费 `placement_hint` 与实时 `intent_effective`；补齐独立 FIFO/RR `RtClass`。验证：双核/四核跨核 PI 反反转断言 + 大小核唤醒迁移断言。

### Wave 3：`Job` 层次化沙箱、轻量能力撤销与五级内存弹性

10. **刀 3.1（`ObjType::Job(11)` 树容器与物理内存/进程配额守恒）**：实装 `Job` 树、父链原子 `ram_bytes_used / quota`、`live_procs / max_procs` 与 `job_kill()` 递归清场；收紧 `process_create` 强制验父 `Job` 的 `RIGHT_MANAGE`（根绝 `close(child_h)` 进程炸弹）。验证：子 `Job` 超内存/超进程帽精确阻断与 `job_kill` 全子树瞬时回收断言。
11. **刀 3.2（句柄槽内联 `Badge` + `RevokeEpoch` O(1) 能力撤销）**：实装 `handle_mint` 与 `RevokeEpoch` 纪元表；推进核心多客户服务（`fsmgr`/`vnet`/`wmd`）利用内核认证 `sender_badge` 收敛通道模型，验证应用 `once`/`session` 授权到期 O(1) 断电返 `ERR_DEAD`；同批将 `能力模型设计` 升格为 `docs/` `Type: standard`。验证：能力伪造拒面与百万次 `badge` 收发 + 即时撤销测试。
12. **刀 3.3（动态大物理内存 + 基数簇 `PageInfo` CoW + L0 `DISCARDABLE` + L1 `0x22` 闭环）**：开放 `TCR_EL1.IPS` 动态 `PARange` 与动态 PMM/直映表（支持 1GiB–16GiB+ RAM）；`vmoledger` 升级两级按需页簇 + `&[AtomicU16]` 帧引用计数以支撑 `vmo_create_child(COW)`；落地 PMM 低水位压力位、`VMO_OPT_DISCARDABLE` 自动摘页与 `0x22 pager_op_range` 冷页换出，`DEMAND_ROOTS` 内联入 `Vmar`；同批将 `内存管理设计` 升格为 `docs/` `Type: standard`。验证：`memhog` 注入下 L0→L1→L2→L3 逐级触发且物理空闲页真实回升断言。

### Wave 4：真 `berry-hal`、真机中断/DMA 隔离、`ramoops` 与工作区收敛

13. **刀 4.1（下沉共享纯核消除 `user/` 逆向依赖 + 抽离 `berry-hal` 五大窄 Trait）**：将 `berry-em` 与点阵字形核迁入内核纯逻辑层（并在 `docs_guard.py` 加「内核层零 `user/` 依赖」门禁）；新建零 `unsafe` 的 `berry-hal` crate，重构 `arch/aarch64` 实现五大 Trait，并将 `arch/x86_64` 接入真实 `berry-kernel` + `berry-sched`。验证：`just build` + `just build-x86` + `smoke-x86` 跑通真内核最小集。
14. **刀 4.2（GICv2/v3 双栈自适应 + `ObjType::Interrupt(8)` 驱动零轮询化）**：按 DTB 自动分派 GICv2 与 GICv3（`ICC_*_EL1` + `GICR`）；实装 `0x71/0x72` 中断对象自动 mask + `Port`/`Event` 唤醒协议，改造 `vblk`、`vnet`、`gui-inputd` 全面移除 1–10ms 睡眠轮询。验证：`virt,gic-version=3` 启动全绿 + 空载稳态 `WAKESRC` 轮询唤醒计数为 `0`。
15. **刀 4.3（`VMO_OPT_CONTIGUOUS` + Cache 维护原语 + SMMUv3 隔离骨架 + `ramoops` 持久黑匣子）**：实装连续物理页 DMA VMO、受控 `vmo_cache_op` 与 SMMUv3 设备流表绑定骨架；划定物理内存顶端 16KiB 免清零 `ramoops` 页承载 `cbox` 与热尾 `klog`（带 CRC32C），支持 EL1 panic 跨热重启由 `svcmgr` 自动排液落盘 `CBOX.LOG`；同批将 `安全与硬件隔离设计` 升格为 `docs/` `Type: standard`。验证：QEMU 注入 EL1 同步异常触发热重启后 `berry crash-log` 精确解析出 `kind=el1` 故障帧。
16. **刀 4.4（独立 `ipc/` Crate 归位 + `faces/` 目录收敛 + `unsafe` 密度 ≤3% 收官）**：落成独立 `ipc/` crate 并拆薄 `kernel/src/main.rs` 与 `syscall.rs`，精简 EL1 `splash`；在单独占窗口原子迁移仓根 `*face` 至 `faces/<name>/`；用 `PerCpu<T>`/`StaticOnce<T>`/`PinnedObj<T>` 清扫残留裸指针与 `static mut`，重产 `unsafe台账.md` 达成生产面密度 ≤ 3.0%。验证：全量 `just test-host` + `just build-release` + 全相 `smoke` + `check-docs --strict` 全绿。
