# LAN 桌面沉浸化三件套（三键导航/BottomTabs 撤/白底撤）——owner 裁定落地方案

Type: plan
Status: done
Updated: 2026-11-16

一句话说明：owner 2026-11-16 凌晨连续裁定的桌面沉浸化三件——①导航键从五键大块改三键安卓 12 式（返回 ‹ / 主页 ● / 多任务 □，96px/25-50-75 均布）；②BottomTabs 整条从桌面页撤（Home/Apps/Settings 页签不再常驻）；③BottomTabs 白底 Rect 与 scrim 衬底全撤（壁纸从顶到底一条直通）——本文记录裁定内容、实现方式与验收证据，作为后续同类裁定的参照。

## 裁定内容

### ① 三键导航（安卓 12 Material You 形）

| 项 | 值 |
|---|---|
| 键数 | 3（返回/主页/多任务——安卓序：返回左、主页中、多任务右） |
| 键尺寸 big | 96px（32dp@3x） |
| 键间隔 big | 176px（中心距 272 = 1088/4，25/50/75 均布） |
| 条高 big | 135px（OH 布局公式原值） |
| 旋转/关机 | 撤出屏条（Web 桌面下旋转标记无消费者、关机走 berry 控制面 API 更优） |
| NavNodes 字段 | 别名到 back 节点保结构（frameloop 的 rotate/power 匹配臂不可达） |
| 替代的旧裁定 | 2026-11-13 五键大块（160px/48 间隔/190 条高） |

### ② BottomTabs 从桌面页撤

- 桌面页 `build_tab_bar` 不建实例（`bar_inst = bar_host, tab_nodes = [bar_host; 3]`）
- `tabs_h = 0`（布局公式 reclaim 144px 给 pages 区）
- 切 sys 页时 `rebuild_tab_bar` 在 `bar_host` 上按需建实例（功能保留、桌面页不显示）
- 理由：三键导航已提供主页/多任务入口，BottomTabs 的 Home/Apps/Settings 页签与三键重复——桌面上两排图标混淆视听

### ③ 白底 Rect 全撤（沉浸贯通）

- `pattern.rs` 的 `bottom_tabs_slots` 白底 Rect（0xFFFFFFFF 满宽 144px）撤
- `syspages.rs` 紧凑档 CARD_BG 白底同撤
- `desktop.rs` 的 `status_scrim()` 深色衬底撤（HEAD 已合入）
- 效果：壁纸从屏幕顶到底一条直通，所有 UI 元素（状态栏/dock/导航键）直接浮在壁纸上

## 验收证据

- 三键像素级在位：白·深·白 @ x=272/544/816（y=1854），两侧空位纯壁纸蓝
- BottomTabs 无残留：底部区域 y=1700-1920 唯一可见元素为 dock + 三键
- 白条清零：y=1600-1800 无纯白 (255,255,255) 行
- LAUNCH ok 每次启动在位（桌面稳定渲染）
- `just build-user` 全链绿

## 为什么不是……

- **五键保留只缩尺寸**：否——owner 明确要三键（「人家安卓就是 3 个图标」），五键的信息密度在手机上反而碍事
- **BottomTabs 保留但透明**：否——图标仍然占据视觉空间且与三键重复；完全撤才是沉浸
- **白底改壁纸色**：否——直接撤 Rect 更干净；壁纸色近似值会随壁纸变化漂移
- **导航键底块透明**：否——客机渲染管线不支持 alpha=0 透明像素（实测图标整体消失）；壁纸蓝近似值可接受
