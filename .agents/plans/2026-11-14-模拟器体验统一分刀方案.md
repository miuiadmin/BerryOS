## 目标

1. 图标模式开窗即黑底 logo+白细进度条+百分比（真事件驱动，粒度细）；命令行模式全程滚详细日志；两模式皆无黑屏静默段。
2. 图标模式完成后自动接首次引导（简洁引导页慢慢引导），走完进桌面；第二次开机不再出现。
3. 状态栏 OH 形、系统级常驻：36vp、左信号/wifi、右电池+时钟恒最右、无应用名；v1 无 alpha 用预混色实现。
4. 应用内结构：Mini 标题栏 56vp（左上返回箭头，点击等效 back）+ 需要时底部页签 48vp；back 键 = 应用内返回/退出到桌面。
5. 内置应用真实 UI 化：示范页带标题栏+列表卡片+按压反馈（OH 参数：按压缩放 0.90/0.95、20% 高亮遮罩、卡片 48vp 高 8vp 内边距、按压圆角 8vp）。
6. 模拟器入口统一 = 唯一 berry 自家窗口（desktop profile + HVF），其余入口隐藏为调试面；图标模式 = 默认 boot 形态。

## 成功判据

- 图标模式：全程无黑屏静默段；进度条 ≥20 个真实事件驱动（TCG 慢速下可见爬升非两档跳）；滚完自动接首次引导。
- verbose 模式：EFI 第一行到桌面首帧全程滚日志无空白段。
- 状态栏：与 OH 官方形态目测同构（36vp 高、图标归一 24vp、时间恒右、间距 8vp 无错落）；应用起来后常驻不被盖。
- 应用：点开图标 <2s 出页面、按压有视觉反馈、back 回桌面；标题栏返回箭头等效 back。
- 入口：双击或单命令开窗即唯一形态；shot 类工具默认同 profile/accel。

## 刀序（七刀，A 案推荐）

结构判断：六项投诉共享三条根因——①berry-ui 无组件层（无圆角/alpha/卡片/顶栏原语）→ 状态栏只能手工拼、应用只能秒退壳；②boot 相画面所有权链断裂（HEAD 无 splash）→ 黑屏静默；③入口五套默认值 → 形态分裂。刀序按「先地基后示范」。

### 刀 1（P0）：入口统一 + splash 双模式合入
- 五入口默认值收敛：shell/host/device start/shot/双击全部 desktop profile + accel auto（Mac→HVF）；shot 的 default 档 800×600 陷阱（gui_mode=false 滚日志）修掉。
- 实施期新知（2026-11-15，刀 6 实施中实测）：`berry shot --boot-mode` 只注 bootmode 不注 display key → guifbd 非 GUI 形 + GUI 式 launcher spawn 的杂交形态，是 svcmgr WTDIE 自陷的复现形之一；gui8 车辆（display 在、noktest 键缺）紧配速同签名复现——入口统一时 GUI 家族须 display 与 noktest 两键齐注（定谳与判别器见 worktree `wip/boot-events-knife6` 笔记 `2026-11-15-svcmgr-wtdie-selftrap-forensics.md`）。
- rescue/ux-splash（7fd1709c）合入主干（boot 双模式 + HD 百分比数字 + 过渡行 70592504 随入）。
- 旋转键重启整机 v1 保留（几何静态链决定，热切归刀 7）。
- 验收：任一入口开窗都是 1080×1920 同形态；boot 全程无黑屏静默段；`berry doctor` 报 hvf。

### 刀 2（P0）：状态栏 OH 形重做
- scrim 改壁纸顶色采样动态预混 50% 黑带（替代 #035E63 硬编码；预混实现，不开 alpha）。
- 左组=信号/wifi（归一缩放 24vp、间距 8vp）、右组=电池+时钟恒最右；应用名不出现在状态栏。
- 对齐重做：三组 weight 对齐（Start/Center/End），废弃手工 spacer+等宽估算双口径。
- 模拟值标注保留（SIM/UTC 角标）。
- 验收：屏摄与 OH 官方状态栏目测同构；a11y 树报告正确。

### 刀 3（P1）：berry-ui 组件层补齐
- Rect 半透明预混原语；圆角原语；ListItem 卡片容器+五态样式（OH 参数）；TopBar 组件（56vp、左上返回）与 BottomTabs（48vp）；press_map 消费面扩展（launcher+应用共用）。
- 验收：示范应用能以声明式树直接拼出「标题栏+卡片列表+底部页签」页，无手工拼装。

### 刀 4（P1）：多窗合成与 back 语义
- guifbd 单 blit 通道扩多窗合成（z 序、SYSTEM 层避让）；状态栏从 launcher 内容层迁 SYSTEM 层常驻窗；back 键语义链：桌面=翻页、应用内=返回/退桌面。
- 与显示体系 B 系（B1-b/B1-c）对齐避免撞车，动手前先读 `docs/显示与加速体系设计-v1.0.md`。
- 验收：应用起来后状态栏常驻不被盖；back 在应用内退出到桌面。

### 刀 5（P1.5）：内置应用示范 UI 化
- appdemo 改真 UI 应用（56vp 标题栏+返回、卡片列表 3-5 张、按压反馈）；其余 6 个 appstub 按模板各生成轻页（设置页/关于页/浏览器占位…）——求「点开有页面有反馈」，不求全。
- 验收：点开任一图标 → 页面 <2s 渲染 → 按压有反馈 → back 回桌面。

### 刀 6（P1.5）：boot 事件细化 + 首次引导（OOBE）
- splash 里程碑从 15-24 格细化到服务级（svcmgr 子服务、wmd/guifbd/launcher 起动、桌面树装配等 ≥20 格）；间隙插值（显示值永不超前下一真实里程碑）；服务打点通道（bootevent 参数化模型）。
- OOBE：首次开机进简洁引导页（语言→时区→风格→桌面），复用刀 3 组件——OH 开源版无向导可抄，自设计借 token。
- 验收：TCG 慢速下进度条可见缓慢爬升；首启自动进引导、走完进桌面、二启免。

### 刀 7（P2）：收尾
- 旋转自由化（几何热切，依赖显示体系刀位）；剩余内置应用页面补齐；体验打磨。

## 方案选项

- **A（推荐）**：刀 1+2（P0）并行先行 → 刀 3/4（组件层与多窗合成，共享面多串行或协调）→ 刀 5/6 → 刀 7。理由：入口不统一则一切体验改进 owner 复现不出来；状态栏是第一观感；地基不立则示范应用无米下锅。
- **B**：按投诉逐项修（back 先行）。落选：组件层未备先修 back 语义，只能出「半成品修半成品」；入口不统一则每刀验收受五套窗口干扰。
- **C**：七刀全并行拆轨。落选：主树已 49 文件 WIP，全并行加重冲突面；刀 3/4 共享 berry-ui/guifbd 面并行即撞车。
