# 终端与命令行全栈闭环五波十八刀实施计划

Type: plan
Status: active
Updated: 2026-11-18

一句话说明：承接已合入主线的莓核 2.0 规格与本次立定的 `pty`、`bsh`、`cli-suite` 三大模块总体设计，按严格依赖拓扑分五波十八刀完成代码落地，率先把 BerryOS 打造成「纯靠命令行即可完整日常操作、编写脚本、联网协作与全栈在机调试」的精品操作系统。

## 背景

在图形桌面尚需长期打磨的阶段，先把「微内核底座 + 终端全栈工作台」做到极致完整，是让 BerryOS 立刻可用、好调、能自证的最高杠杆路径。本计划以前置 [莓核五波十六刀演进实施计划](2026-11-18-莓核五波十六刀演进实施计划.md) 核心能力（无环 Channel、`Port`、`Job`、`SuspendToken`、退出全回收、`Interrupt`）为地基，依据 [终端与命令行全栈体验深度体检报告](../research/2026-11-18-终端与命令行全栈体验深度体检报告.md) 与 [终端优先全栈闭环架构六大核心裁决](../notes/proposed/2026-11-18-终端优先全栈闭环架构六大核心裁决.md)，串联 [pty 总体设计](pty/design.md)、[bsh 总体设计](bsh/design.md) 与 [cli-suite 总体设计](cli-suite/design.md) 的全部工程交付。

## 步骤

### 第一波：莓核关键泄漏清零与 `ProcessArgs v2` + `/svc` 命名空间地基（刀 1–4）

1. **刀 1（莓核长跑防漏与无头启动底座咬合）**：精确对接 [莓核五波十六刀演进实施计划](2026-11-18-莓核五波十六刀演进实施计划.md) `Wave 0（刀 0.1–0.4）`、`Wave 1（刀 1.1 Port）` 与 `Wave 3（刀 3.1 Job 树）`，兑现分代 ASID、`Teardown-Before-Drain` 退出页表全回收、`ChannelShared` 去环与强杀写端触发下游 `SIGNAL_PEER_CLOSED (0 = EOF)`、`Task::sleep_pins`、`ObjType 13..=19` 枚举注册、`Job` 配额树及 `dev` 模式串口 `BREAK` 内核紧急逃生钩子；跑通连续派生回收 `2,000` 个管道子进程 `0` 页泄漏门禁。
2. **刀 2（`ProcessArgs v2`、`berry-libc` 六大 POSIX/Rust `std` 映射与 `SIGPIPE(141)`）**：落地 `berry-exec` v2 与 `berry-libc` 启动协议升级（只读 `ArgsVmo` 最高 `1MiB` 参数环境块 + 类型化 `HandleEntry` 表），将 `fd 0/1/2` 拆分为独立全双工流句柄，实装 `posix_spawn`（让 Rust `std::process::Command` 零改跑通）、`pipe2`、`dup2/fcntl`、基于内核 `Port` 的跨类型统一 `poll/select/epoll` 与死端写入默认 `141`（`SIGPIPE`）收敛，退役 `ARGV_STR[256]` 与 `GIFT_H[6]`；`just test-host` 与既有 smoke 全绿。
3. **刀 3（`rootmgr` `/svc` 能力目录、`opt/berry/bootmode=headless` 与双级会话 `elevate`）**：实现 `berry-svc` 协议与 `/svc/{proc,fs,net,pty,trace,power,cbox,debug,pkg}` 目录路由，打通宿主 `berry --boot-mode headless` 与客机 `opt/berry/bootmode=headless`（及无显示/无指针自动降级）`< 150ms` 纯终端极速启动链，落地 `OperatorSession / elevate` 无 SUID 提权契约，改造 `ps` 与 `berryctl` 经 `/svc/proc` 建立独立会话；在交互 `bsh>` 下直接敲 `ps`、`berryctl ver/ps/mem` 100% 成功返回。
4. **刀 4（统一虚拟挂载树与持久化主目录）**：对接 [storage-image 总体设计](storage-image/design.md) 与全系统存储总纲，建立 `/`（只读根）、`/tmp`（弹性 `tmpfs`）、`/data/system_de/log`（系统持久日志）、`/userdata/home`（持久化读写主目录）与 `/dev/{null,zero,urandom,tty,kmsg}` 统一路径视图，打通 `O_APPEND` 原生追加写游标。

### 第二波：用户态伪终端 `ptyd`、物理控制台 `consoled` 与 `berry-vt` 协议栈（刀 5–8）

5. **刀 5（`faces/utf8width`、`ptyface` 与 `berry-vt` 纯核先行）**：新建零依赖 `no_std` 纯核 `faces/utf8width`（五处共享字符列宽单源）、`user/ptyface`（`Termios` Raw/Cooked/Echo/ISIG 行规、`Winsize` 与边沿流控纯逻辑）与 `user/berry-vt`（VT100 / xterm-256color / TrueColor 解析器、备用屏幕 `?1049h`、括号粘贴 `?2004h`、脏格差分发射器）；宿主机性质测试与 1,000 万字节随机畸形序列 Fuzzing 全绿。
6. **刀 6（`ptyd` 守护进程与双 `64KiB IoRing VMO`）**：落地 `/svc/pty` 服务，签发 `(PtyMasterCap, PtySlaveCap)` 能力对，接通 `InputRing / OutputRing` 零拷贝字节环与 `PtyCtl`（`tcgetattr / tcsetattr / ioctl(TIOCGWINSZ)` libc 适配及 `SIGNAL_PTY_WINCH` 通知）。
7. **刀 7（用户态 `consoled`、`berry-ctlport` 带外复用与后台日志静音分流）**：利用内核 `Interrupt` 对象（`0x71/0x72/0x7A`）由用户态 `consoled` 驱动 PL011 / `virtio-console`，接通 `berry-ctlport` 第二控制口与裸串口 OSC `777/778` 实时缩放及文件分帧回退，退役内核 `task_console` 逐字节 `svc` 循环；将全部后台守护进程日志重定向至 `traced / klog` 环，验证一次性粘贴 `64KiB` 文本 `fwd_drop == 0` 且前台全屏界面零后台串扰。
8. **刀 8（交互子进程全双工直连与异常终端自愈）**：改造 `bsh` 外部命令执行路径为默认继承 `PtySlave` 实时流（彻底废除 `run_output` 退出后攒批打印），并在子进程退出或崩溃后由 `bsh` 自动兜底复原 `Sanity Termios` 与主屏幕缓冲。

### 第三波：`bsh` 3.0 现代编辑器、完整脚本语言与微内核原生作业控制（刀 9–12）

9. **刀 9（剥离自测桩与落地 `berry-line` 二维编辑器）**：将原 `bsh` 内嵌自测拆至 `/bin/bsh-selftest`；新建 `user/berry-line`（共享 `faces/utf8width`）接入 `bsh`，打通 UTF-8/CJK 宽字符光标自由左右移动、词跳、`Home/End`、剪切环、`4096` 条持久化 `.bsh_history`、`Ctrl-R` 反向增量搜索、实时语法着色与命令/路径/旗标多维 `Tab` 补全。
10. **刀 10（`bsh-syntax` 词法/AST、引号展开、路径搜索与混合流管道）**：新建纯核 `user/bsh-syntax`（宿主机 300+ 用例先行），实装单双引号、转义、`${VAR:-def}`、`$(cmd)`、`$((expr))`、通配符 `*`、`< / > / >> / 2> / 2>&1 / <<EOF` 重定向，打通 `./script.sh` 相对/绝对路径直跑与跨 `/userdata/home/bin:/bin` 的 `$PATH` 检索，并支持内建命令与函数出现在管道任意段（`dmesg | head -n 5` 原生跑通且上游按 `141` 即时收敛）。
11. **刀 11（结构化脚本控制流与配置文件体系）**：实装 `if/elif/else`、`for`、`while`、`case`、`fn` 函数与 `local` 作用域、`set -euo pipefail`、`trap` 清理钩子、`#!/bin/bsh` Shebang 自动加载以及 `/etc/profile` + `/userdata/home/.bshrc` 启动链。
12. **刀 12（`Job + SuspendToken` 作业控制与 `sandbox` 能力裁剪内建）**：将每条管道绑定至独立子 `Job`，打通 `&` 后台运行、`Ctrl-C` 整树 `job_kill(130)`、`Ctrl-Z` 持 `SuspendToken` 同步挂起、`jobs / fg / bg / wait / kill` 以及一行式最小特权沙箱命令 `sandbox`。

### 第四波：终端生产力套件与网络协作工具链（刀 13–15）

13. **刀 13（全屏编辑器 `bed`、零拷贝分页器 `less`、离线手册 `man` 与 OSC 52 剪贴板）**：基于 `berry-vt` 落地支持多缓冲、无限撤销树、正则搜索替换、语法高亮与 `.cache/bed` 掉电恢复的轻量编辑器 `/bin/bed`（兼顾无模式与 `--vi` 模态并支持 OSC 52 同步宿主机剪贴板），落地基于 VMO 零拷贝映射与 `F` 追尾的 `/bin/less` 及 `/usr/share/man` 离线手册查看器 `/bin/man`。
14. **刀 14（单串口多窗终端复用器 `bmux` 与宿主 `berry push/pull` 极速传文件 `bscp`）**：落地支持多标签、分屏、回滚复制（含 OSC 52）与断线后台保活重连（`detach / attach`）的 `/bin/bmux`；同步打通宿主 `berry push/pull` 与客机 `bscp` 双向帧校验直传，实现改脚本 0.2 秒热推入机。
15. **刀 15（网络瑞士军刀、归档校验与远程加密终端 `bsshd` / `berry ssh`）**：基于 `netd` 2.0、`berry-netsec` 与 `berry-crypto` 落地 `/bin/{ip,ping,dig,nc,curl}`、流式归档压缩校验 `/bin/{tar,zstd,sha256sum}` 及支持双向 Ed25519 认证与多路 PTY 会话的 `/bin/bsshd` 守护进程，打通宿主 `berry ssh` 并发登录。

### 第五波：微内核内省、系统服务包控制、在机交互调试闭环与 `--json` 收口（刀 16–18）

16. **刀 16（系统监控、身份提权、服务包电源设备控制与微内核能力透视套件）**：基于 `0x07 object_get_info` 六大 `topic` 落地 `free`、`vmstat`、`df`、`whoami / id / elevate`、16 核交互监控面板 `btop`、能力句柄与 Channel 对端拓扑透视器 `lscap`，以及系统运维控制四件套 `svcctl`、`pkg`、`lsdev/lsirq`、`powerctl/timedatectl` 与内核白盒诊断 `kctl`。
17. **刀 17（在机系统调用/IPC 追踪器 `btrace`、交互调试器 `bdbg` 与 `cboxctl`）**：对接 [devtools 总体设计](devtools/design.md) 的 `DebugExceptionChannel`（`0x41`）、`berry-unwind` 与 `traced` 环，落地在机实时解码 `berry_*` 系统调用与 RPC 协议帧的 `btrace`、支持软件断点/硬件观察点/符号化栈回溯的纯命令行调试器 `bdbg`、以及支持 `ramoops` 解码的 `cboxctl` 与 `dmesg -w`。
18. **刀 18（全工具 `--json` Schema 门禁与端到端真人工作流总验收）**：为全部系统查询、运维与诊断工具补齐严格 `--json` 输出与 Schema 单测，接入 `just smoke-cli` 端到端回归（覆盖无头极速启动、64KiB 粘贴、全屏编辑保存运行 `./check.sh`、三段混合管道 `SIGPIPE` 收敛、挂起恢复、`svcctl/pkg/kctl` 运维、在机 `lscap + btrace + bdbg` 断案与跨重启持久化），同步将 [终端优先全栈闭环架构六大核心裁决](../notes/proposed/2026-11-18-终端优先全栈闭环架构六大核心裁决.md) 与 [莓核与终端全栈十项遗漏收口裁决](../notes/proposed/2026-11-18-莓核与终端全栈十项遗漏与ABI撞号收口裁决.md) 翻转为 `implemented`。
