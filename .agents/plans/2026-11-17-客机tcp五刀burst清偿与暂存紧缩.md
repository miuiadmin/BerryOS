## 背景:burst 记差机理勘察结论(五假设按秩)

- **H1(rank1,错误 bail 面具)**:libc K 窗收支恒等式——`sent`/`inflight` 同增(issue 相 :931-932),`inflight` 唯一减点=队头收割且 `res_append` 无条件(:1012-1024)——故「send#2 返回正 500+零残渣」排除 :936-940 EAGAIN 部分写出口(数学上必含两次 250B 入槽),唯一代码面解释=错误 bail(:969 parse 破缺/:982 回显错长/:1008 op 级非 OK——最可能 vnet enqueue 即答 ST_BAD 2B 形或陈值非 RT 形 reply),`bail(sent>0)` 返正值把 errno 吞进部分写契约(:881-887)。时序排除法:90s 收割帽/60s F87 帽/1s BUSY 退避均造不出 511ms。bail 后 2 op 残留在途→60s 帽 TIMEOUT 应答滞留共享 netd 通道无人收割→毒化后续消费者(F147 面,impl 波 echo 相 rx=0 卡 90s 下游链一源)。**判别**:tcptest 重建打 {n,ret,errno} 三元组(原 w=500 面具吞 errno=最大盲区)。
- **H2(rank2,RES_MAX 背压设计面)**:若 bench 为 write-all-then-read 形态,send#2 应 bail(0,EAGAIN) 立即快返——矛盾面:w=500 与 sent=1000(send#2 应报 0/errno),故 H2 非 burst 主因;但「Client recv 空槽恒 EAGAIN(:1047-1065 文档化取舍)+余量准入」使任何 write-write-read 消费者按设计饿死——独立 API 面缺陷候选,判别=read-interleaved 变体一靴两裁。
- H3(vnet 收侧准入拒段复合形)/H4(陈值应答丢弃对 send#2 良性,F147 放大面与 H1 同批清偿)/H5(BUSY 族时序排除,留对表项)——详见勘察 workflow journal(scout:burst-mech,journal.jsonl 留档)。

## 裁决

### 1. 五刀①判别优先,修复随判别结果分轨

判别实验(一靴两裁):tcptest burst 臂 A 形(read-interleaved,原 4/4 形态)vs B 形(write-all-then-read 合法 EAGAIN 对照)+ 失败三连探针(P1 recv 探针/P2 新鲜 send 探针/P3 close+重 connect 滞留检测——早退路径必先 close(fd),原私有件缺陷修掉)。若 A 形 send#2 ret=+500 且 errno≠0 → H1 定谳,修=bail-with-inflight 收口语义改造(帽内等兄弟 op 收割后再返,或显式放弃+残答清扫面)+ F147 跨套接字毒化一并收口;若 errno=0 → H1 死 H2 升格,修=bench 节奏/RES_MAX 抬升/recv 阻塞档立法(API 语义变更走 SDK 执法面,不静默放宽)。

### 2. 五刀②紧缩:弃置水印取权威重发源,绝不取 snd_una

berry-tcp 部分覆盖(straddling)ACK 保槽、RTO **整段重发**原段首(on_rto :369-390)——naive「紧缩到 snd_una」会切掉仍需重发的段前缀击重发臂 trap。裁决:`tx_retx_floor()` 只读方法返回**环头 Data 段首 seq**(环空/头为 Syn|Fin → snd_nxt);vnet `tx_compact()` 在 post_account 单点替换旧「环空失效」臂(环空=floor==snd_nxt 的紧缩特例,行为逐字节等价);零新字段,memmove ≤512B 单线程可忽略;触发不做惰性(闸拒时 ACK 往往未到,缩无可缩)。FIN 占序号 +1 面以 N≥tx_len 分支整体失效处理(非 assert)。

### 3. fixture 纪律(G0 阳性对照门——F94 教训成门)

tcptest 重建件在四刀 tip(B4)链上**必须复现原缺陷**(≥2/2 boot)——证明检出力后才许下「清偿」结论;不复现=fixture 形态漂移,先修 fixture(若 F121 闸使原构造形提前 BUSY 化,以六轮 F121 构造形替代复现基形并记口径差)。三链构建 sha256+boot banner 登记(外来内核新鲜度坑判据);kernel/rootfs 同树同源(混代=netd RPC 死)。
