## 1. 范围与依赖

七件套（裁决自总纲步骤 4 原文，不得擅改）：

- **launcher 双窗化**：状态栏与五键导航条迁出 launcher 内容层（现归属内容层 desktop.rs:17-18，导航条 desktop.rs:718-774 尾 Row），各自成 layer=SYSTEM 窗——顶部 44vp 满宽 + 底部 44vp 满宽；桌面主内容留 layer=APP 窗，几何避让走 WM_CREATE_F_AVOID_SYS（wmd 对全体可见 SYSTEM 窗求差集 table.rs:187-216，多系统窗零改动支持）。launcher = 一个 wm 客户端持三窗。
- **guifbd 带合成 v1**：serve 循环内缓存 SYSTEM/SERVICE 带；APP SUBMIT 后按 SERVICE>SYSTEM>APP 序重放带缓存；只做条区局部重绘（7fd1709c 判例：平滑算法只活 guifbd，总纲 :19 硬约束）。细节 §4。
- **沉浸旗 WM_CREATE_F_IMMERSIVE**：guiproto add-only 旗 + 快照位；沉浸窗在焦 = 状态窗隐藏的示范位（波 4 Photos/Camera 消费）——launcher 订阅表通知，焦点窗沉浸位=1 时 SET_F_VIS HIDE 状态窗（五键条保留），失焦/退场回显；几何避让仍走 AVOID_SYS——IMMERSIVE 窗自身不设避让（全屏几何），wmd 避让算法零改动。
- **I2 返回键路由**：导航条返回 → launcher 查 wmd 焦点 → 桌面翻页 / 应用 OP_WM_BACK → Nav 栈 pop、根页优雅退出、500ms 无响应 wmd 兜底 DESTROY。细节 §3。
- **TabBar 三系统页**：launcher APP 窗内容 = BottomTabs（48vp，波 2 pattern.rs 冻结名）+ 三页——桌面页（现 SwipePager 4 页网格+dock 原样内嵌）、应用列表页（List+ListItem 48vp+Search 输入）、设置页（Toggle/Slider/Radio/Seg 分组，含 boot 模式默认开关）；「BottomTabs 位于五键 SYSTEM 窗之上」由 AVOID_SYS 避让自然达成（不另设层序，2026-11-15 审查建议 b 落地）；press_map 翻页重登记挂账同批清偿（侦察 :31——rehang_a11y 同拍 set_press_map 整表替换，帽 28 以波 2 落地为准）。
- **服务件 softimed**：SERVICE 底窗 QWERTY-lite ASCII 软键盘；显隐 = 焦点窗 ime_wanted；按键经 OP_INPUT_INJECT 与真实输入同一事件面。细节 §5。
- **berry-appshell**：新 crate（user/berry-appshell），抽 launcher 五模块为应用壳 crate + Dialog/Menu/Toast v1；APPDEMO（gui8 TEST_IDS 在册双件之一，desktop.rs:159-163）升格为首个消费者最小样例——本波验收的应用窗载体。细节 §6。

横切件两条：battery 真值通道 BATT_GET（§2）；boot 模式默认持久键 BOOT.JSN（§7）。

依赖与边界：波 2 冻结面按冻结名引用、以波 2 落地为准——OP_WM_FOCUS/OP_WM_BACK/WM_LAYER_SERVICE=2/INPUT_EVT Key·Text/OP_INPUT_INJECT（侦察 §五）+ pattern.rs 模式件（TopBar/BottomTabs/ListItem/Nav/AppBar）+ berry-ui 焦点环；波 1 的 `--boot-mode` 链是设置页默认的宿主消费面（[波1 设计](2026-11-15-波1-开机双模式设计.md) :13）。B 系边界：合成 v1 文件面全在 guifbd guest.rs 的 Srv/submit，不碰 B1-b 壳半（tools/berry 的 display/window）与 B1-c 动态分辨率（SET_SCANOUT 几何/events）的 vgpu/ScanoutMap 面（[显示与加速体系设计 v1.0](../../docs/显示与加速体系设计-v1.0.md) 刀序表 :93-96；侦察 §二 标签错位注记——对齐以 docs 刀序行为准，勿信代码头注的 B1-b/c 字面）。

## 2. 状态栏重做规格

scrim：boot 期壁纸顶部均色采样，动态预混 50% 黑（Rect 无 alpha 通道，预混实现纪律保持 desktop.rs:130-134 形；#035E63 硬编码退役；scrim 先于内容列插入的建树序纪律保持 desktop.rs:347-351）。

图标与真值：OH 资产真值图标（status_icons.rs 生成面勿手改）渲染尺寸归一 24vp（「真值尺寸不缩放」口径退役）；battery 接 simbattery 真值——值通道 = svcmgr app 域 add-only op BATT_GET（svcmgr 预拉 simbattery 时增 gift 查询通道对；simbattery 主循环 wait 集扩双端，应答最近一次 ST_OK 快照的 capacity_pct/status/ac_online——现「已解码零发布面」侦察 §四；launcher 帧 10s 时钟醒同拍拉取，零新增唤醒）；真值缺席回退模拟满电，a11y label 如实（「battery simulated 100」现口径 desktop.rs:483 保留为回退态）。SIM/UTC 角标保留；时钟 UTC 口径不动（时区换算仍挂账，以波 2 落地为准）。

## 3. 返回键路由状态机表

| # | 事件源 | launcher 查询 | 目标与处理 | 超时与回退 |
|---|---|---|---|---|
| R1 | 导航条 back 键（五键 SYSTEM 窗命中，on_nav_click 现翻页语义 frameloop.rs:771-831 改造） | TABLE_GET 快照取焦点窗 | 焦点 = launcher APP 窗：桌面 tab = SwipePager 上一页（page 0 无操作）；非桌面 tab = 回桌面 tab | 本地即答，无超时 |
| R2 | 同 R1 | 同 R1 | 焦点 = 应用窗：OP_WM_BACK(0x67)（wid=焦点窗，波 2 冻结）→ wmd 投递 WM_EVENT_BACK(wid) 至窗属主事件通道 | 500ms 无 BACK_ACK 且无表变更 → wmd 兜底 DESTROY(窗) → refocus 回桌面（表序最末可见窗，table.rs:234-236） |
| R3 | R2 的应用侧（appshell Nav 消费） | — | Nav 栈非空 = pop + BACK_ACK；根页 = 优雅退出（退出码 0 + 窗 DESTROY + BACK_ACK，规范 §4.1 GUI 退出回桌面）；输入焦点环在焦 = 先清环 + 撤 ime_wanted（SET 新 mask 位）+ BACK_ACK（不退出，软键盘先收链支点） | 同 R2 帽内完成 |
| R4 | 系统手势 v2 | 同 R1/R2 | 本波不实现——gui-inputd 手势面挂账波 5 | — |

wmd 配套立法（全部 add-only）：wm 客户端事件通道——WM_CREATE 应答随行 gift 通道端，表项记属主（CREATE 建联、DESTROY 关联关闭；现表项无属主 table.rs:251-283）；帧型 WM_EVENT_BACK(window_id) + WM_EVENT_TABLE(version)（表变更广播；通知尽力而为——非阻塞 send 满即丢，真值恒经 TABLE_GET 快照，丢弃至多迟一拍）；BACK_ACK 1B 回程帧解除兜底；500ms 单槽软定时进 serve 循环（零新增线程）；无事件通道的旧式客户端目标窗 = 直接 DESTROY（返回语义仍正确）。

## 4. 合成 v1 时序（文本）

surface_id 激活：SUBMIT.surface_id = wmd window_id（wire 零改动，现被忽略位 guest.rs:503 激活消费）；surface_id=0 = 兼容档按 APP 层全屏处理（未窗化提交面，带重放仍生效——旧客户端状态栏也常驻）。guifbd 增 wm 客户端面：WM_EVENT_TABLE 通知触发 TABLE_GET 拉表快照（窗口→layer/vis/eff 几何），消费点前 ver 校验；禁止在 SUBMIT 处理内同步 RPC wmd——wmd 中继阻塞等应答（relay.rs:64-117）+ guifbd 阻塞等表 = 死锁对（RELAY_CAP_NS 到点即 trap），故通知驱动 + 异步拉取。

```text
launcher(SYS×2)   应用(APP)    softimed(SVC)   wmd                 guifbd
   |                 |              |            |                     |
   |--SUBMIT sid=1(顶带 damage)-----relay--------->| [SYS路] blit→fb + 写顶带缓存
   |--SUBMIT sid=2(底带 damage)-----relay--------->| [SYS路] blit→fb + 写底带缓存
   |                 |--CREATE(AVOID_SYS)--------->| 表变→WM_EVENT_TABLE(ver) 广播
   |                 |--SUBMIT sid=5(内容 rect)--relay---------------->|
   |                                               | [APP路] 查快照：sid=5 layer=APP
   |                                               |  1 damage rect 行弹 vmo_read→blit→fb（现路径）
   |                                               |  2 带重放：for 带 in [SVC,SYS]（vis=true）：
   |                                               |     for r in damage∩带.rect：带缓存→fb
   |                 |<-FRAME_CALLBACK latch（token 环 8 槽现路径不变）---|
   |   （softimed 显焦）|--SUBMIT sid=9(底带)----relay------------------>| [SVC路] blit→fb + 写 SERVICE 带缓存
```

约束：带缓存静态定容（带数帽 + 带高帽常量，启动门执法——服务状态全静态定容 guest.rs:53-55 与零唤醒不变量 guest.rs:55-56 纪律）；带 rect = 该 surface 窗 eff 几何（快照），缓存像素 = SYSTEM/SERVICE 路 blit 时双写；重放只写 APP damage ∩ 带 rect（条区局部重绘，7fd1709c 判例）；vis=false 窗的 SUBMIT 帧丢弃；SERVICE>SYSTEM>APP 定序与 wmd 层序一致（WM_LAYER_SERVICE=2 波 2 冻结，hit_test layer 降序）；vgpu 后端接缝 = CPU blit 落 fb 后、抽样前（guest.rs:669-675）缝内定序，ramfb 相 None 恒短路零漂移红线不动。

## 5. softimed v1 键位表与显隐协议

键位（QWERTY-lite ASCII 两档，命中区 ≥44px 规范 §3.2，文案限 ASCII）：

```text
字母档：   q w e r t y u i o p
           a s d f g h j k l
           z x c v b n m  BKSP
           SYM         SPACE        DOT  ENTER
数字符号档：1 2 3 4 5 6 7 8 9 0
           - / : ; ( ) $ & @ "
           . , ? ! '   BKSP
           ABC         SPACE        DOT  ENTER
```

按键帧：可见字符 → TextEvent（len=1）；SPACE → TextEvent(" ")；BKSP/ENTER → KeyEvent 控制块码（BACKSPACE/ENTER 波 2 冻结认领值）；经 OP_INPUT_INJECT（0x22，恰 1 帧 ≤48B，Pointer 变体双侧拒）→ gui-inputd → 焦点窗输入 poll 同一事件面。修饰键（shift/长按）v1 不做，挂账。

显隐协议（ime_wanted 位）：guiproto add-only——WM_CREATE_F_IME_WANTED 旗 + 快照位 WM_WIN_F_IME_WANTED + WM_SET 新 mask 位（appshell 随 berry-ui 焦点环置/清，R3 先收键盘链的支点）；softimed 订阅 WM_EVENT_TABLE → TABLE_GET：焦点窗 ime_wanted=1 且软键盘未显 → SET_F_VIS SHOW（SERVICE 底窗，几何约 360vp×260vp 起档）；否则 HIDE。SERVICE 不参与 AVOID_SYS 挖坑（覆盖语义——软键盘暂态压顶，避让反致 APP 窗反复重排；波 2 留白的 SERVICE 避让策略在此裁决）。

进程形态：新 bin user/bins/softimed（rootfs 相 svcmgr 预拉，tools/rootfs-manifest.toml 增 entry）；gift = wmd 通道 + wmd 事件通道 + gui-inputd 注入端通道（授权 = 持通道能力即权限，微内核纪律）；console=false（系统件串口纪律，规范 §11.4）。

## 9. 风险与边界
