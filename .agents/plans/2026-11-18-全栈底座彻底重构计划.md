# BerryOS 全栈底座彻底重构实施计划（六波二十刀）

Type: plan
Status: active
Updated: 2026-11-18

一句话说明：将 [微内核与全栈底座彻底重构规格](2026-11-18-微内核与全栈底座彻底重构规格.md) 拆解为拓扑正序、每刀独立可编译可验证可回滚的六大波次共二十把原子手术刀，彻底清偿 [全栈架构与代码缺陷深研](../research/2026-11-18-全栈架构与代码缺陷深研.md) 检出的全部 53 项缺陷。

## 背景

用户确立最高工程准则：「规范先行、方案先行，不打补丁、不计代价，直接做成最彻底、最优秀、最优雅的终态架构」（决策因果见 [全栈底座彻底重构架构裁决](../notes/proposed/2026-11-18-全栈底座彻底重构架构裁决.md)）。为避免 FreeBSD 5.0 式大爆炸失控，本计划严格按底层依赖顺序推进：**先正硬件寄存器与异常锁地基（第一波）→ 再立内核地址空间与无环通道确定性生命周期（第二波）→ 再上 `Port` 多路聚合与同步 `Call/Reply` 根能力体系（第三波）→ 再换正统加权 EEVDF 与完备 CBS/EDF 调度内核（第四波）→ 再拆用户态三权分立与每客会话服务（第五波）→ 最后完成 PIE ELF 装载器与 `berry-libc` 全量加固（第六波）**。每一刀均遵循 `*face` 纯判定律宿主机测试先行纪律。

## 步骤

### 第一波：ARMv8-A 硬件契约、异常中断守恒与物理 DMA 止血（F0 族 · 4 刀）

1. **F0-1 `DCZID_EL0` 零化、PoU 指令缓存同步与用户入口寄存器洁净刀**
   - **动作**：修正 [vmo.rs](../../kernel/src/vmo.rs) `zero_page_4k` 改读 `DCZID_EL0`（校验 `DZP == 0` 与 `4 << BS` 步长）；在 [mmu.rs](../../arch/aarch64/src/mmu.rs) 新增 `sync_icache_pou(kva, len)`（按 `CTR_EL0` 逐行 `dc cvau` + `dsb ish` + `ic ivau` + `dsb ish`）；改造 [syscall.rs](../../kernel/src/syscall.rs) `pager_supply_one` 与 `vmar_map` 为「先写满物理页并刷 PoU 缓存，最后写有效 PTE」；在 [task.rs](../../arch/aarch64/src/task.rs) `user_entry_trampoline` 清零 `x2..x18, x29, x30`。
   - **可观察验证**：`just test-host` 全绿；QEMU TCG 与 Apple Silicon HVF 双档启动零未定义指令、零取指异常；ktest 新增用户态入口寄存器全零自检与跨核新写代码页立即执行断言通过。

2. **F0-2 分代位图钉死 ASID 分配器与 `TCR_EL1.AS` / W^X / 直映 `PXN` 硬件隔离刀**
   - **动作**：新建纯逻辑 crate `asidface` 实现 `(gen << 16) | hw_asid` 分代位图与在跑核活跃号钉死算法并配齐宿主机穷举测试；[mmu.rs](../../arch/aarch64/src/mmu.rs) 按 `ID_AA64MMFR0_EL1.ASIDBits` 动态置 `TCR_EL1.AS`（bit 36），统一 `asid_shift = 48`，在 `msr contextidr_el1` 后补齐 `isb`；[paging.rs](../../arch/aarch64/src/paging.rs) 落地四态页权限（`UserRo/UserRw/UserRx` 强制 W^X）并将 `TTBR1` 非内核代码段全置 `PXN = 1`。
   - **可观察验证**：`cargo test -p berry-asidface` 覆盖 8 位/16 位千轮回绕与双核钉死零撞号；QEMU 双核连续拉起 `> 600` 进程跨 8 位与 16 位边界零 TLB 串表；ktest 验证写只读页、执行数据页与 EL1 跳直映页均精确触发权限异常。

3. **F0-3 异常 `IrqSaveGuard`、无死锁 `tlbshoot` 内联代消费与独立 `ALLOC_LOCK` 刀**
   - **动作**：[kern_lock.rs](../../arch/aarch64/src/kern_lock.rs) 引入保存恢复 `DAIF` 的 `IrqSaveGuard` 替换 [dpg.rs](../../kernel/src/dpg.rs) `probe_el0` 与 [vmar.rs](../../kernel/src/vmar.rs) `Vmar::Drop` 中的裸取放锁，保证异常出口全程 `PSTATE.I = 1`；[tlbshoot.rs](../../arch/aarch64/src/tlbshoot.rs) 在 `wait_pending` 自旋环内轮询并当场消费本核收到的 shootdown 请求，同时补齐 ZFOD 返回前 `sched_exit_check()`；将 `Buddy` 与 `SlabHeap` 收归独立第 5 层 `ALLOC_LOCK`，以闭包 `mm::with_frames` 取代裸 `&'static mut` 返回。
   - **可观察验证**：开启 `--features lockdep` 跑双核 16 线程并发 `map/unmap/protect` + 按需缺页风暴压测 10 分钟，零 `tlbshoot` 超时 Panic、零 `ELR/SPSR` 踩踏、零 lockdep 违例。

4. **F0-4 `vnet` 物理连续安全 DMA 布局与驱动复位防线刀**
   - **动作**：支持 `VMO_OPT_CONTIGUOUS | VMO_OPT_PINNED` 物理连续页分配与 `vmo_cache_op` 缓存维护原语；修正 [vnet](../../drivers/bins/vnet/src/main.rs) RX/TX 缓冲页几何使全部 `RX_BUFS × 1600B` 严格落在已分配连续物理页界内（根除越界写穿相邻物理页与 `TX_BUF_PAGE` 互踩）；为 MMIO 驱动退出路径补齐内核级 VirtIO `STATUS = 0` 自动复位。
   - **可观察验证**：客机多轮大包 TCP burst 吞吐与并发连接压测 100% 稳定收发，物理内存金丝雀零污损，强杀 `vnet`/`vblk` 后零异步 DMA 写穿。

### 第二波：地址空间两阶段确定性销毁与无环通道生命周期重构（F1 族 · 3 刀）

5. **F1-1 `AddressSpace` 与层级 `Vmar` 区间树解耦刀**
   - **动作**：新建 `vmarface` 纯区间树 crate（支持精确与子区间 `map/unmap/protect` 及子 `Vmar` 管辖界回收）；在 [vmar.rs](../../kernel/src/vmar.rs) 将页表根 `l1_pa`、`atomic_asid`、每空间 `pt_lock` 与页表帧账本抽入 `AddressSpace`，令根/子 `Vmar` 共享 `Arc<AddressSpace>`，调页根表改按 `AddressSpace` 登记（修复 `DEMAND_ROOTS` `Acquire/Release` 内存序与子 `Vmar` `OwnerConflict`）。
   - **可观察验证**：`cargo test -p berry-vmarface` 全绿；ktest 验证父子 `Vmar` 混合映射/按需调页与子 `Vmar` 关闭后父区间重新映射 100% 成功。

6. **F1-2 进程退出两阶段自动拆页表、页表帧全回收与废除 `leak = true` 刀**
   - **动作**：在 [process.rs](../../kernel/src/process.rs) 与 [handle.rs](../../kernel/src/handle.rs) 落地「末线程退场先调 `aspace.teardown()` 清叶 + 单次跨核刷 TLB + 全量 `untrack_map` + 归还 L3/L2/L1 页表帧与 ASID，再调 `ht.drain()`」两阶段销毁；彻底删除 `HandleTable::drain()` 的 `leak = true` 分支；在 `sys_process_create` 触顶 `PROCESS_MAX` 时内联排水 `DRAINQ` 消除忙核假 `-ENOMEM`；简化 [berry-exec](../../user/berry-exec/src/lib.rs) `ChildHandles::reap()` 卸除父侧手工逐窗 `unmap` 负担。
   - **可观察验证**：后台双核跑满计算死循环的同时，前台连续派生并退出 `2000` 个分配了 `berry-mmap` 动态堆与 `pthread` 栈的子进程，全程零 `-ENOMEM`，跑完后 `FrameAllocator` 空闲物理页数与起跑基线严格相等（0 页泄漏）。

7. **F1-3 无环 `ChannelShared`、`Message::Drop` 在途句柄回收与 `SIGNAL_PEER_CLOSED` 刀**
   - **动作**：重构 [channel.rs](../../kernel/src/channel.rs) 为共享内部体 `ChannelShared` + 双端开闭计数 `open_ends: [AtomicU32; 2]`，彻底移除 `ChannelEnd::pair` 的双向 `ObjRef::retain` 自引用环；为 `Message` 补齐 `Drop` 释放未读在途句柄；任一端归零立即置对端 `SIGNAL_PEER_CLOSED`（`1 << 4`）并唤醒全部等待者；补齐 [syscall.rs](../../kernel/src/syscall.rs) 算术边界溢出检查。
   - **可观察验证**：恶意测试循环「建通道 → 塞满 128MiB VMO 句柄 → 关双端」1000 次后内核堆与物理帧零泄漏；服务端强杀崩溃后，阻塞在 `object_wait_one(ch, READABLE | PEER_CLOSED)` 的客户端在 1ms 内立即被唤醒并获知 `PEER_CLOSED`。

### 第三波：根能力双树（`Job` + `Resource`）、一等 `Port`、同步 `Call/Reply` 与独立 `Pager`（F2 族 · 4 刀）

8. **F2-1 根能力 `Job` 树与细分 `Resource` 门控收口刀**
   - **动作**：新建 `jobface` 宿主机可测配额与层级树 crate；内核落地 `ObjType::Job`（层级进程/内存/通道/Deadline 预算、`intent` 天花板、`job_kill` 原子子树清剿）与 `ObjType::Resource`（`Power`、`Policy`、`Telemetry`、`Mmio`、`Irq`、`Bti`）；升级 [abi.toml](../../tools/abi.toml) 至 `BERRY_PLATFORM_LEVEL = 2`，强制 `process_create`、`power_off`、`policy_bind`、`telemetry_open`、`cbox_drain` 校验对应根能力句柄，并将 `policy_bind(STATUS)` 出参改为不透明 `koid`。
   - **可观察验证**：全套无特权沙箱越权攻击用例（自建无父 Job 进程、递归进程炸弹、自铸句柄刷 `policy_bind`、裸调关机与抽干 `klog`/`cbox`）100% 被内核拒绝（`-EBADF` / `-EACCES`），`just abi-check` 四面单源一致。

9. **F2-2 每对象侵入式 `ObserverList` 与一等 `Port` 多路事件聚合刀（废除 `WAIT_ANY`）**
   - **动作**：新建 `portface` 纯状态机 crate；为所有可等待内核对象内嵌侵入式 `ObserverList`；重写 `object_wait_many` 挂栈上定长观察节点并**彻底删除全局 `WAIT_ANY` 哨兵**；新增 `port_create`、`object_wait_async`、`port_wait` 原语实现零分配 O(1) 多路包投递。
   - **可观察验证**：20 个常驻服务阻塞于 `Port` 与 `wait_many` 时，点对点 `channel_send` fastpath 命中率实测 `> 99%`、零无关服务误唤醒；单 `Port` 绑定 512 个通道并发收发零丢包。

10. **F2-3 同步 `channel_call` / `channel_reply`、跨核多跳精确 PI 树与每任务计费刀**
    - **动作**：重构 `piface` 支持跨双核有向阻塞树（`Client.blocked_on -> Server.serving_reply`）；新增 `channel_call` 与一次性 `ReplyToken` `channel_reply`；将代工计费状态从每核静态数组迁入 `Task::serving_domain` 仅统计真实在核运行周期，并在 `channel_reply` 瞬间立即回落 PI 优先级与借入 `intent`。
    - **可观察验证**：双核三跳链 `RT/High-Client (CPU0) -> Mid-Server (Port, CPU1) -> Storage-Driver (Port, CPU0)` 在满载中优先级干扰任务下，客户端往返尾延迟严格受限于纯服务计算时长，应答后服务端优先级当拍归零，抢占穿插任务零串账。

11. **F2-4 每 VMO 独立 `Pager` 对象与缺页隔离刀**
    - **动作**：新增 `ObjType::Pager`（`pager_create(port)`、`pager_create_vmo(pager, key, ...)`），将缺页挂起状态迁入线程自身 TCB 并向绑定 `Port` 投递 `PagerPacket`，退役全局共享 32 槽 `EREQ` 与盲目全对象标 `zfod` 逻辑（改为区间级显式匿名零页 vs Pager 文件页）。
    - **可观察验证**：非特权进程自建空转 `Pager` 触发 64 线程死缺页，系统 `rootpager` 与其他应用按需调页 100% 零阻塞零受扰。

### 第四波：五层正交调度器、真加权 EEVDF、完备 CBS/EDF 与金丝雀护栏（F3 族 · 4 刀）

12. **F3-1 锁位与抑制位物理分离、同步跨核冻结屏障与四槽 RAII 策略快照刀**
    - **动作**：拆分 `Task::held_locks`（纯锁位）与 `Task::inhibit_flags: AtomicU8`（冻结/限流位）；为 `0x3E process_suspend`、`0x03 handle_replace` 与退出自动解冻补齐 `SQ -> RQ0 -> RQ1` 全序锁及对核 `Running` 线程同步切出回执屏障；将 [policy.rs](../../sched/src/policy.rs) 升为 `4` 槽 + RAII `PolicyReadGuard`（析构清 `HAZARD`）并给 `unbind()` 补 `POLICY_LOCK`。
    - **可观察验证**：双核并发执行冻结/解冻、带限流与 10 万次背靠背 `policy_bind` 换表，零 `svc_window` 断言 Panic、零三槽耗尽 Panic，`process_suspend` 返回后被冻进程在对核零指令逃逸。

13. **F3-2 真加权 EEVDF $(w_i, r_i)$ 双旋钮、睡眠滞后衰减与跨核零偏置迁移刀**
    - **动作**：新建 `eevdf` 纯数学 crate（宿主机十万随机序列验证加权虚拟时间 $V(t)$、$\sum w_i \text{lag}_i = 0$ 守恒、睡眠指数衰减与跨核 $v' = V_{\text{dst}} - \ell_i / w_i$ 归一化）；在 [sched/src/](../../sched/src/) 彻底剥离 AI `±64` 权重与严格抢占层，接通 `IntentProfile` 驱动 $(w_i, r_i)$，将未授权 `0x00 UNSPECIFIED` 归一为 `UTILITY`，并修复 `yield_slice_return` 同步重算 `vdeadline`。
    - **可观察验证**：`cargo test -p berry-eevdf` 守恒律全绿；双核满载下 `LC + AI(+64)` 与 `BACKGROUND + AI(-64)` 混跑 30 分钟，后台任务稳定获得正比例带宽（**零饥饿**），跨核偷取前后份额与尾延迟平滑无跳变。

14. **F3-3 完备 CBS/EDF 实时类、唤醒到达律、Tickless 硬件重充源与 `Job` 准入账刀**
    - **动作**：重写 `sliceface` / `cbsface` 实现 CBS 唤醒到达不等式校验与追赶式周期重充，确保 `Deadline` 类纯按物理绝对截止期 EDF 排序；在 `Runqueue` 维护 `min_throttled_dl_vct` 接入 `nearest_deadline()` 唤醒 Tickless 深睡核；将 `DL_TOTAL_UTIL_Q12` 升级为创建预扣、改参差额结算、退出必退的精确账本；重标定宏观后台带 CBS `(quota, period)`，修正「先拆账 `consume`、后原子翻期」顺序并开启 Idle Loan。
    - **可观察验证**：孤立 Deadline 线程在单核/双核深睡 `WFI` 下跑 1000 周期零失醒；睡眠 100ms 唤醒后严格按单期 `budget` 运行零突发霸核；反复创建退出 500 个 Deadline 线程后系统已用带宽精确归 `0`。

15. **F3-4 收益驱动金丝雀策略评估、内核看门狗回滚与 `berry-power` / `berry-thermal` 闭环接线刀**
    - **动作**：新建 `canaryface` 取代「`divergence < 0.1` 自动转正」旧律，绑定 `CpuHdr` 尾延迟退化率、Deadline 零违约与饥饿上限判定晋升，并实装策略表 `ttl_ns` 内核超时自动回滚；打通 [berry-power](../../user/bins/berry-power/src/main.rs) 与 [berry-thermal](../../user/bins/berry-thermal/src/main.rs) 基于 `Port` 定时/事件驱动的常驻闭环（支持大小核多域 EM 表与一次平滑滤波）。
    - **可观察验证**：向内核注入故意劣化交互任务延迟的候选表，1 个金丝雀窗口内自动触发回滚；杀掉 `berry-power` 进程后超时看门狗自动回退默认启发式且服务由 `rootmgr` 自动拉起恢复。

### 第五波：用户态三权分立、每客户端能力会话与中断驱动模型（F4 族 · 3 刀）

16. **F4-1 `ProcessArgs v2` 启动协议与 `rootmgr` / `devmgr` / `appd` 三进程拆分刀**
    - **动作**：落地 32 槽类型化 `ProcessArgs v2` 启动句柄表；将 8571 行 [svcmgr](../../user/bins/svcmgr/src/main.rs) 拆解为精简不死根监督器 `rootmgr`（含 `/svc` 路由与服务崩溃重拉）、硬件资源与中断管家 `devmgr`（单设备独立 4KiB MMIO 窗 + GIC SPI `Interrupt` 转发，让 `vblk`/`vnet`/`gui-inputd` 彻底告别 1ms 轮询）与应用生命周期管家 `appd`（强制验签阻断 + 真实桌面应用接入 AM 五级内存压力回收闭环），全量清除业务路径 `trap()`。
    - **可观察验证**：篡改 `.bap` 或剥离 `.sig` 100% 拒载；空闲态 `vblk`/`vnet` 零定时器轮询唤醒；注入内存压力后后台真实 GUI 应用自动完成冻结与墓碑回收并释放物理页；强杀 `fsmgr` 或 `vnet` 后 `rootmgr` 自动重启并恢复服务。

17. **F4-2 `fsmgr` 每客户端独立会话、`$appdata` 结构化沙箱与每文件缓存刀**
    - **动作**：改造 [fsmgr](../../user/bins/fsmgr/src/main.rs) 与 [berry-fsclient](../../user/berry-fsclient/src/rpc.rs) 为基于 `Port` + `channel_call` 的每客户端独立会话通道与服务端打开文件句柄（彻底废弃全局共享 `FS_A` 与单槽 `staging`）；实现会话根 `root_node` 锁定（`..` 不越根的真 `$appdata` 能力沙箱）；修复 [berry-fatfs](../../user/berry-fatfs/src/lib.rs) 目录位掩码判定并补齐原子 `RENAME` 与 `UNLINK`。
    - **可观察验证**：8 个应用进程并发混合读写各自 `$appdata` 与公共文件 1000 轮，零串包、零会话毒化、零半成品覆写，沙箱应用尝试访问 `../` 或系统配置 100% 返 `-EACCES` / `-ENOENT`。

18. **F4-3 `gui-wmd` 每客会话鉴权、`guifbd` 只读共享帧面与多会话异步 `vnet` 刀**
    - **动作**：`gui-wmd` 迁入 `Port` 多路会话并强制校验窗口属主与 `WM_LAYER_SYSTEM` 能力；表面共享 VMO 在合成器侧以 `UserRo` 只读映射防止合成器误写或跨窗越界；`vnet` 升级为基于 `Port` 的多客户端并发 Socket 会话表（解除单 `session-0` 与仅限网关 IP 限制）。
    - **可观察验证**：普通 GUI 应用伪造指令销毁他窗或建系统层窗口 100% 拒 `-EACCES`；20 窗口并发订阅零句柄截断；4 个网络客户端并发建立多路 TCP 连接全通。
