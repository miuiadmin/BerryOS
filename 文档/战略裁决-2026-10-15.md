## 3. 守住不改（防过度反应）

以下现行决策被 21 份报告+AIOS 调研证据直接支持，任何「改路线」不得波及：① P0→P8 串行主干+小步提交+每阶段 QEMU 可观察里程碑——文档组判定这是「健康主干，修改应集中在顺序与关卡设计而非推翻」（对比 FreeBSD 5.0/Copland 死法）。② Zircon 务实派+纯能力 handle+VMO/用户态 pager+channel/通知/共享内存三件套+~26 个 object_* 合并——接口面小而稳被 seL4(~10 调用)/Redox scheme/FreeRTOS queue 反复验证，LiteOS-A 203/RT-Smart 233 是反面账本（00/03/11号）。③ 机制在内核、策略可插拔、策略用户态+内核兜底——AIOS 结论2：生产证据最密的 ghOSt/sched_ext/ADPF/Thread Director 恰是这条线。④ AI 慢/快循环切分+§11「AI 不拖 v1」范围纪律——行业正收敛到同构形态（结论3），本裁决只做机械化加固（负面 ADR+滑移出口），不放松也不加重。⑤ NO_HZ day-one、绝不倒退回补偿式 tickless——BerryOS 机制上已优于 RT-Thread 睡前停 tick 醒来补账（00/01号）。⑥ 全 Rust+C-ABI 边界+unsafe 收敛四处豁免——zCore 实测 deny(unsafe_code) 可行（11号），这是单人买得起的 seL4 替代品（15号）。⑦ v1 无 fork、不跑 Linux 二进制——维持；仅按 S8 补预写反转触发器（触发时只走用户态服务/VM，永不做内核 syscall 翻译层，NT 六连败为否决依据）。⑧ ARM64 单架构守到 G3 之后——NT 四架构税/NetBSD 53 架构摊薄（13/14/18号）。⑨ v1 单核基线——S6 只是修正「双线并行」的失实表述并补 SMP 锚点，基线实质不变。⑩ G0-G5 既有关卡定义一字不改，只增补 G1.5/G-eco/G-法务三个新门。⑪ 微内核五原则与「塞进内核是反模式」——RT-Smart 全局命名/QNX procnto/Zephyr 270 CVE 三重反面（00/01/09号）。⑫ Phase 2a 已落地成果（调度/tickless/抢占）不因任何新条目返工——新条目全部是增量埋桩或文档级，不动已验收代码。

## 4. 怎样强大、不出错、站在未来

怎样强大：机制在内核 O(1)、智慧在用户态慢循环——这条线被 ghOSt/sched_ext/ADPF/Thread Director 生产验证（AIOS 结论2），BerryOS 加 capacity(0..1023) 三端统一与能力门控即成独占生态位（结论5：零先例=独占位也=独担风险）；强度来自「接口面小而稳」（~26 个 object_*、四操作调度接口，00/11号反复验证）而非机制堆叠，创新预算只投省电与调度策略外移两个 40 年谱系空白格，其余机制零创新照抄幸存者组合（15§10.5）。怎样不出错：三层防御——关卡覆盖信任边界而不只是并发（新增 G1.5 隔离关+G-eco 生态关，00号：最安全攸关的属性最易被系统性遗漏）；主干随时可发布+渐进小步+激进配置常驻 soak 后逐块转正（PREEMPT_RT 模板，12/13/17号五十年收敛的最强存活判别式）；表示法在第一个消费者出现前定死（capacity/周期数/时长型 hint，03号：early wrong=late double pay）。Rust 安全外壳+小 unsafe 核是单人买得起的第三代正确性（15号），unsafe 计数进关卡 checklist（11号 zCore 实测可行）。怎样站在未来：ABI 即产品——双面 ABI（调度注入接口×agent 负载留位）按「可脱离本内核独立成立」标准写，语义对照 sched_ext/ghOSt/ADPF，草案早公开、冻结等消费者；单人无金主项目的最长寿命形态是 Plan 9 式理念转世（可引用、可移植的干净表达），不是装机量（18号）。每条赌注配三件套：day-one 代理指标+P4 最小 demo+预写推翻触发器（16/18号：零信号支柱=零存在感，无退出通道的赌注=WinFS）。对外表述与兑付状态严格一致：可以说「无人区」不可说「领先」，demo 没跑通前 ABI 只叫草案（03号 OpenHarmony 信任税的反面）。最终图景：BerryOS 的强大=被引用的机制与 ABI，不出错=关卡化+渐进+诚实的制度，未来=在 agentic 慢循环行业收敛（AIOS 结论3：SchedCP/LumOS/AKTS 与 BerryOS 逐点同构）关闭窗口前，让这个形态第一次在内核里有一等表达——用最小赌注（字段、空环、脚本 demo）占住最大叙事，主线一分钟不为它停。

## 5. 明确不做（负面清单）

①不做内核内 ML 推理、任何 AI 逻辑不进 pick_next/切换快路径（零生产先例+AIOS 结论4 反例；QNX APS 同款死法）。②不在 P3 冻结 AI ABI 为终版合同——草案 v0 可公开，冻结标签等 P4 公开+首个外部消费者（17号 Linux 判例）。③不为 agent 负载在 MVP 前实现任何机制，只留 schema 位（NT 不为想象客户付端口税，14号）。④不让任何主线里程碑等待 AI 服务成熟度：AI demo 滑移自动顺延、不重开 P4（WinFS 死法）；同时不许 AI 退化为旁路调参工具（A-Tune 死法）——两种死法同时设防。⑤不用自写程序（含 AI demo）顶替 G-eco 的第三方程序验收。⑥不在 TCG 计时 2x/无 PMU 的幻影信号上训练调参或宣布胜利，时序断言不用裸 TCG 承载。⑦不自研全量 libc、不写真机驱动（P8 前设备面锁死 virtio）、不写第二架构 HAL、不引入 Kconfig/双形态分叉（RT_USING_SMART 式侵入是反面，01号）。⑧不做一次性大爆炸切换：高半翻转拆步、G4 全抢占走 PREEMPT_RT 式常驻 soak 逐块转正（12/13号）。⑨不砍 AI 支柱也不加重它——它是唯一差异化支柱（砍掉=又一个 Rust 微内核，02/00号），但兑现形态优先是可引用的干净机制表达而非服务成熟度。⑩不给 handle 表/ABI 事后补 generation 与配额字段——P3 定型时一次做对（事后补=改 ABI，11号）。⑪不让「双线并行」表述继续掩盖 SMP 无锚点的事实，也不因此提前开 SMP（单人并行开线=两条都断，Theseus 前车）。⑫不破「塞进内核是反模式」的任何例外——第一个例外就是下一个 procnto（00号）。

## 7. 附录：双视角主张原话（第一行生存学派 / 第二行未来学派）

BerryOS 不会死于内核写错——会死于没人给它写程序、差异点迟迟不验证、单人断档；主干的渐进+关卡+随时可跑已经站对了 50 年判别式的活路一侧，真正要做的是把「跑真程序、验差异化、仓库可用」三件事从路线图末尾提到前面，AI 坚守「最后一轨」不与主线绑死。
把「下一代计算形态」的赌注显式命名为 agent 时代 OS 基座——用一张双面 ABI（内核第一类 AI 调度接口 × agent 一等负载接口）吃下 2026 年正在收敛的 agentic 慢循环空白，赢法不是内核更快，而是让这个正在行业收敛的形态第一次在内核里有一等表达，并赶在窗口关闭前把它变成有 day-one 指标、有 P4 demo、可独立出版引用的公开资产。
