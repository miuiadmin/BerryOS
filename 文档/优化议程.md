## 1. IPC：练成拳头（人有我强）

**及格线**：fastpath <500 cycle 验收线 + 大数据走 VMO 句柄免拷 + PM 走共享环形缓冲（`IPC设计.md` / `调度器设计.md` 既有）。

| 动作 | 内容 | 验收 | 挂 |
|------|------|------|-----|
| **1.1 同核亲和** | 调度器知道 channel 拓扑，通话双方放同核/同簇，cache 热着传话——**Linux 调度器不知道 pipe 两端是一对，这是架构级信息差**。实现走策略层（capacity/EPP 框架加工 hint，wake_affine 类语义），机制零改动 | bench 中同核 vs 异核 ping-pong 差距 + 开启后改善 %；**不得打破公平带包络**（ADR #42 红线） | P5（PM 服务同期） |
| **1.2 批量消息** | 一次 syscall 收发 N 条，摊薄陷入内核的门钱；消息格式按 ABI §8.5 **add-only** 扩展 | 往返延迟/条随 N 的摊薄曲线 | P4 IPC 收口后 |
| **1.3 IRQ 句柄直通** | 中断以 handle 交付用户态驱动（Zircon interrupt object 同形），内核只路由不中转——能力模型原生支持 | 驱动收中断路径零内核拷贝 | P6 驱动框架 |
| **1.4 scoreboard** | `just bench` 进 CI：IPC ping-pong / 吞吐 / p99，同机 Linux pipe 对照表，遥测环采集、趋势线随 `just size` 同报 | **有公开数字才算「强」**——每 Phase 回归不倒退 | P4 末起 |

## 2. 生态：伺候 Rust 程序员（人有我强 + 人无我有）

**及格线**：G-eco 关（P4 硬验收，未修改的 ripgrep/hexyl 跑通）。

| 动作 | 内容 | 挂 |
|------|------|-----|
| 2.1 移植模板 | cargo generate 模板 + 移植指南（常见 crate 依赖面清单） | P4 末–P5 |
| **2.2 崩溃报告 AI 可读**（杀手锏） | 结构化 backtrace（JSON）+ 语义化错误（`BERRY_ERR_*` 已有语义层）+ 环境快照进遥测环——**报错直接喂 AI 可定位。别家崩溃报告写给人看，我们的写给 AI 看** | P5（libc / panic runtime 同期） |
| 2.3 target 官方化 | `aarch64-unknown-berry` 进 rustup 分发（redox 先例）；先决 = G-eco 稳定 + target spec 成熟。**不进承诺** | P6+ |
| 2.4 C 面 | POSIX 库收口后 musl 系 C 程序批量移植（12 号既有判断） | P5–P6 |

## 3. 驱动：数量回避，质量碾压（人无我有）

**及格线**：选驱动面最小的端（ADR #39）+ 借嵌入式 Rust 生态（寄存器定义 crate、embassy 式 HAL 模式，MIT）。

| 动作 | 内容 | 验收 | 挂 |
|------|------|------|-----|
| **3.1 热换不重启** | 驱动崩 → 监督重启（隔离机制 G1.5 已验）；OTA 场景**驱动升级不重启整机**——安卓/iOS 无此承诺 | kill 驱动服务，业务零中断或秒级恢复，遥测留痕 | P6 驱动服务化落地时 |
| **3.2 unsafe 配额进遥测** | 每驱动 unsafe 块数/位置进遥测环，AI 可审计安全面；编译期上限断言 | 新驱动 unsafe 数量趋势不升 | P6 |

## 4. 性能：不打的不追，打的全上 scoreboard（人有我强）

**及格线**：维度化宣称（12 号 §9——可赢：IPC 延迟/尾延迟/隔离/启动/空载零唤醒；明示放弃：服务器吞吐/GPU/驱动广度/GUI 通用性）。

| 动作 | 内容 | 验收 | 挂 |
|------|------|------|-----|
| 4.1 启动 <1s | 无 init 长链 + 服务依赖图并行拉起 | QEMU 计时起步；真机上电到表盘（P8 功耗计同场） | P5–P8 |
| 4.2 尾延迟 p99 | intent 分带 + tickless（ADR #42 机制）| bench 出 p50/p99/p99.9 表，每 Phase 回归 | P5 起 |
| 4.3 空载功耗 | 唤醒源最小化 + µA 级深睡 | **真机功耗计**（QEMU 测不了 µA，P8 既有里程碑） | P8 |
| 4.4 遥测出厂自带 | per-CPU 环 day-one（`可观测性设计.md` 既有）——Linux 后装 perf，我们出生自带，**迭代速度即竞争力** | 遥测环标记数随 smoke 断言 | P3 末起 |

## 5. AI 调度：独一份加码（人无我有）

**及格线**：注入面 + 带内限死 + 遥测入场券 + band/intent 不入 AI 动作空间（ADR #42）。

| 动作 | 内容 | 挂 |
|------|------|-----|
| **5.1 决策日志数据集化** | 调度决策（pick/intent/EPP/放置）结构化落遥测环，**可回放**——AI 测试友好化攒的家底，策略研究的地基 | 数据采集 P3 末（遥测环 instrumentation 即 3-4c 同期）起持续攒 |
| **5.2 trace 驱动调度模拟器** | 回放 trace 评估策略，不跑真机（A-Tune 教训：有数据才有策略）；实验轨道，kill criteria 按 `AI调度设计.md` | P6+，不进承诺 |
| 5.3 护栏不动摇 | 任何优化动作不得破 ADR #42 红线（公平默认、叠加永不替代、带外包络） | 恒定 |
