## §2 八刀各一段（做了什么 / 出口标记 / 最大实踩教训）

### A-1 RAM-fs 服务最小面（`FS ok n=2156`，rootfs 相第 11 标记）

- **做了什么**：`berry-fsproto` 纯函数协议 crate（严格串行 RPC：PUT/TRUNC/GET/LIST，
  ≤256B inline、192B 分片、NAME_MAX=48/FILE_SIZE_MAX=16KiB/FILE_COUNT_MAX=8 双端同值执法，
  host 18 测）+ `bins/fsmgr` RAM-fs 常驻服务（空队 wait 10s 帽超时重臂——交互 client
  长空闲合法）+ svcmgr 双 gift 拓扑（fs_b 随 env 块迁 fsmgr、fs_a dup 交 bsh——bsh 成
  fs_a 队列唯一读者防回复混流）+ bsh `>` 重定向/cat/ls 内建 + 自驱自验（64B 单片 +
  2156B 十二片 more 链对拍才打标记）。
- **最大实踩**：**标记子串混叠**——`FS ok` ⊂ 内核 boot 行 `ROOTFS ok src=`，`grep -qF`
  被启动行满足 = FS 门零鉴别力（DEMO ok ⊂ AIDEMO ok 同族坑第三例）；修 = 带参形态
  `FS ok n=`。连带修：encode 空 out 违 None 契约（「编不出就拒绝不截断」day-one 化）、
  **收侧超时会话毒化**（`FS_SESSION_OK`——迟到应答错配下一请求 = GET 静默错数据
  off-by-one 永不自愈，确定性失败优于无告警错数据）。
- 对抗审查 15 agents：5 confirmed 全修 / 6 refuted。

### A-2 MMIO 物理窗口 VMO + vprobe（`VIRTIO ok did=2 ven=0x554d4551 slot=31`，第 12）

- **做了什么**：`Vmo::create_mmio(pa_base, size)` boot-only 构造（pages 恒空 = Drop 零
  动作、commit/read/write 一律 NotSupported、Device-nGnRnE 映射、**size 页对齐执法**——
  静默取整会把相邻设备 PA 漏授 EL0）；窗口 = virtio-mmio 整窗 32 槽 × 0x200；svcmgr 表
  第 4 插 0x0001_0004 授能 + `SpawnSpec.mmio_vmo` 映固定高带 VA；vprobe 扫全 32 槽断言
  magic/ver==2/did 分类。
- **最大实踩**：**QEMU virt 按槽 31→0 倒序建 32 条 virtio-mmio 总线、首个 `-device` 落
  最高槽**——首版绑死 slot 0 即 FAIL（空槽 magic 对但 ver=1/did=0）；修 = 整窗扫槽，
  **绑死槽号 = 把 QEMU 总线排布焊进标记**。二踩：build-user 无 `set -e` 静默吞编译失败
  → mkcpio 打包陈旧产物四门假绿（D6「缺产物编译期炸响」只护了内核侧）——修 = `set -e`。
- 对抗审查 9 agents：3 confirmed 全修 / 2 refuted（MMIO 固定 VA Overlap 前置检等）。

### A-3 virtio-blk 真块设备（`VBLK ok cap=2048 slot=…`，第 13）

- **做了什么**：syscall 0x1B `vmo_get_phys`（ABI 扩号 29→30 在册；「几何非内容」need=0
  惯例；用户态 DMA 面 = 纯 VMO 机制零新对象变体）+ `berry-virtio` split-ring 纯函数
  crate（13 测）+ `bins/vblk` 驱动（modern v2 协商、DMA 双页 VMO 从不进任何地址空间——
  构造/收割全走 vmo_write/read staged 页 + get_phys 查后备；LBA0 印章 + LBA1 写读回
  双对拍）。
- **最大实踩（联调三 bug，各自入 Gotchas）**：①**TPIDR_EL0 每任务保存**——寄存器每 CPU
  一份不随任务切换，vblk 首次 TLS 访问在数秒设备 IO 后 = 拿别人 TLS 指针裸奔 D-abort
  （TaskContext +tpidr@104 + switch asm 存/取对）；②**常驻服务空闲超时重臂**——10s 帽
  到点自陷死改 -ETIMEDOUT 重臂（安静是合法态，守门权交发问方）；③**used ring poll 偏移**：
  poll 读了 flags 位（恒 0）非 idx（used_off+2），且诊断面用了正确 API——「诊断面与
  被测面同 API，差一个偏移的两次同一读必然自欺」，三节取证全证伪后破案。
- 对抗审查 10 agents：8 raw → 5 confirmed（去重 2）全修 / 1 refuted（§8.3 注记 errno
  对齐、门铃前 `dmb ish`、复位回读等）。

### A-4 vblk 服务化 + berry-blkproto（`BLKD ok n=512`，第 14）

- **做了什么**：`berry-blkproto`（严格串行 RPC：请求 9B/应答 1B/扇区定值 512 无 len
  字段——多扇区随 v2；编码器 None 契约 day-one，13 测）+ **数据面 = VMO 随行迁移**
  （client dup R|W 别名随请求 send → driver bounce-buffer → 每请求毕 close——「能力经
  消息交付」在数据面的第一用）+ vblk 常驻服务化（自验后不退出，client 错误一律
  ST_BAD/ST_RANGE 应答服务不死）+ svcmgr 消费自验（512B pattern 写 LBA5 → **读前把
  VMO 本体刷反值 0xA5** → 读回对拍——反值刷本体 = 假绿防线主位）。
- **最大实踩**：`vmo_commit` **整页粒度执法**（offset 与 len 都须页对齐，512B 扇区直接
  commit 被拒——create 取整是成文设计、commit 不取整直接拒，两者口径相反）；驱动 recv
  收口容量 4 收协议定值 1（恰按 1 收会让垃圾消息的 -EINVAL 误入链断 trap 杀服务）。
- 对抗审查 12 agents：8 confirmed 全修 / 0 refuted（serve() 别名回收撞 -EBUSY 分流降级
  勿 trap、0xA5 防线错位修正、恰满容量钉板等）。

### A-5 FAT 只读底座（`FAT ok n=5000`，第 15）

- **做了什么**：`工具链/mkfat.py` 确定性 FAT12 造盘器（无时刻输入、字段全定宽；保留区
  LBA0-15 与卷数据零交集；`--fixture` 产 host 共识基准 + `--check-fixture` 守卫挂
  test-host 前置）+ `berry-fatfs` 纯函数 crate（BPB 合法域/FAT12 紧包/目录项分类/
  name_to_fat11，11 测含四个 fixture 共识——python 造盘与 Rust 解析互不借码双绿即独立
  收敛）+ fsmgr `fat.rs` 只读层（eager 探测三验定位卷、GET 按簇界分片 + 单簇缓存、
  RPC 三态 RpcRes 含**收侧超时会话毒化**、overlay 语义：RAM 写通道 + FAT 只读底座、
  名字空间按构造隔离）+ vblk 先于 fsmgr 拉起（blk_a 经 env 块 gift[3] 交付）+ bsh 自驱
  自验（HELLO.TXT 28B + PATTERN.BIN 5000B 三面同源 pattern 对拍）。
- **最大实踩**：**跨实现共识测试的基准漂移面**——改 mkfat 忘重产 fixture，共识测试对
  陈旧基准照跑照绿（「双绿即独立收敛」退化成单实现自洽）；修 = `--check-fixture` 内存
  重产逐字节比对机器守卫（hexyl 宿主基准同族但那边只有注释纪律）。
- 对抗审查 10 agents：4 confirmed 全修 / 2 refuted（尾点别名留档 v2 扩名时收）。

### A-6 FAT 读写 fat:rw（`FATW ok n=3000`，第 16）

- **做了什么**：berry-fatfs 写基元（fat12_set 双项读改写/find_free_cluster 升序确定性
  分配/encode_file_entry，11→14 测，fixture 同时钉读写两面编码一致）+ fsmgr staging +
  commit 两段写（PUT 进 staging 不碰盘，TRUNC 触发八步序**任一步失败内存态不变**：
  old-chain collect → alloc-before-free → 数据扇区 → 旧链释放 → 双 FAT 镜像 → 根目录
  两遍 → **根扇区写盘读回对拍** → install 工作副本）+ bsh 面（8.3 大写名走 FAT 真落盘、
  小写名仍 RAM）+ smoke 第四跑 FAT 持久化相（不重造盘复用已写盘——mkfat 重产 = 持久化
  零验收；全 -drive 线 `cache.writeback=off` + DEADLINE_ROOTFS=240s）。
- **最大实踩（三节排障）**：FATW 首版「hang」实为**client 收侧帽结构性误杀**——TRUNC
  触发整链 commit = 一串串行扇区 RPC（TCG 下单次 ~0.8s × 13 次 > 10s 帽），bsh 超时打
  fs unreachable 时 fsmgr 仍在走完整 commit（**服务慢 ≠ 服务死**）；修 = 收侧帽按服务端
  worst 路径成本定值 90s + **分片 PUT 与 TRUNC 同帽**（跨名 PUT 隐式重跑整链 commit）。
  方法论：估算链路时长用 RPC 成本模型，别拿 syscall cycle 外推。
- 对抗审查 8 agents：3 confirmed 全修 / 1 refuted（LBA0 印章 dd 守卫对称性——触发前提
  被证伪）。

### A-7 virtio-net + ARP/ICMP（`NET ok ping=32 slot=30`，第 17）

- **做了什么**：`berry-netproto`（eth 14B/ARP 28B 变体 + padding 容忍/IPv4 RFC1071 校验
  和 + total_len 权威/ICMP echo，11 测）+ `bins/vnet`（按类扫槽认领唯一 net → modern
  v2 协商（NET_F_MAC + **NET_F_MRG_RXBUF**）→ 双队列 + rx 单描述符整收（12B 头+帧同
  缓冲，几何结论）→ ARP 解网关 MAC → ICMP 32B 往返逐字节对拍 → **exit 前 STATUS=0
  复位撤队列**）+ QEMU 接线 `-netdev user` SLIRP。
- **最大实踩（调试史三连修）**：①不协商 MRG_RXBUF = QEMU modern 路径仍按 12B 剥
  vnet_hdr → TX 帧斩头 2B SLIRP 静默丢（rx 永假超时是唯一死状）——排障方法论 =
  `-object filter-dump` 抓 pcap 看线上真值；②SLIRP 把 42B ARP 补零到 64B 最小线宽——
  **解析器长度权威在报文自身域**（hlen/plen、total_len），按恰长执法 = 每帧必拒；
  ③**退出不复位 = 设备 DMA 写已还帧**（SLIRP 周期性 IPv6 RA 无需 guest 发包即触发，
  交互 >6 分钟必踩、静默腐化无关进程）——vblk「退出不复位」refute 前提是被动设备无
  外部写者，**refute 前提不跨设备类转移**；修 = `reset_device`（写 0 + 回读 1s 帽）
  协商起点与退出终点共用。
- 对抗审查 12 agents：4 confirmed 全修 / 2 refuted（tx_send copy_from_slice 自重叠 UB、
  头注 padding 口径等）。

### A-8 DNS 服务化 + berry-netdproto（`DNS ok addr=127.0.0.1`，第 18）

- **做了什么**（A-7「网络服务化随 v2」的提前兑现，a/b/c/d 四小步）：**a** netproto 增
  encode_udp/parse_udp（伪头校验和）+ encode_dns_query_a（name 两遍验证）+
  parse_dns_a_reply（**id 精确匹配在纯函数层** + QR/opcode/TC/rcode/QDCOUNT 五检 +
  压缩指针等价认 + 跳 CNAME 取首个 A），11→17 测；netdproto（第 6 例，13→14 测）请求
  `[op][nlen][name]` 恰 2+len、应答 `[st][addr 4B]` 恰 5B、**「非 OK 恒全零 addr」烘焙线
  双侧执法**。**b** vnet 常驻 serve()：自验移 serve 前、此后不退出不 reap（表槽有界 =
  生命周期）；空闲 wait 10s 帽重臂；DNS 链 = DNS_ID 单调发号 + **id 与四元组双滤杂散**
  （SLIRP IPv6 RA/迟到帧不误配）；服务端整体帽 20s < client 60s（ST_TIMEOUT 先于
  client 超时到达）。**c** svcmgr `dns_selftest`：`"localhost"` → 127.0.0.1 对拍
  （SLIRP 虚拟 DNS 10.0.2.3 → 宿主 /etc/hosts，离线确定无外网依赖）；失败分诊
  `eco: dns rpc`（链路断）vs `eco: dns reply`（链路活答案错）；**超帽不重发**（v1 无
  请求序号，重发 = 重复操作）。**d** 对抗审查 6 confirmed 全修 / 1 refuted——
  `reply_wire_pinned` 应答黄金字节钉板（roundtrip 对「编码/解码被一致改字段序或 addr
  排序」的对称漂移不设防，钉板炸响）。
- **最大实踩**：无运行期缺陷（6 confirmed = 1 测试盲区 + 5 注释口径）；纪律面收获 =
  重试型 client 须自实现会话毒化或请求序号（树内 client 防线是超帽不重发）。
