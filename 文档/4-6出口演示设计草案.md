## 2. B 半管线设计（F1 字面链路的最小兑现）

F1 链路：**遥测环 → 脚本 advisor → 注入环 → 内核拒收越界并回退**。

### 2.1 四段形态

1. **遥测 dump（内核）**：demo 任务（或 watchdog 尾）把 SwitchRec/WAKE_RING 摘要打串口——复用既有读 API（`telemetry::total/span/last/wake_*`，watchdog 断言同款读法），**零新内核面**，只加打印路径。schema 走 F6 第一级（QEMU 可靠：vct/切换数/醒因/唤醒延迟——无 PMU/能耗，TCG 计时 2x 坑已载 CLAUDE.md，**时序断言一律 -icount 承载**（F5））。
2. **脚本 advisor（host，`工具链/advisor.py`）**：解析 smoke log 遥测行 → 按 policy 词汇表（3-4c 冻结四类：放置 hint / 包络内权重微调 / EPP 二值 / 频率走 PM 不入表）产出建议清单：**合法项**（如「任务 X weight +8 / EPP=efficiency」）+ **故意越界项**（weight +200 超 ±64 包络——演示拒收面的探针）。纯 Python、离线、确定性（同输入同输出，测试策略红线）。
3. **注入环（构建期）**：advisor 产出 `建议 JSON` → 生成内核侧静态注入表（demo 构建期 include，诚实标注「演示级注入通道」）。**v1 不立运行时注入 ABI**——表世代计数/事务化换表（F4 内容）随 ADR #21 实验轨道再立；AI ABI 只骑既有 channel/共享环（F11②），不为此开新 syscall。
4. **内核拒收越界并回退（执法点活证）**：policy 表既有包络执法 = `apply()` 的 `weight.clamp(-WEIGHT_MAX, WEIGHT_MAX)`（静默夹）——demo 需**可观测拒收**：越界项被夹后 trace 行（`policy: clamp w=200 -> 64` 同款）+ demo 任务断言夹后值；回退证明 = 越界项夹后行为与无注入等价（POLICY A/B 面的机器断言模式复用）。

### 2.2 F9 两不变量的最小兑现

- **不变量①（快路径开销与策略无关）**：FAST bench（4-4）双配置对比——无注入 vs 合法注入（越界项被拒后实际生效集 = 合法子集）各跑一轮，`rt_ticks` 差分在容差内断言。-icount 承载（F5），TCG 裸计时不作数。
- **不变量②（护栏单调收窄）**：拒收面即活证——越界项只能被夹/拒、不存在提权路径（`apply` 幂等自基线重算非累积，3-4c 已然）。demo 断言 + trace 双证。

### 2.3 现有基建贴合度（已核实）

| 需求 | 现状 | 缺口 |
